1. 什麼是 t-SNE？

1.1 基本概念

t-SNE (t-Distributed Stochastic Neighbor Embedding) 是一種非常強大的非線性降維技術， 特別擅長將高維度資料視覺化為 2D 或 3D 圖形。它由 Laurens van der Maaten 和 Geoffrey Hinton 在 2008 年提出。

t-SNE 的核心目標：在低維空間中保留高維資料的局部結構，使得原本相似的資料點在視覺化後仍然靠近。

1.2 主要特點

  • 非線性降維：可以捕捉複雜的非線性關係
  • 保留局部結構：相似的資料點會聚集在一起
  • 視覺化導向：主要用於資料探索和視覺化
  • 機率分布建模：基於相似度的機率分布

1.3 適用場景

應用領域 具體案例
影像分析 圖片資料集視覺化、特徵空間探索
生物資訊 基因表達分析、單細胞測序資料
自然語言處理 詞向量視覺化、文件聚類
遙感影像 多光譜資料分析、作物分類
機器學習 模型特徵視覺化、異常檢測

2. t-SNE 如何運作？

2.1 核心概念

t-SNE 的運作分為兩個主要步驟：

步驟 1：建立高維空間的機率分布

對於每個資料點，計算它與其他點的相似度，轉換為機率分布：

p(j|i) = exp(-||xi - xj||² / 2σi²) / Σk≠i exp(-||xi - xk||² / 2σi²)

其中 σi 由困惑度 (perplexity) 決定

步驟 2：建立低維空間的機率分布

在 2D/3D 空間中使用 t-分布（而非高斯分布）來計算相似度：

q(j|i) = (1 + ||yi - yj||²)-1 / Σk≠i (1 + ||yi - yk||²)-1

使用 t-分布可以避免「擁擠問題」(crowding problem)

步驟 3：最小化 KL 散度

調整低維空間的點位置，使兩個機率分布盡可能接近：

KL(P||Q) = Σi Σj pij log(pij / qij)

使用梯度下降法迭代優化

2.2 為什麼使用 t-分布？

t-分布具有重尾特性 (heavy tail)，可以：
  • 讓中等距離的點在低維空間分得更開
  • 避免不同群聚擠在一起（擁擠問題）
  • 更好地保留資料的群聚結構

3. 關鍵參數說明

3.1 困惑度 (Perplexity) ⭐ 最重要

困惑度是 t-SNE 最關鍵的參數！它控制著演算法對局部與全域結構的關注程度。

📊 困惑度的含義

困惑度可以理解為：

  • 概念上：每個點「有效的」鄰居數量
  • 技術上：高斯核寬度的平滑度量
  • 直觀理解：局部 vs 全域視角的平衡

🎯 如何選擇困惑度

資料規模 建議困惑度 說明
< 100 樣本 5 - 20 小資料集使用小困惑度
100 - 1,000 20 - 50 一般小型專案
1,000 - 10,000 30 - 100 中型資料集（最常見）
10,000 - 100,000 50 - 200 大型資料集
> 100,000 100 - 500 超大規模資料

⚖️ 困惑度大小的影響

小困惑度 (5-15)
  • ✅ 強調局部結構，細節清晰
  • ✅ 適合探索微小群聚
  • ❌ 可能忽略整體分布
  • ❌ 容易產生碎片化群聚
中等困惑度 (30-50) ⭐ 推薦
  • ✅ 平衡局部與全域
  • ✅ 適合大多數應用場景
  • ✅ scikit-learn 預設值 30
大困惑度 (100+)
  • ✅ 重視全域結構
  • ✅ 主要群聚清晰
  • ❌ 可能喪失局部細節
  • ❌ 計算成本增加
關鍵建議：不要只用一個困惑度！請測試多個值（如 5, 10, 30, 50, 100）並比較結果。

3.2 學習率 (Learning Rate)

基本設定

  • 預設值：200.0
  • 建議範圍：10 - 1000
  • 影響：優化速度與收斂品質

如何調整

  • 學習率過大 → 可能不收斂，形成「球狀」分布
  • 學習率過小 → 收斂過慢，陷入局部最優
  • 經驗法則：資料量大時可適度提高（如 500-1000）

3.3 迭代次數 (n_iter)

  • 預設值：1000
  • 最小建議：250（快速測試）
  • 推薦範圍：1000 - 5000
觀察 KL 散度的變化：如果仍在下降，增加迭代次數可改善結果

3.4 初始化方法 (init)

方法 說明 適用場景
'pca' ⭐ 使用 PCA 初始化 大多數情況（預設，推薦）
'random' 隨機初始化 探索不同視角
PCA 初始化通常能獲得更穩定且有意義的結果

3.5 隨機種子 (random_state)

強烈建議設定！確保結果可重現：

tsne = TSNE(random_state=42)

4. 如何有效使用 t-SNE

4.1 資料預處理

✅ 必須做的預處理

from sklearn.preprocessing import StandardScaler

# 1. 標準化（非常重要！）
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 2. 移除缺失值
X_clean = X.dropna()

# 3. 處理異常值
# 可使用 IQR 或 Z-score 方法
未標準化的資料會導致 t-SNE 結果被尺度大的特徵主導！

4.2 高維資料處理

建議先用 PCA 降維（特別是特徵數 > 50 時） 
from sklearn.decomposition import PCA

# 先降到 50 維
pca = PCA(n_components=50)
X_pca = pca.fit_transform(X_scaled)

# 再使用 t-SNE
tsne = TSNE(n_components=2, random_state=42)
X_tsne = tsne.fit_transform(X_pca)

好處：

  • 大幅減少計算時間
  • 降低雜訊影響
  • 結果通常更穩定

4.3 完整工作流程範例

推薦的標準流程
import numpy as np
import matplotlib.pyplot as plt
from sklearn.manifold import TSNE
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

# 1. 載入資料
X = your_data  # shape: (n_samples, n_features)
y = your_labels  # 用於著色

# 2. 資料清理與標準化
X_clean = X.dropna()
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X_clean)

# 3. 如果特徵數過多，先用 PCA
if X_scaled.shape[1] > 50:
    pca = PCA(n_components=50)
    X_scaled = pca.fit_transform(X_scaled)
    print(f'PCA 保留變異量: {pca.explained_variance_ratio_.sum():.2%}')

# 4. 測試多個困惑度
perplexities = [5, 10, 30, 50, 100]

fig, axes = plt.subplots(1, len(perplexities), figsize=(20, 4))

for idx, perp in enumerate(perplexities):
    # 執行 t-SNE
    tsne = TSNE(
        n_components=2,
        perplexity=perp,
        n_iter=1000,
        learning_rate=200,
        random_state=42,
        init='pca'
    )
    X_tsne = tsne.fit_transform(X_scaled)

    # 視覺化
    ax = axes[idx]
    scatter = ax.scatter(
        X_tsne[:, 0],
        X_tsne[:, 1],
        c=y,
        cmap='tab10',
        s=10,
        alpha=0.6
    )
    ax.set_title(f'Perplexity={perp}\nKL={tsne.kl_divergence_:.2f}')
    ax.set_xlabel('t-SNE 1')
    ax.set_ylabel('t-SNE 2')

plt.colorbar(scatter, ax=axes, label='類別')
plt.tight_layout()
plt.savefig('tsne_comparison.png', dpi=300, bbox_inches='tight')
plt.show()

print('完成！請比較不同困惑度的結果')

4.4 評估 t-SNE 結果

觀察重點

  1. KL 散度：越小越好（典型值 0.5-3.0）
  2. 群聚清晰度：同類別是否聚集？
  3. 穩定性：多次執行結果是否一致？
  4. 領域知識：結果是否符合預期？

量化評估（選用）

from sklearn.metrics import silhouette_score

# 計算輪廓係數
score = silhouette_score(X_tsne, y)
print(f'輪廓係數: {score:.3f}')  # 接近 1 表示群聚良好

5. 常見誤解與陷阱

❌ 誤解 1：t-SNE 揭示「真實」結構

正確理解：t-SNE 是探索性工具，不是真理。不同參數會產生不同視角，都可能有效。

❌ 誤解 2：群聚大小代表樣本數量

正確理解：t-SNE 不保留密度資訊。大群聚不一定代表樣本多，可能只是分布較鬆散。

❌ 誤解 3：群聚間距離有意義

正確理解：t-SNE 只保留局部結構。兩個遠離的群聚在高維空間可能很接近！

❌ 誤解 4：可以用 t-SNE 做預測

正確理解：t-SNE 只能 fit_transform，無法對新資料進行轉換。它不是特徵提取器。

❌ 誤解 5：一個困惑度足夠

正確理解：必須測試多個困惑度才能全面理解資料。單一視角可能遺漏重要結構。

5.1 t-SNE 無法做的事

錯誤用法 原因 正確做法
用於機器學習的特徵工程 無法轉換新資料 使用 PCA 或 Autoencoder
比較不同資料集的 KL 散度 KL 值不具跨資料可比性 各自獨立分析
解讀群聚間的精確距離 不保留全域距離 結合領域知識判斷
從視覺化推斷樣本密度 不保留密度資訊 使用密度估計方法

5.2 避免過度解讀

正確態度：

  • ✅ t-SNE 是假說生成工具，用於探索與發現
  • ✅ 結果需要用其他方法驗證（統計檢定、領域知識）
  • ✅ 搭配多種視覺化方法（PCA、UMAP、散布矩陣）
  • ❌ 不要僅憑 t-SNE 圖做決策

MNIST 手寫數字資料集

import matplotlib.pyplot as plt

# 載入資料
digits = load_digits()

    s=5,
    alpha=0.7
)

plt.title('MNIST 手寫數字 t-SNE 視覺化')
plt.xlabel('t-SNE 1')
plt.ylabel('t-SNE 2')
plt.show()

6.2 遙感影像光譜分析

多光譜資料群聚分析
import pandas as pd
from sklearn.manifold import TSNE
from sklearn.preprocessing import StandardScaler

# 載入光譜資料
df = pd.read_excel('植生指標萃取結果範例.xlsx')

# 選擇光譜特徵
spectral_features = ['B1', 'B2', 'B3', 'B4', 'NDVI', 'GNDVI', 'EVI']
X = df[spectral_features].values
y = df['期作別'].values

# 標準化
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# t-SNE 分析
tsne = TSNE(
    n_components=2,
    perplexity=50,
    n_iter=1000,
    random_state=42
)
X_tsne = tsne.fit_transform(X_scaled)

# 視覺化
plt.figure(figsize=(12, 8))
for period in np.unique(y):
    mask = (y == period)
    plt.scatter(
        X_tsne[mask, 0],
        X_tsne[mask, 1],
        label=period,
        s=20,
        alpha=0.6
    )

plt.xlabel('t-SNE Component 1')
plt.ylabel('t-SNE Component 2')
plt.title(f'作物光譜特徵 t-SNE 分析 (Perplexity={tsne.perplexity})')
plt.legend()
plt.grid(alpha=0.3)
plt.show()

print(f'KL 散度: {tsne.kl_divergence_:.4f}')

7. 與其他降維方法比較

方法 類型 優點 缺點 適用場景
PCA 線性 快速、可解釋、可轉換新資料 無法捕捉非線性結構 初步探索、特徵工程
t-SNE 非線性 優秀的局部結構保留、視覺化清晰 慢、無法轉換新資料、不保留全域結構 複雜資料視覺化
UMAP 非線性 比 t-SNE 快、保留更多全域結構 參數調整更複雜 大規模資料視覺化
Autoencoder 非線性 可轉換新資料、可用於生成 需要訓練、計算成本高 特徵學習、生成模型

7.1 何時選擇 t-SNE？

選擇 t-SNE 的情境：

  • ✅ 需要視覺化高維資料的局部群聚結構
  • ✅ 資料量適中（< 10,000 樣本較佳）
  • ✅ 主要目的是探索性分析，而非建模
  • ✅ 預期資料有非線性流形結構

考慮其他方法的情境：

  • 需要轉換新資料 → PCA 或 Autoencoder
  • 資料量超大 (> 100,000) → UMAP
  • 需要保留全域結構 → PCA 或 MDS
  • 需要可解釋性 → PCA

8. 進階技巧

8.1 加速 t-SNE 計算

方法 1：使用 Barnes-Hut 近似

# scikit-learn 預設使用 Barnes-Hut（樣本數 > 500 時）
tsne = TSNE(method='barnes_hut', angle=0.5)

angle 參數：越小越精確但越慢（預設 0.5）

方法 2：使用多核心實作

# 安裝 MulticoreTSNE
# pip install MulticoreTSNE

from MulticoreTSNE import MulticoreTSNE as TSNE

tsne = TSNE(n_jobs=4)  # 使用 4 個 CPU 核心

方法 3：使用 OpenTSNE

# 更現代化的實作，支援大規模資料
# pip install opentsne

from openTSNE import TSNE

tsne = TSNE(n_jobs=-1, random_state=42)

8.4 診斷與除錯

常見問題與解決方案

症狀 可能原因 解決方法
所有點擠成一團 學習率過高 降低 learning_rate (試 10-100)
形成奇怪的對稱形狀 資料未標準化 使用 StandardScaler
執行時間過長 資料維度或樣本數太多 先用 PCA 降維、減少迭代次數
每次結果差異很大 未固定隨機種子 設定 random_state=42
群聚過於碎片化 困惑度過小 增加 perplexity (試 30-100)

10. 總結與建議

🎯 核心要點

  1. t-SNE 是探索工具，不是真理或預測模型
  2. 必須測試多個困惑度，單一視角不足
  3. 資料預處理至關重要，尤其是標準化
  4. 不要過度解讀群聚大小和間距
  5. 結合領域知識解釋結果

✅ 推薦的工作流程

  1. 資料清理與標準化

  3. 測試多個困惑度 (5, 10, 30, 50, 100)
  4. 固定隨機種子確保可重現
  5. 比較不同參數的結果
  6. 用其他方法驗證發現
  7. 結合領域知識做最終判斷
