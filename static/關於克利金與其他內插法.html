關於克利金與其他內插法

空間內插是將離散的採樣點資料，推估為連續空間分布的技術。在精準農業中，常用於土壤養分分布圖、產量地圖、病蟲害分布等應用。本文介紹克利金（Kriging）及其他常用內插方法。

一、空間內插概述

什麼是空間內插

空間內插是根據已知點的值，推估未知位置的值的過程。基本假設是「空間上相近的點，其值也相近」（空間自相關）。

內插法分類

類型方法特點
確定性方法IDW、樣條、多項式直接由數學公式計算
地統計方法克利金系列考慮空間結構，提供誤差估計
機器學習隨機森林、神經網路可納入輔助變數

二、反距離加權法（IDW）

原理

IDW（Inverse Distance Weighting）假設距離越近的點影響越大：

           Σ(Zi / di^p)
Z(x) = ─────────────────
           Σ(1 / di^p)

其中：
Z(x) = 預測點的值
Zi   = 第 i 個已知點的值
di   = 預測點到第 i 個已知點的距離
p    = 權重指數（通常 p=2）

特點

  • 優點：簡單直觀、計算快速、參數少
  • 缺點：會產生「牛眼效應」、無法外推、無誤差估計

Python 實作

import numpy as np
from scipy.spatial.distance import cdist

def idw_interpolation(known_points, known_values, predict_points, power=2):
    """
    反距離加權內插

    參數：
        known_points: 已知點座標 (n, 2)
        known_values: 已知點值 (n,)
        predict_points: 預測點座標 (m, 2)
        power: 權重指數

    回傳：
        預測值 (m,)
    """
    # 計算距離矩陣
    distances = cdist(predict_points, known_points)

    # 避免除以零
    distances = np.where(distances == 0, 1e-10, distances)

    # 計算權重
    weights = 1 / (distances ** power)

    # 正規化權重
    weights_sum = weights.sum(axis=1, keepdims=True)
    weights_normalized = weights / weights_sum

    # 加權平均
    predictions = np.dot(weights_normalized, known_values)

    return predictions

# 使用範例
known_xy = np.array([[0, 0], [1, 0], [0, 1], [1, 1]])
known_z = np.array([10, 20, 15, 25])
predict_xy = np.array([[0.5, 0.5], [0.25, 0.75]])

result = idw_interpolation(known_xy, known_z, predict_xy)
print(f"預測值: {result}")

三、克利金法（Kriging）

基本概念

克利金（Kriging）是一種地統計內插方法，由南非礦業工程師 D.G. Krige 發展。它不僅估計數值，還提供估計不確定性。

核心概念：變異元

變異元（Variogram）描述空間自相關結構：

              1
γ(h) = ───── Σ[Z(xi) - Z(xi + h)]²
           2N(h)

其中：
γ(h) = 距離 h 的半變異數
N(h) = 距離為 h 的點對數量
Z(xi) = 位置 xi 的觀測值

變異元參數

參數英文說明
基台值Sill變異數趨於穩定的值
變程Range達到基台值的距離，超過此距離無空間相關
塊金值Nugget距離為 0 時的變異數（測量誤差+微尺度變異）

常用變異元模型

import numpy as np

def spherical_model(h, nugget, sill, range_):
    """球型模型"""
    c = sill - nugget
    if h == 0:
        return 0
    elif h < range_:
        return nugget + c * (1.5 * h/range_ - 0.5 * (h/range_)**3)
    else:
        return sill

def exponential_model(h, nugget, sill, range_):
    """指數模型"""
    c = sill - nugget
    if h == 0:
        return 0
    return nugget + c * (1 - np.exp(-3 * h / range_))

def gaussian_model(h, nugget, sill, range_):
    """高斯模型"""
    c = sill - nugget
    if h == 0:
        return 0
    return nugget + c * (1 - np.exp(-3 * (h/range_)**2))

克利金類型

類型假設應用場景
簡單克利金平均值已知且恆定理論研究
普通克利金平均值未知但恆定最常用
泛克利金有趨勢（漂移）有明顯趨勢的資料
共克利金多變數利用輔助變數
指標克利金二元或類別超標機率估計

Python 克利金實作

from pykrige.ok import OrdinaryKriging
import numpy as np
import matplotlib.pyplot as plt

# 準備資料
np.random.seed(42)
x = np.random.rand(20) * 100
y = np.random.rand(20) * 100
z = np.sin(x/20) + np.cos(y/20) + np.random.randn(20) * 0.1

# 建立普通克利金模型
OK = OrdinaryKriging(
    x, y, z,
    variogram_model='spherical',  # 變異元模型
    verbose=False,
    enable_plotting=False
)

# 建立預測網格
grid_x = np.arange(0, 100, 2)
grid_y = np.arange(0, 100, 2)

# 執行內插
z_pred, z_var = OK.execute('grid', grid_x, grid_y)

# 視覺化
fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# 預測值
im1 = axes[0].imshow(z_pred, origin='lower', extent=[0, 100, 0, 100], cmap='RdYlGn')
axes[0].scatter(x, y, c=z, edgecolors='black', cmap='RdYlGn')
axes[0].set_title('克利金預測值')
plt.colorbar(im1, ax=axes[0])

# 變異數（不確定性）
im2 = axes[1].imshow(z_var, origin='lower', extent=[0, 100, 0, 100], cmap='YlOrRd')
axes[1].scatter(x, y, c='black', s=20)
axes[1].set_title('估計變異數（不確定性）')
plt.colorbar(im2, ax=axes[1])

plt.tight_layout()
plt.show()

四、其他內插方法

樣條內插（Spline）

使用數學函數建立通過所有已知點的平滑曲面。

from scipy.interpolate import RBFInterpolator
import numpy as np

# 徑向基函數內插
known_xy = np.random.rand(30, 2) * 100
known_z = np.sin(known_xy[:, 0]/20) + np.cos(known_xy[:, 1]/20)

# 建立內插器
rbf = RBFInterpolator(known_xy, known_z, kernel='thin_plate_spline')

# 預測
grid_x, grid_y = np.meshgrid(np.linspace(0, 100, 50), np.linspace(0, 100, 50))
predict_xy = np.column_stack([grid_x.ravel(), grid_y.ravel()])
z_pred = rbf(predict_xy).reshape(grid_x.shape)

自然鄰近法（Natural Neighbor）

基於 Voronoi 圖的內插方法，權重由幾何關係決定。

from scipy.interpolate import NearestNDInterpolator, LinearNDInterpolator

# 線性內插（基於三角化）
linear_interp = LinearNDInterpolator(known_xy, known_z)
z_linear = linear_interp(predict_xy)

# 最近鄰內插
nearest_interp = NearestNDInterpolator(known_xy, known_z)
z_nearest = nearest_interp(predict_xy)

趨勢面分析（Trend Surface）

用多項式擬合整體趨勢。

from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression

# 二次趨勢面
poly = PolynomialFeatures(degree=2)
X_poly = poly.fit_transform(known_xy)

model = LinearRegression()
model.fit(X_poly, known_z)

# 預測
predict_poly = poly.transform(predict_xy)
z_trend = model.predict(predict_poly)

五、方法比較

方法優點缺點適用場景
IDW 簡單快速 牛眼效應、無誤差估計 快速預覽、資料探索
克利金 最佳線性無偏估計、有誤差 計算量大、需擬合變異元 精準農業、土壤調查
樣條 平滑、通過所有點 可能過度擬合、邊界震盪 地形建模
趨勢面 呈現整體趨勢 忽略局部變異 區域趨勢分析
自然鄰近 無參數、結果合理 計算較慢 不規則分布資料

六、農業應用範例

土壤養分內插

import pandas as pd
import numpy as np
from pykrige.ok import OrdinaryKriging
import matplotlib.pyplot as plt

# 假設土壤採樣資料
soil_data = pd.DataFrame({
    'E': [250100, 250200, 250150, 250300, 250050, 250250],
    'N': [2770100, 2770100, 2770200, 2770150, 2770250, 2770300],
    'pH': [6.2, 6.5, 6.1, 6.8, 5.9, 6.4],
    'N_content': [45, 52, 38, 61, 42, 55]  # 氮含量 ppm
})

# 建立氮含量克利金模型
OK = OrdinaryKriging(
    soil_data['E'].values,
    soil_data['N'].values,
    soil_data['N_content'].values,
    variogram_model='spherical',
    verbose=False
)

# 建立網格
grid_e = np.linspace(250000, 250400, 50)
grid_n = np.linspace(2770000, 2770400, 50)

# 內插
n_pred, n_var = OK.execute('grid', grid_e, grid_n)

# 繪製氮含量分布圖
plt.figure(figsize=(10, 8))
plt.imshow(n_pred, origin='lower',
           extent=[250000, 250400, 2770000, 2770400],
           cmap='YlGn')
plt.colorbar(label='氮含量 (ppm)')
plt.scatter(soil_data['E'], soil_data['N'],
            c=soil_data['N_content'], edgecolors='black',
            s=100, cmap='YlGn')
plt.xlabel('E (m)')
plt.ylabel('N (m)')
plt.title('土壤氮含量分布圖')
plt.show()

變量施肥處方圖

def create_fertilizer_prescription(n_map, target_n=60):
    """
    根據氮含量分布圖建立施肥處方

    參數：
        n_map: 氮含量內插結果
        target_n: 目標氮含量

    回傳：
        施肥量地圖
    """
    # 計算氮缺乏量
    n_deficit = target_n - n_map

    # 負值設為 0（不需要施肥）
    n_deficit = np.maximum(n_deficit, 0)

    # 轉換為肥料用量（假設利用率 50%）
    fertilizer_rate = n_deficit / 0.5 * 2.17  # kg/ha 尿素

    return fertilizer_rate

七、實作建議

樣點設計

  • 樣點數量：建議至少 30-50 點
  • 樣點間距：考慮變異元變程
  • 分布方式：網格或隨機，避免群聚

方法選擇流程

開始
 ├─ 需要誤差估計？
 │   ├─ 是 → 克利金
 │   └─ 否 → 繼續
 │
 ├─ 資料有明顯趨勢？
 │   ├─ 是 → 泛克利金或趨勢面+殘差克利金
 │   └─ 否 → 繼續
 │
 ├─ 快速預覽？
 │   ├─ 是 → IDW
 │   └─ 否 → 克利金或樣條
 │
 └─ 資料通過所有點？
     ├─ 是 → 樣條
     └─ 否 → 克利金

驗證方法

from sklearn.model_selection import LeaveOneOut

def cross_validation(x, y, z, method='kriging'):
    """留一法交叉驗證"""
    loo = LeaveOneOut()
    errors = []

    for train_idx, test_idx in loo.split(x):
        # 訓練
        x_train, y_train, z_train = x[train_idx], y[train_idx], z[train_idx]
        x_test, y_test, z_test = x[test_idx], y[test_idx], z[test_idx]

        # 預測（使用克利金）
        OK = OrdinaryKriging(x_train, y_train, z_train,
                            variogram_model='spherical', verbose=False)
        z_pred, _ = OK.execute('points', x_test, y_test)

        errors.append(z_test[0] - z_pred[0])

    rmse = np.sqrt(np.mean(np.array(errors)**2))
    mae = np.mean(np.abs(errors))

    return {'RMSE': rmse, 'MAE': mae}

八、常見問題

問題可能原因解決方法
變異元無法收斂 資料量不足、無空間結構 增加樣點、改用 IDW
預測值超出合理範圍 外推、資料異常 檢查異常值、限制預測範圍
結果過於平滑 變程設太大 重新擬合變異元
計算太慢 點數過多 降低解析度、使用搜尋半徑
