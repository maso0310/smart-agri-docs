第一部分：HTML - 網頁的骨架

HTML 是什麼？

HTML（HyperText Markup Language，超文本標記語言）用來定義網頁的結構和內容。

它不是程式語言，而是「標記語言」，用各種標籤（Tag）來標記內容的意義。

HTML 基本結構

<!DOCTYPE html>
<html lang="zh-TW">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>我的第一個網頁</title>
</head>
<body>
    <h1>歡迎來到智慧溫室</h1>
    <p>這是一個監控系統。</p>
</body>
</html>

第二部分：CSS - 網頁的外觀

CSS 是什麼？

CSS（Cascading Style Sheets，層疊樣式表）用來定義網頁的視覺外觀。

透過 CSS，我們可以控制：
- 顏色、字型、大小
- 間距、邊框、陰影
- 排版、對齊、佈局
- 動畫、轉場效果

CSS 的三種寫法

方式一：行內樣式（Inline Style）

直接寫在 HTML 標籤的 style 屬性中：

<p style="color: red; font-size: 20px;">這是紅色大字</p>
<div style="background-color: yellow; padding: 10px;">黃色背景區塊</div>
  • 優點：快速測試
  • 缺點：難以維護、無法重複使用

方式二：內部樣式（Internal Style）

寫在 <head> 中的 <style> 標籤內：

<!DOCTYPE html>
<html>
<head>
    <style>
        h1 {
            color: blue;
            text-align: center;
        }
        p {
            font-size: 16px;
            line-height: 1.6;
        }
    </style>
</head>
<body>
    <h1>標題會是藍色置中</h1>
    <p>段落會套用指定樣式</p>
</body>
</html>
  • 優點：樣式集中管理
  • 缺點：只能用於單一頁面

方式三：外部樣式（External Style）- 推薦

將 CSS 寫在獨立的 .css 檔案中：

index.html:

<!DOCTYPE html>
<html>
<head>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>標題</h1>
    <p>內容</p>
</body>
</html>

style.css:

h1 {
    color: blue;
    text-align: center;
}

p {
    font-size: 16px;
    line-height: 1.6;
}
  • 優點：可重複使用、易於維護、瀏覽器可快取
  • 缺點：需要多一個檔案

CSS 選擇器

選擇器決定「哪些元素」要套用樣式：

/* 標籤選擇器：選取所有該標籤 */
p {
    color: gray;
}

/* Class 選擇器：選取有該 class 的元素（可重複使用） */
.highlight {
    background-color: yellow;
}

/* ID 選擇器：選取該 ID 的元素（唯一） */
#header {
    font-size: 24px;
}

/* 後代選擇器：選取某元素內部的元素 */
.card p {
    margin: 10px;
}

/* 組合選擇器：同時選取多個 */
h1, h2, h3 {
    font-family: "Microsoft JhengHei", sans-serif;
}

/* 偽類選擇器：特定狀態 */
a:hover {
    color: red;
}

button:active {
    transform: scale(0.95);
}

HTML 搭配使用：

    }

        toggleDevice('pump');
        showNotification('土壤過乾，已自動開啟灌溉');

    if (sensorData.soil > 60 && deviceStatus.pump) {
        toggleDevice('pump');
        showNotification('土壤濕度足夠，已自動關閉灌溉');

問題一：JavaScript 沒有執行

可能原因：
1. 腳本放在元素之前
2. 語法錯誤
3. 檔案路徑錯誤

解決方案：

2. 開啟瀏覽器開發者工具（F12）查看 Console 錯誤訊息
