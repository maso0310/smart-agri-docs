關於衛星與無人機影像如何處理散射干擾

在遙測影像擷取過程中，電磁波在穿越大氣層時會受到散射（Scattering）的影響，導致影像品質下降、色彩失真、對比度降低。了解散射的原理與校正方法，是遙測影像分析的重要基礎。

一、什麼是大氣散射

基本概念

當電磁波（光）通過大氣層時，會與大氣中的氣體分子和懸浮微粒（氣膠、水滴、灰塵等）發生交互作用，使光的傳播方向改變，這就是大氣散射。

散射對遙測影像的影響：
  • 降低影像對比度和清晰度
  • 產生色偏（尤其是藍色調增加）
  • 干擾地表真實反射率的測量
  • 影響植被指數（如 NDVI）的準確性

散射的物理過程

感測器接收到的輻射能量包含三個部分：

  1. 路徑輻射（Path Radiance）：大氣散射直接進入感測器的光
  2. 地表反射輻射：經大氣衰減後的地表反射光
  3. 鄰近效應（Adjacency Effect）：周圍地物反射後再散射進入視場的光
感測器接收輻射 = 路徑輻射 + 衰減後的地表輻射 + 鄰近效應
Lsensor = Lpath + T × Lsurface + Ladjacent

二、散射的類型

根據散射粒子大小與電磁波波長的關係，散射主要分為三種類型：

散射類型 粒子大小 波長依賴性 主要影響波段 常見情境
瑞利散射
（Rayleigh）		 遠小於波長
（< 0.1λ）		 與 λ-4 成正比
（短波強烈散射）		 藍光、紫外線 晴朗天空、高空大氣
米氏散射
（Mie）		 與波長相近
（0.1λ ~ 10λ）		 與 λ-1 ~ λ-2 成正比 可見光全波段 霧霾、煙塵、水滴
非選擇性散射
（Non-selective）		 遠大於波長
（> 10λ）		 與波長無關
（各波段均勻散射）		 所有可見光 雲、霧、大水滴

瑞利散射 - 天空為什麼是藍色的？

瑞利散射強度與波長的四次方成反比：

I ∝ 1/λ4

這意味著：

  • 藍光（~450nm）的散射強度是紅光（~650nm）的約 (650/450)^4 ≈ 4.4 倍
  • 因此晴天時天空呈現藍色
  • 遙測影像中會出現「藍色霧霾」效應

米氏散射 - 霧霾天的元兇

當大氣中存在氣膠（aerosol）、煙塵、細懸浮微粒（PM2.5）時：

  • 散射發生在整個可見光波段
  • 影像整體對比度下降
  • 遠處物體變得模糊
  • 在農業遙測中會嚴重影響植被指數計算
注意：台灣常見的霧霾天氣（尤其是秋冬季節），主要是米氏散射造成，會嚴重影響無人機和衛星影像品質。建議選擇能見度良好的日子進行航拍。

三、散射對農業遙測的影響

對植被指數的影響

以 NDVI 為例，散射會造成：

影響 原因 結果
紅光波段值偏高 路徑輻射增加紅光反射值 NDVI 被低估
近紅外波段值偏低 大氣吸收與衰減 NDVI 被低估
時序不一致 不同日期大氣條件不同 難以進行變化偵測
實例：未經大氣校正的 NDVI 可能比實際值低 0.1~0.2，這在作物健康監測中可能導致誤判。

不同平台的散射影響程度

平台 飛行高度 大氣路徑長度 散射影響 校正必要性
高軌衛星 36,000 km 非常長 嚴重 必須校正
低軌衛星 400-800 km 長 顯著 建議校正
載人飛機 1-10 km 中等 中等 視情況
無人機 50-500 m 短 較輕微 通常可忽略

四、散射校正方法

方法一：暗物體減法（Dark Object Subtraction, DOS）

最簡單的大氣校正方法，適合快速處理：

原理

  • 假設影像中存在「絕對黑」的物體（如深水、陰影）
  • 這些物體的反射率理論上為 0
  • 實際測得的值即為大氣散射造成的路徑輻射
  • 將整張影像減去這個最小值
import numpy as np
import rasterio

def dark_object_subtraction(image_path, output_path):
    """
    暗物體減法大氣校正
    """
    with rasterio.open(image_path) as src:
        # 讀取所有波段
        bands = src.read()
        profile = src.profile

        corrected_bands = []
        for i, band in enumerate(bands):
            # 找出每個波段的最小值（暗物體值）
            # 使用第1百分位數避免異常值影響
            dark_value = np.percentile(band[band > 0], 1)

            # 減去暗物體值
            corrected = band.astype(float) - dark_value
            corrected = np.clip(corrected, 0, None)  # 確保非負

            corrected_bands.append(corrected)
            print(f"Band {i+1}: 暗物體值 = {dark_value:.2f}")

        # 寫入校正後影像
        corrected_array = np.array(corrected_bands)
        with rasterio.open(output_path, 'w', **profile) as dst:
            dst.write(corrected_array.astype(profile['dtype']))

    return output_path

# 使用範例
# dark_object_subtraction('raw_image.tif', 'corrected_image.tif')
DOS 的改進版本：
  • DOS1：直接使用最小值
  • DOS2：考慮 1% 大氣透過率
  • DOS3：加入瑞利散射估算
  • DOS4 (COST)：考慮太陽天頂角的餘弦校正

方法二：直方圖匹配法

利用已知參考影像校正目標影像：

import numpy as np
from skimage import exposure

def histogram_matching(source, reference):
    """
    直方圖匹配校正
    source: 待校正影像
    reference: 參考影像（已校正或地面真值）
    """
    matched = exposure.match_histograms(source, reference, channel_axis=0)
    return matched

方法三：6S 輻射傳輸模型

6S（Second Simulation of the Satellite Signal in the Solar Spectrum）是專業的大氣校正模型：

輸入參數

  • 幾何參數：太陽天頂角、方位角、感測器角度
  • 大氣模型：熱帶、中緯度夏季/冬季等
  • 氣膠模型：大陸型、海洋型、城市型等
  • 光譜參數：波段響應函數
  • 地表參數：地表反射率估計
# 使用 Py6S 進行大氣校正
from Py6S import *

def atmospheric_correction_6s(band_radiance, wavelength, geometry, atmos_profile):
    """
    使用 6S 模型進行大氣校正
    """
    # 建立 6S 物件
    s = SixS()

    # 設定幾何參數
    s.geometry = Geometry.User()
    s.geometry.solar_z = geometry['solar_zenith']
    s.geometry.solar_a = geometry['solar_azimuth']
    s.geometry.view_z = geometry['view_zenith']
    s.geometry.view_a = geometry['view_azimuth']

    # 設定大氣模型
    s.atmos_profile = AtmosProfile.PredefinedType(atmos_profile)

    # 設定氣膠模型
    s.aero_profile = AeroProfile.PredefinedType(AeroProfile.Continental)

    # 設定波長
    s.wavelength = Wavelength(wavelength)

    # 執行模擬
    s.run()

    # 取得校正係數
    xa = s.outputs.coef_xa
    xb = s.outputs.coef_xb
    xc = s.outputs.coef_xc

    # 計算地表反射率
    y = xa * band_radiance - xb
    surface_reflectance = y / (1 + xc * y)

    return surface_reflectance

五、衛星影像的大氣校正

使用已校正產品

許多衛星資料提供者已提供大氣校正後的產品：

衛星 原始產品 校正後產品 說明

Sentinel-2 大氣校正範例

import ee

# 使用 Google Earth Engine 取得已校正的 Sentinel-2 影像
ee.Initialize()

# Level-2A 產品已經過大氣校正
s2_sr = ee.ImageCollection('COPERNICUS/S2_SR_HARMONIZED') \
    .filterDate('2024-01-01', '2024-06-01') \
    .filterBounds(ee.Geometry.Point([120.5, 23.5])) \
    .filter(ee.Filter.lt('CLOUDY_PIXEL_PERCENTAGE', 10))

# 取得地表反射率（已除以 10000 的縮放因子）
def scale_bands(image):
    optical = image.select('B.*').divide(10000)
    return image.addBands(optical, overwrite=True)

s2_scaled = s2_sr.map(scale_bands)

# 現在可以直接計算 NDVI
def add_ndvi(image):
    ndvi = image.normalizedDifference(['B8', 'B4']).rename('NDVI')
    return image.addBands(ndvi)

s2_ndvi = s2_scaled.map(add_ndvi)
print("影像數量:", s2_ndvi.size().getInfo())

自行校正 Landsat 影像

import numpy as np
import rasterio
from datetime import datetime
import math

def landsat_toa_to_sr(dn_image, metadata):
    """
    Landsat DN 值轉換為地表反射率（簡化版）

    步驟：
    1. DN -> 輻射值 (Radiance)
    2. 輻射值 -> 大氣頂反射率 (TOA Reflectance)
    3. TOA -> 地表反射率 (Surface Reflectance) - 使用 DOS
    """

    # 從 metadata 取得校正參數
    mult = metadata['REFLECTANCE_MULT']  # 乘數
    add = metadata['REFLECTANCE_ADD']    # 加數
    sun_elevation = metadata['SUN_ELEVATION']

    # DN -> TOA 反射率
    toa = mult * dn_image + add

    # 太陽天頂角校正
    sun_zenith = 90 - sun_elevation
    toa_corrected = toa / math.cos(math.radians(sun_zenith))

    # DOS 大氣校正
    dark_value = np.percentile(toa_corrected[toa_corrected > 0], 1)
    surface_reflectance = toa_corrected - dark_value
    surface_reflectance = np.clip(surface_reflectance, 0, 1)

    return surface_reflectance

六、無人機影像的散射處理

無人機的優勢

相較於衛星，無人機受大氣散射影響較小：

  • 低飛行高度：大氣路徑短，散射影響小
  • 彈性時間：可選擇天氣最佳時拍攝
  • 輻射校正板：可放置地面參考板進行校正

仍需注意的情況

以下情況無人機影像仍需考慮大氣影響：
  • 霧霾嚴重的日子（能見度 < 5km）
  • 飛行高度較高（> 300m）
  • 需要與衛星資料比對時
  • 多時序分析需要一致性時

輻射校正板方法

使用已知反射率的標準板進行經驗線校正：

import numpy as np
from scipy import stats

def empirical_line_correction(image, reference_panels):
    """
    經驗線校正法

    reference_panels: list of dicts
        [{'dn_value': 數位值, 'reflectance': 已知反射率}, ...]
    """

    # 收集參考點資料
    dn_values = [p['dn_value'] for p in reference_panels]
    reflectances = [p['reflectance'] for p in reference_panels]

    # 線性迴歸求校正係數
    slope, intercept, r_value, p_value, std_err = stats.linregress(
        dn_values, reflectances
    )

    print(f"校正方程式: 反射率 = {slope:.6f} × DN + {intercept:.6f}")
    print(f"R² = {r_value**2:.4f}")

    # 套用校正
    corrected = slope * image + intercept
    corrected = np.clip(corrected, 0, 1)

    return corrected

# 使用範例
panels = [
    {'dn_value': 50, 'reflectance': 0.04},   # 黑色板
    {'dn_value': 120, 'reflectance': 0.23},  # 灰色板
    {'dn_value': 200, 'reflectance': 0.48},  # 白色板
]

DLS（Downwelling Light Sensor）校正

部分多光譜相機（如 MicaSense）配備入射光感測器，可補償光照變化：

def dls_correction(raw_image, dls_irradiance, panel_irradiance, panel_reflectance):
    """
    使用 DLS 資料進行輻射校正

    raw_image: 原始影像數位值
    dls_irradiance: 拍攝時的入射光強度
    panel_irradiance: 校正板拍攝時的入射光強度
    panel_reflectance: 校正板已知反射率
    """

    # 計算校正係數
    calibration_factor = panel_reflectance / (panel_raw_dn / panel_irradiance)

    # 校正影像
    reflectance = calibration_factor * (raw_image / dls_irradiance)

    return reflectance

七、實務建議

衛星影像處理流程

  1. 優先使用官方 L2 產品：Sentinel-2 Level-2A、Landsat Level-2
  2. 檢查品質遮罩：排除雲、雲影、異常像元
  3. 若需自行校正：DOS 方法簡單快速，適合教學；專業研究建議使用 6S 或 FLAASH
  4. 驗證校正結果：與地面實測或其他來源比對

無人機影像處理流程

  1. 選擇好天氣：晴朗、能見度佳、光照穩定
  2. 放置校正板：至少黑、灰、白三階
  3. 一致的拍攝條件：相同時段、相同參數
  4. 經驗線校正：使用校正板進行反射率轉換

軟體工具推薦

八、完整校正範例

"""
完整的遙測影像大氣校正流程範例
"""

import numpy as np
import rasterio
from rasterio.plot import show
import matplotlib.pyplot as plt

class AtmosphericCorrection:
    """大氣校正處理類別"""

    def __init__(self, image_path):
        self.image_path = image_path
        self.load_image()

    def load_image(self):
        """載入影像"""
        with rasterio.open(self.image_path) as src:
            self.bands = src.read()
            self.profile = src.profile
            self.band_count = src.count
            print(f"載入影像: {self.band_count} 個波段")

    def dos_correction(self, percentile=1):
        """
        暗物體減法校正
        """
        corrected = []
        for i, band in enumerate(self.bands):
            valid_pixels = band[band > 0]
            dark_value = np.percentile(valid_pixels, percentile)

            band_corrected = band.astype(float) - dark_value
            band_corrected = np.clip(band_corrected, 0, None)
            corrected.append(band_corrected)

            print(f"Band {i+1}: 暗物體值 = {dark_value:.2f}")

        self.corrected_bands = np.array(corrected)
        return self.corrected_bands

    def calculate_ndvi(self, red_band_idx=2, nir_band_idx=3):
        """
        計算 NDVI
        使用校正後的波段（若已校正）
        """
        bands = self.corrected_bands if hasattr(self, 'corrected_bands') else self.bands

        red = bands[red_band_idx].astype(float)
        nir = bands[nir_band_idx].astype(float)

        # 避免除以零
        np.seterr(divide='ignore', invalid='ignore')
        ndvi = (nir - red) / (nir + red)
        ndvi = np.where(np.isfinite(ndvi), ndvi, 0)

        return ndvi

    def compare_correction(self, red_idx=2, nir_idx=3):
        """
        比較校正前後的 NDVI
        """
        # 校正前 NDVI
        red_raw = self.bands[red_idx].astype(float)
        nir_raw = self.bands[nir_idx].astype(float)
        ndvi_raw = (nir_raw - red_raw) / (nir_raw + red_raw + 1e-10)

        # 執行校正
        self.dos_correction()

        # 校正後 NDVI
        ndvi_corrected = self.calculate_ndvi(red_idx, nir_idx)

        # 視覺化比較
        fig, axes = plt.subplots(1, 3, figsize=(15, 5))

        im1 = axes[0].imshow(ndvi_raw, cmap='RdYlGn', vmin=-0.2, vmax=0.8)
        axes[0].set_title('NDVI (未校正)')
        plt.colorbar(im1, ax=axes[0])

        im2 = axes[1].imshow(ndvi_corrected, cmap='RdYlGn', vmin=-0.2, vmax=0.8)
        axes[1].set_title('NDVI (DOS 校正後)')
        plt.colorbar(im2, ax=axes[1])

        diff = ndvi_corrected - ndvi_raw
        im3 = axes[2].imshow(diff, cmap='coolwarm', vmin=-0.2, vmax=0.2)
        axes[2].set_title('差異 (校正後 - 校正前)')
        plt.colorbar(im3, ax=axes[2])

        plt.tight_layout()
        plt.savefig('ndvi_comparison.png', dpi=150)
        plt.show()

        # 統計比較
        print(f"\n統計比較:")
        print(f"未校正 NDVI: 平均={np.nanmean(ndvi_raw):.3f}, 標準差={np.nanstd(ndvi_raw):.3f}")
        print(f"校正後 NDVI: 平均={np.nanmean(ndvi_corrected):.3f}, 標準差={np.nanstd(ndvi_corrected):.3f}")
        print(f"平均差異: {np.nanmean(diff):.3f}")

    def save_corrected(self, output_path):
        """儲存校正後影像"""
        if not hasattr(self, 'corrected_bands'):
            raise ValueError("請先執行校正")

        with rasterio.open(output_path, 'w', **self.profile) as dst:
            dst.write(self.corrected_bands.astype(self.profile['dtype']))

        print(f"已儲存校正後影像: {output_path}")

九、總結

重點回顧

  • 散射原理：瑞利散射（藍光強）、米氏散射（霧霾）、非選擇性散射（雲）
  • 影響：降低對比度、色偏、干擾植被指數計算
  • 校正方法：DOS（簡單）、6S/FLAASH（精確）、經驗線法（無人機）
  • 實務建議：優先使用官方 L2 產品，無人機使用校正板
正確的大氣校正是遙測定量分析的基礎。選擇適合的校正方法，取決於影像來源、應用需求和可用資源。對於教學和一般應用，DOS 方法已足夠；專業研究則建議使用輻射傳輸模型。
