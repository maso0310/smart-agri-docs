關於 RTK 高精度定位

什麼是 RTK？

RTK (Real-Time Kinematic，實時動態定位) 是一種高精度的衛星定位技術，能將 GPS/GNSS 定位精度從數公尺提升至公分等級。在智慧農業中，RTK 技術是實現精準農業、自動駕駛農機的關鍵。

一句話解釋

RTK 就像「GPS 的糾錯系統」：透過地面基站提供即時修正資料，讓移動設備的定位從「大概在這一帶」變成「精確在這個點」。

一般 GPS 2-5 公尺 5-10 公尺 導航、手機定位

RTK 工作原理

GNSS 誤差來源

衛星定位的誤差主要來自以下因素：

誤差來源 影響範圍 說明
電離層延遲 2-50 公尺 訊號穿過電離層時速度改變
對流層延遲 2-10 公尺 大氣水氣影響訊號傳播
衛星軌道誤差 1-5 公尺 衛星位置預報不精確
衛星時鐘誤差 0-2 公尺 原子鐘的微小偏差
多路徑效應 0-1 公尺 訊號被建築物反射
接收器雜訊 0-0.5 公尺 設備本身的誤差

RTK 運作步驟

  1. 基準站接收衛星訊號：架設在已知精確座標的位置
  2. 計算修正量：比較計算位置與已知位置的差異
  3. 傳送修正資料：透過無線電或網路傳給移動站
  4. 移動站套用修正：即時修正定位結果
  5. 輸出高精度座標：達到公分級定位精度

解析 NMEA 資料

import serial
import pynmea2

def parse_rtk_data(port='/dev/ttyUSB0', baudrate=115200):
    """解析 RTK 接收器的 NMEA 資料"""

    ser = serial.Serial(port, baudrate, timeout=1)

    while True:
        line = ser.readline().decode('ascii', errors='replace')

        if line.startswith('$GNGGA') or line.startswith('$GPGGA'):
            try:
                msg = pynmea2.parse(line)

                # 提取定位資訊
                lat = msg.latitude
                lon = msg.longitude
                alt = msg.altitude
                fix_quality = msg.gps_qual
                num_sats = msg.num_sats
                hdop = msg.horizontal_dil

                # RTK 固定解 (Fix) 判斷
                # 4 = RTK Fixed, 5 = RTK Float
                if fix_quality == 4:
                    status = "RTK Fixed (高精度)"
                elif fix_quality == 5:
                    status = "RTK Float (中精度)"
                else:
                    status = f"一般定位 (品質={fix_quality})"

                print(f"緯度: {lat:.8f}")
                print(f"經度: {lon:.8f}")
                print(f"高程: {alt:.3f} m")
                print(f"衛星數: {num_sats}")
                print(f"HDOP: {hdop}")
                print(f"狀態: {status}")
                print("-" * 40)

            except pynmea2.ParseError:
                pass

if __name__ == "__main__":
    parse_rtk_data()

NTRIP 客戶端連線

import socket
import base64

class NTRIPClient:
    """簡易 NTRIP 客戶端"""

    def __init__(self, host, port, mountpoint, user, password):
        self.host = host
        self.port = port
        self.mountpoint = mountpoint
        self.user = user
        self.password = password
        self.socket = None

    def connect(self):
        """連接 NTRIP 伺服器"""
        self.socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        self.socket.connect((self.host, self.port))

        # 建立認證標頭
        auth = base64.b64encode(
            f"{self.user}:{self.password}".encode()
        ).decode()

        # 發送請求
        request = (
            f"GET /{self.mountpoint} HTTP/1.0\r\n"
            f"Host: {self.host}\r\n"
            f"Authorization: Basic {auth}\r\n"
            f"User-Agent: NTRIP PythonClient/1.0\r\n"
            f"\r\n"
        )
        self.socket.send(request.encode())

        # 讀取回應
        response = self.socket.recv(1024).decode()
        if "200 OK" in response:
            print("NTRIP 連線成功！")
            return True
        else:
            print(f"連線失敗: {response}")
            return False

    def read_rtcm(self):
        """讀取 RTCM 修正資料"""
        return self.socket.recv(1024)

    def send_gga(self, gga_sentence):
        """發送 GGA 位置資訊給伺服器"""
        self.socket.send(gga_sentence.encode())

    def close(self):
        if self.socket:
            self.socket.close()

軌跡記錄與匯出

import csv
import json
from datetime import datetime

class TrajectoryRecorder:
    """RTK 軌跡記錄器"""

    def __init__(self, filename):
        self.filename = filename
        self.points = []

    def add_point(self, lat, lon, alt, fix_quality, timestamp=None):
        """新增軌跡點"""
        if timestamp is None:
            timestamp = datetime.now().isoformat()

        point = {
            'timestamp': timestamp,
            'latitude': lat,
            'longitude': lon,
            'altitude': alt,
            'fix_quality': fix_quality
        }
        self.points.append(point)

    def export_csv(self):
        """匯出為 CSV"""
        with open(f"{self.filename}.csv", 'w', newline='') as f:
            writer = csv.DictWriter(f, fieldnames=[
                'timestamp', 'latitude', 'longitude',
                'altitude', 'fix_quality'
            ])
            writer.writeheader()
            writer.writerows(self.points)
        print(f"已匯出 {len(self.points)} 個點到 {self.filename}.csv")

    def export_geojson(self):
        """匯出為 GeoJSON"""
        features = []
        for p in self.points:
            feature = {
                "type": "Feature",
                "geometry": {
                    "type": "Point",
                    "coordinates": [p['longitude'], p['latitude'], p['altitude']]
                },
                "properties": {
                    "timestamp": p['timestamp'],
                    "fix_quality": p['fix_quality']
                }
            }
            features.append(feature)

        geojson = {
            "type": "FeatureCollection",
            "features": features
        }

        with open(f"{self.filename}.geojson", 'w') as f:
            json.dump(geojson, f, indent=2)
        print(f"已匯出到 {self.filename}.geojson")

    def export_kml(self):
        """匯出為 KML (Google Earth)"""
        kml_header = '''


    RTK Trajectory
    
    
        Trajectory
        
            '''

        coords = []
        for p in self.points:
            coords.append(f"{p['longitude']},{p['latitude']},{p['altitude']}")

        kml_footer = '''
        
    

'''

        with open(f"{self.filename}.kml", 'w') as f:
            f.write(kml_header)
            f.write('\n                '.join(coords))
            f.write(kml_footer)
        print(f"已匯出到 {self.filename}.kml")

# 使用範例
recorder = TrajectoryRecorder("field_survey_2024")
recorder.add_point(24.123456, 120.654321, 50.5, 4)
recorder.add_point(24.123466, 120.654331, 50.6, 4)
recorder.export_geojson()

常見問題排解

無法獲得 Fixed 解

問題：RTK 一直顯示 Float 或 Single，無法達到公分級精度

可能原因與解決方案：

原因 解決方案
衛星數量不足 確保天線視野開闊，至少需要 10+ 顆衛星
天線遮擋 遠離高大建築、樹木，避免多路徑效應
基站距離過遠 距離 >20km 時考慮使用網路 RTK
NTRIP 連線中斷 檢查網路訊號，確認帳號密碼正確
天線品質不佳 使用支援多頻多系統的測量級天線

精度驗證方法

def check_rtk_accuracy(points, known_point):
    """驗證 RTK 定位精度"""
    import numpy as np

    # 計算與已知點的偏差
    errors = []
    for p in points:
        dx = (p['lon'] - known_point['lon']) * 111000 * np.cos(np.radians(p['lat']))
        dy = (p['lat'] - known_point['lat']) * 111000
        dz = p['alt'] - known_point['alt']

        horizontal_error = np.sqrt(dx**2 + dy**2)
        errors.append({
            'horizontal': horizontal_error,
            'vertical': abs(dz)
        })

    # 統計分析
    h_errors = [e['horizontal'] for e in errors]
    v_errors = [e['vertical'] for e in errors]

    print(f"水平誤差 - 平均: {np.mean(h_errors):.3f}m, 標準差: {np.std(h_errors):.3f}m")
    print(f"垂直誤差 - 平均: {np.mean(v_errors):.3f}m, 標準差: {np.std(v_errors):.3f}m")
    print(f"CEP50 (50% 圓概率誤差): {np.percentile(h_errors, 50):.3f}m")
    print(f"CEP95 (95% 圓概率誤差): {np.percentile(h_errors, 95):.3f}m")

最佳實踐

1. 天線架設

  • 天線應安裝在最高點，確保 360 度開闊視野
  • 避免金屬物體干擾（至少離開 1 公尺）
  • 使用接地板減少多路徑效應
  • 確保天線水平（使用水平儀）

2. 作業流程

RTK 作業標準流程：

1. 開機預熱 (5-10 分鐘)
2. 確認衛星訊號 (>10 顆)
3. 連接 NTRIP 或基站
4. 等待 Fixed 解 (通常 1-3 分鐘)
5. 驗證已知點精度
6. 開始作業
7. 定期檢查狀態
8. 作業結束，匯出資料

3. 資料品質控制

品質指標檢查清單：

  • Fix Quality = 4 (RTK Fixed)
  • HDOP < 1.0
  • 衛星數 > 12
  • Age of Correction < 5 秒
  • 基線長度 < 20 km
