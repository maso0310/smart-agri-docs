Meta AI Research | 2023

📖 什麼是 SAM？

SAM (Segment Anything Model) 是 Meta AI 於 2023 年 4 月發布的一個革命性圖像分割模型。它是一個「基礎模型」(Foundation Model)，能夠在零樣本（zero-shot）情況下分割圖像中的任何物體，無需針對特定任務進行訓練。

SAM 的訓練使用了超過 1100 萬張影像和 11 億個遮罩（masks），是目前最大規模的分割資料集 SA-1B。這使得 SAM 具有強大的泛化能力，可以處理從未見過的物體類別。

2024 年 7 月，Meta 發布了 SAM 2，進一步支援影片分割功能，能夠在影片中追蹤和分割移動物體。

🌟 SAM 的核心特點

🎯 零樣本學習

無需訓練即可分割任何物體，支援點擊、框選、文字提示等多種互動方式。

🏗️ SAM 模型架構

SAM 採用三個主要組件構成的架構設計：

三大核心組件

1️⃣ Image Encoder（影像編碼器）

基於 Vision Transformer (ViT)，將輸入影像轉換為高維特徵表示。使用 ViT-H/L/B 三種規模。

2️⃣ Prompt Encoder（提示編碼器）

處理使用者輸入的提示（點、框、文字等），轉換為模型可理解的嵌入向量。

3️⃣ Mask Decoder（遮罩解碼器）

結合影像特徵和提示嵌入，生成精確的分割遮罩。使用 Transformer 架構。

💡 設計理念：Promptable Segmentation

SAM 的核心創新是「可提示分割」（Promptable Segmentation）概念。傳統分割模型需要為每個任務訓練專門的模型，但 SAM 通過接受提示（prompts）來指定要分割的目標，實現了一個模型適用於所有分割任務的目標。

支援的提示類型：

  • 點提示（Point）：點擊物體中心或邊緣
  • 框提示（Bounding Box）：拖曳框選目標區域
  • 文字提示（Text）：輸入物體名稱或描述（SAM 需配合 CLIP 等模型）
  • 遮罩提示（Mask）：提供粗略的遮罩進行精修

範例 1：使用點提示分割物體

import numpy as np
import torch
import matplotlib.pyplot as plt
import cv2
from segment_anything import sam_model_registry, SamPredictor

# 1. 載入模型
sam_checkpoint = "sam_vit_h_4b8939.pth"
model_type = "vit_h"
device = "cuda" if torch.cuda.is_available() else "cpu"

sam = sam_model_registry[model_type](checkpoint=sam_checkpoint)
sam.to(device=device)

# 2. 建立預測器
predictor = SamPredictor(sam)

# 3. 讀取影像
image = cv2.imread('your_image.jpg')
image = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)

# 4. 設定影像
predictor.set_image(image)

# 5. 使用點提示進行分割
input_point = np.array([[500, 375]])  # [x, y] 座標
input_label = np.array([1])  # 1 表示前景點，0 表示背景點

masks, scores, logits = predictor.predict(
    point_coords=input_point,
    point_labels=input_label,
    multimask_output=True,
)

# 6. 顯示結果
for i, (mask, score) in enumerate(zip(masks, scores)):
    plt.figure(figsize=(10,10))
    plt.imshow(image)
    plt.imshow(mask, alpha=0.5, cmap='jet')
    plt.title(f"Mask {i+1}, Score: {score:.3f}")
    plt.axis('off')
    plt.show()

範例 4：SAM 2.0 影片分割

from sam2.build_sam import build_sam2_video_predictor

# 載入 SAM 2.0 影片預測器
checkpoint = "./checkpoints/sam2_hiera_large.pt"
model_cfg = "sam2_hiera_l.yaml"
predictor = build_sam2_video_predictor(model_cfg, checkpoint)

# 處理影片
video_dir = "./videos/your_video"
with torch.inference_mode(), torch.autocast("cuda", dtype=torch.bfloat16):
    state = predictor.init_state(video_path=video_dir)

    # 在第一幀添加點提示
    frame_idx = 0
    obj_id = 1
    points = np.array([[500, 375]], dtype=np.float32)
    labels = np.array([1], dtype=np.int32)

    _, out_obj_ids, out_mask_logits = predictor.add_new_points(
        inference_state=state,
        frame_idx=frame_idx,
        obj_id=obj_id,
        points=points,
        labels=labels,
    )

    # 傳播到所有幀
    video_segments = {}
    for out_frame_idx, out_obj_ids, out_mask_logits in predictor.propagate_in_video(state):
        video_segments[out_frame_idx] = {
            out_obj_id: (out_mask_logits[i] > 0.0).cpu().numpy()
            for i, out_obj_id in enumerate(out_obj_ids)
        }

print(f"處理了 {len(video_segments)} 幀影片")

🌾 SAM 在智慧農業的應用

🎯 為什麼 SAM 適合智慧農業？

傳統農業影像分割模型需要大量標註資料，且只能識別特定作物或病害。SAM 的零樣本能力使得它可以：

  • ✅ 無需訓練即可分割新品種作物
  • ✅ 適應不同光照、角度、生長階段
  • ✅ 快速建立新的農業資料集（半自動標註）
  • ✅ 處理多樣化的農業場景（果園、溫室、田間等）
🍎

1. 水果品質檢測

應用：自動分割蘋果、番茄、柑橘等水果，提取缺陷區域進行品質評估。

優勢：可處理不同品種、大小、成熟度的水果，無需重新訓練。

🦠

2. 病害區域定位

應用：精確分割葉片上的病斑、蟲害區域，計算病害面積和嚴重程度。

優勢：適用於各種作物病害，提高診斷精度。

🌿

3. 雜草識別與分割

應用：在田間影像中分割作物與雜草，用於精準除草機器人。

優勢：減少除草劑使用，降低環境污染。

📊

4. 作物計數與產量估算

應用：分割並計數果實（蘋果、葡萄、番茄等），估算產量。

優勢：配合無人機影像，實現大規模農田監測。

🤖

5. 採收機器人視覺

應用：為採收機器人提供精確的果實定位和分割，引導機械臂抓取。

優勢：即時處理，適應不同光照和遮擋情況。

🏷️

6. 資料集半自動標註

應用：快速建立農業影像資料集，使用 SAM 進行初步標註後人工修正。

優勢：大幅降低標註成本，加速 AI 模型開發。

🌱

7. 幼苗生長監測

應用：分割幼苗，追蹤生長速度、葉片數量、健康狀況。

優勢：SAM 2 的影片功能可追蹤時間序列變化。

🛰️

8. 衛星/無人機影像分析

應用：分割農田、作物區域、灌溉系統等，進行精準農業管理。

優勢：SAM 在遙感影像上表現優異。

💻 農業應用程式碼範例

範例：蘋果品質檢測 - 自動分割缺陷區域

import cv2
import numpy as np
import torch
from segment_anything import sam_model_registry, SamAutomaticMaskGenerator

# 載入 SAM 模型
sam = sam_model_registry["vit_h"](checkpoint="sam_vit_h_4b8939.pth")
sam.to(device="cuda")

# 建立自動遮罩生成器（調整參數以適應蘋果檢測）
mask_generator = SamAutomaticMaskGenerator(
    model=sam,
    points_per_side=32,
    pred_iou_thresh=0.86,
    stability_score_thresh=0.92,
    crop_n_layers=1,
    crop_n_points_downscale_factor=2,
    min_mask_region_area=100,  # 過濾小區域
)

# 讀取蘋果影像
image = cv2.imread('apple.jpg')
image = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)

# 生成所有遮罩
masks = mask_generator.generate(image)

# 分析每個遮罩，找出可能的缺陷區域
defects = []
for mask in masks:
    area = mask['area']
    bbox = mask['bbox']

    # 提取遮罩區域的顏色特徵
    segmentation = mask['segmentation']
    masked_region = image * segmentation[:, :, None]

    # 計算平均顏色（簡化版 - 實際應用需更複雜的特徵提取）
    mean_color = masked_region[segmentation > 0].mean(axis=0)

    # 判斷是否為缺陷（例如：顏色偏暗或偏綠）
    # 這裡使用簡單的閾值，實際應用建議使用機器學習分類器
    if mean_color[0] < 100 and mean_color[1] < 80:  # 褐色病斑
        defects.append({
            'mask': segmentation,
            'area': area,
            'bbox': bbox,
            'type': 'brown_spot'
        })
    elif mean_color[1] > mean_color[0] * 1.5:  # 綠色未熟區域
        defects.append({
            'mask': segmentation,
            'area': area,
            'bbox': bbox,
            'type': 'unripe'
        })

# 計算品質等級
total_area = image.shape[0] * image.shape[1]
defect_area = sum([d['area'] for d in defects])
defect_ratio = defect_area / total_area

if defect_ratio < 0.05:
    quality = "A級（優質）"
elif defect_ratio < 0.15:
    quality = "B級（良好）"
else:
    quality = "C級（瑕疵）"

print(f"檢測到 {len(defects)} 個缺陷區域")
print(f"缺陷佔比: {defect_ratio*100:.2f}%")
print(f"品質等級: {quality}")

# 視覺化結果
import matplotlib.pyplot as plt
fig, axes = plt.subplots(1, 2, figsize=(15, 7))

# 原圖
axes[0].imshow(image)
axes[0].set_title('原始影像')
axes[0].axis('off')

# 缺陷標註
axes[1].imshow(image)
for defect in defects:
    mask = defect['mask']
    color = [1, 0, 0] if defect['type'] == 'brown_spot' else [1, 1, 0]
    axes[1].imshow(np.dstack([mask*color[0], mask*color[1], mask*color[2]]), alpha=0.6)
axes[1].set_title(f'缺陷檢測結果 - {quality}')
axes[1].axis('off')

plt.tight_layout()
plt.savefig('apple_quality_result.jpg', dpi=150, bbox_inches='tight')
plt.show()

🔧 進階技巧與最佳實踐

💡 提高分割精度的技巧

  • 多點提示：使用多個正面點和負面點可以更精確地控制分割範圍
  • 結合框選：點擊 + 邊界框的組合通常效果最好
  • 迭代細化：使用前一次的分割結果作為下一次的提示
  • 調整參數：SamAutomaticMaskGenerator 有豐富的參數可調整
  • 後處理：使用形態學操作（膨脹、腐蝕）改善遮罩邊緣

⚡ 性能優化建議

  • 使用 GPU：啟用 CUDA 可將速度提升 10-50 倍
  • 批次處理：一次設定影像，多次預測可減少重複計算
  • 縮小影像：將高解析度影像縮小到 1024px 可加快速度且不顯著影響精度
  • 選擇合適模型：ViT-B 比 ViT-H 快 3-4 倍，精度僅略降
  • 混合精度：使用 FP16 可減少顯存佔用並加速推理

⚠️ 常見問題與限制

  • 小物體分割：極小物體（< 20px）可能被忽略，建議提高影像解析度
  • 邊緣模糊：對於邊界不清晰的物體（如透明物），分割可能不準確
  • 語義理解有限：SAM 不進行分類，無法區分「蘋果」和「番茄」，需配合其他模型
  • 顯存需求：ViT-H 模型需要至少 6GB 顯存（建議 8GB+）
  • 影片處理：長影片處理需要大量顯存，建議分段處理

🔗 與其他模型結合

SAM + YOLO = 完美組合

將物件偵測模型（如 YOLOv8）與 SAM 結合，可實現：

  1. YOLO 偵測物體位置和類別
  2. 將 YOLO 的 bounding box 作為 SAM 的提示
  3. SAM 生成精確的像素級遮罩
  4. 得到帶有類別標籤的精準分割結果
# YOLO + SAM 範例
from ultralytics import YOLO
import numpy as np

# 1. 使用 YOLO 偵測物體
yolo_model = YOLO('yolov8n.pt')
results = yolo_model(image)

# 2. 對每個偵測結果使用 SAM 分割
predictor.set_image(image)

for result in results:
    boxes = result.boxes.xyxy.cpu().numpy()  # 邊界框
    classes = result.boxes.cls.cpu().numpy()  # 類別

    for box, cls in zip(boxes, classes):
        # 使用 YOLO 的框作為 SAM 的提示
        masks, scores, _ = predictor.predict(
            box=box[None, :],
            multimask_output=False
        )

        # 現在我們有了精確的遮罩和類別標籤
        print(f"類別: {yolo_model.names[int(cls)]}, 分割得分: {scores[0]:.3f}")
