終端機與 VS Code 操作新手指南

一、什麼是終端機？

終端機（Terminal）是一個用文字指令操作電腦的工具，雖然沒有圖形介面，但能更快速、精確地執行任務。

名稱 說明
命令提示字元 (CMD) Windows 傳統終端機
PowerShell Windows 新版終端機（功能較強）
Terminal Mac / Linux 的終端機

二、開啟終端機的方式

方法 1：Windows 搜尋

  1. 按下 Win 鍵
  2. 輸入 cmd 或 powershell
  3. 按 Enter 開啟

方法 2：在資料夾中開啟

  1. 開啟檔案總管，進入目標資料夾
  2. 在路徑列輸入 cmd 後按 Enter
  3. 終端機會直接在該資料夾開啟

方法 3：VS Code 內建終端機（推薦）

  1. 開啟 VS Code
  2. 按下 Ctrl + ` (數字 1 左邊的按鍵)
  3. 或從選單：檢視 → 終端機

三、終端機基本指令

目錄操作

指令 說明 範例
cd 切換目錄 cd D:\Course
cd .. 回上一層 cd ..
dir 列出目錄內容 (Windows) dir
ls 列出目錄內容 (Mac/Linux) ls
mkdir 建立資料夾 mkdir my_folder

切換磁碟機 (Windows)

# 切換到 D 槽
D:

# 然後切換目錄
cd Course\Smart_Agri_Course

清除畫面

cls      # Windows
clear    # Mac/Linux

四、Python 相關指令

確認 Python 版本

python --version

建立虛擬環境

# 建立名為 venv 的虛擬環境
python -m venv venv

啟動虛擬環境

# Windows
venv\Scripts\activate

# Mac/Linux
source venv/bin/activate

啟動成功後，終端機前面會出現 (venv) 標示：

(venv) D:\Course\Smart_Agri_Course>

離開虛擬環境

deactivate

安裝套件

# 安裝單一套件
pip install flask

# 從 requirements.txt 安裝
pip install -r requirements.txt

# 從 .whl 檔案安裝
pip install GDAL-3.3.0-cp39-cp39-win_amd64.whl

查看已安裝套件

pip list

執行 Python 程式

python my_script.py

五、VS Code 基本操作

安裝 VS Code

  1. 下載：https://code.visualstudio.com/
  2. 安裝時勾選「Add to PATH」

開啟資料夾

  1. 檔案 → 開啟資料夾
  2. 選擇 D:\Course\Smart_Agri_Course
  3. 左側會顯示整個專案結構

必裝擴充功能

擴充功能 用途 安裝方式
Python Python 開發必備 搜尋 "Python"
Live Server 網頁即時預覽 搜尋 "Live Server"
Chinese (Traditional) 繁體中文介面 搜尋 "Chinese"

安裝步驟：
1. 按下 Ctrl + Shift + X 開啟擴充功能
2. 搜尋擴充功能名稱
3. 點擊「安裝」

常用快捷鍵

快捷鍵 功能
Ctrl + `` 開啟/關閉終端機
Ctrl + S 儲存檔案
Ctrl + Shift + S 另存新檔
Ctrl + P 快速開啟檔案
Ctrl + Shift + P 開啟命令面板
Ctrl + B 顯示/隱藏側邊欄
F5 執行程式（需設定）
Ctrl + F 搜尋
Ctrl + H 搜尋並取代

執行 Python 程式

方法 1：使用終端機
1. 按 Ctrl + ` 開啟終端機
2. 輸入 python 檔案名稱.py

方法 2：右鍵執行
1. 在 .py 檔案上右鍵
2. 選擇「在終端機中執行 Python 檔案」

方法 3：執行按鈕
1. 開啟 .py 檔案
2. 點擊右上角的 ▶ 播放按鈕

選擇 Python 直譯器

  1. 按 Ctrl + Shift + P
  2. 輸入 Python: Select Interpreter
  3. 選擇虛擬環境中的 Python（顯示 venv 路徑）

六、Live Server 使用（網頁開發）

啟動 Live Server

  1. 開啟 HTML 檔案
  2. 右鍵 → 「Open with Live Server」
  3. 或點擊右下角的「Go Live」

特點

  • 儲存檔案後自動重新整理瀏覽器
  • 適合 HTML/CSS/JavaScript 開發
  • WebGIS Leaflet 課程會用到

七、常見問題

Q1: 'python' 不是內部或外部命令

原因：Python 未加入系統 PATH

解決：
1. 重新安裝 Python，勾選「Add Python to PATH」
2. 或手動加入環境變數

Q2: 終端機顯示亂碼

解決：

chcp 65001

Q3: VS Code 終端機無法啟動虛擬環境

原因：PowerShell 執行原則限制

解決：

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Q4: pip install 出現紅字錯誤

常見原因：
- 網路問題 → 換網路或使用鏡像源
- 權限問題 → 加上 --user
- 版本不相容 → 確認 Python 版本

Q5: VS Code 沒有偵測到 Python

  1. 確認已安裝 Python 擴充功能
  2. 按 Ctrl + Shift + P → Python: Select Interpreter
  3. 選擇正確的 Python 路徑

八、實用技巧

Tab 自動補全

輸入部分檔名後按 Tab 鍵，終端機會自動補全：

cd Cour[Tab]  →  cd Course

上下鍵歷史指令

按 ↑ ↓ 可以瀏覽之前輸入過的指令

複製貼上

  • CMD：選取文字後按 Enter 複製，右鍵貼上
  • PowerShell / VS Code 終端機：Ctrl + C 複製，Ctrl + V 貼上

中斷執行中的程式

按 Ctrl + C 可以中斷正在執行的程式
