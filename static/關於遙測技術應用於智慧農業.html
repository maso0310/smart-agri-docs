關於遙測技術應用於智慧農業

遙測（Remote Sensing）是指不直接接觸目標物體，透過感測器從遠距離收集資訊的技術。在智慧農業中，遙測技術能提供大面積、即時的農地監測，協助農民做出更精準的決策。

一、什麼是遙測技術

基本原理

遙測技術的核心是利用電磁波與地表物體的交互作用來獲取資訊：

  1. 太陽輻射照射地表
  2. 不同物體吸收、反射不同波長的電磁波
  3. 感測器接收反射或發射的電磁波
  4. 經過處理分析，獲得地表資訊

遙測平台分類

平台類型 高度 特點 應用場景
衛星遙測 200-36000 km 覆蓋範圍大、定期重訪 大區域監測、氣候分析
航空遙測 1-10 km 解析度高、可彈性規劃 區域調查、專案測量
無人機遙測 50-500 m 機動性強、成本低 農場巡檢、精準農業
地面遙測 0-50 m 精度最高、範圍小 樣區調查、設備校正

二、電磁波譜與農業應用

常用波段

波段 波長範圍 農業應用
可見光（RGB） 400-700 nm 作物外觀、病蟲害辨識
近紅外線（NIR） 700-1100 nm 植物健康、生物量估算
短波紅外線（SWIR） 1100-2500 nm 水分含量、土壤特性
熱紅外線（TIR） 8000-14000 nm 作物蒸散、灌溉管理
微波（雷達） 1 mm - 1 m 土壤濕度、穿透雲層

植被光譜特性

健康植物的光譜反射特性：

  • 藍光（450 nm）：被葉綠素強烈吸收
  • 綠光（550 nm）：反射較多，所以植物呈綠色
  • 紅光（650 nm）：被葉綠素強烈吸收
  • 近紅外（750-1300 nm）：細胞結構強烈反射
重要觀念：健康植物在紅光波段反射低（被吸收）、近紅外波段反射高；生病或缺水的植物這個差異會縮小。

三、植被指數

NDVI - 常態化差異植生指數

最常用的植被指數，反映植物健康狀態：

NDVI = (NIR - Red) / (NIR + Red)

其中：
NIR = 近紅外波段反射值
Red = 紅光波段反射值
NDVI 值 代表意義 地表狀態
-1.0 ~ 0 非植被 水體、裸土、人造物
0 ~ 0.2 稀疏植被 沙漠、裸露地
0.2 ~ 0.4 中等植被 草地、灌木
0.4 ~ 0.6 茂密植被 農作物、一般森林
0.6 ~ 1.0 非常茂密 熱帶雨林、健康作物

其他常用植被指數

指數 全名 公式 用途
EVI 增強型植被指數 2.5 × (NIR-Red)/(NIR+6×Red-7.5×Blue+1) 高植被覆蓋區域
NDWI 水分指數 (NIR - SWIR) / (NIR + SWIR) 植物水分含量
SAVI 土壤調整植被指數 (NIR-Red)×(1+L)/(NIR+Red+L) 稀疏植被區
LAI 葉面積指數 由多波段推算 生物量估算
GNDVI 綠色植被指數 (NIR - Green) / (NIR + Green) 葉綠素含量

六、農業應用案例

1. 作物生長監測

利用時序 NDVI 追蹤作物整個生長週期：

  • 播種期：NDVI 低（裸土）
  • 營養生長期：NDVI 快速上升
  • 成熟期：NDVI 達到高峰
  • 收穫期：NDVI 下降

2. 病蟲害偵測

病害會影響植物光譜特性：

  • 葉綠素減少 → 紅光反射增加
  • 細胞結構改變 → 近紅外反射降低
  • 表現為 NDVI 局部異常降低

3. 灌溉管理

使用熱紅外遙測監測作物水分狀態：

  • 缺水作物蒸散減少 → 溫度上升
  • 建立作物水分逆境指數（CWSI）
  • 指導精準灌溉決策

4. 產量預估

5. 變量施肥

根據 NDVI 分區圖制定施肥處方：

NDVI 分區 作物狀態 氮肥建議
高 NDVI 區 生長旺盛 減少用量
中 NDVI 區 正常生長 標準用量
低 NDVI 區 生長受限 增加用量或調查原因

七、Python 遙測分析範例

計算 NDVI

import numpy as np
import rasterio
from rasterio.plot import show
import matplotlib.pyplot as plt

# 讀取多光譜影像
with rasterio.open('multispectral.tif') as src:
    # 假設 Band 4 是紅光，Band 5 是近紅外
    red = src.read(4).astype(float)
    nir = src.read(5).astype(float)

# 計算 NDVI
# 避免除以零
np.seterr(divide='ignore', invalid='ignore')
ndvi = (nir - red) / (nir + red)

# 處理無效值
ndvi = np.where(np.isfinite(ndvi), ndvi, 0)

# 視覺化
plt.figure(figsize=(10, 8))
plt.imshow(ndvi, cmap='RdYlGn', vmin=-1, vmax=1)
plt.colorbar(label='NDVI')
plt.title('NDVI Map')
plt.show()

    .filterBounds(farm) \

    .filter(ee.Filter.lt('CLOUDY_PIXEL_PERCENTAGE', 20))

# 計算 NDVI 函數
def add_ndvi(image):
    ndvi = image.normalizedDifference(['B8', 'B4']).rename('NDVI')
    return image.addBands(ndvi)

# 套用函數

八、挑戰與限制

技術挑戰

  • 雲層遮蔽：光學遙測無法穿透雲層
  • 大氣校正：需移除大氣影響
  • 混合像元：一個像元可能包含多種地物
  • 時間解析度：重訪週期可能錯過關鍵時期

應用限制

  • 需要地面真值資料驗證
  • 不同作物需要不同的分析模型
  • 初期投資和學習成本
  • 資料處理需要專業知識

九、未來趨勢

  • 小衛星星群：更高時間解析度
  • AI 影像分析：自動化病蟲害辨識
  • 多源資料融合：結合衛星、無人機、地面感測器
  • 即時決策系統：從監測到行動的自動化
  • 雲端運算普及：降低分析門檻
