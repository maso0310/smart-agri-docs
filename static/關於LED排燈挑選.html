關於 LED 排燈挑選

什麼是 LED 排燈？

LED 排燈（LED Strip Light） 是將多顆 LED 焊接在柔軟的電路板（FPC）上，形成可彎曲、可裁剪的燈條。常見於裝飾照明、背光、植物補光等應用。

LED 排燈結構示意：
┌─────────────────────────────────────────────────────┐
│  ●──●──●──●──●──●──●──●──●──●──●──●──●──●──●──●     │
│  ↑     ↑     ↑     ↑     ↑     ↑     ↑     ↑       │
│ LED   LED   LED   LED   LED   LED   LED   LED      │
│                                                     │
│  ═══════════════════════════════════════════════   │
│              柔性電路板（FPC）                       │
└─────────────────────────────────────────────────────┘
        ↑
      可裁剪線（通常每 3 顆為一單位）

LED 排燈的分類

依照控制方式分類

1. 單色 LED 排燈（最簡單）

特點：
┌────────────────────────────────────┐
│ • 整條只有一種顏色                 │
│ • 只需控制電源開關或亮度           │
│ • 接線最簡單（正負極兩條線）       │
│ • 價格最便宜                       │
└────────────────────────────────────┘

常見顏色：
🔴 紅色    - 波長 620-630nm
🟢 綠色    - 波長 520-530nm
🔵 藍色    - 波長 460-470nm
⚪ 白色    - 色溫 3000K-6500K
🟡 暖白色  - 色溫 2700-3200K

控制方式：
Arduino ──[PWM]──→ MOSFET ──→ LED 排燈
                              （調整亮度）

2. RGB LED 排燈（可混色）

特點：
┌────────────────────────────────────┐
│ • 每顆 LED 包含紅、綠、藍三色      │
│ • 可混合出各種顏色                 │
│ • 需要 4 條線（R、G、B、共用極）   │
│ • 整條燈同時變色                   │
└────────────────────────────────────┘

接線方式：
┌─────────────────┐
│   RGB 排燈      │
│                 │
│  R ─── 紅色控制 │
│  G ─── 綠色控制 │
│  B ─── 藍色控制 │
│  + ─── 12V 電源 │ （共陽極）
│  或              │
│  - ─── GND      │ （共陰極）
└─────────────────┘

顏色混合原理：
🔴 紅 + 🟢 綠 = 🟡 黃
🔴 紅 + 🔵 藍 = 🟣 紫
🟢 綠 + 🔵 藍 = 🔵 青
🔴 + 🟢 + 🔵  = ⚪ 白

3. 可定址 LED 排燈（獨立控制）⭐

特點：
┌────────────────────────────────────┐
│ • 每顆 LED 可獨立控制顏色與亮度    │
│ • 可做跑馬燈、彩虹、動態效果       │
│ • 只需 3 條線（VCC、GND、DATA）    │
│ • 價格較高但效果最炫               │
└────────────────────────────────────┘

資料傳輸方式：
Arduino ──[DATA]──→ LED1 ──→ LED2 ──→ LED3 ──→ ...
                     ↓        ↓        ↓
                   顏色1    顏色2    顏色3

每顆 LED 內建控制晶片，接收並轉發資料

電源計算

單顆 LED 功耗

WS2812B 單顆 LED：
┌──────────────────────────────────┐
│ 紅色全亮：約 20mA                │
│ 綠色全亮：約 20mA                │
│ 藍色全亮：約 20mA                │
│ 白色全亮：約 60mA（RGB 同時亮）  │
└──────────────────────────────────┘

電源需求計算公式

總電流 = LED 數量 × 每顆電流 × 使用比例

範例：60 LED/m 的燈條，長度 2 公尺

LED 數量 = 60 × 2 = 120 顆
最大電流 = 120 × 60mA = 7200mA = 7.2A

建議電源 = 7.2A × 1.2（留餘量）≈ 9A

所以需要 5V 9A 的電源供應器

常見配置建議

燈條長度 LED 數量(60/m) 最大電流 建議電源
0.5m 30 顆 1.8A 5V 2A
1m 60 顆 3.6A 5V 5A
2m 120 顆 7.2A 5V 10A
5m 300 顆 18A 5V 20A

⚠️ 注意： 超過 1 公尺建議從兩端供電，避免壓降！

資料線注意事項

建議在資料線上串聯一個 300-500Ω 電阻：

Arduino D6 ──[330Ω]──→ WS2812B DIN

原因：
• 保護 Arduino 腳位
• 減少訊號反射
• 提高穩定性

Arduino 程式範例

安裝函式庫

推薦使用 FastLED 或 Adafruit NeoPixel：

  1. 工具 → 管理程式庫...
  2. 搜尋 FastLED 或 NeoPixel
  3. 安裝

範例 1：基本點亮（FastLED）

#include <FastLED.h>

#define LED_PIN     6
#define NUM_LEDS    30
#define BRIGHTNESS  128

CRGB leds[NUM_LEDS];

void setup() {
  FastLED.addLeds<WS2812B, LED_PIN, GRB>(leds, NUM_LEDS);
  FastLED.setBrightness(BRIGHTNESS);
}

void loop() {
  // 全部設為紅色
  fill_solid(leds, NUM_LEDS, CRGB::Red);
  FastLED.show();
  delay(1000);

  // 全部設為綠色
  fill_solid(leds, NUM_LEDS, CRGB::Green);
  FastLED.show();
  delay(1000);

  // 全部設為藍色
  fill_solid(leds, NUM_LEDS, CRGB::Blue);
  FastLED.show();
  delay(1000);
}

範例 2：彩虹效果

#include <FastLED.h>

#define LED_PIN     6
#define NUM_LEDS    30
#define BRIGHTNESS  100

CRGB leds[NUM_LEDS];
uint8_t hue = 0;

void setup() {
  FastLED.addLeds<WS2812B, LED_PIN, GRB>(leds, NUM_LEDS);
  FastLED.setBrightness(BRIGHTNESS);
}

void loop() {
  // 彩虹效果
  fill_rainbow(leds, NUM_LEDS, hue, 7);
  FastLED.show();

  hue++;  // 顏色偏移
  delay(20);
}

範例 3：跑馬燈效果

#include <FastLED.h>

#define LED_PIN     6
#define NUM_LEDS    30

CRGB leds[NUM_LEDS];

void setup() {
  FastLED.addLeds<WS2812B, LED_PIN, GRB>(leds, NUM_LEDS);
  FastLED.setBrightness(100);
}

void loop() {
  // 跑馬燈
  for (int i = 0; i < NUM_LEDS; i++) {
    leds[i] = CRGB::Red;
    FastLED.show();
    delay(50);
    leds[i] = CRGB::Black;
  }
}

常見問題

Q1：燈條閃爍或顏色錯誤？

可能原因：
1. 電源不足 → 加大電源供應器
2. 接地不良 → 確認 GND 連接
3. 資料線太長 → 加訊號放大器
4. 顏色順序錯 → 修改程式 GRB/RGB

Q2：燈條只有前幾顆會亮？

可能原因：
1. 某顆 LED 損壞 → 剪掉壞的那段
2. 電源不足 → 從多點供電
3. 焊點脫落 → 重新焊接

Q3：Arduino 供電給 LED 安全嗎？

LED 數量與供電方式：

1-5 顆：可以用 Arduino 5V 腳位
6-10 顆：建議外接 USB 供電
10 顆以上：必須外接電源！

⚠️ Arduino 5V 腳位最大只能提供約 500mA
   10 顆 LED 全白 = 600mA，已經超過了！

Q4：顏色順序怎麼確認？

// 常見顏色順序：
// WS2812B 大多是 GRB
// 有些是 RGB 或 BRG

// FastLED 設定方式：
FastLED.addLeds<WS2812B, PIN, GRB>(leds, NUM);  // 最常見
FastLED.addLeds<WS2812B, PIN, RGB>(leds, NUM);  // 若 GRB 顏色錯
FastLED.addLeds<WS2812B, PIN, BRG>(leds, NUM);  // 其他可能

// 測試方法：設定紅色，看實際亮什麼色
leds[0] = CRGB::Red;  // 應該亮紅色

狀態指示燈

用 LED 排燈顯示溫室狀態：

● 綠色呼吸燈 → 系統正常運作
● 藍色閃爍   → 正在澆水
● 紅色常亮   → 溫度過高警告
● 彩虹跑馬燈 → 展示模式
