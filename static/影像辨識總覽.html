快速開始

步驟一：安裝套件

方法 A：使用 requirements.txt（推薦）

pip install -r requirements.txt

方法 B：手動安裝核心套件

pip install ultralytics opencv-python pillow

這會安裝：

  • ultralytics：YOLOv8 模型框架
  • opencv-python：影像處理
  • pillow：圖片讀寫
首次安裝會自動下載 PyTorch，可能需要幾分鐘時間

步驟二：執行快速展示

物件偵測：

cd 01_Object_Detection
python 01_quick_demo.py

語意分割：

cd 02_Semantic_Segmentation
python 01_quick_demo.py

首次執行會自動下載預訓練模型（約 6MB）。

技術比較

物件偵測 vs 語意分割

特性物件偵測語意分割
輸出邊界框（Bounding Box）像素級遮罩（Mask）
精確度大致位置精確輪廓
速度較快較慢
資源需求較低較高
標註難度簡單（畫框）複雜（描邊）
適用場景找出「有什麼」「在哪裡」計算面積、精確分析

何時選擇哪個？

選擇物件偵測：
├─ 只需要知道物體位置
├─ 需要即時處理
├─ 資源有限（如嵌入式裝置）
└─ 快速開發原型

選擇語意分割：
├─ 需要計算面積/比例
├─ 需要精確的物體邊界
├─ 用於覆蓋率分析
└─ 需要提取物體輪廓

使用的工具：YOLOv8

我們使用 Ultralytics YOLOv8，目前最流行的物件偵測框架之一。

為什麼選擇 YOLOv8？

  1. 易於使用：幾行程式碼就能完成
  2. 速度快：支援即時偵測
  3. 效果好：準確度高
  4. 功能全面：同時支援偵測和分割
  5. 社群活躍：文件完整、更新頻繁

模型版本比較

模型大小速度準確度推薦用途
YOLOv8n6MB最快較低學習、即時偵測
YOLOv8s22MB快中等一般應用
YOLOv8m50MB中等較高平衡選擇
YOLOv8l84MB較慢高重視準確度
YOLOv8x131MB慢最高研究、競賽
建議從 yolov8n 開始，它足夠學習和開發使用。

訓練自己的模型

資料集準備流程

1. 收集圖片
   └─ 拍攝或下載相關圖片

2. 標註資料
   ├─ 物件偵測：使用 LabelImg 畫框
   └─ 語意分割：使用 LabelMe 描邊

3. 整理格式
   └─ 轉換成 YOLO 格式

4. 分割資料
   └─ 80% 訓練、20% 驗證

5. 建立設定檔
   └─ 建立 data.yaml

資料量建議

任務最少建議理想
物件偵測每類 30 張每類 100 張每類 300+ 張
語意分割每類 50 張每類 200 張每類 500+ 張

常見問題

Q1: 需要 GPU 才能訓練嗎？

不需要！CPU 也可以訓練，只是速度較慢。小資料集（100 張以內）用 CPU 訓練完全可行。

Q2: 記憶體不足怎麼辦？

# 減少批次大小
model.train(data='data.yaml', batch=4)

# 減少圖片大小
model.train(data='data.yaml', imgsz=320)

Q3: 模型效果不好怎麼辦？

  1. 增加訓練資料量
  2. 檢查標註品質
  3. 增加訓練輪數
  4. 嘗試更大的模型

Q4: 如何在樹莓派上使用？

YOLOv8 可以在樹莓派上運行：

# 使用最小模型
model = YOLO('yolov8n.pt')

# 降低輸入大小以加速
results = model(frame, imgsz=320)

建議使用 Raspberry Pi 4 或更新版本。
