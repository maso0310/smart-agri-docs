1. 開源地理資料概述

在智慧農業領域，開源地理空間資料提供了豐富的環境資訊，包括土壤特性、衛星影像、氣候資料等。這些資料可用於：

  • 精準農業：根據土壤特性進行差異化管理
  • 作物監測：利用衛星影像追蹤作物生長狀況
  • 災害評估：監測乾旱、洪水等自然災害影響
  • 產量預測：結合多源資料建立預測模型

2. SoilGrids 土壤資料

SoilGrids 是由 ISRIC（國際土壤參考與資訊中心）提供的全球土壤資料系統，提供 250 公尺解析度的土壤特性預測圖。

SoilGrids 2.0 免費REST API

全球土壤屬性預測資料，涵蓋多個深度層次

https://soilgrids.org/

可用的土壤屬性

屬性代碼 說明 單位
soc 土壤有機碳含量 g/kg (dg/kg)
phh2o 土壤 pH 值（水溶液） pH × 10
nitrogen 總氮含量 cg/kg
clay 黏土含量 g/kg
sand 砂土含量 g/kg
silt 粉土含量 g/kg
bdod 土壤容重 cg/cm³
cec 陽離子交換容量 mmol(c)/kg
cfvo 粗礫含量 cm³/dm³
ocd 有機碳密度 hg/m³

深度層次

SoilGrids 提供六個標準深度層的資料：

  • 0-5cm - 表土層
  • 5-15cm - 淺層
  • 15-30cm - 耕作層
  • 30-60cm - 根系層
  • 60-100cm - 深層
  • 100-200cm - 底土層

使用 REST API 取得資料

import requests import json def get_soilgrids_data(lat, lon, properties=None, depths=None): """ 從 SoilGrids API 取得指定位置的土壤資料 參數: lat: 緯度 lon: 經度 properties: 土壤屬性列表，如 ['soc', 'phh2o', 'clay'] depths: 深度列表，如 ['0-5cm', '5-15cm'] """ # API 端點 base_url = "https://rest.isric.org/soilgrids/v2.0/properties/query" # 預設屬性和深度 if properties is None: properties = ['soc', 'phh2o', 'clay', 'sand', 'nitrogen'] if depths is None: depths = ['0-5cm', '5-15cm', '15-30cm'] # 建立查詢參數 params = { 'lon': lon, 'lat': lat, 'property': properties, 'depth': depths, 'value': 'mean' # 可選: mean, Q0.05, Q0.5, Q0.95, uncertainty } # 發送請求 response = requests.get(base_url, params=params) if response.status_code == 200: return response.json() else: raise Exception(f"API 錯誤: {response.status_code}") # 範例：查詢台灣某農田位置的土壤資料 lat, lon = 24.1477, 120.6736 # 台中地區 try: soil_data = get_soilgrids_data(lat, lon) # 解析結果 for layer in soil_data['properties']['layers']: prop_name = layer['name'] print(f"\n土壤屬性: {prop_name}") for depth in layer['depths']: depth_label = depth['label'] mean_value = depth['values']['mean'] print(f" {depth_label}: {mean_value}") except Exception as e: print(f"錯誤: {e}")

下載柵格資料（GeoTIFF）

import requests from pathlib import Path def download_soilgrids_tiff(property_name, depth, bbox, output_path): """ 下載指定區域的 SoilGrids GeoTIFF 資料 參數: property_name: 土壤屬性 (如 'soc', 'phh2o') depth: 深度 (如 '0-5cm') bbox: 邊界框 [west, south, east, north] output_path: 輸出檔案路徑 """ # WCS (Web Coverage Service) 端點 base_url = "https://maps.isric.org/mapserv" # 建立 WCS 請求 params = { 'map': f'/map/{property_name}.map', 'SERVICE': 'WCS', 'VERSION': '2.0.1', 'REQUEST': 'GetCoverage', 'COVERAGEID': f'{property_name}_{depth}_mean', 'FORMAT': 'image/tiff', 'SUBSET': [ f'X({bbox[0]},{bbox[2]})', f'Y({bbox[1]},{bbox[3]})' ], 'SUBSETTINGCRS': 'http://www.opengis.net/def/crs/EPSG/0/4326' } response = requests.get(base_url, params=params, stream=True) if response.status_code == 200: with open(output_path, 'wb') as f: for chunk in response.iter_content(chunk_size=8192): f.write(chunk) print(f"已下載: {output_path}") else: raise Exception(f"下載失敗: {response.status_code}") # 範例：下載台灣中部地區的有機碳資料 bbox = [120.0, 23.5, 121.5, 25.0] # 西、南、東、北 download_soilgrids_tiff('soc', '0-5cm', bbox, 'taiwan_soc_0-5cm.tif')

API 使用限制

SoilGrids REST API 有請求頻率限制。建議：

  • 批次查詢時加入適當延遲（如每秒 1-2 次請求）
  • 大範圍區域建議下載 GeoTIFF 格式進行離線處理
  • 快取已查詢過的資料以減少重複請求

3. Copernicus 哥白尼計畫

Copernicus（哥白尼）是歐盟的地球觀測計畫，提供免費、開放的環境監測資料。對農業應用特別重要的服務包括：

Copernicus Open Access Hub 免費衛星資料

Sentinel 系列衛星原始資料下載平台

https://scihub.copernicus.eu/

Copernicus Climate Data Store (CDS) 免費API

氣候再分析資料、季節預報、歷史氣候資料

https://cds.climate.copernicus.eu/

Copernicus Land Monitoring Service 免費

土地覆蓋/利用、植被指標、水體監測

https://land.copernicus.eu/

主要服務類別

服務 內容 農業應用
大氣監測 (CAMS) 空氣品質、太陽輻射、氣溶膠 光合作用評估、噴藥時機
海洋監測 (CMEMS) 海水溫度、海流、水質 沿海養殖、鹽害預警
土地監測 (CLMS) 植被、土地覆蓋、水體 作物監測、灌溉管理
氣候變遷 (C3S) 氣候再分析、季節預報 長期規劃、災害預警
緊急管理 (EMS) 洪水、火災、乾旱監測 災害評估、保險理賠

使用 Sentinel Hub 取得資料

Sentinel Hub API

雲端處理平台，提供即時衛星影像處理和分析

https://www.sentinel-hub.com/
# 安裝: pip install sentinelhub from sentinelhub import ( SHConfig, BBox, CRS, DataCollection, SentinelHubRequest, MimeType, bbox_to_dimensions ) import numpy as np # 設定認證（需要註冊 Sentinel Hub 帳號） config = SHConfig() config.sh_client_id = 'YOUR_CLIENT_ID' config.sh_client_secret = 'YOUR_CLIENT_SECRET' # 定義感興趣區域（台中農業區） bbox = BBox(bbox=[120.5, 24.0, 120.8, 24.3], crs=CRS.WGS84) resolution = 10 # 10 公尺解析度 size = bbox_to_dimensions(bbox, resolution=resolution) # 定義 NDVI 計算腳本 evalscript = """ //VERSION=3 function setup() { return { input: ["B04", "B08"], output: { bands: 1, sampleType: "FLOAT32" } }; } function evaluatePixel(sample) { let ndvi = (sample.B08 - sample.B04) / (sample.B08 + sample.B04); return [ndvi]; } """ # 建立請求 request = SentinelHubRequest( evalscript=evalscript, input_data=[ SentinelHubRequest.input_data( data_collection=DataCollection.SENTINEL2_L2A, time_interval=('2024-03-01', '2024-03-31'), maxcc=0.3 # 雲覆蓋率 < 30% ) ], responses=[SentinelHubRequest.output_response('default', MimeType.TIFF)], bbox=bbox, size=size, config=config ) # 取得 NDVI 影像 ndvi_image = request.get_data()[0] print(f"NDVI 影像尺寸: {ndvi_image.shape}") print(f"NDVI 範圍: {np.nanmin(ndvi_image):.2f} ~ {np.nanmax(ndvi_image):.2f}")

使用 Google Earth Engine

免費存取大量資料

Google Earth Engine (GEE) 提供免費存取 Sentinel、Landsat 等衛星資料，並支援雲端運算，適合大規模分析。

# 安裝: pip install earthengine-api # 首次使用需要認證: earthengine authenticate import ee # 初始化 ee.Initialize() # 定義研究區域（台灣中部農業區） roi = ee.Geometry.Rectangle([120.5, 24.0, 120.8, 24.3]) # 載入 Sentinel-2 影像集 s2 = ee.ImageCollection('COPERNICUS/S2_SR_HARMONIZED') \ .filterBounds(roi) \ .filterDate('2024-03-01', '2024-06-30') \ .filter(ee.Filter.lt('CLOUDY_PIXEL_PERCENTAGE', 20)) print(f"找到 {s2.size().getInfo()} 張影像") # 計算 NDVI def add_ndvi(image): ndvi = image.normalizedDifference(['B8', 'B4']).rename('NDVI') return image.addBands(ndvi) s2_ndvi = s2.map(add_ndvi) # 取得時間序列平均 NDVI mean_ndvi = s2_ndvi.select('NDVI').mean() # 匯出到 Google Drive task = ee.batch.Export.image.toDrive( image=mean_ndvi, description='Taiwan_NDVI_2024', folder='GEE_Exports', region=roi, scale=10, maxPixels=1e9 ) task.start() print("匯出任務已啟動")

import requests import pandas as pd def get_nasa_power_data(lat, lon, start_date, end_date, parameters=None): """ 從 NASA POWER API 取得農業氣象資料 參數: lat, lon: 座標 start_date, end_date: 日期 (YYYYMMDD 格式) parameters: 氣象參數列表 """ if parameters is None: parameters = [ 'T2M', # 2公尺氣溫 'T2M_MAX', # 最高溫 'T2M_MIN', # 最低溫 'PRECTOTCORR', # 校正降水量 'RH2M', # 相對濕度 'ALLSKY_SFC_SW_DWN', # 日射量 'WS2M', # 2公尺風速 'GWETROOT' # 根區土壤濕度 ] base_url = "https://power.larc.nasa.gov/api/temporal/daily/point" params = { 'parameters': ','.join(parameters), 'community': 'AG', # 農業社群 'longitude': lon, 'latitude': lat, 'start': start_date, 'end': end_date, 'format': 'JSON' } response = requests.get(base_url, params=params) data = response.json() # 轉換為 DataFrame df = pd.DataFrame(data['properties']['parameter']) df.index = pd.to_datetime(df.index, format='%Y%m%d') return df # 範例：取得台中地區過去一年的氣象資料 lat, lon = 24.1477, 120.6736 df = get_nasa_power_data(lat, lon, '20230101', '20231231') print("資料範圍:", df.index.min(), "~", df.index.max()) print("\n統計摘要:") print(df.describe())

建立多源資料整合類別

if response.status_code == 200: raw_data = response.json() soil_data = self._parse_soilgrids(raw_data) self.cache[cache_key] = soil_data return soil_data except Exception as e: print(f"SoilGrids 查詢失敗: {e}") return {} def _parse_soilgrids(self, raw_data: Dict) -> Dict: """解析 SoilGrids 回應""" result = {} for layer in raw_data.get('properties', {}).get('layers', []): prop_name = layer['name'] result[prop_name] = {} for depth in layer.get('depths', []): depth_label = depth['label'] mean_value = depth['values'].get('mean') result[prop_name][depth_label] = mean_value return result def get_weather_data(self, lat: float, lon: float, start_date: str, end_date: str) -> pd.DataFrame: """取得氣象資料""" params = { 'parameters': 'T2M,T2M_MAX,T2M_MIN,PRECTOTCORR,RH2M,ALLSKY_SFC_SW_DWN,WS2M', response.status_code == 200: data = response.json() df = pd.DataFrame(data['properties']['parameter']) df.index = pd.to_datetime(df.index, format='%Y%m%d') return df except Exception as e: print(f"NASA POWER 查詢失敗: {e}") return pd.DataFrame() def get_complete_profile(self, lat: float, lon: float, weather_start: str, weather_end: str) -> LocationData: """取得完整的位置環境資料""" print(f"正在查詢位置 ({lat}, {lon})...") # 取得土壤資料 print(" - 取得土壤資料...") soil = self.get_soil_data(lat, lon) time.sleep(0.5) # 避免請求過快 # 取得氣象資料 print(" - 取得氣象資料...") weather = self.get_weather_data(lat, lon, weather_start, weather_end) return LocationData( latitude=lat, longitude=lon, soil=soil, weather=weather ) def generate_report(self, data: LocationData) -> str: """生成環境報告""" report = [] report.append(f"=== 農地環境報告 ===") report.append(f"位置: ({data.latitude}, {data.longitude})") report.append("") # 土壤摘要 if data.soil: report.append("【土壤特性】") if 'phh2o' in data.soil: ph = data.soil['phh2o'].get('0-5cm', 0) / 10 7. 農業應用案例

案例 1：適地適種分析

根據土壤特性和氣候條件，評估特定作物的種植適宜性。

案例 2：NDVI 時間序列分析

import matplotlib.pyplot as plt import numpy as np def analyze_ndvi_timeseries(ndvi_data: np.ndarray, dates: list): """ 分析 NDVI 時間序列 參數: ndvi_data: NDVI 值陣列 dates: 對應日期列表 """ # 計算統計值 stats = { 'mean': np.nanmean(ndvi_data), 'max': np.nanmax(ndvi_data), 'min': np.nanmin(ndvi_data), 'std': np.nanstd(ndvi_data) } # 找出生長季節 threshold = 0.4 # NDVI > 0.4 視為健康植被 growing_mask = ndvi_data > threshold growing_days = np.sum(growing_mask) # 偵測異常（可能的病蟲害或乾旱） anomaly_threshold = stats['mean'] - 2 * stats['std'] anomalies = np.where(ndvi_data < anomaly_threshold)[0] # 繪製圖表 fig, ax = plt.subplots(figsize=(12, 5)) ax.plot(dates, ndvi_data, 'g-', linewidth=2, label='NDVI') ax.axhline(y=stats['mean'], color='blue', linestyle='--', alpha=0.5, label='平均值') ax.axhline(y=threshold, color='orange', linestyle=':', alpha=0.5, label='健康閾值') # 標記異常點 if len(anomalies) > 0: ax.scatter([dates[i] for i in anomalies], ndvi_data[anomalies], color='red', s=100, zorder=5, label='異常點') ax.set_xlabel('日期') ax.set_ylabel('NDVI') ax.set_title('農田 NDVI 時間序列分析') ax.legend() ax.grid(True, alpha=0.3) plt.tight_layout() plt.savefig('ndvi_analysis.png', dpi=150) return { 'statistics': stats, 'growing_days': growing_days, 'anomaly_dates': [dates[i] for i in anomalies] }

class IrrigationAdvisor: """智慧灌溉建議系統""" def __init__(self, crop_type: str = 'general'): self.crop_type = crop_type # 作物水分需求係數 (Kc) self.kc_values = { 'rice': 1.2, 'vegetables': 1.0, 'fruits': 0.85, 'general': 1.0 } def calculate_et(self, temp: float, humidity: float, solar_rad: float, wind_speed: float) -> float: """ 計算作物蒸發散量 (簡化 FAO Penman-Monteith) 回傳: mm/day """ # 參考蒸發散量（簡化公式） et0 = 0.0023 * (temp + 17.8) * np.sqrt(solar_rad) * (1 - humidity/100) * 0.5 # 作物蒸發散量 kc = self.kc_values.get(self.crop_type, 1.0) etc = et0 * kc return max(0, etc) def get_recommendation(self, soil_moisture: float, weather_forecast: pd.DataFrame) -> Dict: """ 取得灌溉建議 參數: soil_moisture: 當前土壤含水量 (0-1) weather_forecast: 未來幾天的天氣預報 """ # 計算預期蒸發散量 total_et = 0 total_rain = 0 for _, row in weather_forecast.iterrows(): et = self.calculate_et( row.get('T2M', 25), row.get('RH2M', 70), row.get('ALLSKY_SFC_SW_DWN', 15), row.get('WS2M', 2) ) total_et += et total_rain += row.get('PRECTOTCORR', 0) # 水分平衡 water_balance = total_rain - total_et # 決策邏輯 if soil_moisture > 0.7: action = "不需灌溉" urgency = "低" amount = 0 elif soil_moisture > 0.4 and water_balance > 0: action = "暫緩灌溉" urgency = "低" amount = 0 elif soil_moisture > 0.4: action = "輕度灌溉" urgency = "中" amount = abs(water_balance) * 0.5 else: action = "立即灌溉" urgency = "高" amount = abs(water_balance) + (0.6 - soil_moisture) * 50 return { 'action': action, 'urgency': urgency, 'recommended_amount_mm': round(amount, 1), 'expected_et_mm': round(total_et, 1), 'expected_rain_mm': round(total_rain, 1), 'water_balance_mm': round(water_balance, 1) } # 使用範例 advisor = IrrigationAdvisor(crop_type='vegetables') # 假設當前土壤濕度為 45% soil_moisture = 0.45 # 使用氣象資料 if not profile.weather.empty: forecast = profile.weather.head(3) # 未來 3 天 rec = advisor.get_recommendation(soil_moisture, forecast) print("=== 灌溉建議 ===") print(f"建議動作: {rec['action']}") print(f"緊急程度: {rec['urgency']}") print(f"建議灌溉量: {rec['recommended_amount_mm']} mm") print(f"預期蒸發散: {rec['expected_et_mm']} mm") print(f"預期降雨: {rec['expected_rain_mm']} mm")

資料整合最佳實踐

  • 資料快取：對於不常變動的資料（如土壤），建立本地快取減少 API 請求
  • 錯誤處理：API 可能不穩定，確保有適當的例外處理和重試機制
  • 資料驗證：檢查回傳資料的合理性，過濾異常值
  • 空間對齊：不同資料來源的空間解析度可能不同，需要適當內插或聚合
  • 時間同步：確保比較的資料在時間上對應正確
