1. 基礎概念

機器學習 Machine Learning, ML

讓電腦從資料中自動學習規律，而不需要人類明確編寫每一條規則的技術。

就像教小孩認識水果，你不用告訴他「紅色圓形的是蘋果」這種規則，只要給他看很多蘋果的照片，他自己就會學會辨認。機器學習就是讓電腦用同樣的方式學習。
模型 Model

從資料中學習到的「規律」或「知識」的數學表示形式。

模型就像是一個「經驗老到的專家」。這個專家看過很多案例後，累積了判斷的經驗。當你問他問題時，他會根據過去的經驗給你答案。
訓練好的蘋果品質辨識模型，就像一個看過幾萬顆蘋果的品管專家，能快速判斷蘋果好不好。
訓練 Training

讓模型從資料中學習規律的過程。

就像學生在學校上課、做練習題。電腦會反覆看資料、做預測、檢查答案、修正自己，直到學會為止。
推論 / 預測 Inference / Prediction

使用訓練好的模型來處理新資料，得出結果的過程。

學生考試時，用學到的知識來解答沒見過的題目。模型用學到的規律來判斷新的資料。
特徵 Feature

用來描述資料的各種屬性或特性，是模型學習的依據。

就像你描述一個人時會說「身高180、體重70、黑髮」，這些就是特徵。對於圖片來說，每個像素的顏色值都是特徵。
判斷蘋果品質時，顏色、大小、形狀、有無斑點都是特徵。
標籤 Label

資料的「正確答案」，告訴模型這筆資料應該被分類為什麼。

就像考卷的標準答案。我們告訴電腦「這張圖是蘋果」、「這張圖是橘子」，這些就是標籤。

監督式學習 Supervised Learning

訓練資料有標籤（正確答案）的學習方式。

就像有老師在旁邊指導的學習。學生做完題目，老師會告訴他對不對，錯了要怎麼改。
給電腦看 1000 張標記好「健康/生病」的蘋果圖片，讓它學會判斷。
非監督式學習 Unsupervised Learning

訓練資料沒有標籤，讓模型自己發現資料中的規律。

就像把一堆東西丟給小孩，讓他自己分類。他可能會把紅色的放一堆、圓形的放一堆，自己找出分類方式。
給電腦 1000 張水果圖片（不告訴它是什麼水果），讓它自己把相似的分在一起。
強化學習 Reinforcement Learning

透過與環境互動，根據獎勵或懲罰來學習最佳策略。

就像訓練小狗。做對了給零食（獎勵），做錯了不給（懲罰）。久了小狗就會學會什麼行為能得到獎勵。
訓練 AI 玩遊戲，贏了加分、輸了扣分，讓它自己學會怎麼玩得更好。

2. 資料相關術語

訓練集 Training Set

用來訓練模型的資料集，模型會從這些資料中學習。

就像學生的課本和練習題。這些是用來學習的材料。
驗證集 Validation Set

在訓練過程中用來調整模型的資料，幫助選擇最佳設定。

就像模擬考。用來檢查學習進度，看哪種讀書方法效果最好，但不是真正的考試。
測試集 Test Set

訓練完成後，用來評估模型最終表現的資料。模型在訓練過程中從未見過這些資料。

就像正式考試。用全新的題目來測試真正的實力，這些題目學生從沒看過。

資料集分割的比喻

想像準備大考：

  • 訓練集 (70-80%)：課本和習題 → 用來學習知識
  • 驗證集 (10-15%)：模擬考 → 調整讀書策略
  • 測試集 (10-15%)：正式考試 → 評估真實能力
資料增強 Data Augmentation

透過對原始資料進行變換（旋轉、翻轉、縮放等），人工產生更多訓練資料。

就像把一張蘋果照片旋轉、放大、調亮度，變成好幾張不同的照片。這樣電腦看到的「蘋果樣本」就變多了，學得更全面。
一張蘋果圖片 → 水平翻轉、旋轉15度、調整亮度 → 變成4張訓練圖片
正規化 / 標準化 Normalization / Standardization

將資料調整到統一的範圍或分布，讓模型更容易學習。

就像把不同單位統一。如果身高用公分、體重用公斤、年齡用年，數值差很大。把它們都調整到 0~1 之間，模型比較好處理。
正規化：x_new = (x - min) / (max - min) → 結果範圍 0~1
標準化：x_new = (x - mean) / std → 平均值=0，標準差=1
類別不平衡 Class Imbalance

訓練資料中，各類別的數量差異很大。

就像考試題目 100 題有 95 題是選擇題，只有 5 題是問答題。學生會專注練選擇題而忽略問答題。模型也一樣，會偏向多數類別。
1000 張健康蘋果 + 50 張病蟲害蘋果 = 模型可能會傾向都判斷為健康
批次 Batch

每次訓練時，一起送入模型的資料數量。

就像老師改作業。不是每寫完一題就給老師改，而是累積一疊（比如 32 份）一起交。這樣效率更高。
批次大小 Batch Size

每個批次包含的資料筆數。

一疊作業有幾份。常見的批次大小有 16、32、64、128。
批次大小 優點 缺點
小 (8-16) 記憶體需求低、可能找到更好的解 訓練較慢、不穩定
大 (64-256) 訓練快、較穩定 記憶體需求高、可能陷入局部最佳解

3. 訓練過程術語

Epoch（訓練週期） Epoch

模型完整看過訓練集一次，稱為一個 epoch。

就像讀完整本課本一遍。通常要讀好幾遍（好幾個 epoch）才會學得好。
如果訓練集有 1000 張圖片，模型看完這 1000 張 = 1 個 epoch
迭代 Iteration

模型處理一個批次並更新一次參數，稱為一次迭代。

每交一疊作業、老師改完、學生訂正一次 = 一次迭代。
一個 Epoch 的迭代次數 = 訓練資料總數 / 批次大小
例：1000 張圖片 / 批次32 = 約 31 次迭代
損失函數 Loss Function

用來衡量模型預測結果與正確答案之間差距的函數。

就像考試的扣分標準。答案越離譜，扣越多分。模型會努力降低損失（少被扣分）。
預測機率 0.9 是蘋果，實際是蘋果 → 損失小
預測機率 0.2 是蘋果，實際是蘋果 → 損失大
學習率 Learning Rate

每次更新模型參數時，調整的幅度大小。

就像爬山找山頂時，每一步要跨多大。步伐太大可能跨過頭、步伐太小走太慢。
學習率 效果
太大 (0.1, 1.0) 學習不穩定，可能永遠找不到好答案
適中 (0.001, 0.01) 穩定學習，通常是好的起點
太小 (0.00001) 學習太慢，需要很長時間
過擬合 Overfitting

模型在訓練資料上表現很好，但在新資料上表現很差。模型「背答案」而非真正理解。

就像學生只背考古題，遇到新題目就不會了。模型把訓練資料的細節都記住了（包括雜訊），但沒學會真正的規律。
欠擬合 Underfitting

模型在訓練資料上表現就不好，沒有學到足夠的規律。

就像學生根本沒讀書，連課本題目都不會。可能是模型太簡單，或是訓練不夠。

正則化 Regularization

防止過擬合的技術，限制模型的複雜度。

就像叫學生不要死背，要理解重點。常見方法有 L1/L2 正則化、Dropout 等。
Dropout Dropout

訓練時隨機「關閉」一部分神經元，防止模型過度依賴特定神經元。

就像小組報告時，隨機讓某些組員「請假」。這樣每個人都要學會做所有事，不能只依賴某個人。
早停 Early Stopping

當驗證集表現開始變差時，提前停止訓練。

就像煮菜要在剛好熟的時候關火，不要煮過頭。訓練太久會過擬合。

4. 模型評估指標

準確率 Accuracy

所有預測中，正確預測的比例。

考試答對幾題除以總題數。100 題答對 85 題 = 85% 準確率。
準確率 = 正確預測數 / 總預測數

注意：類別不平衡時不可靠

如果 100 張圖有 95 張是蘋果，模型全部猜蘋果就有 95% 準確率，但其實什麼都沒學到。

精確率 Precision

在所有被模型判斷為「正類」的樣本中，真正是正類的比例。

模型說「這是壞蘋果」的時候，有多少次是真的壞。重點是「說的準不準」。
精確率 = 真正例 / (真正例 + 假正例)
模型判定 10 顆蘋果有病蟲害，其中 8 顆確實有 → 精確率 = 80%
召回率 Recall

在所有真正的正類樣本中，被模型正確找出來的比例。

真正壞的蘋果中，模型找出了多少。重點是「有沒有漏掉」。
召回率 = 真正例 / (真正例 + 假負例)
實際有 20 顆壞蘋果，模型找出 16 顆 → 召回率 = 80%

精確率 vs 召回率的比喻

想像用金屬探測器找地雷：

  • 精確率高：探測器響了，挖下去幾乎都是地雷（很少誤報）
  • 召回率高：地雷幾乎都被找到了（很少漏掉）
  • 實務中兩者要取捨：太敏感會誤報多、太遲鈍會漏掉
F1 分數 F1 Score

精確率和召回率的調和平均數，綜合評估模型表現。

把精確率和召回率「平均」起來看。如果兩個都高，F1 就高；如果有一個很低，F1 也會被拉低。
F1 = 2 × (精確率 × 召回率) / (精確率 + 召回率)
混淆矩陣 Confusion Matrix

展示模型預測結果的表格，可以看出模型把什麼類別誤判成什麼。

一張成績單，顯示每種錯誤犯了幾次。
預測：正 預測：負
實際：正 真正例 (TP) 假負例 (FN)
實際：負 假正例 (FP) 真負例 (TN)
IoU（交併比） Intersection over Union

物件偵測中，評估預測框與實際框重疊程度的指標。

你畫的框和正確答案的框，重疊的部分佔多少比例。100% 表示完全重合。
IoU = 重疊面積 / 聯集面積
IoU > 0.5 通常視為「正確偵測到」
mAP（平均精確率均值） mean Average Precision

物件偵測常用的綜合評估指標，考慮所有類別在不同閾值下的表現。

把所有類別的偵測表現「平均」起來的分數。mAP 越高越好，YOLO 等模型常用。

5. 神經網路術語

神經網路 Neural Network

模仿人腦神經元結構的運算模型，由多個「神經元」連接組成。

就像很多小工人（神經元）組成的工廠。每個工人做一點計算，把結果傳給下一個工人，最後產出答案。
神經元 / 節點 Neuron / Node

神經網路的基本運算單元，接收輸入、做運算、產出輸出。

一個小工人。他收到幾個數字，做加權平均，再決定要不要「激活」（輸出結果）。
層 Layer

一群同時運作的神經元組成一層，神經網路由多層堆疊而成。

工廠的一個部門。輸入層（接收部）→ 隱藏層（加工部）→ 輸出層（出貨部）。

權重 Weight

神經元之間連接的「強度」，決定輸入對輸出的影響程度。

每個輸入的「重要性分數」。權重大的輸入影響力大，權重小的影響力小。訓練就是在調整這些權重。
偏差 Bias

神經元的一個額外參數，讓輸出可以做平移調整。

就像考試加分。不管輸入是什麼，都可以加上一個固定值來調整結果。
激活函數 Activation Function

決定神經元是否「激活」（輸出）的函數，引入非線性讓網路能學習複雜模式。

就像開關的判斷標準。計算結果超過某個值就「開啟」輸出，否則「關閉」或減弱。
激活函數 特性 常用場景
ReLU 負值=0，正值不變 隱藏層首選
Sigmoid 輸出 0~1 二元分類輸出
Softmax 輸出機率分布（總和=1） 多類別分類輸出
Tanh 輸出 -1~1 RNN
反向傳播 Backpropagation

計算損失對每個權重的影響，從輸出層往回傳遞，用來更新權重。

考試檢討。從最後的答案開始往回追，看是哪一步算錯了，一步一步修正。
梯度 Gradient

損失函數對權重的偏微分，指出權重應該往哪個方向調整。

就像站在山上，梯度告訴你「往哪邊走是下坡」。我們要往下坡走才能到達山谷（最小損失）。
梯度消失 / 梯度爆炸 Vanishing / Exploding Gradient

深層網路中，梯度在傳遞過程中變得極小或極大，導致訓練困難。

梯度消失：像傳話遊戲傳太多人，訊息越傳越小聲，最後聽不到。
梯度爆炸：像滾雪球越滾越大，最後大到無法控制。

6. 深度學習架構

深度學習 Deep Learning

使用多層神經網路（深層網路）的機器學習方法。

工廠有很多層加工部門，能處理更複雜的任務。「深」是指層數多。
CNN（卷積神經網路） Convolutional Neural Network

專門處理圖像的神經網路，使用卷積運算來提取圖像特徵。

就像用放大鏡一小塊一小塊檢查圖片，找出邊緣、紋理、形狀等特徵。是圖像辨識的標準工具。
卷積 Convolution

用小型濾波器（kernel）在圖像上滑動，提取局部特徵的運算。

像拿一個小印章在圖片上蓋，每蓋一個位置就計算一次。不同的印章可以找出不同的特徵（橫線、直線、角等）。
池化 Pooling

縮小特徵圖的尺寸，保留重要資訊，減少運算量。

把 4 個像素合併成 1 個（取最大值或平均值）。就像把高畫質圖片縮小，檔案變小但還是看得出內容。
RNN（遞迴神經網路） Recurrent Neural Network

能處理序列資料的神經網路，具有「記憶」功能。

看句子時，會記住前面看過的字。就像讀文章會記得前面講了什麼，才能理解後面的意思。
用途：文字生成、語音辨識、時間序列預測
LSTM（長短期記憶網路） Long Short-Term Memory

改良版的 RNN，能記住更長期的資訊，解決梯度消失問題。

RNN 只能記住剛剛發生的事，LSTM 可以記住更久以前的重要資訊，像是有一個筆記本專門記錄重點。
Transformer Transformer

使用注意力機制的架構，能平行處理序列，是現代 NLP 的主流。

不用一個字一個字慢慢讀，而是一眼看整段話，同時注意每個字跟其他字的關係。處理速度更快，效果更好。
GPT、BERT、ChatGPT 都是基於 Transformer。
注意力機制 Attention Mechanism

讓模型學習「該注意哪裡」，對重要的部分給予更多權重。

就像看一張圖片時，眼睛會自動看重點。模型學會在一堆資訊中，找出最相關的部分來做決策。
YOLO You Only Look Once

快速的物件偵測模型，只看一次圖片就能同時偵測多個物件。

不像傳統方法要掃很多次，YOLO 看一眼就知道圖片裡有什麼東西、在哪裡。速度快到能即時處理影片。
GAN（生成對抗網路） Generative Adversarial Network

兩個網路互相對抗：一個生成假資料，一個判斷真假，互相進步。

就像偽鈔集團和警察。偽鈔做得越來越像，警察辨識能力也越來越強。最後偽鈔（生成的圖片）可以以假亂真。
自編碼器 Autoencoder

學習將資料壓縮再還原的網路，中間的壓縮表示是有用的特徵。

就像把一篇文章摘要成幾個關鍵字，再從關鍵字還原成文章。中間那幾個關鍵字就是精華。

7. 優化技術

優化器 Optimizer

決定如何根據梯度來更新權重的演算法。

就像爬山的策略。有人喜歡穩穩走、有人喜歡看情況調整步伐。不同優化器有不同的策略。
梯度下降 Gradient Descent

最基本的優化方法，沿著梯度的反方向（下坡方向）更新權重。

閉著眼睛往下坡方向走，每走一步就重新感覺哪邊是下坡，最後走到山谷。
SGD（隨機梯度下降） Stochastic Gradient Descent

每次只用一個（或一小批）樣本來計算梯度，而不是用全部資料。

不用等全班作業都交齊才檢討，每收到幾份就先改先調整。速度快但方向可能不太穩定。
動量 Momentum

讓更新帶有「慣性」，考慮之前的更新方向，使訓練更穩定。

像滾球下山，即使遇到小坑洞也能靠慣性滾過去，不會卡住。
Adam Adaptive Moment Estimation

結合動量和自適應學習率的優化器，是目前最常用的優化器之一。

聰明的登山者，會記住之前走過的方向（動量），也會根據地形調整步伐大小（自適應學習率）。大多數情況用它就對了。
學習率排程 Learning Rate Schedule

在訓練過程中動態調整學習率的策略。

一開始大步快走（高學習率），接近目標時小步慢走（低學習率）。常見策略有每隔幾個 epoch 減半、或用 cosine 曲線下降。
Batch Normalization 批次正規化

在每層之間加入正規化，使訓練更穩定、更快收斂。

每一層做完後，把結果「校準」一下，確保數值範圍正常，不會太大或太小。就像每站都校正一下時間，避免誤差累積。

8. 進階概念

遷移學習 Transfer Learning

把在大資料集上學到的知識，應用到新的（通常較小的）資料集上。

會開車的人學騎機車比較快。因為很多技巧是共通的。同樣地，學過辨識貓狗的模型，拿來辨識蘋果也會比從零開始快。
預訓練模型 Pre-trained Model

已經在大型資料集上訓練好的模型，可以直接使用或進一步微調。

別人幫你讀完大學課程的畢業生。你可以直接聘用，或是稍微訓練一下他特定領域的知識。
ImageNet 預訓練的 ResNet、GPT、BERT 等
微調 Fine-tuning

在預訓練模型的基礎上，用自己的資料繼續訓練，使其適應新任務。

派畢業生去你公司實習幾天，讓他熟悉你們的業務。不用從幼稚園教起，很快就能上手。
端到端學習 End-to-End Learning

模型直接從原始輸入學習到最終輸出，不需要人工設計中間步驟。

給模型看原始圖片，直接輸出答案，中間怎麼處理讓它自己學。不需要人類先做特徵工程。
超參數 Hyperparameter

訓練前需要人工設定的參數，不是由模型學習得到的。

就像煮飯前要決定火力大小、煮多久。學習率、批次大小、網路層數都是超參數。
常見超參數：學習率、批次大小、epoch 數、隱藏層神經元數
超參數調優 Hyperparameter Tuning

嘗試不同的超參數組合，找出最佳設定。

試不同的火力和時間，找出最好吃的煮飯方式。常見方法有網格搜尋、隨機搜尋、貝氏優化等。
交叉驗證 Cross-Validation

將資料分成多份，輪流用不同部分做訓練和驗證，更可靠地評估模型。

就像考多次模擬考，每次題目略有不同，平均成績比較能反映真實實力。
集成學習 Ensemble Learning

結合多個模型的預測結果，通常比單一模型更準確。

三個臭皮匠勝過諸葛亮。讓多個模型投票，多數決通常比單一意見更可靠。
Random Forest、Boosting、模型平均等
嵌入 / 向量表示 Embedding

將離散資料（如文字、類別）轉換成連續向量，使其能被神經網路處理。

把「蘋果」、「香蕉」這種文字，變成一串數字 [0.2, 0.8, 0.3...]。相似的東西，數字會比較接近。
推論時間 Inference Time

模型處理一筆資料所需的時間。

模型回答一個問題要花多少時間。即時應用（如自駕車）需要很短的推論時間。
模型壓縮 Model Compression

縮小模型大小、加快推論速度，同時盡量維持準確度。

把大模型「瘦身」，讓它能在手機或嵌入式設備上運行。方法有剪枝、量化、知識蒸餾等。
量化 Quantization

將模型中的浮點數權重轉換為低精度數字（如 8-bit 整數）。

把 3.14159265 簡化成 3.14。精確度稍微降低，但檔案變小、運算變快。
