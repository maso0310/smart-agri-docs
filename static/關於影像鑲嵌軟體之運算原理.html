關於影像鑲嵌軟體之運算原理

攝影測量與 SfM 概述

攝影測量 (Photogrammetry) 是一門透過分析照片來獲取物體幾何資訊的科學。 現代影像鑲嵌軟體如 Agisoft Metashape、Pix4D、 OpenDroneMap 等，都是基於 運動恢復結構 (Structure from Motion, SfM) 和多視圖立體匹配 (Multi-View Stereo, MVS) 技術來處理無人機航拍影像。

這些軟體能夠從大量重疊的二維照片中，重建出三維場景結構，並產生正射影像、數值高程模型 (DEM)、 三維點雲等成果，廣泛應用於智慧農業、測繪、建築、考古等領域。

第一階段：特徵提取與匹配

1特徵點檢測 (Feature Detection)

軟體首先在每張影像中檢測關鍵點 (Keypoints)，這些是影像中具有獨特性、 容易辨識的點位，如角點、斑點等。常用的演算法包括：

  • SIFT (Scale-Invariant Feature Transform)：尺度不變特徵轉換，對旋轉、縮放、光照變化具有良好的不變性
  • SURF (Speeded Up Robust Features)：加速穩健特徵，比 SIFT 更快
  • ORB (Oriented FAST and Rotated BRIEF)：開源且快速的替代方案
  • SuperPoint：基於深度學習的特徵檢測器

SIFT 特徵檢測原理

  1. 尺度空間極值檢測：建立高斯金字塔，檢測 DoG (Difference of Gaussian) 極值點
  2. 關鍵點定位：精確定位極值點位置，濾除低對比度點和邊緣響應點
  3. 方向分配：基於梯度方向直方圖為關鍵點分配主方向
  4. 描述子生成：在關鍵點周圍計算 128 維特徵向量

2特徵匹配 (Feature Matching)

在所有影像對之間進行特徵點匹配，找出對應的同名點。這個步驟決定了哪些影像有重疊區域。

匹配策略

  • 暴力匹配 (Brute-Force)：計算所有描述子對之間的距離
  • FLANN (Fast Library for Approximate Nearest Neighbors)：使用 KD-Tree 加速近鄰搜尋
  • 比值測試 (Ratio Test)：過濾不可靠的匹配，最近鄰/次近鄰距離比 < 0.8

誤匹配剔除

  • RANSAC (Random Sample Consensus)：隨機抽樣一致性算法，剔除離群點
  • 基礎矩陣約束：匹配點對需滿足對極幾何約束
  • 雙向匹配驗證：A→B 和 B→A 的匹配結果需一致

Python 特徵匹配範例

import cv2
import numpy as np

def detect_and_match_features(img1_path, img2_path, method='sift'):
    """
    特徵檢測與匹配

    Args:
        img1_path, img2_path: 影像路徑
        method: 特徵檢測方法 ('sift', 'orb', 'akaze')

    Returns:
        matches: 匹配的特徵點對
        kp1, kp2: 關鍵點
    """
    # 讀取影像
    img1 = cv2.imread(img1_path, cv2.IMREAD_GRAYSCALE)
    img2 = cv2.imread(img2_path, cv2.IMREAD_GRAYSCALE)

    # 選擇特徵檢測器
    if method == 'sift':
        detector = cv2.SIFT_create(nfeatures=10000)
    elif method == 'orb':
        detector = cv2.ORB_create(nfeatures=10000)
    elif method == 'akaze':
        detector = cv2.AKAZE_create()

    # 檢測特徵點並計算描述子
    kp1, des1 = detector.detectAndCompute(img1, None)
    kp2, des2 = detector.detectAndCompute(img2, None)

    print(f"影像1特徵點: {len(kp1)}")
    print(f"影像2特徵點: {len(kp2)}")

    # 特徵匹配
    if method == 'orb':
        # ORB 使用 Hamming 距離
        bf = cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=False)
    else:
        # SIFT/AKAZE 使用 L2 距離
        bf = cv2.BFMatcher(cv2.NORM_L2, crossCheck=False)

    # KNN 匹配
    matches = bf.knnMatch(des1, des2, k=2)

    # 比值測試過濾
    good_matches = []
    for m, n in matches:
        if m.distance < 0.75 * n.distance:
            good_matches.append(m)

    print(f"初步匹配點: {len(matches)}")
    print(f"過濾後匹配點: {len(good_matches)}")

    # 使用 RANSAC 剔除誤匹配
    if len(good_matches) >= 4:
        src_pts = np.float32([kp1[m.queryIdx].pt for m in good_matches]).reshape(-1, 1, 2)
        dst_pts = np.float32([kp2[m.trainIdx].pt for m in good_matches]).reshape(-1, 1, 2)

        # 計算基礎矩陣，同時進行 RANSAC 過濾
        F, mask = cv2.findFundamentalMat(src_pts, dst_pts, cv2.FM_RANSAC, 3.0)

        # 只保留內點
        matches_mask = mask.ravel().tolist()
        inlier_matches = [m for m, msk in zip(good_matches, matches_mask) if msk]

        print(f"RANSAC 後匹配點: {len(inlier_matches)}")

        return inlier_matches, kp1, kp2, img1, img2

    return good_matches, kp1, kp2, img1, img2


def visualize_matches(img1, img2, kp1, kp2, matches, output_path):
    """視覺化匹配結果"""
    result = cv2.drawMatches(
        img1, kp1, img2, kp2, matches[:100],  # 只繪製前100個匹配
        None, flags=cv2.DrawMatchesFlags_NOT_DRAW_SINGLE_POINTS
    )
    cv2.imwrite(output_path, result)
    print(f"匹配結果已儲存: {output_path}")


# 使用範例
matches, kp1, kp2, img1, img2 = detect_and_match_features(
    'drone_image_001.jpg',
    'drone_image_002.jpg',
    method='sift'
)
visualize_matches(img1, img2, kp1, kp2, matches, 'matches_result.jpg')

第二階段：運動恢復結構 (SfM)

3相機姿態估計 (Camera Pose Estimation)

SfM 的核心是從二維影像匹配點中恢復相機的三維位置和姿態（外部參數）， 以及相機的內部參數（焦距、主點、畸變係數等）。

相機模型

針孔相機模型： s · [u, v, 1]T = K · [R | t] · [X, Y, Z, 1]T
  • K：內部參數矩陣（焦距 fx, fy，主點 cx, cy）
  • R：旋轉矩陣（3×3）
  • t：平移向量（3×1）
  • [u, v]：影像座標
  • [X, Y, Z]：世界座標

增量式 SfM 流程

  1. 選擇初始影像對（匹配點多、基線適當）
  2. 計算本質矩陣 (Essential Matrix)，分解得到 R, t
  3. 三角測量 (Triangulation) 得到初始 3D 點
  4. 逐步加入新影像，使用 PnP (Perspective-n-Point) 算法估計相機姿態
  5. 對新影像進行三角測量，加入更多 3D 點
  6. 光束平差 (Bundle Adjustment) 全局優化

4光束平差 (Bundle Adjustment)

光束平差是 SfM 的關鍵優化步驟，它同時優化所有相機參數和 3D 點位置， 最小化重投影誤差 (Reprojection Error)。

min Σi Σj || xij - π(Ci, Xj) ||²

其中：

  • xij：第 j 個 3D 點在第 i 張影像上的觀測位置
  • π(Ci, Xj)：3D 點 Xj 透過相機 Ci 投影的預測位置

光束平差通常使用 Levenberg-Marquardt 演算法求解這個非線性最小二乘問題。 由於問題的稀疏結構（每個點只被部分相機觀測到），可以使用稀疏矩陣技術加速計算。

SfM 基本實作範例

import cv2
import numpy as np
from scipy.optimize import least_squares
from scipy.sparse import lil_matrix

class SimpleSfM:
    """簡化版 SfM 實作"""

    def __init__(self, camera_matrix):
        """
        Args:
            camera_matrix: 相機內參矩陣 K
        """
        self.K = camera_matrix
        self.camera_poses = []  # 相機姿態 [R, t]
        self.points_3d = []     # 3D 點雲
        self.observations = []  # 觀測記錄

    def estimate_essential_matrix(self, pts1, pts2):
        """
        估計本質矩陣

        Args:
            pts1, pts2: 匹配點對

        Returns:
            E: 本質矩陣
            mask: 內點遮罩
        """
        E, mask = cv2.findEssentialMat(
            pts1, pts2, self.K,
            method=cv2.RANSAC,
            prob=0.999,
            threshold=1.0
        )
        return E, mask

    def decompose_essential_matrix(self, E, pts1, pts2):
        """
        分解本質矩陣得到 R, t

        Args:
            E: 本質矩陣
            pts1, pts2: 匹配點

        Returns:
            R, t: 旋轉矩陣和平移向量
        """
        _, R, t, mask = cv2.recoverPose(E, pts1, pts2, self.K)
        return R, t, mask

    def triangulate_points(self, R1, t1, R2, t2, pts1, pts2):
        """
        三角測量

        Args:
            R1, t1, R2, t2: 兩相機的姿態
            pts1, pts2: 對應的影像點

        Returns:
            points_3d: 三維點座標
        """
        # 建立投影矩陣
        P1 = self.K @ np.hstack([R1, t1])
        P2 = self.K @ np.hstack([R2, t2])

        # 三角測量
        pts1_norm = pts1.reshape(-1, 2).T
        pts2_norm = pts2.reshape(-1, 2).T

        points_4d = cv2.triangulatePoints(P1, P2, pts1_norm, pts2_norm)

        # 轉換為 3D 座標
        points_3d = points_4d[:3] / points_4d[3]

        return points_3d.T

    def pnp_pose_estimation(self, points_3d, points_2d):
        """
        PnP 相機姿態估計

        Args:
            points_3d: 已知 3D 點
            points_2d: 對應的影像點

        Returns:
            R, t: 相機姿態
            inliers: 內點索引
        """
        success, rvec, tvec, inliers = cv2.solvePnPRansac(
            points_3d, points_2d, self.K, None,
            iterationsCount=1000,
            reprojectionError=2.0,
            flags=cv2.SOLVEPNP_ITERATIVE
        )

        if success:
            R, _ = cv2.Rodrigues(rvec)
            return R, tvec, inliers.flatten()

        return None, None, None

    def bundle_adjustment(self, camera_params, points_3d, observations,
                          camera_indices, point_indices):
        """
        光束平差優化

        Args:
            camera_params: 相機參數 (n_cameras, 6) - [rvec, tvec]
            points_3d: 3D 點 (n_points, 3)
            observations: 2D 觀測點 (n_observations, 2)
            camera_indices: 每個觀測對應的相機索引
            point_indices: 每個觀測對應的點索引

        Returns:
            optimized_camera_params, optimized_points_3d
        """
        n_cameras = camera_params.shape[0]
        n_points = points_3d.shape[0]
        n_observations = observations.shape[0]

        # 將參數展平
        x0 = np.hstack([camera_params.ravel(), points_3d.ravel()])

        def residual_func(x):
            """計算殘差"""
            camera_params = x[:n_cameras * 6].reshape(n_cameras, 6)
            points = x[n_cameras * 6:].reshape(n_points, 3)

            residuals = np.zeros(n_observations * 2)

            for i, (cam_idx, pt_idx) in enumerate(zip(camera_indices, point_indices)):
                # 取得相機參數
                rvec = camera_params[cam_idx, :3]
                tvec = camera_params[cam_idx, 3:6]

                # 旋轉矩陣
                R, _ = cv2.Rodrigues(rvec)

                # 投影
                pt_3d = points[pt_idx]
                pt_cam = R @ pt_3d + tvec
                pt_proj = self.K @ pt_cam
                pt_2d_pred = pt_proj[:2] / pt_proj[2]

                # 殘差
                residuals[2*i:2*i+2] = observations[i] - pt_2d_pred

            return residuals

        # 建立稀疏 Jacobian 結構
        def build_sparse_jacobian_structure():
            m = n_observations * 2
            n = n_cameras * 6 + n_points * 3
            A = lil_matrix((m, n), dtype=int)

            for i, (cam_idx, pt_idx) in enumerate(zip(camera_indices, point_indices)):
                # 相機參數的影響
                A[2*i:2*i+2, cam_idx*6:(cam_idx+1)*6] = 1
                # 點位置的影響
                A[2*i:2*i+2, n_cameras*6 + pt_idx*3:n_cameras*6 + (pt_idx+1)*3] = 1

            return A

        A = build_sparse_jacobian_structure()

        # 使用 Levenberg-Marquardt 優化
        result = least_squares(
            residual_func, x0,
            jac_sparsity=A,
            verbose=2,
            x_scale='jac',
            ftol=1e-4,
            method='trf'
        )

        # 解析結果
        optimized_camera_params = result.x[:n_cameras * 6].reshape(n_cameras, 6)
        optimized_points_3d = result.x[n_cameras * 6:].reshape(n_points, 3)

        return optimized_camera_params, optimized_points_3d


# 使用範例
if __name__ == '__main__':
    # 假設的相機內參
    K = np.array([
        [1000, 0, 960],
        [0, 1000, 540],
        [0, 0, 1]
    ], dtype=np.float64)

    sfm = SimpleSfM(K)

    # 模擬匹配點
    pts1 = np.random.rand(100, 2) * 500 + 200
    pts2 = pts1 + np.random.randn(100, 2) * 2 + np.array([50, 10])

    # 估計本質矩陣
    E, mask = sfm.estimate_essential_matrix(pts1, pts2)
    print(f"本質矩陣計算完成，內點數: {mask.sum()}")

    # 分解得到相對姿態
    R, t, _ = sfm.decompose_essential_matrix(E, pts1[mask.ravel()==1], pts2[mask.ravel()==1])
    print(f"相機相對旋轉:\n{R}")
    print(f"相機相對平移: {t.T}")

第三階段：密集重建

5多視圖立體匹配 (Multi-View Stereo, MVS)

SfM 產生的是稀疏點雲，密集重建則是在每個像素位置估計深度值，產生密集點雲。

常用 MVS 演算法

演算法 原理 特點
PMVS/CMVS Patch-based MVS 經典方法，穩定可靠
PatchMatch Stereo 隨機初始化 + 傳播 快速，GPU 加速
SGM Semi-Global Matching 適用於雙目立體
Deep MVS 深度學習方法 MVSNet, CasMVSNet

深度估計流程

  1. 深度假設：在一定範圍內假設多個深度值
  2. 代價計算：計算參考視圖與源視圖的光度一致性
  3. 代價聚合：空間正則化，考慮鄰域一致性
  4. 深度選擇：選擇代價最小的深度值
  5. 深度細化：濾除異常值，平滑處理

6網格重建與紋理貼圖

網格重建方法

  • Delaunay 三角化：基於點雲的三角網格
  • Poisson 重建：基於法向量的隱式曲面重建
  • Marching Cubes：從體素網格提取等值面
  • Alpha Shapes：保持幾何細節

紋理貼圖

紋理貼圖是將原始影像的色彩資訊映射到三維網格表面。需要處理：

  • 影像選擇：選擇最佳視角的影像
  • 接縫處理：減少不同影像間的色差
  • 光照補償：校正不同時間拍攝的光照差異

第四階段：成果產出

7正射影像 (Orthomosaic)

正射影像是經過幾何校正的影像，消除了地形起伏和相機傾斜造成的變形， 具有統一的比例尺，可以直接進行測量。

正射校正原理

對於每個 DSM 上的點 (X, Y, Z)，計算其在原始影像中的位置，取得像素值

生成流程

  1. 建立數值表面模型 (DSM)
  2. 定義輸出正射影像的範圍和解析度
  3. 對每個輸出像素，反投影到原始影像取樣
  4. 處理多影像重疊區域的融合
  5. 色彩均衡和接縫處理
