關於 RTC 時鐘 (Real-Time Clock)

什麼是 RTC？

RTC（Real-Time Clock，即時時鐘） 是一種專門用來追蹤時間的電子元件。簡單來說，它就像是電腦或手機裡面的「小時鐘」，即使主電源關閉，它也能靠著一顆小電池繼續運作，記住現在是幾點幾分。

生活中的 RTC 例子

你可能已經在日常生活中遇過 RTC：
- 🖥️ 電腦：關機後重新開機，時間還是正確的
- 📺 微波爐/烤箱：拔掉插頭再插回去，時間還在
- ⏰ 電子鬧鐘：換電池後時間不會歸零
- 🚗 汽車儀表板：熄火後時間依然正確

這些設備都有內建 RTC 模組！

為什麼 Arduino 需要 RTC？

Arduino 本身的時間問題

Arduino 有一個 millis() 函數可以計算「開機後經過多少毫秒」，但它有幾個致命缺點：

Arduino 內建計時的問題：

1. 斷電歸零
   ┌─────────────────────────────────┐
   │  開機 → millis() 從 0 開始計算  │
   │  關機 → 一切歸零                │
   │  再開機 → 又從 0 開始           │
   └─────────────────────────────────┘

2. 不知道「現在」是什麼時候
   - millis() 只知道「開機後過了多久」
   - 不知道「現在是 2024 年 12 月 19 日 下午 3 點」

3. 長時間會有誤差
   - Arduino 的時鐘並不精準
   - 一天可能差幾秒到幾十秒

有了 RTC 之後

RTC 解決的問題：

✓ 斷電不歸零（有備用電池）
✓ 知道真實的日期與時間
✓ 精度高（好的 RTC 一個月只差幾秒）
✓ 可以做「定時」功能

RTC 的工作原理

核心概念：石英振盪器

RTC 的心臟是一顆「石英晶體」，它有一個神奇的特性：

石英晶體的特性：

        ⚡ 通電
           ↓
    ┌─────────────┐
    │   石英晶體   │ ← 會以非常穩定的頻率振動
    └─────────────┘
           ↓
    每秒振動 32,768 次
    （這個數字 = 2 的 15 次方）
           ↓
    電路計數 32,768 次 = 1 秒
           ↓
    累計 60 秒 = 1 分鐘
           ↓
    以此類推...

為什麼是 32,768？

這不是隨便選的數字！32,768 = 2^15，用二進位表示就是：

32768 = 1000000000000000 (二進位)

每振動 32768 次，最高位元進位一次 = 1 秒

這讓電路設計變得非常簡單！

備用電池的作用

正常運作時：
┌─────────┐      ┌─────────┐
│ Arduino │──5V──│   RTC   │
│  主電源  │      │  模組   │
└─────────┘      └─────────┘

斷電時：
┌─────────┐      ┌─────────┐
│ Arduino │  ✕   │   RTC   │←── 小電池（CR2032）
│  無電源  │      │ 繼續走  │     持續供電
└─────────┘      └─────────┘

一顆 CR2032 電池大約可以讓 RTC 運作 3-5 年！

DS3231 模組接線

腳位說明

DS3231 模組（常見款）：
┌─────────────────────────┐
│  ┌─────────────────┐    │
│  │     DS3231      │    │
│  │   [電池座]      │    │
│  └─────────────────┘    │
│                         │
│  32K  SQW  SCL  SDA  VCC  GND
│   │    │    │    │    │    │
└───┴────┴────┴────┴────┴────┘

必要接線：
- VCC → Arduino 5V（或 3.3V）
- GND → Arduino GND
- SDA → Arduino A4（I2C 資料線）
- SCL → Arduino A5（I2C 時鐘線）

選用接線：
- SQW → 方波輸出（可做鬧鐘中斷）
- 32K → 32.768KHz 輸出（通常不用）

範例 1：讀取時間

/*
 * RTC 基本讀取範例
 * 使用 DS3231 模組
 */

#include <Wire.h>
#include <RTClib.h>

RTC_DS3231 rtc;

// 星期名稱（中文）
const char* weekDays[] = {
  "星期日", "星期一", "星期二", "星期三",
  "星期四", "星期五", "星期六"
};

void setup() {
  Serial.begin(9600);

  // 初始化 I2C
  Wire.begin();

  // 初始化 RTC
  if (!rtc.begin()) {
    Serial.println("找不到 RTC 模組！");
    Serial.println("請檢查接線...");
    while (1);  // 停在這裡
  }

  // 檢查 RTC 是否曾經設定過時間
  if (rtc.lostPower()) {
    Serial.println("RTC 電池沒電或首次使用，正在設定時間...");
    // 設定為編譯時的電腦時間
    rtc.adjust(DateTime(F(__DATE__), F(__TIME__)));
  }

  Serial.println("RTC 初始化完成！");
  Serial.println();
}

void loop() {
  // 取得目前時間
  DateTime now = rtc.now();

  // 顯示日期
  Serial.print("日期: ");
  Serial.print(now.year());
  Serial.print("/");
  Serial.print(now.month());
  Serial.print("/");
  Serial.print(now.day());
  Serial.print(" ");
  Serial.println(weekDays[now.dayOfTheWeek()]);

  // 顯示時間
  Serial.print("時間: ");
  if (now.hour() < 10) Serial.print("0");
  Serial.print(now.hour());
  Serial.print(":");
  if (now.minute() < 10) Serial.print("0");
  Serial.print(now.minute());
  Serial.print(":");
  if (now.second() < 10) Serial.print("0");
  Serial.println(now.second());

  Serial.println("-------------------");

  delay(1000);
}

範例 2：手動設定時間

/*
 * RTC 手動設定時間範例
 */

#include <Wire.h>
#include <RTClib.h>

RTC_DS3231 rtc;

void setup() {
  Serial.begin(9600);
  Wire.begin();

  if (!rtc.begin()) {
    Serial.println("找不到 RTC！");
    while (1);
  }

  // 手動設定時間
  // DateTime(年, 月, 日, 時, 分, 秒)
  rtc.adjust(DateTime(2024, 12, 19, 15, 30, 0));

  Serial.println("時間已設定為 2024/12/19 15:30:00");
}

void loop() {
  DateTime now = rtc.now();

  // 格式化輸出
  char buffer[30];
  sprintf(buffer, "%04d/%02d/%02d %02d:%02d:%02d",
          now.year(), now.month(), now.day(),
          now.hour(), now.minute(), now.second());

  Serial.println(buffer);
  delay(1000);
}

範例 3：定時執行任務

/*
 * RTC 定時任務範例
 * 每天早上 8:00 和晚上 6:00 執行動作
 */

#include <Wire.h>
#include <RTClib.h>

RTC_DS3231 rtc;

#define LED_PIN 13

// 上次執行的時間（避免重複觸發）
int lastTriggeredHour = -1;

void setup() {
  Serial.begin(9600);
  Wire.begin();

  pinMode(LED_PIN, OUTPUT);

  if (!rtc.begin()) {
    Serial.println("找不到 RTC！");
    while (1);
  }

  Serial.println("定時任務系統啟動");
  Serial.println("排程：08:00 開燈, 18:00 關燈");
}

void loop() {
  DateTime now = rtc.now();
  int currentHour = now.hour();
  int currentMinute = now.minute();

  // 只在整點且尚未觸發時執行
  if (currentMinute == 0 && currentHour != lastTriggeredHour) {

    // 早上 8:00 - 開燈
    if (currentHour == 8) {
      digitalWrite(LED_PIN, HIGH);
      Serial.println("08:00 - 執行開燈任務！");
      lastTriggeredHour = currentHour;
    }

    // 晚上 18:00 - 關燈
    if (currentHour == 18) {
      digitalWrite(LED_PIN, LOW);
      Serial.println("18:00 - 執行關燈任務！");
      lastTriggeredHour = currentHour;
    }
  }

  // 每秒顯示時間
  static unsigned long lastPrint = 0;
  if (millis() - lastPrint >= 1000) {
    lastPrint = millis();

    Serial.print("目前時間: ");
    Serial.print(currentHour);
    Serial.print(":");
    if (currentMinute < 10) Serial.print("0");
    Serial.print(currentMinute);
    Serial.print(" | LED: ");
    Serial.println(digitalRead(LED_PIN) ? "ON" : "OFF");
  }

  delay(100);
}

範例 4：DS3231 溫度讀取

DS3231 內建溫度感測器（用於校正），我們也可以讀取它：

/*
 * DS3231 溫度讀取範例
 */

#include <Wire.h>
#include <RTClib.h>

RTC_DS3231 rtc;

void setup() {
  Serial.begin(9600);
  Wire.begin();

  if (!rtc.begin()) {
    Serial.println("找不到 RTC！");
    while (1);
  }

  Serial.println("DS3231 時間與溫度監測");
}

void loop() {
  DateTime now = rtc.now();
  float temp = rtc.getTemperature();  // DS3231 特有功能

  Serial.print("時間: ");
  Serial.print(now.hour());
  Serial.print(":");
  if (now.minute() < 10) Serial.print("0");
  Serial.print(now.minute());
  Serial.print(":");
  if (now.second() < 10) Serial.print("0");
  Serial.print(now.second());

  Serial.print(" | 晶片溫度: ");
  Serial.print(temp, 1);
  Serial.println(" °C");

  delay(1000);
}

常見問題與解決

Q1：RTC 時間不準？

可能原因與解決方法：

1. 電池沒電
   → 更換 CR2032 電池

2. 使用 DS1307（精度較低）
   → 改用 DS3231（有溫度補償）

3. 環境溫度變化大
   → DS3231 可自動補償

4. 石英晶體品質差
   → 購買品質好的模組

Q2：每次上傳程式時間都會重設？

// 問題程式碼：
void setup() {
  rtc.adjust(DateTime(F(__DATE__), F(__TIME__)));
  // 每次上傳都會執行這行！
}

// 正確做法：
void setup() {
  if (rtc.lostPower()) {  // 只有電池沒電時才設定
    rtc.adjust(DateTime(F(__DATE__), F(__TIME__)));
  }
}

Q3：時間差了好幾個小時？

可能是時區問題！

__TIME__ 是編譯時的電腦時間
如果電腦時區設定錯誤，RTC 時間也會錯

解決方法：
1. 確認電腦時區設定正確
2. 或手動設定正確時間：
   rtc.adjust(DateTime(2024, 12, 19, 15, 30, 0));

Q4：找不到 RTC 模組？

檢查清單：

□ VCC 和 GND 接線正確？
□ SDA 接到 A4？
□ SCL 接到 A5？
□ 模組上的電池有裝？
□ 電池方向正確？（正極朝上）

測試 I2C 連線：
使用 I2C Scanner 程式掃描位址
DS3231 位址通常是 0x68
