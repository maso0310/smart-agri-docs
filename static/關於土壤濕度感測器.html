關於土壤濕度感測器

前言：為什麼需要土壤濕度感測器？

在智慧農業中，適當的澆水是植物健康生長的關鍵：

  • 澆水太少：植物缺水枯萎
  • 澆水太多：根部腐爛、滋生病菌
  • 澆水時機不對：浪費水資源

土壤濕度感測器能夠即時監測土壤的水分含量，配合自動灌溉系統，實現「缺水才澆、澆到剛好」的精準灌溉！

一、土壤濕度感測器是什麼？

一句話解釋

土壤濕度感測器是一種測量土壤中水分含量的裝置，透過電阻或電容變化來判斷土壤的乾濕程度。

想像土壤濕度感測器是一個「口渴偵測器」：

三、工作原理

電阻式原理

電阻式感測器原理：

    電流流動
      ↓
    ┌───┐         ┌───┐
    │ A │ ─ ─ ─ → │ B │
    │探 │  土壤   │探 │
    │針 │ ← ─ ─ ─ │針 │
    └───┘         └───┘
      │             │
      └─────┬───────┘
            │
         測量電阻

乾燥土壤：
- 水分少，導電性差
- 電阻高（數百 KΩ）
- Arduino 讀到高數值（接近 1023）

濕潤土壤：
- 水分多，導電性好
- 電阻低（數 KΩ）
- Arduino 讀到低數值（接近 0）

電容式原理

電容式感測器原理：

    ┌─────────────────────┐
    │  ═══════════════    │  ← 上電極板
    │                     │
    │  ░░░░░░░░░░░░░░░    │  ← 土壤（介電質）
    │  ░░░░░░░░░░░░░░░    │
    │                     │
    │  ═══════════════    │  ← 下電極板
    └─────────────────────┘

電容公式：C = ε × A / d

ε = 介電常數（土壤中水分影響此值）
A = 電極面積
d = 電極距離

水的介電常數（~80）遠大於乾土（~3-5）
→ 水分越多，電容越大
→ 電容變化轉換成電壓輸出

輸出方式

感測器輸出類型：

1. 類比輸出（AO / AOUT）
   - 輸出 0-5V 電壓
   - Arduino analogRead() 得到 0-1023
   - 可得知精確濕度值

2. 數位輸出（DO）
   - 只有 HIGH / LOW 兩種狀態
   - 透過旋鈕調整觸發門檻
   - 只能知道「乾/濕」，無法知道具體數值

建議使用類比輸出（AO），資訊更完整！

五、數值校正

為什麼需要校正？

不同感測器、不同土壤，讀數都會不同：

感測器 A：乾燥=850, 浸水=350
感測器 B：乾燥=780, 浸水=420
感測器 C：乾燥=900, 浸水=300

所以需要針對「你的感測器」和「你的土壤」進行校正！

校正步驟

簡易校正流程：

步驟 1：測量乾燥值
┌─────────────────────────────────────┐
│ 將感測器放在「完全乾燥」的土壤中    │
│ 或放在空氣中                        │
│ 記錄 Arduino 讀到的數值             │
│ 這就是「乾燥值」（例如：850）       │
└─────────────────────────────────────┘

步驟 2：測量濕潤值
┌─────────────────────────────────────┐
│ 將感測器放入「剛澆過水」的土壤中    │
│ 或直接放入水中                      │
│ 記錄 Arduino 讀到的數值             │
│ 這就是「濕潤值」（例如：350）       │
└─────────────────────────────────────┘

步驟 3：計算濕度百分比
┌─────────────────────────────────────┐
│ 濕度% = (乾燥值 - 讀數) / (乾燥值 - 濕潤值) × 100 │
│                                     │
│ 範例：                              │
│ 讀數 = 600                          │
│ 濕度% = (850-600) / (850-350) × 100│
│      = 250 / 500 × 100              │
│      = 50%                          │
└─────────────────────────────────────┘

校正程式

/*
 * 土壤濕度感測器校正程式
 * 依照提示進行校正
 */

const int SENSOR_PIN = A0;

int dryValue = 0;    // 乾燥值
int wetValue = 0;    // 濕潤值

void setup() {
  Serial.begin(9600);
  Serial.println("=== 土壤濕度感測器校正 ===");
  Serial.println();

  // 校正乾燥值
  Serial.println("步驟 1：將感測器放在空氣中或乾燥土壤");
  Serial.println("準備好後按任意鍵...");
  waitForInput();

  dryValue = getAverageReading();
  Serial.print("乾燥值：");
  Serial.println(dryValue);
  Serial.println();

  // 校正濕潤值
  Serial.println("步驟 2：將感測器插入水中或非常濕的土壤");
  Serial.println("準備好後按任意鍵...");
  waitForInput();

  wetValue = getAverageReading();
  Serial.print("濕潤值：");
  Serial.println(wetValue);
  Serial.println();

  // 顯示校正結果
  Serial.println("=== 校正完成 ===");
  Serial.println("請將以下數值記錄到你的程式中：");
  Serial.print("const int DRY_VALUE = ");
  Serial.print(dryValue);
  Serial.println(";");
  Serial.print("const int WET_VALUE = ");
  Serial.print(wetValue);
  Serial.println(";");
  Serial.println();
  Serial.println("現在開始即時監測...");
}

void loop() {
  int rawValue = analogRead(SENSOR_PIN);
  int moisturePercent = map(rawValue, dryValue, wetValue, 0, 100);
  moisturePercent = constrain(moisturePercent, 0, 100);

  Serial.print("原始值：");
  Serial.print(rawValue);
  Serial.print("  濕度：");
  Serial.print(moisturePercent);
  Serial.println("%");

  delay(1000);
}

// 取得平均讀數（減少誤差）
int getAverageReading() {
  long sum = 0;
  for (int i = 0; i < 10; i++) {
    sum += analogRead(SENSOR_PIN);
    delay(100);
  }
  return sum / 10;
}

// 等待使用者輸入
void waitForInput() {
  while (Serial.available() == 0) {
    delay(100);
  }
  while (Serial.available() > 0) {
    Serial.read();
  }
}

範例 3：LED 濕度指示

/*
 * 使用 LED 顯示土壤濕度狀態
 * 紅燈：太乾
 * 黃燈：適中
 * 綠燈：足夠
 */

const int SENSOR_PIN = A0;
const int LED_RED = 5;
const int LED_YELLOW = 6;
const int LED_GREEN = 7;

const int DRY_VALUE = 850;
const int WET_VALUE = 350;

// 門檻值
const int THRESHOLD_DRY = 30;   // 低於 30% 為乾燥
const int THRESHOLD_WET = 70;   // 高於 70% 為濕潤

void setup() {
  Serial.begin(9600);
  pinMode(LED_RED, OUTPUT);
  pinMode(LED_YELLOW, OUTPUT);
  pinMode(LED_GREEN, OUTPUT);

  Serial.println("土壤濕度 LED 指示器");
}

void loop() {
  int rawValue = analogRead(SENSOR_PIN);
  int moisture = map(rawValue, DRY_VALUE, WET_VALUE, 0, 100);
  moisture = constrain(moisture, 0, 100);

  // 關閉所有 LED
  digitalWrite(LED_RED, LOW);
  digitalWrite(LED_YELLOW, LOW);
  digitalWrite(LED_GREEN, LOW);

  // 根據濕度點亮對應 LED
  if (moisture < THRESHOLD_DRY) {
    digitalWrite(LED_RED, HIGH);
    Serial.print("乾燥！");
  } else if (moisture > THRESHOLD_WET) {
    digitalWrite(LED_GREEN, HIGH);
    Serial.print("濕潤 ");
  } else {
    digitalWrite(LED_YELLOW, HIGH);
    Serial.print("適中 ");
  }

  Serial.print(" 濕度：");
  Serial.print(moisture);
  Serial.println("%");

  delay(1000);
}

範例 4：自動澆水系統

/*
 * 簡易自動澆水系統
 * 土壤太乾時自動啟動水泵
 */

const int SENSOR_PIN = A0;
const int PUMP_RELAY = 7;

const int DRY_VALUE = 850;
const int WET_VALUE = 350;

// 控制參數
const int START_WATERING = 30;   // 低於 30% 開始澆水
const int STOP_WATERING = 60;    // 高於 60% 停止澆水
const unsigned long PUMP_TIME = 3000;  // 每次澆水 3 秒
const unsigned long WAIT_TIME = 10000; // 等待 10 秒讓水分滲透

bool isWatering = false;
unsigned long pumpStartTime = 0;
unsigned long lastWateringTime = 0;

void setup() {
  Serial.begin(9600);
  pinMode(PUMP_RELAY, OUTPUT);
  digitalWrite(PUMP_RELAY, LOW);

  Serial.println("=== 自動澆水系統 ===");
  Serial.print("啟動門檻：");
  Serial.print(START_WATERING);
  Serial.println("%");
  Serial.print("停止門檻：");
  Serial.print(STOP_WATERING);
  Serial.println("%");
}

void loop() {
  int rawValue = analogRead(SENSOR_PIN);
  int moisture = map(rawValue, DRY_VALUE, WET_VALUE, 0, 100);
  moisture = constrain(moisture, 0, 100);

  Serial.print("土壤濕度：");
  Serial.print(moisture);
  Serial.print("%  ");

  // 正在澆水中
  if (isWatering) {
    if (millis() - pumpStartTime >= PUMP_TIME) {
      // 澆水時間到，停止
      digitalWrite(PUMP_RELAY, LOW);
      isWatering = false;
      lastWateringTime = millis();
      Serial.println("澆水完成，等待滲透...");
    } else {
      Serial.println("澆水中...");
    }
  }
  // 不在澆水中
  else {
    // 檢查是否需要澆水
    if (moisture < START_WATERING) {
      // 確保有足夠的等待時間
      if (millis() - lastWateringTime >= WAIT_TIME) {
        digitalWrite(PUMP_RELAY, HIGH);
        isWatering = true;
        pumpStartTime = millis();
        Serial.println("土壤太乾，開始澆水！");
      } else {
        Serial.println("等待中...");
      }
    } else if (moisture >= STOP_WATERING) {
      Serial.println("濕度足夠");
    } else {
      Serial.println("正常");
    }
  }

  delay(1000);
}

    return;
  }

  // 自動澆水邏輯
  if (shouldWater(moisture)) {
    doWatering();
  } else {
    Serial.println(getStatusMessage(moisture));
  }

  delay(2000);
}

int getMoisturePercent() {
  int rawValue = analogRead(SENSOR_PIN);
  int moisture = map(rawValue, DRY_VALUE, WET_VALUE, 0, 100);
  return constrain(moisture, 0, 100);
}

bool shouldWater(int moisture) {
  // 檢查濕度是否過低
  if (moisture >= START_THRESHOLD) {
    return false;
  }

  // 檢查間隔時間
  if (millis() - lastWateringEnd < MIN_INTERVAL) {
    Serial.print("需等待 ");
    Serial.print((MIN_INTERVAL - (millis() - lastWateringEnd)) / 1000);
    Serial.println(" 秒");
    return false;
  }

  // 檢查每日上限
  if (todayWateringTime >= MAX_DAILY_TIME) {
    Serial.println("已達每日上限！");
    return false;
  }

  return true;
}

void doWatering() {
  Serial.println(">>> 開始澆水 <<<");
  digitalWrite(PUMP_RELAY, HIGH);

  unsigned long startTime = millis();
  while (millis() - startTime < PUMP_DURATION) {
    // 澆水中可以顯示進度
    Serial.print(".");
    delay(500);
  }

  digitalWrite(PUMP_RELAY, LOW);
  Serial.println();
  Serial.println(">>> 澆水完成 <<<");

  todayWateringTime += PUMP_DURATION;
  lastWateringEnd = millis();
}

String getStatusMessage(int moisture) {
  if (moisture >= STOP_THRESHOLD) {
    return "水分充足";
  } else if (moisture >= START_THRESHOLD) {
    return "水分適中";
  } else {
    return "需要澆水";
  }
}

範例 6：多點監測

/*
 * 多點土壤濕度監測
 * 監測多個位置的土壤濕度
 */

const int SENSOR_PINS[] = {A0, A1, A2};
const int NUM_SENSORS = 3;
const char* LOCATION_NAMES[] = {"花盆A", "花盆B", "花盆C"};

const int DRY_VALUE = 850;
const int WET_VALUE = 350;

void setup() {
  Serial.begin(9600);
  Serial.println("=== 多點土壤濕度監測 ===");
}

void loop() {
  Serial.println("-------------------");

  int minMoisture = 100;
  int maxMoisture = 0;
  int avgMoisture = 0;

  for (int i = 0; i < NUM_SENSORS; i++) {
    int rawValue = analogRead(SENSOR_PINS[i]);
    int moisture = map(rawValue, DRY_VALUE, WET_VALUE, 0, 100);
    moisture = constrain(moisture, 0, 100);

    Serial.print(LOCATION_NAMES[i]);
    Serial.print("：");
    Serial.print(moisture);
    Serial.print("% ");

    // 狀態提示
    if (moisture < 30) {
      Serial.println("[需澆水!]");
    } else if (moisture > 70) {
      Serial.println("[水分足]");
    } else {
      Serial.println("[正常]");
    }

    // 統計
    if (moisture < minMoisture) minMoisture = moisture;
    if (moisture > maxMoisture) maxMoisture = moisture;
    avgMoisture += moisture;
  }

  avgMoisture /= NUM_SENSORS;

  Serial.println("-------------------");
  Serial.print("平均：");
  Serial.print(avgMoisture);
  Serial.print("%  最低：");
  Serial.print(minMoisture);
  Serial.print("%  最高：");
  Serial.print(maxMoisture);
  Serial.println("%");

  delay(5000);
}

範例 7：搭配 LCD 顯示

/*
 * 土壤濕度 + LCD 顯示
 */

#include <Wire.h>
#include <LiquidCrystal_I2C.h>

const int SENSOR_PIN = A0;
const int DRY_VALUE = 850;
const int WET_VALUE = 350;

LiquidCrystal_I2C lcd(0x27, 16, 2);

// 自訂字元：水滴
byte droplet[8] = {
  B00100, B00100, B01010, B01010,
  B10001, B10001, B10001, B01110
};

// 自訂字元：進度條
byte bar[8] = {
  B11111, B11111, B11111, B11111,
  B11111, B11111, B11111, B11111
};

void setup() {
  lcd.init();
  lcd.backlight();
  lcd.createChar(0, droplet);
  lcd.createChar(1, bar);

  lcd.setCursor(0, 0);
  lcd.print("Soil Moisture");
  lcd.setCursor(0, 1);
  lcd.print("Initializing...");
  delay(2000);
}

void loop() {
  int rawValue = analogRead(SENSOR_PIN);
  int moisture = map(rawValue, DRY_VALUE, WET_VALUE, 0, 100);
  moisture = constrain(moisture, 0, 100);

  lcd.clear();

  // 第一行：數值
  lcd.setCursor(0, 0);
  lcd.write(byte(0));  // 水滴圖示
  lcd.print(" Moisture:");
  lcd.print(moisture);
  lcd.print("%");

  // 第二行：進度條
  lcd.setCursor(0, 1);
  int bars = map(moisture, 0, 100, 0, 16);
  for (int i = 0; i < 16; i++) {
    if (i < bars) {
      lcd.write(byte(1));  // 填滿
    } else {
      lcd.print(" ");      // 空白
    }
  }

  delay(1000);
}

七、感測器保養與注意事項

電阻式感測器的問題

⚠️ 電阻式感測器的致命缺點：腐蝕

原因：
- 通電時會產生電解作用
- 探針金屬會逐漸腐蝕
- 特別是在濕潤環境下更嚴重

腐蝕過程：
新品         使用數週       使用數月
┌─┐ ┌─┐     ┌─┐ ┌─┐       ┌─┐ ┌─┐
│█│ │█│ →   │▓│ │▓│   →   │░│ │░│
│█│ │█│     │▓│ │▓│       │ │ │ │
│█│ │█│     │▓│ │▓│       │ │ │ │
└─┘ └─┘     └─┘ └─┘       └─┘ └─┘
 完好         變色          腐蝕嚴重

延長壽命的方法

/*
 * 間歇供電法 - 延長電阻式感測器壽命
 * 只在讀取時供電，減少電解作用
 */

const int SENSOR_PIN = A0;
const int SENSOR_VCC = 8;  // 用數位腳位供電

void setup() {
  Serial.begin(9600);
  pinMode(SENSOR_VCC, OUTPUT);
  digitalWrite(SENSOR_VCC, LOW);  // 預設關閉
}

void loop() {
  int moisture = readSensorSafe();

  Serial.print("濕度：");
  Serial.println(moisture);

  delay(5000);  // 每 5 秒讀一次就夠了
}

int readSensorSafe() {
  // 開啟電源
  digitalWrite(SENSOR_VCC, HIGH);
  delay(100);  // 等待穩定

  // 讀取數值
  int value = analogRead(SENSOR_PIN);

  // 關閉電源（減少腐蝕）
  digitalWrite(SENSOR_VCC, LOW);

  return value;
}

電容式感測器注意事項

電容式感測器使用注意：

1. 電壓要求
   - 大多數是 3.3V 供電
   - 使用 5V 可能損壞！
   - 購買前確認規格

2. 防水處理
   - 感測區域已有塗層
   - 但電路板部分要避免碰水
   - 長期使用可塗防水膠

3. 插入深度
   - 感測區域要完全埋入土壤
   - 電路板部分保持在土壤外

正確插入方式：
    ┌────────┐
    │ 電路板 │  ← 土壤外
    │        │
────│────────│──── 土壤表面
    │▓▓▓▓▓▓▓▓│
    │▓感測區▓│  ← 埋入土壤
    │▓▓▓▓▓▓▓▓│
    └────────┘

八、常見問題排解

問題 1：讀數一直是 0 或 1023

檢查步驟：

□ 1. 接線正確嗎？（VCC, GND, AO）
□ 2. 感測器有插入土壤嗎？
□ 3. 電源電壓正確嗎？（5V 或 3.3V）
□ 4. 換一個類比腳位試試
□ 5. 感測器是否損壞？（探針腐蝕）

問題 2：讀數不穩定跳動

可能原因與解決方法：

1. 電源不穩
   → 加 100μF 電容在 VCC-GND 之間

2. 土壤不均勻
   → 確保探針周圍土壤緊實
   → 多讀幾次取平均值

3. 接線鬆動
   → 檢查杜邦線連接

4. 感測器腐蝕
   → 更換新的感測器

程式解決方案：
int getStableReading() {
  long sum = 0;
  for (int i = 0; i < 10; i++) {
    sum += analogRead(SENSOR_PIN);
    delay(10);
  }
  return sum / 10;
}

問題 3：乾濕讀數差異太小

可能原因：

1. 感測器品質差
   → 更換品質較好的感測器

2. 土壤導電性低
   → 某些培養土不導電
   → 換一般園藝土試試

3. 探針接觸不良
   → 確保探針完全插入土壤
   → 土壤要緊實接觸探針

問題 4：電容式感測器沒反應

檢查步驟：

□ 1. 確認使用 3.3V 供電
□ 2. 感測區域是否完全埋入土壤
□ 3. 土壤是否太乾或太硬
□ 4. 檢查感測器是否進水損壞
