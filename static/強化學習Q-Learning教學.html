🎮 強化學習 Q-Learning 教學

讓 AI 學會智慧決策的訓練方法

📚 什麼是強化學習？

強化學習 (Reinforcement Learning, RL) 是一種讓 AI 透過「試錯」來學習的方法。就像訓練小狗一樣，做對了給獎勵，做錯了給懲罰，AI 慢慢學會什麼行為能獲得最多獎勵。

🤖 代理人 Agent

做決策的 AI，例如：智慧灌溉控制器

🌍 環境 Environment

代理人所處的世界，例如：農田、溫室

📊 狀態 State

環境的當前情況，例如：溫度 30°C、濕度 40%

⚡ 動作 Action

代理人可以執行的行為，例如：開灌溉、關風扇

🏆 獎勵 Reward

對動作的評價，例如：+10（作物健康）、-5（浪費水）

🎯 目標

累積最多獎勵，學會最佳策略

🧮 Q-Learning 演算法

Q-Learning 是最基礎的強化學習演算法，透過建立一個「Q 表」來記錄每個狀態下採取每個動作的價值。

Q 值更新公式

Q(s,a) ← Q(s,a) + α × [R + γ × max Q(s',a') - Q(s,a)]

α = 學習率 | γ = 折扣因子 | R = 即時獎勵 | s' = 下一個狀態

參數 說明 常用值
α (alpha) 學習率，決定新經驗的權重 0.1 ~ 0.5
γ (gamma) 折扣因子，決定對未來獎勵的重視程度 0.9 ~ 0.99
ε (epsilon) 探索率，隨機嘗試新動作的機率 0.1 ~ 0.3（逐漸降低）
💻 Q-Learning 實作
import numpy as np import random class QLearningAgent: def __init__(self, n_states, n_actions, alpha=0.1, gamma=0.95, epsilon=0.3): """ 初始化 Q-Learning 代理人 參數: n_states: 狀態數量 n_actions: 動作數量 alpha: 學習率 gamma: 折扣因子 epsilon: 探索率 """ self.n_states = n_states self.n_actions = n_actions self.alpha = alpha self.gamma = gamma self.epsilon = epsilon # 初始化 Q 表（全部設為 0） self.q_table = np.zeros((n_states, n_actions)) def choose_action(self, state): """選擇動作（ε-greedy 策略）""" if random.random() < self.epsilon: # 探索：隨機選擇 return random.randint(0, self.n_actions - 1) else: # 利用：選擇最佳動作 return np.argmax(self.q_table[state]) def learn(self, state, action, reward, next_state): """更新 Q 值""" # Q-Learning 更新公式 best_next = np.max(self.q_table[next_state]) td_target = reward + self.gamma * best_next td_error = td_target - self.q_table[state, action] self.q_table[state, action] += self.alpha * td_error def decay_epsilon(self, decay_rate=0.995, min_epsilon=0.01): """逐漸降低探索率""" self.epsilon = max(min_epsilon, self.epsilon * decay_rate)
🌾 農業灌溉模擬器
class IrrigationEnvironment: """簡易灌溉環境""" def __init__(self): # 狀態：土壤濕度等級 (0=乾燥, 1=適中, 2=潮濕) self.state = 1 self.day = 0 def reset(self): """重置環境""" self.state = random.randint(0, 2) self.day = 0 return self.state def step(self, action): """ 執行動作 動作: 0=不灌溉, 1=灌溉 回傳: (下一狀態, 獎勵, 是否結束) """ self.day += 1 # 模擬天氣影響（隨機蒸發） weather_effect = random.choice([-1, 0, 0]) # 計算新狀態 if action == 1: # 灌溉 self.state = min(2, self.state + 1) self.state = max(0, self.state + weather_effect) # 計算獎勵 if self.state == 1: # 適中最好 reward = 10 elif self.state == 0: # 太乾 reward = -5 else: # 太濕 reward = -3 # 浪費水的懲罰 if action == 1 and self.state == 2: reward -= 5 done = self.day >= 30 # 30 天為一輪 return self.state, reward, done # 訓練迴圈 env = IrrigationEnvironment() agent = QLearningAgent(n_states=3, n_actions=2) for episode in range(1000): state = env.reset() total_reward = 0 while True: action = agent.choose_action(state) next_state, reward, done = env.step(action) agent.learn(state, action, reward, next_state) total_reward += reward state = next_state if done: break agent.decay_epsilon() if episode % 100 == 0: print(f'Episode {episode}, Total Reward: {total_reward}, Epsilon: {agent.epsilon:.3f}') print('\\n學習完成！Q 表：') print('狀態\\動作 不灌溉 灌溉') for i, row in enumerate(agent.q_table): print(f' {["乾燥", "適中", "潮濕"][i]}: {row[0]:6.2f} {row[1]:6.2f}')
🎯 訓練結果解讀
💡 理想的 Q 表應該顯示：
• 乾燥狀態 → 灌溉的 Q 值較高（應該灌溉）
• 適中狀態 → 不灌溉的 Q 值較高（保持現狀）
• 潮濕狀態 → 不灌溉的 Q 值明顯較高（避免浪費水）
