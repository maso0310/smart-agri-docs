📚 什麼是機器學習？

機器學習 (Machine Learning) 是人工智慧的一個分支，讓電腦能夠從資料中「學習」模式，而不需要明確地編寫規則。

📝 傳統程式設計

規則 + 資料 → 答案

# 人工寫規則 if 綠色 > 紅色 and 綠色 > 藍色: return "植物" else: return "非植物"

🧠 機器學習

資料 + 答案 → 規則（模型）

# 讓機器從資料學習 model.fit(圖片資料, 標籤) prediction = model.predict(新圖片)
💡 核心概念：
機器學習就是讓電腦看大量範例，自己找出規律，就像小孩看很多貓狗照片後，能自己分辨貓和狗一樣！

🎯 機器學習三大類型

👨‍🏫

監督式學習 Supervised

有老師教導：資料都有正確答案（標籤）

範例：

  • 分類：蘋果好壞判定
  • 迴歸：作物產量預測
🔍

非監督式學習 Unsupervised

自己探索：沒有標籤，自己找規律

範例：

  • 分群：客戶分群
  • 降維：特徵壓縮
🎮

強化學習 Reinforcement

試錯學習：透過獎勵/懲罰學習策略

範例：

  • 遊戲 AI
  • 智慧灌溉控制

資料分割的重要性

from sklearn.model_selection import train_test_split # 將資料分成訓練集和測試集 X_train, X_test, y_train, y_test = train_test_split( features, # 特徵資料 labels, # 標籤 test_size=0.2, # 20% 作為測試集 random_state=42 # 隨機種子（確保可重現） ) print(f'訓練資料: {len(X_train)} 筆') print(f'測試資料: {len(X_test)} 筆')
⚠️ 為什麼要分割資料？
如果用相同的資料訓練和測試，模型可能只是「背答案」（過擬合），
遇到新資料就無法正確預測！測試集是用來驗證模型「泛化能力」的。

🧰 常用機器學習演算法

分類問題

演算法 特點 適用場景
決策樹 Decision Tree 直觀易解釋、像是問答遊戲 簡單分類、規則提取
隨機森林 Random Forest 多棵決策樹投票、較穩定 複雜分類、避免過擬合

隨機森林範例

from sklearn.ensemble import RandomForestClassifier from sklearn.metrics import accuracy_score, classification_report # 建立隨機森林模型 rf = RandomForestClassifier( n_estimators=100, # 100 棵樹 max_depth=10, # 最大深度 random_state=42 ) # 訓練模型 rf.fit(X_train, y_train) # 預測 y_pred = rf.predict(X_test) # 評估準確度 accuracy = accuracy_score(y_test, y_pred) print(f'準確度: {accuracy:.2%}') # 詳細報告 print(classification_report(y_test, y_pred))

支援向量機範例

from sklearn.svm import SVC from sklearn.preprocessing import StandardScaler # SVM 對特徵尺度敏感，需要標準化 scaler = StandardScaler() X_train_scaled = scaler.fit_transform(X_train) X_test_scaled = scaler.transform(X_test) # 建立 SVM 模型 svm = SVC( kernel='rbf', # 使用 RBF 核函數 C=1.0, # 正則化參數 gamma='scale' # 核函數係數 ) # 訓練與預測 svm.fit(X_train_scaled, y_train) y_pred = svm.predict(X_test_scaled) accuracy = accuracy_score(y_test, y_pred) print(f'SVM 準確度: {accuracy:.2%}')

Recall
召回率

混淆矩陣

from sklearn.metrics import confusion_matrix import matplotlib.pyplot as plt import seaborn as sns # 計算混淆矩陣 cm = confusion_matrix(y_test, y_pred) # 視覺化 plt.figure(figsize=(8, 6)) sns.heatmap(cm, annot=True, fmt='d', cmap='Blues', xticklabels=['健康', '病變'], yticklabels=['健康', '病變']) plt.xlabel('預測值') plt.ylabel('實際值') plt.title('混淆矩陣') plt.show() # 解讀: # 預測健康 預測病變 # 實際健康 TN FP (誤報) # 實際病變 FN (漏報) TP
💡 如何選擇指標？
• 蘋果品質檢測：Precision 重要（避免把壞蘋果誤判為好的）
• 病蟲害偵測：Recall 重要（寧可誤報也不能漏報）
• 一般情況：F1-Score 可以平衡兩者

⚖️ 過擬合與欠擬合

🔥 過擬合 Overfitting

模型「背答案」，訓練集表現好但測試集差

症狀：

  • 訓練準確度 > 98%
  • 測試準確度 < 80%

解決方法：

  • 增加訓練資料
  • 減少模型複雜度
  • 使用正則化
  • 加入 Dropout

❄️ 欠擬合 Underfitting

模型太簡單，無法學到規律

症狀：

  • 訓練準確度 < 70%
  • 測試準確度也差

解決方法：

  • 使用更複雜的模型
  • 增加特徵數量
  • 減少正則化
  • 訓練更久

交叉驗證 Cross-Validation

from sklearn.model_selection import cross_val_score # 5-fold 交叉驗證 scores = cross_val_score( model, # 模型 X, y, # 資料 cv=5, # 5 折 scoring='accuracy' ) print(f'各折準確度: {scores}') print(f'平均準確度: {scores.mean():.2%} (+/- {scores.std() * 2:.2%})') # 如果標準差很大，可能有過擬合風險

🧠 深度學習簡介

深度學習是機器學習的子集，使用多層神經網路自動學習特徵。

傳統 ML vs 深度學習

項目 傳統機器學習 深度學習
特徵工程 需要手動設計 自動學習
資料需求 較少即可 需要大量資料
運算資源 CPU 即可 需要 GPU
可解釋性 較容易解釋 黑盒子
適合問題 結構化資料 影像、語音、自然語言

CNN 卷積神經網路

專門處理影像的神經網路，能自動提取影像特徵。

from tensorflow.keras.models import Sequential from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten, Dense, Dropout # 建立 CNN 模型 model = Sequential([ # 卷積層 - 提取特徵 Conv2D(32, (3, 3), activation='relu', input_shape=(128, 128, 3)), MaxPooling2D((2, 2)), Conv2D(64, (3, 3), activation='relu'), MaxPooling2D((2, 2)), Conv2D(128, (3, 3), activation='relu'), MaxPooling2D((2, 2)), # 全連接層 - 分類 Flatten(), Dense(128, activation='relu'), Dropout(0.5), # 防止過擬合 Dense(2, activation='softmax') # 2 類別：健康/病變 ]) # 編譯模型 model.compile( optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'] ) # 訓練模型 history = model.fit( X_train, y_train, epochs=20, validation_split=0.2, batch_size=32 )
🎯 YOLO 目標偵測

YOLO (You Only Look Once) 是一種即時目標偵測演算法，能同時辨識圖片中多個物件的位置和類別。

from ultralytics import YOLO # 載入預訓練模型 model = YOLO('yolov8n.pt') # nano 版本，速度快 # 對圖片進行偵測 results = model('farm.jpg') # 查看結果 for result in results: boxes = result.boxes for box in boxes: # 取得邊界框座標 x1, y1, x2, y2 = box.xyxy[0].tolist() # 取得信心度 conf = box.conf[0].item() # 取得類別 cls = model.names[int(box.cls[0])] print(f'{cls}: {conf:.2%} at ({x1:.0f}, {y1:.0f}, {x2:.0f}, {y2:.0f})') # 自訂模型訓練 model.train( data='apple_dataset.yaml', # 資料集設定檔 epochs=100, imgsz=640, batch=16 )

資料為王

花 80% 時間在資料品質上，只有好資料才能訓練出好模型。標註要一致、避免類別不平衡。

🎯

從簡單開始

先嘗試簡單模型（如 Random Forest），確認有效後再考慮深度學習。不要過度工程化！

📈

持續監控

模型上線後要持續監控效能，環境變化（如季節）可能導致模型效能下降。
