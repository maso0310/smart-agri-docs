樹莓派是什麼？

樹莓派（Raspberry Pi）是一款信用卡大小的單板電腦，由英國樹莓派基金會開發。它是一台完整的電腦，可以運行 Linux 作業系統，執行各種程式。

什麼時候用 Arduino？

適合 Arduino 的情境：
✓ 簡單的感測器讀取與控制
✓ 需要精確時序控制（如 PWM、伺服馬達）
✓ 低功耗應用（電池供電）
✓ 即時反應需求高
✓ 成本敏感的專案
✓ 類比訊號處理（ADC 內建）
✓ 24/7 穩定運行的簡單任務

範例：
- 溫濕度感測器讀取
- LED 燈條控制
- 馬達驅動
- 按鈕輸入處理

什麼時候用樹莓派？

適合樹莓派的情境：
✓ 需要運行完整作業系統
✓ 網路服務（Web Server、MQTT Broker）
✓ 資料庫操作
✓ 影像處理與機器學習
✓ 多工處理
✓ 圖形介面應用
✓ 複雜的資料分析

範例：
- 物聯網閘道器
- 網頁儀表板伺服器
- 攝影機影像辨識
- 資料彙整與儲存
- 遠端監控中心

GPIO 與 Arduino 的差異

┌─────────────────────────────────────────────────────────────────┐
│                  GPIO 使用注意事項                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ⚠️ 重要差異：                                                  │
│                                                                 │
│  1. 電壓等級                                                    │
│     - 樹莓派 GPIO 是 3.3V（不是 5V！）                          │
│     - 接入 5V 訊號會損壞樹莓派                                  │
│     - 需要電平轉換器與 5V 設備溝通                              │
│                                                                 │
│  2. 沒有類比輸入                                                │
│     - 樹莓派沒有內建 ADC                                        │
│     - 需要外接 ADC 晶片（如 MCP3008）讀取類比訊號               │
│                                                                 │
│  3. 電流限制                                                    │
│     - 單一 GPIO 最大 16mA                                       │
│     - 全部 GPIO 總和最大 50mA                                   │
│     - 驅動 LED 需要限流電阻                                     │
│                                                                 │
│  4. 非即時系統                                                  │
│     - Linux 不是即時作業系統                                    │
│     - 精確時序控制不如 Arduino                                  │
│     - 需要即時控制時，建議搭配 Arduino                          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

作業系統安裝

步驟一：準備材料

需要準備：
□ microSD 卡（建議 16GB 以上，Class 10）
□ SD 卡讀卡機
□ 電腦（用於燒錄系統）
□ 電源供應器（5V 3A，USB-C 或 microUSB）
□ HDMI 線（首次設定用）
□ 鍵盤、滑鼠（首次設定用）
□ 螢幕（首次設定用）

步驟二：下載 Raspberry Pi Imager

1. 前往官網下載 Raspberry Pi Imager
   https://www.raspberrypi.com/software/

2. 安裝並開啟 Raspberry Pi Imager

步驟四：首次開機

1. 將 SD 卡插入樹莓派
2. 連接螢幕、鍵盤、滑鼠
3. 接上電源
4. 等待開機（首次約 1-2 分鐘）
5. 進入桌面環境

如果在 Imager 設定了 WiFi 和 SSH：
- 可以不接螢幕，直接用 SSH 連線
- 開機後等待 1-2 分鐘
- 從路由器查詢樹莓派的 IP 位址
- 使用 SSH 連線

SSH 遠端連線

Windows 連線方式

方法一：使用 PowerShell 或命令提示字元

1. 開啟 PowerShell
2. 輸入：ssh pi@192.168.x.x
   （將 192.168.x.x 替換成樹莓派的 IP）
3. 首次連線會詢問是否信任，輸入 yes
4. 輸入密碼

方法二：使用 PuTTY

1. 下載並安裝 PuTTY
2. Host Name: 192.168.x.x
3. Port: 22
4. Connection type: SSH
5. 點擊 Open
6. 輸入帳號密碼

查詢樹莓派 IP 位址

方法一：從路由器管理頁面查看

方法二：使用 hostname（如果設定了）
  ping raspberrypi.local

方法三：在樹莓派上查看（如有螢幕）
  終端機輸入：hostname -I

#!/usr/bin/env python3
"""
LED 閃爍範例 - 使用 RPi.GPIO
接線：GPIO17 (Pin 11) → 電阻 (220Ω) → LED → GND
"""

import RPi.GPIO as GPIO
import time

# 設定
LED_PIN = 17

# 初始化
GPIO.setmode(GPIO.BCM)  # 使用 BCM 編號
GPIO.setup(LED_PIN, GPIO.OUT)

print("LED 閃爍開始，按 Ctrl+C 停止")

try:
    while True:
        GPIO.output(LED_PIN, GPIO.HIGH)  # LED 亮
        print("LED ON")
        time.sleep(1)

        GPIO.output(LED_PIN, GPIO.LOW)   # LED 滅
        print("LED OFF")
        time.sleep(1)

except KeyboardInterrupt:
    print("\n程式結束")

finally:
    GPIO.cleanup()  # 清理 GPIO 設定

樹莓派與 Arduino 通訊

方法一：UART 序列通訊

接線：
┌────────────┐         ┌────────────┐
│ 樹莓派     │         │  Arduino   │
│            │         │            │
│  TX (GPIO14)├────────┤ RX         │
│  RX (GPIO15)├────────┤ TX         │
│  GND       ├─────────┤ GND        │
└────────────┘         └────────────┘

注意：樹莓派是 3.3V，Arduino 是 5V
      RX 線需要分壓或電平轉換

樹莓派端 Python 程式：

#!/usr/bin/env python3
"""
樹莓派透過 UART 與 Arduino 通訊
"""

import serial
import time

# 開啟序列埠
ser = serial.Serial('/dev/serial0', 9600, timeout=1)
time.sleep(2)  # 等待連接穩定

print("開始與 Arduino 通訊")

try:
    while True:
        # 發送指令給 Arduino
        ser.write(b'GET_DATA\n')

        # 讀取 Arduino 回應
        if ser.in_waiting > 0:
            response = ser.readline().decode('utf-8').strip()
            print(f"Arduino 回應: {response}")

        time.sleep(2)

except KeyboardInterrupt:
    print("\n程式結束")

finally:
    ser.close()

Arduino 端程式：

/*
 * Arduino 端 - 與樹莓派 UART 通訊
 */

#include <DHT.h>

#define DHT_PIN 2
DHT dht(DHT_PIN, DHT11);

void setup() {
    Serial.begin(9600);
    dht.begin();
}

void loop() {
    if (Serial.available() > 0) {
        String command = Serial.readStringUntil('\n');
        command.trim();

        if (command == "GET_DATA") {
            float temp = dht.readTemperature();
            float humi = dht.readHumidity();

            Serial.print("TEMP:");
            Serial.print(temp);
            Serial.print(",HUMI:");
            Serial.println(humi);
        }
    }
}

智慧農業應用範例

範例：溫室監控伺服器

#!/usr/bin/env python3
"""
智慧溫室監控伺服器
功能：
- 讀取感測器資料
- 提供 Web API
- 儲存歷史資料
"""

from flask import Flask, jsonify, render_template_string
import adafruit_dht
import board
from gpiozero import MCP3008, OutputDevice
from datetime import datetime
import threading
import time

app = Flask(__name__)

# 感測器初始化
dht = adafruit_dht.DHT11(board.D4)
soil_sensor = MCP3008(channel=0)

# 繼電器（控制風扇和水泵）
fan_relay = OutputDevice(17, active_high=False)
pump_relay = OutputDevice(27, active_high=False)

# 資料儲存
sensor_data = {
    'temperature': 0,
    'humidity': 0,
    'soil_moisture': 0,
    'fan_status': False,
    'pump_status': False,
    'last_update': ''
}

history = []

# 感測器讀取執行緒
def sensor_thread():
    global sensor_data
    while True:
        try:
            sensor_data['temperature'] = dht.temperature or 0
            sensor_data['humidity'] = dht.humidity or 0
            sensor_data['soil_moisture'] = int((1 - soil_sensor.value) * 100)
            sensor_data['last_update'] = datetime.now().strftime('%Y-%m-%d %H:%M:%S')

            # 加入歷史記錄
            history.append({
                'time': sensor_data['last_update'],
                'temp': sensor_data['temperature'],
                'humi': sensor_data['humidity'],
                'soil': sensor_data['soil_moisture']
            })

            # 只保留最近 100 筆
            if len(history) > 100:
                history.pop(0)

        except Exception as e:
            print(f"感測器錯誤: {e}")

        time.sleep(5)

# API 路由
@app.route('/api/sensors')
def get_sensors():
    return jsonify(sensor_data)

@app.route('/api/history')
def get_history():
    return jsonify(history[-20:])  # 返回最近 20 筆

@app.route('/api/control/<device>/<action>')
def control_device(device, action):
    if device == 'fan':
        if action == 'on':
            fan_relay.on()
            sensor_data['fan_status'] = True
        else:
            fan_relay.off()
            sensor_data['fan_status'] = False

    elif device == 'pump':
        if action == 'on':
            pump_relay.on()
            sensor_data['pump_status'] = True
        else:
            pump_relay.off()
            sensor_data['pump_status'] = False

    return jsonify({'success': True, 'device': device, 'status': action})

# 簡單的網頁介面
@app.route('/')
def index():
    html = '''
    <!DOCTYPE html>
    <html>
    <head>
        <title>智慧溫室監控</title>
        <meta charset="UTF-8">
        <meta http-equiv="refresh" content="5">
        <style>
            body { font-family: Arial; max-width: 800px; margin: 0 auto; padding: 20px; }
            .card { background: #f5f5f5; padding: 20px; margin: 10px 0; border-radius: 10px; }
            .value { font-size: 32px; font-weight: bold; }
            button { padding: 10px 20px; margin: 5px; cursor: pointer; }
            .on { background: #4CAF50; color: white; }
            .off { background: #ccc; }
        </style>
    </head>
    <body>
        <h1>智慧溫室監控系統</h1>
        <div class="card">
            <h3>溫度</h3>
            <div class="value">{{ data.temperature }}°C</div>
        </div>
        <div class="card">
            <h3>濕度</h3>
            <div class="value">{{ data.humidity }}%</div>
        </div>
        <div class="card">
            <h3>土壤濕度</h3>
            <div class="value">{{ data.soil_moisture }}%</div>
        </div>
        <div class="card">
            <h3>設備控制</h3>
            <div>
                風扇:
                <a href="/api/control/fan/on"><button class="{{ 'on' if data.fan_status else 'off' }}">開啟</button></a>
                <a href="/api/control/fan/off"><button class="{{ 'off' if data.fan_status else 'on' }}">關閉</button></a>
            </div>
            <div>
                水泵:
                <a href="/api/control/pump/on"><button class="{{ 'on' if data.pump_status else 'off' }}">開啟</button></a>
                <a href="/api/control/pump/off"><button class="{{ 'off' if data.pump_status else 'on' }}">關閉</button></a>
            </div>
        </div>
        <p>最後更新: {{ data.last_update }}</p>
    </body>
    </html>
    '''
    return render_template_string(html, data=sensor_data)

if __name__ == '__main__':
    # 啟動感測器執行緒
    t = threading.Thread(target=sensor_thread, daemon=True)
    t.start()

    # 啟動網頁伺服器
    print("伺服器啟動於 http://0.0.0.0:5000")
    app.run(host='0.0.0.0', port=5000)

常見問題與排除

問題一：無法開機

症狀：接上電源後沒有反應，或紅燈閃爍

檢查項目：
□ 電源供應器是否足夠（5V 3A）
□ SD 卡是否正確插入
□ SD 卡系統是否正確燒錄
□ SD 卡是否損壞

解決方案：
1. 使用官方電源供應器
2. 重新燒錄系統到 SD 卡
3. 嘗試不同的 SD 卡

問題二：無法連接 WiFi

症狀：找不到 WiFi 或無法連線

檢查項目：
□ WiFi 名稱和密碼是否正確
□ 是否使用 2.4GHz WiFi（Pi 3B 不支援 5GHz）
□ WiFi 國家設定是否正確

解決方案：
1. 在 Imager 重新設定 WiFi
2. 或編輯 /etc/wpa_supplicant/wpa_supplicant.conf

問題三：SSH 無法連線

症狀：連線被拒絕或超時

檢查項目：
□ SSH 是否已啟用
□ IP 位址是否正確
□ 防火牆設定

解決方案：
1. 在 SD 卡 boot 分區建立空白的 ssh 檔案
2. 確認樹莓派已連接網路
3. 使用 ping 測試連通性

問題四：GPIO 沒有反應

症狀：程式執行但 GPIO 沒有輸出

檢查項目：
□ 接線是否正確
□ GPIO 編號是否正確（BCM vs BOARD）
□ 是否有足夠權限

解決方案：
1. 確認使用正確的 GPIO 編號
2. 使用 sudo 執行程式
3. 檢查是否有其他程式佔用 GPIO

問題五：溫度過高

症狀：系統變慢或自動降頻

檢查項目：
□ 是否有足夠散熱
□ 環境溫度是否過高

解決方案：
1. 安裝散熱片
2. 使用散熱風扇
3. 使用金屬外殼（導熱）
4. 避免放在密閉空間
