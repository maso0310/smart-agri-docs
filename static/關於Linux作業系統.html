關於 Linux 作業系統

「Linux 無所不在：從你的手機到超級電腦，從智慧家電到國際太空站，Linux 驅動著這個世界。」

什麼是 Linux？

Linux 是一個開源的作業系統核心（Kernel），由芬蘭大學生 Linus Torvalds 於 1991 年創建。它是類 Unix 系統，遵循 POSIX 標準，以穩定、安全、開放著稱。

關於 Linus Torvalds

「Talk is cheap. Show me the code.」（空談廉價，給我看程式碼。）
— Linus Torvalds

Linus Torvalds 是 Linux 核心和 Git 版本控制系統的創造者。他至今仍是 Linux 核心的首席維護者，負責最終決定哪些程式碼能夠進入核心。

Linux 發行版（Distributions）

Linux 核心本身只是作業系統的核心部分。發行版（簡稱 Distro）是將 Linux 核心與應用程式、套件管理器、桌面環境等打包在一起的完整作業系統。

常見發行版比較

發行版 特點 適合對象 套件管理
Ubuntu 使用者友善、社群大、資源多 初學者、桌面使用 apt (deb)
Debian 穩定、保守、純自由軟體 伺服器、進階使用者 apt (deb)
Fedora 新技術先驅、GNOME 旗艦 開發者、愛好者 dnf (rpm)
CentOS/Rocky 企業級穩定、長期支援 企業伺服器 dnf (rpm)
Arch Linux 滾動更新、高度客製化 進階使用者 pacman
Linux Mint 類似 Windows、開箱即用 Windows 轉換者 apt (deb)
Raspberry Pi OS 樹莓派專用、GPIO 支援 樹莓派使用者 apt (deb)
Alpine Linux 極輕量、安全導向 容器、嵌入式 apk

Linux 檔案系統結構

Linux 使用階層式的目錄結構，一切從根目錄 / 開始。與 Windows 不同，Linux 沒有磁碟機代號（C:、D:），所有東西都掛載在同一個樹狀結構下。

路徑概念

絕對路徑 vs 相對路徑：
────────────────────────────────────────────────────────

絕對路徑：從根目錄 / 開始的完整路徑
  /home/pi/Documents/project/main.py

相對路徑：相對於目前目錄的路徑
  ./main.py          （目前目錄下的 main.py）
  ../config.txt      （上一層目錄的 config.txt）
  Documents/file     （目前目錄下的 Documents 資料夾中的 file）

特殊目錄符號：
  /      根目錄
  ~      目前使用者的家目錄（例如 /home/pi）
  .      目前目錄
  ..     上一層目錄

│  ─────────────────────────────                                  │
│  - UID 1-999（通常）                                            │

權限修改指令：
──────────────────────────────────────────────────────────────────

# chmod - 修改權限
chmod 755 file           使用數字設定權限
chmod u+x file           給擁有者加上執行權限
chmod g-w file           移除群組的寫入權限
chmod o=r file           設定其他人只有讀取權限
chmod a+x file           給所有人加上執行權限
chmod -R 755 dir         遞迴修改目錄權限

# chown - 修改擁有者
sudo chown user file              修改擁有者
sudo chown user:group file        同時修改擁有者和群組
sudo chown -R user:group dir      遞迴修改

# chgrp - 修改群組
sudo chgrp group file

樹莓派基本設定流程

# 1. 更新系統
sudo apt update && sudo apt upgrade -y

# 2. 設定系統（語系、時區、介面等）
sudo raspi-config

# 3. 啟用 SSH（如果還沒啟用）
sudo systemctl enable ssh
sudo systemctl start ssh

# 4. 查看 IP 位址
hostname -I

# 5. 安裝常用工具
sudo apt install vim git python3-pip

# 6. 設定靜態 IP（可選）
# 編輯 /etc/dhcpcd.conf
sudo nano /etc/dhcpcd.conf

# 加入：
interface eth0
static ip_address=192.168.1.100/24
static routers=192.168.1.1
static domain_name_servers=8.8.8.8

# 7. 重新啟動網路
sudo systemctl restart dhcpcd

│                    管線與重導向                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  管線（|）將前一個指令的輸出作為下一個指令的輸入                │
│  ──────────────────────────────────────                         │
│  ls -la | grep ".txt"        列出 .txt 檔案                     │
│  cat file | wc -l            計算檔案行數                       │
│  ps aux | grep python        找出 python 程序                   │
│  history | tail -20          顯示最近 20 個指令                 │
│                                                                 │
│  輸出重導向（>、>>）                                            │
│  ──────────────────────────────────────                         │
│  echo "hello" > file         輸出到檔案（覆蓋）                 │
│  echo "world" >> file        輸出到檔案（附加）                 │
│  ls > filelist.txt           將 ls 結果存到檔案                 │
│  command 2> error.log        將錯誤輸出存到檔案                 │
│  command > out.log 2>&1      將正常和錯誤輸出都存到檔案         │
│  command &> all.log          同上（較簡短的寫法）               │
│                                                                 │
│  輸入重導向（<）                                                │
│  ──────────────────────────────────────                         │
│  command < file              從檔案讀取輸入                     │
│  mysql < script.sql          執行 SQL 腳本                      │
│                                                                 │
│  常用組合：                                                     │
│  ──────────────────────────────────────                         │
│  cat file | sort | uniq      排序並去除重複                     │
