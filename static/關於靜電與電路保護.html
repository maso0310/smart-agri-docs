關於靜電與電路保護

靜電是電子電路的隱形殺手。了解靜電的危害與防護措施，可以大幅降低元件損壞的風險。

一、什麼是靜電（ESD）

ESD（Electrostatic Discharge，靜電放電）是指靜電荷在物體間快速轉移的現象。

日常靜電來源

情境 產生電壓
走過地毯 1,500 ~ 35,000V
拿起塑膠袋 1,200 ~ 20,000V
坐在椅子上起身 1,500 ~ 18,000V
穿脫毛衣 7,000 ~ 15,000V

人體感知靜電的門檻約 3,000V，但許多電子元件在 100V 以下就會損壞！

為什麼靜電會傷害電路

電子元件內部的電路非常精密，尤其是：
- MOSFET 電晶體：閘極氧化層極薄，數十伏特就可能擊穿
- IC 晶片：內部線路寬度僅奈米等級
- 微控制器（如 Arduino、ESP8266）：內含大量敏感電路

靜電放電時，瞬間電流可達數安培，足以燒毀微小的電路結構。

二、靜電對常見元件的影響

2.1 敏感度分類

敏感度等級 元件類型 損壞電壓
極高敏感 MOSFET、JFET、CMOS IC < 100V
高敏感 運算放大器、微控制器 100 ~ 500V
中等敏感 LED、二極體、電晶體 500 ~ 2000V
低敏感 電阻、電容、繼電器 > 2000V

2.2 常見 Arduino 相關元件敏感度

元件 敏感度 注意事項
Arduino UNO 中高 ATmega328P 需注意
ESP8266 / ESP32 高 WiFi 晶片敏感
DHT11 / DHT22 中 內部有 IC
OLED 螢幕 高 驅動 IC 敏感
伺服馬達 低 相對耐受
繼電器模組 低 機械結構為主
LED 中 直接觸摸影響小
步進馬達驅動板 高 含 MOSFET

三、靜電損壞的類型

3.1 立即性損壞（Catastrophic Failure）

元件當場失效，完全無法運作。
- 症狀：元件發熱、燒焦痕跡、完全不動作
- 容易發現，但元件報廢

3.2 潛在性損壞（Latent Damage）

更危險的情況！

元件受損但仍能運作，但：
- 效能下降
- 穩定性變差
- 壽命大幅縮短
- 可能在日後突然失效

這種損壞難以察覺，元件可能在使用數週或數月後才出問題。

四、靜電防護措施

4.1 個人防護

防靜電手環

最有效的個人防護工具：

│                                     │
│    [手環] ──── [導線] ──── [接地]   │
│                                     │
│    • 手環緊貼手腕                   │
│    • 導線連接到接地點               │
│    • 電阻約 1MΩ（安全放電）         │
│                                     │
└─────────────────────────────────────┘

使用方式：
1. 將手環戴在手腕上，金屬片接觸皮膚
2. 鱷魚夾夾在接地點（如電腦機殼金屬部分）
3. 確保導線沒有斷裂

沒有手環時的替代方案

方法 操作 效果

避免合成纖維 穿棉質衣物 預防
洗手 操作前洗手擦乾 輔助

4.3 元件存放

防靜電袋的種類

類型 外觀 用途
粉紅色防靜電袋 粉紅半透明 防止摩擦產生靜電
銀色屏蔽袋 銀灰色金屬感 完全隔絕外部靜電
黑色導電袋 黑色不透明 導電保護，適合運輸

正確存放方式：
- IC 晶片插在導電泡棉上
- 開發板放入原廠防靜電袋
- 散裝元件用防靜電盒分類

五、電路串接時的注意事項

5.1 操作前準備

  1. 整理工作區
  2. 清除塑膠袋、保麗龍等易產生靜電的物品

  3. 準備好所有需要的元件

  4. 釋放身體靜電

  5. 戴上防靜電手環，或

  6. 觸摸接地金屬 5 秒以上

  7. 確認濕度

  8. 乾燥環境靜電更容易產生
  9. 冬天或冷氣房要特別注意

5.2 拿取元件的正確方式

IC 晶片

正確拿法：
     ┌───────────┐
     │  IC 晶片  │
     └───────────┘
         ↑
    握住兩側邊緣
    避免碰觸接腳

錯誤拿法：
     ┌───────────┐
     │  IC 晶片  │  ← 手指壓在晶片上
     └─┬─┬─┬─┬─┬─┘
       ↑ ↑ ↑ ↑ ↑
      碰觸到接腳 ✗

開發板

正確拿法：
┌─────────────────────┐
│                     │
│    Arduino UNO      │
│                     │
└─────────────────────┘
  ↑                 ↑
握住板子邊緣，避免碰觸：
- USB 接口金屬部分
- 排針接腳
- 晶片表面

5.3 插拔元件的安全步驟

正確順序：

  1. 確保電路斷電
  2. 釋放身體靜電
  3. 一手扶穩電路板
  4. 另一手拿取元件邊緣
  5. 對準位置輕輕插入
  6. 確認方向正確再通電

常見錯誤：
- ❌ 帶電插拔元件
- ❌ 用力過猛導致接腳彎曲
- ❌ 在地毯上操作
- ❌ 穿著毛衣操作

5.4 焊接時的靜電防護

注意事項 說明
使用接地烙鐵 烙鐵頭接地可防止靜電
先焊不敏感元件 電阻、電容先焊
敏感元件最後焊 IC、微控制器最後處理
避免長時間加熱 快速完成焊接

六、靜電損壞的診斷

6.1 懷疑靜電損壞時的檢查

症狀 可能原因
元件完全不動作 立即性損壞
時好時壞 潛在性損壞
異常發熱 內部短路
電流消耗異常 漏電
數值讀取不穩定 內部電路受損

6.2 簡易測試方法

對於 Arduino：

void setup() {
  Serial.begin(9600);
  Serial.println("Arduino 正常運作");

  // 測試所有數位腳位
  for (int i = 2; i <= 13; i++) {
    pinMode(i, OUTPUT);
    digitalWrite(i, HIGH);
    delay(100);
    digitalWrite(i, LOW);
  }
  Serial.println("腳位測試完成");
}

void loop() {
  // 持續監控
  Serial.println(millis());
  delay(1000);
}

如果某些腳位無法正常輸出，可能已受損。

八、常見問題 FAQ

Q1：普通塑膠袋可以裝電子元件嗎？

不建議。 普通塑膠袋：
- 摩擦會產生靜電
- 無法隔絕外部靜電
- 可能造成潛在損壞

應使用粉紅色防靜電袋或銀色屏蔽袋。

Q2：防靜電手環一定要接地嗎？

最好要接地。
- 接地型手環效果最好
- 無線型手環效果有限
- 沒有手環時，頻繁觸摸接地金屬

Q3：室內濕度多少最安全？

40% ~ 60% RH 最佳。
- 濕度太低（<30%）：靜電容易累積
- 濕度太高（>70%）：可能造成結露

Q4：新買的元件需要特別處理嗎？

保持在原包裝內直到使用。
- 原廠包裝通常有防靜電設計
- 拆封後盡快使用或轉存到防靜電袋
- 不要隨意放在桌面上

Q5：學生實驗課需要很嚴格的防護嗎？

基本防護即可：
1. 操作前觸摸接地金屬
2. 避免穿毛衣操作
3. 保持桌面整潔，移除塑膠袋
4. 斷電後再插拔元件

九、重點總結

必記守則

  1. 操作前先放電 - 觸摸接地金屬或戴手環
  2. 握邊緣不握腳 - 拿元件時握邊緣
  3. 斷電再插拔 - 永遠在斷電狀態操作
  4. 妥善存放 - 使用防靜電袋保存元件
  5. 保持適當濕度 - 避免過於乾燥的環境

高風險情境

  • 冬天乾燥的室內
  • 冷氣房
  • 鋪地毯的房間
  • 穿著合成纖維衣物
  • 剛拆開塑膠包裝後
