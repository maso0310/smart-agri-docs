關於 Scikit-learn 套件

Scikit-learn（sklearn）是 Python 最受歡迎的機器學習套件，提供簡潔一致的 API 來實作各種機器學習演算法。適合傳統機器學習任務，是入門 ML 的最佳選擇。

二、核心 API 設計

一致的介面

所有模型都遵循相同的介面：

# 所有模型的通用流程
model = SomeModel(parameters)  # 初始化
model.fit(X_train, y_train)    # 訓練
predictions = model.predict(X_test)  # 預測
score = model.score(X_test, y_test)  # 評估

Estimator 類型

類型方法用途
分類器predict(), predict_proba()分類任務
迴歸器predict()迴歸任務
轉換器fit_transform(), transform()資料轉換
分群器fit_predict()非監督式分群

五、模型評估

分類指標

from sklearn.metrics import (
    accuracy_score, precision_score, recall_score, f1_score,
    classification_report, confusion_matrix
)

# 準確率
acc = accuracy_score(y_test, y_pred)

# 精確率、召回率、F1
precision = precision_score(y_test, y_pred, average='weighted')
recall = recall_score(y_test, y_pred, average='weighted')
f1 = f1_score(y_test, y_pred, average='weighted')

# 完整報告
print(classification_report(y_test, y_pred))

# 混淆矩陣
cm = confusion_matrix(y_test, y_pred)

迴歸指標

from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score

mse = mean_squared_error(y_test, y_pred)
rmse = mean_squared_error(y_test, y_pred, squared=False)
mae = mean_absolute_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)

交叉驗證

from sklearn.model_selection import cross_val_score, KFold

# 5 折交叉驗證
scores = cross_val_score(model, X, y, cv=5, scoring='accuracy')
print(f"準確率: {scores.mean():.3f} (+/- {scores.std()*2:.3f})")

# 自訂 K 折
kfold = KFold(n_splits=10, shuffle=True, random_state=42)
scores = cross_val_score(model, X, y, cv=kfold)

七、Pipeline 與超參數調整

Pipeline

from sklearn.pipeline import Pipeline

# 建立 Pipeline
pipe = Pipeline([
    ('scaler', StandardScaler()),
    ('pca', PCA(n_components=10)),
    ('classifier', RandomForestClassifier())
])

# 訓練與預測
pipe.fit(X_train, y_train)

超參數搜尋

from sklearn.model_selection import GridSearchCV, RandomizedSearchCV

# Grid Search
param_grid = {
    'n_estimators': [50, 100, 200],
    'max_depth': [3, 5, 10, None],
    'min_samples_split': [2, 5, 10]
}

grid_search = GridSearchCV(
    RandomForestClassifier(),
    param_grid,
    cv=5,
    scoring='accuracy',
    n_jobs=-1
)
grid_search.fit(X_train, y_train)

print(f"最佳參數: {grid_search.best_params_}")
print(f"最佳分數: {grid_search.best_score_:.3f}")
best_model = grid_search.best_estimator_

八、農業應用範例

作物分類

import pandas as pd
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import classification_report

# 假設資料包含：NDVI, 溫度, 濕度, 土壤pH 等特徵
data = pd.read_csv('crop_data.csv')
X = data[['ndvi', 'temperature', 'humidity', 'soil_ph', 'rainfall']]
y = data['crop_type']

# 分割
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 訓練
clf = RandomForestClassifier(n_estimators=100, random_state=42)
clf.fit(X_train, y_train)

# 評估
y_pred = clf.predict(X_test)
print(classification_report(y_test, y_pred))

# 特徵重要性
importance = pd.DataFrame({
    'feature': X.columns,
    'importance': clf.feature_importances_
}).sort_values('importance', ascending=False)
print(importance)

產量預測

from sklearn.ensemble import GradientBoostingRegressor
from sklearn.metrics import mean_absolute_error, r2_score

# 特徵：氣象、土壤、施肥量等
X = data[['avg_temp', 'total_rainfall', 'fertilizer_n', 'soil_organic']]
y = data['yield_kg_per_ha']

# 訓練
reg = GradientBoostingRegressor(n_estimators=100)
reg.fit(X_train, y_train)

# 預測與評估
y_pred = reg.predict(X_test)
print(f"MAE: {mean_absolute_error(y_test, y_pred):.2f} kg/ha")
print(f"R²: {r2_score(y_test, y_pred):.3f}")
