Arduino 常見錯誤排解指南

本文整理了 Arduino 開發過程中最常遇到的錯誤與解決方法，幫助你快速排除問題。

一、編譯錯誤（Compile Error）

編譯錯誤發生在「驗證」或「上傳」時，程式碼有語法問題。

1.1 找不到函式庫

錯誤訊息：

fatal error: DHT.h: No such file or directory

原因： 尚未安裝所需的函式庫

解決方法：
1. 開啟 Arduino IDE
2. 工具 → 管理程式庫
3. 搜尋函式庫名稱（如 DHT）
4. 點擊「安裝」

常用函式庫 用途
DHT sensor library DHT11/DHT22 溫溼度
LiquidCrystal_I2C I2C LCD 螢幕
Servo 伺服馬達
IRremote 紅外線遙控
Stepper 步進馬達
Wire I2C 通訊

1.2 變數未宣告

錯誤訊息：

error: 'ledPin' was not declared in this scope

原因： 使用了未定義的變數

解決方法：

// 錯誤
void setup() {
  pinMode(ledPin, OUTPUT);  // ledPin 未定義
}

// 正確
int ledPin = 13;  // 先宣告變數
void setup() {
  pinMode(ledPin, OUTPUT);
}

1.3 缺少分號

錯誤訊息：

error: expected ';' before 'delay'

原因： 上一行結尾少了分號 ;

解決方法：

// 錯誤
digitalWrite(LED, HIGH)  // 少了分號
delay(1000);

// 正確
digitalWrite(LED, HIGH);  // 加上分號
delay(1000);

1.4 括號不配對

錯誤訊息：

error: expected '}' at end of input

原因： 大括號 {} 或小括號 () 數量不對

解決方法：
- 檢查每個 { 是否都有對應的 }
- 使用 IDE 的自動格式化（Ctrl+T）幫助檢查
- 點擊括號時，IDE 會高亮對應的另一個括號

1.5 函數重複定義

錯誤訊息：

error: redefinition of 'void setup()'

原因： 同一個函數被定義了兩次

解決方法：
- 檢查是否有兩個 setup() 或兩個 loop()
- 確保每個函數只定義一次

二、上傳錯誤（Upload Error）

程式碼正確，但無法上傳到開發板。

2.1 找不到開發板 / COM Port

錯誤訊息：

Serial port 'COM3' not found

或

No device found on COM3

解決方法：

步驟 操作
1 確認 USB 線有連接好
2 檢查 USB 線是否支援資料傳輸（非純充電線）
3 工具 → 序列埠 → 選擇正確的 COM Port
4 裝置管理員 → 確認有顯示 Arduino 或 CH340

如果裝置管理員顯示驚嘆號：
- 需要安裝驅動程式
- CH340：下載 CH340 驅動
- CP2102：下載 CP2102 驅動
- 原廠 Arduino：通常自動安裝

2.2 開發板類型選錯

錯誤訊息：

avrdude: stk500_recv(): programmer is not responding

解決方法：
1. 工具 → 開發板 → 選擇正確的開發板
2. 常見對應：

開發板 選擇
Arduino UNO Arduino Uno
Arduino Nano（新版） Arduino Nano
Arduino Nano（舊版） Arduino Nano + ATmega328P (Old Bootloader)
ESP8266 Generic ESP8266 Module 或 NodeMCU
ESP32 ESP32 Dev Module

2.3 COM Port 被占用

錯誤訊息：

Serial port COM3 already in use

解決方法：
1. 關閉其他可能使用該 COM Port 的程式（如 Serial Monitor、Python 程式）
2. 關閉 Arduino IDE 後重新開啟
3. 拔掉 USB 重新插入

2.4 ESP8266/ESP32 上傳失敗

錯誤訊息：

Failed to connect to ESP8266: Timed out waiting for packet header

解決方法：
1. 按住開發板上的 BOOT/FLASH 按鈕
2. 點擊上傳
3. 看到「Connecting...」時放開按鈕
4. 或者接線時將 GPIO0 接到 GND

三、執行時錯誤（Runtime Error）

程式上傳成功，但執行結果不如預期。

3.1 感測器讀數異常

現象： 溫度顯示 0、-999 或 NaN

原因與解決：

原因 解決方法
接線錯誤 確認 VCC、GND、DATA 接線正確
腳位設定錯誤 檢查程式中的腳位編號是否與實際接線一致
需要上拉電阻 DHT11 的 DATA 腳需接 10K 上拉電阻到 VCC
感測器損壞 更換感測器測試
讀取太頻繁 DHT11 最快 1 秒讀一次，加入 delay(2000)

3.2 LCD 不顯示或亂碼

現象： LCD 背光亮但沒有字，或顯示方塊

解決方法：

問題 解決
背光亮無字 調整背面的可變電阻（對比度）
I2C 位址錯誤 執行 I2C 掃描程式找到正確位址
接線錯誤 SDA→A4, SCL→A5（UNO）

I2C 位址掃描程式：

#include <Wire.h>

void setup() {
  Wire.begin();
  Serial.begin(9600);
  Serial.println("掃描 I2C 設備...");

  for (byte address = 1; address < 127; address++) {
    Wire.beginTransmission(address);
    if (Wire.endTransmission() == 0) {
      Serial.print("找到設備: 0x");
      Serial.println(address, HEX);
    }
  }
}

void loop() {}

常見 I2C 位址：0x27 或 0x3F

3.3 馬達不轉或抖動

現象： 馬達完全不動，或只抖動不轉

解決方法：

問題 解決
電源不足 馬達需要獨立電源，不能只靠 Arduino 5V
接線錯誤 檢查驅動板接線
PWM 值太低 馬達需要一定電壓才會轉，嘗試較高的 PWM 值
伺服馬達角度超出範圍 SG90 範圍約 0-180 度

3.4 Serial Monitor 顯示亂碼

現象： Serial Monitor 顯示奇怪符號

原因： 鮑率（Baud Rate）設定不一致

解決方法：

// 程式中設定
Serial.begin(9600);  // 使用 9600

// Serial Monitor 右下角也要選擇 9600

常用鮑率：9600、115200

3.5 繼電器不動作

現象： 繼電器沒有喀噠聲

解決方法：

問題 解決
觸發電平錯誤 確認是高電平還是低電平觸發（大多是低電平）
電源不足 繼電器模組需要 5V 電源
腳位錯誤 確認訊號腳接對 
// 低電平觸發
digitalWrite(relayPin, LOW);   // 繼電器 ON
digitalWrite(relayPin, HIGH);  // 繼電器 OFF

// 高電平觸發
digitalWrite(relayPin, HIGH);  // 繼電器 ON
digitalWrite(relayPin, LOW);   // 繼電器 OFF

四、WiFi 連線問題（ESP8266/ESP32）

4.1 無法連線 WiFi

現象： 一直顯示「Connecting...」

解決方法：

原因 解決
SSID 或密碼錯誤 注意大小寫，不能有多餘空格
2.4GHz vs 5GHz ESP8266/ESP32 只支援 2.4GHz
訊號太弱 移近路由器測試
特殊字元 WiFi 名稱避免使用中文或特殊符號

4.2 MQTT 連線失敗

現象： 無法連線到 MQTT Broker

解決方法：
1. 確認 Broker 位址和 Port 正確
2. 確認網路連線正常
3. 確認 Client ID 唯一（不能重複）
4. 如果使用 TLS，確認憑證設定

五、電源相關問題

5.1 Arduino 不斷重啟

現象： 程式跑一下就重新啟動

原因： 電源供應不穩定或電流不足

解決方法：
- 使用外部電源供應器（7-12V）
- 大電流元件（馬達、LED 燈條）使用獨立電源
- 加入電容穩壓

5.2 USB 供電不足

現象： 接上馬達或多個感測器後不穩定

原因： USB 電流有限（約 500mA）

解決方法：
- 使用外部電源
- 使用 VIN 腳位供電（7-12V）
- 馬達使用獨立電源

六、快速排錯檢查清單

遇到問題時，依序檢查：

編譯問題

  • [ ] 函式庫是否已安裝？
  • [ ] 變數是否有宣告？
  • [ ] 分號是否都有加？
  • [ ] 括號是否配對？

上傳問題

  • [ ] USB 線是否為資料線？
  • [ ] COM Port 是否選對？
  • [ ] 開發板類型是否選對？
  • [ ] 驅動程式是否已安裝？

執行問題

  • [ ] 接線是否正確？
  • [ ] 電源是否足夠？
  • [ ] 腳位編號是否與程式一致？
  • [ ] Serial Monitor 鮑率是否正確？

七、常用除錯技巧

7.1 使用 Serial.print 除錯

void loop() {
  int sensorValue = analogRead(A0);

  // 印出數值來檢查
  Serial.print("感測器數值: ");
  Serial.println(sensorValue);

  delay(1000);
}

7.2 LED 指示燈除錯

// 用內建 LED 確認程式有在執行
void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  // 執行某些操作
  digitalWrite(LED_BUILTIN, LOW);
  delay(100);
}

7.3 分段測試

將程式拆成小部分，逐一測試：
1. 先測試感測器能否正確讀值
2. 再測試顯示器能否正常顯示
3. 最後整合在一起
