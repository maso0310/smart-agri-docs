關於各種電子線材

走進電子材料行，各式各樣的線材讓人眼花撩亂。本文整理常見線材的種類、用途與選購要點，幫助你快速找到需要的線材。

一、杜邦線（Jumper Wire）

最常用的 Arduino 接線工具，方便快速搭建電路原型。

1.1 三種接頭類型

類型 外觀 用途
公對公（M-M） 兩端都是針腳 麵包板之間連接
公對母（M-F） 一端針腳、一端插孔 Arduino 腳位接到麵包板
母對母（F-F） 兩端都是插孔 連接模組的排針

1.2 圖示說明

────┤   ├──────────┤   ├────
    └───┘   導線   └───┘
    針腳            針腳

公對母 (Male-to-Female)
    ┌───┐          ╔═══╗
────┤   ├──────────╢   ╟────
    └───┘   導線   ╚═══╝
    針腳            插孔

母對母 (Female-to-Female)
    ╔═══╗          ╔═══╗

    插孔            插孔

1.3 常見規格

長度 適用場景
10cm 緊湊接線，麵包板內部
20cm 最常用，一般接線
30cm 較遠距離連接
40cm 模組間連接

1.4 選購建議

  • 初學者套裝：三種類型各 40 條（120 條組合包）
  • 顏色選擇：多色有助於識別不同訊號線
  • 品質辨別：接頭要緊實，線材要柔軟

二、單芯線與多芯線

2.1 單芯線（Solid Core Wire）

橫切面：
    ┌─────────┐
    │ ┌─────┐ │
    │ │ 銅  │ │ ← 單一銅芯
    │ └─────┘ │
    │  絕緣層  │
    └─────────┘

特點：
- 銅芯為單一實心導體
- 硬挺不易彎曲
- 適合插入麵包板
- 焊接後不易脫落

適用場景：
- 麵包板接線
- PCB 焊接
- 固定式配線

2.2 多芯線（Stranded Wire）

橫切面：
    ┌─────────┐
    │ ○○○○○○ │
    │ ○○○○○○ │ ← 多股細銅絲
    │ ○○○○○○ │
    │  絕緣層  │
    └─────────┘

特點：
- 由多股細銅絲組成
- 柔軟可彎曲
- 耐反覆彎折
- 導電面積較大

適用場景：
- 需要彎曲的配線
- 機器人、可動部件
- 長距離佈線

2.3 比較表

特性 單芯線 多芯線
柔軟度 硬 軟
耐彎折 差（易斷） 佳
麵包板適用 適合 不適合
焊接難度 簡單 需先絞線
價格 較便宜 較貴
載流量 較小 較大

三、矽膠線（Silicone Wire）

高品質的多芯線，專業玩家首選。

3.1 特點

優點 說明
超柔軟 比一般多芯線更柔軟
耐高溫 可耐 200°C 高溫
耐低溫 -60°C 也不會變硬
抗老化 不易氧化變質
絕緣佳 矽膠絕緣性能優異

3.2 常見規格（AWG）

AWG 外徑約 載流量 適用場景
30 0.8mm 0.5A 訊號線
26 1.3mm 1.3A 小電流
22 1.7mm 3A 一般用途
20 2.0mm 5A LED 燈條
18 2.3mm 7A 馬達電源
16 2.7mm 10A 大電流
14 3.2mm 15A 電池連接
12 4.0mm 20A 高功率

AWG 數字越小，線越粗，可承載電流越大

3.3 選購建議

  • 常備規格：22 AWG（一般用途）、18 AWG（電源線）
  • 顏色慣例：紅色=正極、黑色=負極、其他=訊號
  • 長度建議：每色各買 5-10 公尺

四、排線（Ribbon Cable）

多條導線並排的扁平線材。

4.1 結構

└──┴──┴──┴──┴──┴──┴──┴──┘
│紅│橙│黃│綠│藍│紫│灰│白│  ← 彩虹色順序

4.2 常見類型

類型 芯數 用途
彩虹排線 10/20/40 芯 通用接線、GPIO
IDC 排線 10/16/20/40 pin 連接擴充板

接頭類型 說明
杜邦頭 可自行壓接

五、漆包線（Enameled Wire）

表面塗有絕緣漆的銅線。

5.1 特點

橫切面：
    ┌───────┐
    │┌─────┐│
    ││ 銅 ││ ← 銅芯
    │└─────┘│
    │ 漆皮  │ ← 很薄的絕緣層
    └───────┘
  • 絕緣層極薄（僅漆皮）
  • 可密繞不短路
  • 需刮除或燒除漆皮才能焊接

5.2 用途

11.2 線材選擇公式

所需線徑計算：

電流 (A) × 安全係數 (1.5~2) = 參考載流量

例如：馬達需要 2A
     2A × 1.5 = 3A
     → 選擇 22 AWG（載流量 3A）或更粗

十三、常見問題 FAQ

Q1：麵包板該用什麼線？

單芯線或實心杜邦線。 多芯線太軟，插不進麵包板孔。

Q2：如何分辨充電線和數據線？

  • 數據線較粗（有 4 條內芯）
  • 充電線較細（只有 2 條電源線）
  • 測試方法：連接電腦看能否識別裝置

Q3：線材顏色有規定嗎？

建議遵循慣例但非強制：
- 紅色 = VCC（正極）
- 黑色 = GND（負極）
- 其他顏色 = 訊號線

Q4：電源線要選多粗？

根據電流選擇：
- 500mA 以下：26-28 AWG
- 1-3A：22-24 AWG
- 3-5A：20 AWG
- 5A 以上：18 AWG 或更粗

Q5：熱縮管用什麼加熱？

  • 熱風槍（最佳）
  • 打火機（小心燒焦）
  • 烙鐵側面（應急用）
  • 吹風機（效果較差）

Q6：杜邦線品質怎麼看？

  • 接頭插拔順暢不鬆脫
  • 線材柔軟不易斷
  • 顏色鮮明好辨識
  • 標示線號 AWG 規格
