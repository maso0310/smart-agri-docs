關於 TensorFlow 與 PyTorch

深度學習框架概述

TensorFlow 和 PyTorch 是當今最流行的兩大深度學習框架。 TensorFlow 由 Google Brain 團隊開發，於 2015 年開源；PyTorch 則由 Facebook AI Research (FAIR) 開發，於 2016 年發布。兩者各有特色，在學術研究和工業應用中都佔有重要地位。

在智慧農業領域，這兩個框架被廣泛應用於作物病蟲害識別、果實品質分類、產量預測、 無人機影像分析等任務。選擇合適的框架對於專案的成功至關重要。

框架核心比較

特性 TensorFlow PyTorch
開發公司 Google Brain Meta AI (Facebook)
發布時間 2015年11月 2016年10月
計算圖 靜態圖 (v1) / 動態圖 (v2) 動態圖 (Eager Execution)
API 風格 高階 (Keras) / 低階 Pythonic，直觀易用
調試難度 中等（TF2 已改善） 簡單，支援標準 Python 調試
部署能力 優秀 (TFLite, TF Serving) 良好 (TorchServe, ONNX)
視覺化 TensorBoard（內建） TensorBoard（需設定）
學術論文 較少 主流（約 70%+）
行動裝置 TensorFlow Lite PyTorch Mobile

PyTorch

import torch
import torch.nn as nn
import torch.nn.functional as F

class CNN(nn.Module):
    def __init__(self, num_classes=10):
        super(CNN, self).__init__()
        # 卷積層
        self.conv1 = nn.Conv2d(3, 32, 3)
        self.pool = nn.MaxPool2d(2, 2)

        self.conv2 = nn.Conv2d(32, 64, 3)
        self.conv3 = nn.Conv2d(64, 128, 3)

        # 全連接層
        self.fc1 = nn.Linear(128 * 26 * 26, 256)
        self.dropout = nn.Dropout(0.5)
        self.fc2 = nn.Linear(256, num_classes)

    def forward(self, x):
        x = self.pool(F.relu(self.conv1(x)))
        x = self.pool(F.relu(self.conv2(x)))
        x = self.pool(F.relu(self.conv3(x)))

        x = x.view(x.size(0), -1)  # Flatten
        x = F.relu(self.fc1(x))
        x = self.dropout(x)
        x = self.fc2(x)
        return x

model = CNN(num_classes=10)
print(model)

criterion = nn.CrossEntropyLoss()

# 訓練迴圈
for epoch in range(50):
    model.train()
    running_loss = 0.0

    for images, labels in train_loader:
        images, labels = images.to(device), labels.to(device)

        optimizer.zero_grad()
        outputs = model(images)
        loss = criterion(outputs, labels)
        loss.backward()
        optimizer.step()

        running_loss += loss.item()

遷移學習

遷移學習是深度學習中的重要技術，可以利用在大型資料集（如 ImageNet）上預訓練的模型， 遷移到特定任務上。這對於農業影像分析特別有用，因為通常我們只有少量標註資料。

TensorFlow 遷移學習

import tensorflow as tf
from tensorflow.keras.applications import ResNet50
from tensorflow.keras import layers, models

# 載入預訓練模型
base_model = ResNet50(
    weights='imagenet',
    include_top=False,
    input_shape=(224, 224, 3)
)

# 凍結預訓練權重
base_model.trainable = False

# 建立新模型
model = models.Sequential([
    base_model,
    layers.GlobalAveragePooling2D(),
    layers.Dense(256, activation='relu'),
    layers.Dropout(0.5),
    layers.Dense(5, activation='softmax')  # 5類作物病害
])

# 編譯模型
model.compile(
    optimizer=tf.keras.optimizers.Adam(1e-4),
    loss='categorical_crossentropy',
    metrics=['accuracy']
)

# 微調：解凍部分層
base_model.trainable = True
for layer in base_model.layers[:-20]:
    layer.trainable = False

# 重新編譯（使用較小學習率）
model.compile(
    optimizer=tf.keras.optimizers.Adam(1e-5),
    loss='categorical_crossentropy',
    metrics=['accuracy']
)

PyTorch 遷移學習

import torch
import torch.nn as nn
from torchvision import models

# 載入預訓練模型
base_model = models.resnet50(pretrained=True)

# 凍結預訓練權重
for param in base_model.parameters():
    param.requires_grad = False

# 修改最後的全連接層
num_features = base_model.fc.in_features
base_model.fc = nn.Sequential(
    nn.Linear(num_features, 256),
    nn.ReLU(),
    nn.Dropout(0.5),
    nn.Linear(256, 5)  # 5類作物病害
)

model = base_model.to(device)

# 只訓練新增的層
optimizer = torch.optim.Adam(
    model.fc.parameters(), lr=1e-4
)

# 微調：解凍部分層
for param in model.layer4.parameters():
    param.requires_grad = True

# 更新優化器（較小學習率）
optimizer = torch.optim.Adam([
    {'params': model.layer4.parameters(), 'lr': 1e-5},
    {'params': model.fc.parameters(), 'lr': 1e-4}
])

智慧農業應用範例

作物病害識別系統

以下範例展示如何使用 PyTorch 建立一個作物病害識別系統：

import torch
import torch.nn as nn
from torchvision import models, transforms
from PIL import Image
import os

class CropDiseaseClassifier:
    """作物病害分類器"""

    def __init__(self, model_path, class_names, device=None):
        """
        初始化分類器

        Args:
            model_path: 訓練好的模型路徑
            class_names: 類別名稱列表
            device: 計算裝置
        """
        self.device = device or torch.device(
            'cuda' if torch.cuda.is_available() else 'cpu'
        )
        self.class_names = class_names

        # 載入模型
        self.model = models.resnet50(pretrained=False)
        num_features = self.model.fc.in_features
        self.model.fc = nn.Linear(num_features, len(class_names))

        self.model.load_state_dict(torch.load(model_path, map_location=self.device))
        self.model = self.model.to(self.device)
        self.model.eval()

        # 影像預處理
        self.transform = transforms.Compose([
            transforms.Resize((224, 224)),
            transforms.ToTensor(),
            transforms.Normalize(
                mean=[0.485, 0.456, 0.406],
                std=[0.229, 0.224, 0.225]
            )
        ])

    def predict(self, image_path):
        """
        預測單張影像

        Args:
            image_path: 影像路徑

        Returns:
            dict: 包含預測類別、信心度和所有類別機率
        """
        # 載入並預處理影像
        image = Image.open(image_path).convert('RGB')
        input_tensor = self.transform(image).unsqueeze(0).to(self.device)

        # 推論
        with torch.no_grad():
            outputs = self.model(input_tensor)
            probabilities = torch.nn.functional.softmax(outputs, dim=1)
            confidence, predicted = torch.max(probabilities, 1)

        # 取得所有類別機率
        all_probs = {
            name: prob.item()
            for name, prob in zip(self.class_names, probabilities[0])
        }

        return {
            'class': self.class_names[predicted.item()],
            'confidence': confidence.item(),
            'probabilities': all_probs
        }

    def predict_batch(self, image_paths, batch_size=32):
        """批次預測多張影像"""
        results = []

        for i in range(0, len(image_paths), batch_size):
            batch_paths = image_paths[i:i+batch_size]
            batch_tensors = []

            for path in batch_paths:
                image = Image.open(path).convert('RGB')
                tensor = self.transform(image)
                batch_tensors.append(tensor)

            batch = torch.stack(batch_tensors).to(self.device)

            with torch.no_grad():
                outputs = self.model(batch)
                probs = torch.nn.functional.softmax(outputs, dim=1)
                confidences, predictions = torch.max(probs, 1)

            for j, path in enumerate(batch_paths):
                results.append({
                    'path': path,
                    'class': self.class_names[predictions[j].item()],
                    'confidence': confidences[j].item()
                })

        return results


# 使用範例
if __name__ == '__main__':
    # 病害類別
    disease_classes = [
        '健康',
        '細菌性斑點病',
        '早疫病',
        '晚疫病',
        '葉黴病',
        '黃葉捲曲病毒'
    ]

    # 初始化分類器
    classifier = CropDiseaseClassifier(
        model_path='tomato_disease_model.pth',
        class_names=disease_classes
    )

    # 單張影像預測
    result = classifier.predict('test_leaf.jpg')
    print(f"診斷結果: {result['class']}")
    print(f"信心度: {result['confidence']:.2%}")

    # 批次預測
    image_folder = 'field_images/'
    image_paths = [
        os.path.join(image_folder, f)
        for f in os.listdir(image_folder)
        if f.endswith(('.jpg', '.png'))
    ]

    batch_results = classifier.predict_batch(image_paths)

    # 統計分析
    disease_counts = {}
    for r in batch_results:
        disease = r['class']
        disease_counts[disease] = disease_counts.get(disease, 0) + 1

    print("\n田間病害分佈統計:")
    for disease, count in sorted(disease_counts.items(), key=lambda x: -x[1]):
        percentage = count / len(batch_results) * 100
        print(f"  {disease}: {count} 張 ({percentage:.1f}%)")

TensorFlow Lite 部署於邊緣裝置

import tensorflow as tf
import numpy as np
from PIL import Image

class EdgeDeviceClassifier:
    """邊緣裝置分類器（使用 TensorFlow Lite）"""

    def __init__(self, tflite_model_path, class_names):
        """
        初始化 TFLite 分類器

        Args:
            tflite_model_path: TFLite 模型路徑
            class_names: 類別名稱列表
        """
        # 載入 TFLite 模型
        self.interpreter = tf.lite.Interpreter(model_path=tflite_model_path)
        self.interpreter.allocate_tensors()

        # 取得輸入輸出資訊
        self.input_details = self.interpreter.get_input_details()
        self.output_details = self.interpreter.get_output_details()

        self.class_names = class_names

        # 取得輸入形狀
        self.input_shape = self.input_details[0]['shape'][1:3]

    def preprocess(self, image_path):
        """影像預處理"""
        image = Image.open(image_path).convert('RGB')
        image = image.resize(self.input_shape)
        image_array = np.array(image, dtype=np.float32)

        # 正規化
        image_array = image_array / 255.0
        image_array = np.expand_dims(image_array, axis=0)

        return image_array

    def predict(self, image_path):
        """執行推論"""
        input_data = self.preprocess(image_path)

        # 設定輸入
        self.interpreter.set_tensor(
            self.input_details[0]['index'],
            input_data
        )

        # 執行推論
        self.interpreter.invoke()

        # 取得輸出
        output_data = self.interpreter.get_tensor(
            self.output_details[0]['index']
        )

        # 解析結果
        predicted_idx = np.argmax(output_data[0])
        confidence = output_data[0][predicted_idx]

        return {
            'class': self.class_names[predicted_idx],
            'confidence': float(confidence)
        }


# 模型轉換函數
def convert_to_tflite(keras_model_path, output_path, quantize=False):
    """
    將 Keras 模型轉換為 TFLite 格式

    Args:
        keras_model_path: Keras 模型路徑
        output_path: 輸出 TFLite 模型路徑
        quantize: 是否進行量化
    """
    # 載入模型
    model = tf.keras.models.load_model(keras_model_path)

    # 建立轉換器
    converter = tf.lite.TFLiteConverter.from_keras_model(model)

    if quantize:
        # 動態範圍量化（減少模型大小）
        converter.optimizations = [tf.lite.Optimize.DEFAULT]

        # 完整整數量化（需要校正資料）
        # converter.target_spec.supported_types = [tf.int8]

    # 轉換
    tflite_model = converter.convert()

    # 儲存
    with open(output_path, 'wb') as f:
        f.write(tflite_model)

    print(f"模型已儲存至: {output_path}")
    print(f"模型大小: {len(tflite_model) / 1024 / 1024:.2f} MB")

選擇建議

選擇 PyTorch 的情況：
  • 學術研究和實驗原型開發
  • 需要頻繁調試和快速迭代
  • 團隊成員較熟悉 Python
  • 需要實現最新論文中的演算法
  • 使用動態計算圖的場景
選擇 TensorFlow 的情況：
  • 需要部署到生產環境（Web、行動裝置）
  • 需要完整的 MLOps 工具鏈
  • 需要 TensorFlow Lite 支援邊緣裝置
  • 專案需要使用 TensorFlow Extended (TFX)
  • 需要強大的視覺化工具 (TensorBoard)
