關於三用電表使用

三用電表（Multimeter）是電子電路測試與除錯最基本也最重要的工具。學會正確使用三用電表，可以快速診斷電路問題。

一、什麼是三用電表

1.1 基本介紹

三用電表能測量三種基本電學量：
- 電壓（Voltage） - 單位：伏特（V）
- 電流（Current） - 單位：安培（A）
- 電阻（Resistance） - 單位：歐姆（Ω）

現代數位三用電表（DMM, Digital Multimeter）通常還具備更多功能。

1.2 類型比較

類型 優點 缺點 價格範圍
指針式（類比） 觀察變化直覺、不需電池顯示 讀數較難、精度較低 NT$ 200-500
數位式（DMM） 讀數清楚、精度高、功能多 需要電池、反應稍慢 NT$ 300-2000+
自動量程 操作簡單、不怕選錯檔位 價格較高 NT$ 500+
手動量程 價格便宜、可控制精度 需要選對檔位 NT$ 300+

初學者建議：選擇自動量程的數位三用電表，操作簡單不易出錯。

2.2 旋轉開關檔位

符號 功能 說明
OFF 關閉 不使用時轉到此檔
V⎓ 或 DCV 直流電壓 測量電池、Arduino 輸出
V~ 或 ACV 交流電壓 測量家用電（危險！）
A 或 mA 電流 測量電路電流消耗
Ω 電阻 測量電阻值、檢查通斷
⫘ 或 ))) 通斷測試 檢查線路是否連通（會發出嗶聲）
⫘ 或 →|← 二極體測試 檢查二極體、LED 方向
hFE 電晶體測試 測量電晶體放大倍率
°C/°F 溫度 需搭配溫度探棒
Hz 頻率 測量訊號頻率
F 電容 測量電容值

2.3 測試棒插孔

插孔 顏色 用途
COM 黑色 共用端（負極/接地）
VΩmA 紅色 電壓、電阻、小電流測量
10A 或 20A 紅色 大電流測量（通常另一孔）

重要：測量電流時，紅色測試棒要插對孔位！

三、測量直流電壓（最常用）

3.1 適用場景

  • 檢查電源供應電壓
  • 測量 Arduino 腳位輸出
  • 檢查電池電量
  • 驗證電路各點電壓

3.2 操作步驟

步驟 1：插入測試棒
┌─────────────────┐
│  COM    VΩmA    │
│   ●       ●     │
│   ↑       ↑     │
│  黑棒    紅棒   │
└─────────────────┘

步驟 2：選擇檔位
• 自動量程：轉到 V⎓ 即可
• 手動量程：選擇大於預期電壓的檔位
  - 測 5V → 選 20V 檔
  - 測 12V → 選 20V 檔
  - 不確定 → 從最大檔位開始

步驟 3：測量
      ┌──────────┐
 紅棒 →│   +5V    │← 被測電壓正極
      │          │
 黑棒 →│   GND    │← 被測電壓負極
      └──────────┘

步驟 4：讀取數值
• 顯示正值：紅棒接正極
• 顯示負值：極性接反（不會損壞）

3.3 Arduino 電壓測量範例

測量 Arduino 的 5V 輸出：

    Arduino UNO
    ┌──────────────┐
    │              │
    │  5V  ●───────┼──→ 紅棒
    │              │
    │  GND ●───────┼──→ 黑棒
    │              │
    └──────────────┘

預期讀數：4.8V ~ 5.2V（正常範圍）

測量數位腳位輸出：

    Arduino UNO
    ┌──────────────┐
    │              │
    │  D13 ●───────┼──→ 紅棒
    │              │
    │  GND ●───────┼──→ 黑棒
    │              │
    └──────────────┘

預期讀數：
• HIGH 狀態：約 5V
• LOW 狀態：約 0V

3.4 常見問題

現象 可能原因
顯示 0V 電源未開、線路斷開、檔位錯誤
數值不穩定 接觸不良、電源不穩
顯示 OL 超出量程、斷路
數值偏低 電池沒電、負載過重

四、測量電阻

4.1 適用場景

  • 確認電阻值
  • 檢查線路是否斷開
  • 測量感測器電阻變化
  • 檢查焊點品質

4.2 操作步驟

重要：測量電阻前必須斷電！

步驟 1：斷開被測電路的電源

步驟 2：選擇 Ω 檔位
• 自動量程：轉到 Ω 即可
• 手動量程：
  - 測 1kΩ → 選 2kΩ 或 20kΩ 檔
  - 測 10kΩ → 選 20kΩ 或 200kΩ 檔

步驟 3：將測試棒接觸電阻兩端
       ┌─────┐
  紅棒 →│█████│← 黑棒
       └─────┘
        電阻

步驟 4：讀取數值
• 單位注意：Ω、kΩ、MΩ
• 1kΩ = 1000Ω
• 1MΩ = 1000kΩ = 1,000,000Ω

4.3 電阻色碼對照

四環電阻讀法：
┌─────────────────────────────┐
│  ██  ██  ██  ██             │
│  第1 第2 倍率 誤差           │
└─────────────────────────────┘

顏色對照：
黑=0  棕=1  紅=2  橙=3  黃=4
綠=5  藍=6  紫=7  灰=8  白=9

倍率環：
黑=×1  棕=×10  紅=×100  橙=×1k  黃=×10k

範例：棕黑橙金 = 10 × 1000 = 10kΩ（誤差±5%）

4.4 注意事項

注意事項 說明
必須斷電 帶電測量會損壞電表或得到錯誤數值
不要用手碰觸 人體電阻會影響測量結果
電路中測量 需將電阻從電路中取出，否則會測到並聯電阻
顯示 OL 電阻值超出量程或斷路

五、通斷測試（Continuity）

5.1 適用場景

  • 檢查線路是否連通
  • 檢查焊點是否良好
  • 找出斷線位置
  • 驗證開關功能

5.2 操作步驟

步驟 1：轉到通斷測試檔位（⫘ 或 )))）

步驟 2：將測試棒接觸兩個測試點

      測試點A           測試點B
         ●───────────────●
         ↑               ↑
        紅棒            黑棒

步驟 3：判斷結果
• 發出「嗶」聲 → 導通（連接良好）
• 沒有聲音 → 斷路（沒有連接）
• 顯示數值 → 電阻值（小於 50Ω 通常會響）

5.3 應用範例

檢查杜邦線是否正常：

    ┌─────────────────────────┐
    │ 杜邦線                   │
    ●─────────────────────────●
    ↑                         ↑
   紅棒                      黑棒

   嗶聲 → 線材正常
   無聲 → 線材斷裂

檢查麵包板連接：

    麵包板
    ┌───────────────┐
    │ ● ● ● ● ●    │  ← 同一排應該導通
    │               │
    │ ● ● ● ● ●    │  ← 不同排應該不導通
    └───────────────┘

六、測量直流電流

6.1 適用場景

  • 測量電路總耗電
  • 檢查元件電流消耗
  • 驗證電源供應能力
  • 診斷異常耗電

6.2 重要概念

電壓測量 = 並聯（跨接在被測點兩端）

    電源 ──┬── 負載 ──┐
           │          │
          電表        │
           │          │
           └──────────┘

電流測量 = 串聯（電流必須流經電表）

    電源 ──── 電表 ──── 負載 ──┐
                              │
              ←───────────────┘

6.3 操作步驟

步驟 1：選擇正確的插孔
• 小電流（<200mA）：使用 mA 孔
• 大電流（>200mA）：使用 10A/20A 孔

步驟 2：斷開電路

步驟 3：將電表串聯到電路中

    修改前：
    電源(+) ────────────── 負載 ──── 電源(-)

    修改後：
    電源(+) ── 紅棒 ─[電表]─ 黑棒 ── 負載 ──── 電源(-)

步驟 4：開啟電源，讀取數值

步驟 5：測量完畢後恢復電路

6.4 Arduino 電流測量範例

測量 Arduino + LED 的總電流：

    USB 電源             Arduino
       │                ┌──────┐
       ├──紅棒─[電表]─黑棒─┤ VIN  │
       │                │      │
       └────────────────┤ GND  │
                        │      │
                        │  D13 ├──[R]──[LED]──┐
                        │      │              │
                        │  GND ├──────────────┘
                        └──────┘

預期讀數：
• Arduino 待機：約 30-50mA
• Arduino + LED：約 40-70mA

6.5 安全注意事項

注意事項 說明
從大量程開始 不確定電流大小時，先用最大檔位
檢查插孔 mA 孔通常有保險絲保護，10A 孔可能沒有
不可測市電 電流檔測量市電非常危險！
快速測量 大電流測量時不要持續太久
勿並聯測電流 會造成短路！

七、二極體測試

7.1 適用場景

  • 確認 LED 極性
  • 檢查二極體好壞
  • 判斷二極體方向

7.2 操作步驟

步驟 1：轉到二極體測試檔位（→|←）

步驟 2：正向測試
        ┌──────┐
   紅棒 →│ →|← │→ 黑棒
        └──────┘
         二極體

   • LED 微亮 → 正向導通
   • 顯示 0.5-0.7V → 矽二極體正常
   • 顯示 0.2-0.3V → 蕭基二極體正常

步驟 3：反向測試（對調測試棒）
        ┌──────┐
   黑棒 →│ →|← │→ 紅棒
        └──────┘

   • 顯示 OL → 反向截止（正常）
   • 顯示數值 → 二極體可能損壞

7.3 LED 極性判斷

使用二極體檔位測試 LED：

    紅棒接長腳（正極）
        ↓
       ┌─┐
       │●│ ← LED 會微微發光
       └┬┘
        ↑
    黑棒接短腳（負極）

如果不亮，對調測試棒即可找到正確極性

八、實用測量技巧

8.1 測量前檢查

每次使用前的自我檢測：

1. 檢查電池電量
   • 顯示低電量符號要換電池
   • 數值不穩定可能是電池問題

2. 測試棒檢查
   • 通斷檔，紅黑棒相碰應該響
   • 檢查測試棒有無斷裂

3. 歸零確認
   • 電阻檔，紅黑棒相碰應顯示接近 0Ω

8.2 提高測量準確度

技巧 說明
穩定接觸 測試棒要穩定接觸測量點
等待穩定 數值跳動時等待穩定再讀取
多次測量 重要數據測量 2-3 次確認
注意單位 mV/V、mA/A、Ω/kΩ/MΩ
適當量程 手動量程時選擇最適合的檔位

8.3 Arduino 常用測量項目

測量項目 檔位 預期數值
5V 電源 DCV 4.8 ~ 5.2V
3.3V 電源 DCV 3.2 ~ 3.4V
數位 HIGH DCV 4.5 ~ 5V
數位 LOW DCV 0 ~ 0.5V
類比輸出 (PWM) DCV 0 ~ 5V 平均值
LED 限流電阻 Ω 220Ω ~ 1kΩ
上拉電阻 Ω 4.7kΩ ~ 10kΩ
待機電流 mA 30 ~ 50mA

九、安全注意事項

9.1 危險警告

⚠️ 絕對禁止事項：

1. 電流檔測量電壓
   → 會造成短路，燒毀保險絲或電表

2. 測量市電時使用錯誤檔位
   → 可能觸電或損壞電表

3. 超過電表額定值
   → 損壞電表，可能引發危險

4. 使用破損的測試棒
   → 可能觸電

9.2 安全守則

守則 說明
先確認檔位 測量前再次確認旋鈕位置
單手操作 測量高壓時僅用單手，減少電流經過心臟風險
檢查額定值 不超過電表標示的最大值
測試棒檢查 使用前檢查絕緣是否完好
低壓優先 初學者先從低壓電路開始練習

9.3 Arduino 專案安全電壓

安全範圍（初學者適用）：

✓ 安全：
  • 電池供電（3V ~ 12V）
  • USB 供電（5V）
  • Arduino 腳位（0 ~ 5V）
  • 各種感測器訊號

✗ 危險（需專業指導）：
  • 市電 110V/220V
  • 馬達驅動高電壓
  • 電源供應器內部

十一、常見問題 FAQ

Q1：顯示 OL 是什麼意思？

OL = Over Limit（超出量程）
- 電壓檔：電壓超過最大量程
- 電阻檔：電阻值太大或斷路
- 解決：換更大的量程或檢查連接

Q2：為什麼測量電阻時數值一直跳動？

可能原因：
1. 手碰觸到測試點（人體電阻干擾）
2. 接觸不良
3. 電路未完全斷電
4. 被測元件有電容效應

Q3：自動量程和手動量程怎麼選？

類型 優點 缺點
自動量程 方便、不怕選錯 反應稍慢、價格較高
手動量程 反應快、便宜 需要判斷量程

建議：初學者選自動量程，熟練後可用手動量程。

Q4：電表需要校正嗎？

一般使用不需要。 但：
- 高精度需求時建議定期校正
- 懷疑數值不準時，可用已知電阻/電壓對照
- 專業用途建議每年校正一次

Q5：保險絲燒了怎麼辦？

更換保險絲：
1. 打開電表後蓋
2. 找到燒毀的保險絲
3. 更換相同規格的保險絲（注意電流值和類型）
4. 檢討為何燒毀，避免再次發生

十二、重點整理

測量檔位選擇

測量項目 檔位 接法
直流電壓 V⎓ 並聯
交流電壓 V~ 並聯
電阻 Ω 斷電後測量
直流電流 A/mA 串聯
通斷 ⫘ 斷電後測量
二極體 →|← 斷電後測量

安全原則

  1. 測量前確認檔位 - 避免燒毀電表
  2. 電阻測量要斷電 - 否則數值錯誤
  3. 電流測量要串聯 - 並聯會短路
  4. 從大量程開始 - 不確定時的安全做法
  5. 定期檢查測試棒 - 確保安全

初學者練習順序

1. 測量電池電壓（1.5V、9V）
2. 測量電阻（確認色碼）
3. 通斷測試（檢查線路）
4. 測量 Arduino 5V 輸出
5. 測量數位腳位高低電位
6. 測量 LED 限流電阻
7. 測量電路電流（進階）
