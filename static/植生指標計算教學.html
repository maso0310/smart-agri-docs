🌿 植生指標計算教學

利用遙測影像評估作物健康狀態

📖 什麼是植生指標？

植生指標 (Vegetation Index, VI) 是利用植物對不同波段光線的反射特性，透過數學運算得出的數值，用來評估植物的健康狀態、覆蓋程度與生長情況。

植物的光譜特性

🔵 藍光 (450-495nm)

被葉綠素強烈吸收

吸收

🟢 綠光 (495-570nm)

反射較多，植物呈綠色

反射

🔴 紅光 (620-750nm)

被葉綠素強烈吸收

吸收

🌡️ 近紅外 (750-1400nm)

被細胞結構強烈反射

高反射
💡 核心原理：
健康植物會強烈吸收紅光（用於光合作用），同時強烈反射近紅外光（因細胞結構）。
這個對比就是大多數植生指標的計算基礎！

🌱 NDVI - 常態差異植生指標

NDVI (Normalized Difference Vegetation Index) 是最廣泛使用的植生指標，用於評估植物的健康程度。

Normalized Difference Vegetation Index
NDVI = (NIR - Red) / (NIR + Red)

NIR = 近紅外波段反射值，Red = 紅光波段反射值

NDVI 數值解讀

-1.0
+1.0
-1.0~0: 水體
0~0.1: 裸土/岩石
0.1~0.2: 枯萎植被
0.2~0.3: 稀疏植被
0.3~0.5: 中度健康
0.5~0.7: 健康植被
0.7~1.0: 茂密植被

Python 實作

import numpy as np import cv2 def calculate_NDVI(nir_band, red_band): """ 計算 NDVI 指標 參數: nir_band: 近紅外波段影像 (numpy array) red_band: 紅光波段影像 (numpy array) 回傳: ndvi: NDVI 值 (-1 到 1) ndvi_colored: 彩色視覺化影像 """ # 轉換為浮點數避免溢位 nir = nir_band.astype(np.float32) red = red_band.astype(np.float32) # 避免除以零 denominator = nir + red denominator[denominator == 0] = 1e-10 # 計算 NDVI ndvi = (nir - red) / denominator # 確保值在 -1 到 1 之間 ndvi = np.clip(ndvi, -1, 1) # 建立彩色視覺化 (使用色彩映射) ndvi_normalized = ((ndvi + 1) * 127.5).astype(np.uint8) ndvi_colored = cv2.applyColorMap(ndvi_normalized, cv2.COLORMAP_JET) return ndvi, ndvi_colored # 使用範例 nir = cv2.imread('nir_band.tif', cv2.IMREAD_GRAYSCALE) red = cv2.imread('red_band.tif', cv2.IMREAD_GRAYSCALE) ndvi, ndvi_vis = calculate_NDVI(nir, red) # 統計分析 print(f'NDVI 範圍: {ndvi.min():.3f} ~ {ndvi.max():.3f}') print(f'NDVI 平均: {ndvi.mean():.3f}') # 找出健康植被區域 (NDVI > 0.3) healthy_mask = ndvi > 0.3 healthy_ratio = np.sum(healthy_mask) / healthy_mask.size * 100 print(f'健康植被覆蓋率: {healthy_ratio:.2f}%')
📊 農業應用：
• 監測作物生長狀態
• 偵測病蟲害區域（NDVI 異常降低）
• 評估灌溉效果
• 預測產量

🌿 ExG - 超綠指數

ExG (Excess Green Index) 是使用一般 RGB 相機就能計算的植生指標，適合無人機或一般數位相機拍攝的影像。

Excess Green Index
ExG = 2g - r - b

r, g, b 為正規化後的 RGB 值（各通道除以總和）

Python 實作

import numpy as np import cv2 def calculate_ExG(image): """ 計算 ExG 超綠指數 參數: image: BGR 格式的彩色影像 回傳: exg: ExG 值 (約 -1 到 1) exg_display: 顯示用影像 (0-255) """ # 分離 BGR 通道並轉為浮點數 B = image[:, :, 0].astype(np.float32) G = image[:, :, 1].astype(np.float32) R = image[:, :, 2].astype(np.float32) # 正規化 (除以總和) total = R + G + B + 1e-10 # 避免除以零 r = R / total g = G / total b = B / total # 計算 ExG exg = 2 * g - r - b # 轉換為顯示格式 (0-255) exg_display = ((exg + 1) * 127.5).astype(np.uint8) return exg, exg_display def create_vegetation_mask(image, threshold=0.1): """使用 ExG 建立植被遮罩""" exg, _ = calculate_ExG(image) mask = (exg > threshold).astype(np.uint8) * 255 return mask # 使用範例 img = cv2.imread('farm_field.jpg') exg, exg_vis = calculate_ExG(img) veg_mask = create_vegetation_mask(img, threshold=0.1) # 計算植被覆蓋率 coverage = np.sum(veg_mask > 0) / veg_mask.size * 100 print(f'植被覆蓋率: {coverage:.2f}%') # 標記植被區域 result = img.copy() result[veg_mask > 0] = [0, 255, 0] # 綠色標記 blended = cv2.addWeighted(img, 0.7, result, 0.3, 0)
💡 ExG 的優點：
• 只需要一般 RGB 相機
• 計算簡單快速
• 適合即時處理
• 對綠色植物敏感度高

📊 其他常用植生指標

ExGR (超綠減超紅指數)

ExGR = ExG - ExR
= (2g - r - b) - (1.4r - g)

更能區分植被與土壤

GLI (綠葉指數)

GLI = (2G - R - B) / (2G + R + B)

正規化的綠色指標

VARI (可見大氣阻抗植生指數)

VARI = (G - R) / (G + R - B)

減少大氣影響

SAVI (土壤調整植生指數)

SAVI = (NIR - R) × (1+L) / (NIR + R + L)

L=0.5，減少土壤背景影響

完整計算範例

import numpy as np class VegetationIndices: """植生指標計算器""" def __init__(self, image): # 分離通道並正規化 self.B = image[:, :, 0].astype(np.float32) self.G = image[:, :, 1].astype(np.float32) self.R = image[:, :, 2].astype(np.float32) total = self.R + self.G + self.B + 1e-10 self.r = self.R / total self.g = self.G / total self.b = self.B / total def ExG(self): """超綠指數""" return 2 * self.g - self.r - self.b def ExR(self): """超紅指數""" return 1.4 * self.r - self.g def ExGR(self): """超綠減超紅""" return self.ExG() - self.ExR() def GLI(self): """綠葉指數""" numerator = 2 * self.G - self.R - self.B denominator = 2 * self.G + self.R + self.B + 1e-10 return numerator / denominator def VARI(self): """可見大氣阻抗植生指數""" numerator = self.G - self.R denominator = self.G + self.R - self.B + 1e-10 return numerator / denominator def get_all(self): """取得所有指標""" return { 'ExG': self.ExG(), 'ExR': self.ExR(), 'ExGR': self.ExGR(), 'GLI': self.GLI(), 'VARI': self.VARI() } # 使用範例 img = cv2.imread('crop.jpg') vi = VegetationIndices(img) indices = vi.get_all() for name, values in indices.items(): print(f'{name}: 平均={values.mean():.4f}, 標準差={values.std():.4f}')

🚜 農業實際應用

1. 雜草偵測

def detect_weeds(image, crop_mask, exg_threshold=0.1): """ 偵測作物區外的雜草 參數: image: BGR 影像 crop_mask: 已知作物區域的遮罩 exg_threshold: 綠色植物閾值 """ # 計算 ExG 找出所有綠色區域 exg, _ = calculate_ExG(image) all_green = exg > exg_threshold # 雜草 = 綠色區域 - 作物區域 weed_mask = all_green & ~crop_mask # 標記雜草區域 result = image.copy() result[weed_mask] = [0, 0, 255] # 紅色標記雜草 return weed_mask, result

2. 作物健康評估

def assess_crop_health(ndvi): """根據 NDVI 評估作物健康狀態""" total_pixels = ndvi.size # 分類統計 stressed = np.sum(ndvi < 0.2) / total_pixels * 100 # 嚴重不健康 moderate = np.sum((ndvi >= 0.2) & (ndvi < 0.4)) / total_pixels * 100 # 輕度問題 healthy = np.sum((ndvi >= 0.4) & (ndvi < 0.6)) / total_pixels * 100 # 健康 vigorous = np.sum(ndvi >= 0.6) / total_pixels * 100 # 非常健康 print("=== 作物健康評估報告 ===") print(f"🔴 嚴重問題 (NDVI < 0.2): {stressed:.1f}%") print(f"🟡 需注意 (0.2-0.4): {moderate:.1f}%") print(f"🟢 健康 (0.4-0.6): {healthy:.1f}%") print(f"🌟 非常健康 (> 0.6): {vigorous:.1f}%") # 整體評分 (0-100) score = healthy * 0.5 + vigorous * 1.0 + moderate * 0.3 print(f"\n整體健康分數: {min(score, 100):.1f}/100") return { 'stressed': stressed, 'moderate': moderate, 'healthy': healthy, 'vigorous': vigorous, 'score': min(score, 100) }

3. 時間序列分析

def analyze_growth_trend(ndvi_series, dates): """ 分析 NDVI 時間變化趨勢 參數: ndvi_series: list of NDVI 平均值 dates: 對應的日期列表 """ import matplotlib.pyplot as plt # 計算變化率 changes = np.diff(ndvi_series) # 繪製趨勢圖 fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(10, 8)) # NDVI 趨勢 ax1.plot(dates, ndvi_series, 'g-o', linewidth=2) ax1.axhline(y=0.4, color='orange', linestyle='--', label='健康閾值') ax1.set_title('NDVI 時間變化') ax1.set_ylabel('NDVI') ax1.legend() ax1.grid(True, alpha=0.3) # 變化率 colors = ['green' if c > 0 else 'red' for c in changes] ax2.bar(dates[1:], changes, color=colors) ax2.set_title('NDVI 變化率') ax2.set_ylabel('變化量') ax2.grid(True, alpha=0.3) plt.tight_layout() plt.savefig('growth_analysis.png') return changes

🎯 如何選擇適合的指標？

應用場景 推薦指標 原因
作物健康監測 NDVI 對葉綠素含量敏感，需要多光譜相機
一般 RGB 相機 ExG, GLI 不需特殊設備，適合無人機
雜草偵測 ExGR 能區分不同類型綠色植物
土壤背景明顯 SAVI 減少土壤對結果的影響
大氣干擾明顯 VARI 減少大氣散射影響
⚠️ 注意事項：
• 光線條件會影響指標計算結果（建議中午拍攝）
• 不同作物的健康閾值可能不同
• 季節變化需要納入考量
• 最好結合多種指標進行綜合評估
