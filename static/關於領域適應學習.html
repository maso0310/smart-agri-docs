關於領域適應學習

領域適應（Domain Adaptation）是遷移學習的重要分支，解決訓練資料與實際應用資料分布不同的問題。在農業 AI 中，這對於跨農場、跨季節的模型部署非常重要。

一、基本概念

為什麼需要領域適應

機器學習模型的假設：訓練資料與測試資料來自相同分布。但實際上常常不同：

  • 在 A 農場訓練的病蟲害偵測，應用於 B 農場效果下降
  • 夏季拍攝訓練的模型，冬季使用準確率降低
  • 在理想光照下訓練，陰天效果變差

術語定義

術語說明
源領域（Source Domain）有標註資料的訓練領域
目標領域（Target Domain）實際應用的領域，通常少或無標註
領域偏移（Domain Shift）源領域與目標領域的分布差異
協變量偏移（Covariate Shift）輸入分布不同，但 P(Y|X) 相同

二、領域適應類型

類型目標領域標註說明
監督式完全有有少量目標領域標註資料
半監督式部分有目標領域有部分標註
無監督式完全無目標領域完全無標註（最常見挑戰）

三、常見方法

1. 特徵對齊（Feature Alignment）

讓源領域與目標領域的特徵分布對齊：

  • MMD（Maximum Mean Discrepancy）：最小化兩個分布的差異
  • CORAL：對齊二階統計量（協方差矩陣）
  • Domain Adversarial：對抗式訓練使特徵無法區分領域

2. 對抗式領域適應（DANN）

import torch
import torch.nn as nn

class DomainAdversarialNetwork(nn.Module):
    """
    Domain Adversarial Neural Network (DANN)
    """
    def __init__(self, num_classes):
        super().__init__()
        # 特徵提取器
        self.feature_extractor = nn.Sequential(
            nn.Conv2d(3, 64, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(64, 128, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Flatten(),
            nn.Linear(128 * 56 * 56, 256)
        )

        # 類別分類器
        self.class_classifier = nn.Sequential(
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Linear(128, num_classes)
        )

        # 領域判別器
        self.domain_classifier = nn.Sequential(
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Linear(128, 2)  # 源領域 or 目標領域
        )

    def forward(self, x, alpha=1.0):
        features = self.feature_extractor(x)

        # 類別預測
        class_output = self.class_classifier(features)

        # 領域預測（梯度反轉）
        reversed_features = GradientReversalLayer.apply(features, alpha)
        domain_output = self.domain_classifier(reversed_features)

        return class_output, domain_output

class GradientReversalLayer(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x, alpha):
        ctx.alpha = alpha
        return x.view_as(x)

    @staticmethod
    def backward(ctx, grad_output):
        return grad_output.neg() * ctx.alpha, None

3. 自訓練（Self-Training）

def self_training(model, source_data, target_data, threshold=0.9, iterations=5):
    """
    自訓練領域適應
    """
    # 先用源領域訓練
    train_on_source(model, source_data)

    for i in range(iterations):
        # 在目標領域預測
        predictions = model.predict(target_data)
        confidences = predictions.max(dim=1).values

        # 選擇高信心樣本
        high_conf_mask = confidences > threshold
        pseudo_labels = predictions.argmax(dim=1)[high_conf_mask]
        pseudo_data = target_data[high_conf_mask]

        # 用偽標籤繼續訓練
        train_with_pseudo_labels(model, pseudo_data, pseudo_labels)

        print(f"Iteration {i+1}: {high_conf_mask.sum()} pseudo-labeled samples")

    return model

六、實務建議

  1. 先嘗試簡單方法：資料增強 → 微調 → 複雜適應
  2. 收集少量目標資料：即使 10-50 張也有幫助
  3. 分析領域差異：了解差異來源（光照？角度？品種？）
  4. 漸進式適應：如果差異太大，考慮中間領域
  5. 持續監控：部署後追蹤效能變化

七、相關技術

  • 遷移學習：更廣泛的概念，包含領域適應
  • 少樣本學習：用極少樣本學習新類別
  • 持續學習：不斷適應新資料而不遺忘舊知識
  • 聯邦學習：多方資料協作訓練而不共享資料
