關於 DHT 溫溼度感測器

前言：為什麼需要溫溼度感測器？

在智慧農業應用中，溫度和濕度是影響植物生長的關鍵因素：

  • 溫度過高：植物蒸散過快、容易枯萎
  • 溫度過低：生長緩慢、可能凍傷
  • 濕度過高：容易滋生黴菌、病蟲害
  • 濕度過低：植物缺水、葉片乾枯

DHT 系列感測器是最常用的溫溼度感測器，價格便宜、使用簡單，非常適合入門學習！

一、DHT 感測器是什麼？

一句話解釋

DHT 感測器是一個「溫度 + 濕度」二合一的數位感測器，只需要一根訊號線就能同時讀取溫度和濕度。

外觀辨識

DHT11（藍色外殼）           DHT22（白色外殼）
┌─────────────┐            ┌─────────────┐
│ ┌─────────┐ │            │ ┌─────────┐ │
│ │ ░░░░░░░ │ │            │ │ ░░░░░░░ │ │
│ │ ░░░░░░░ │ │            │ │ ░░░░░░░ │ │
│ │ ░░░░░░░ │ │            │ │ ░░░░░░░ │ │
│ └─────────┘ │            │ └─────────┘ │
│   DHT11     │            │   DHT22     │
│  (藍色)     │            │   AM2302    │
└──┬──┬──┬──┬─┘            └──┬──┬──┬──┬─┘
   │  │  │  │                 │  │  │  │
   1  2  3  4                 1  2  3  4

腳位（由左至右）：
1 = VCC（電源正極）
2 = DATA（資料訊號）
3 = NC（未使用）
4 = GND（電源負極）

模組版 vs 裸裝版

【裸裝版】需要自己加電阻      【模組版】已內建電阻，推薦初學者

    ┌───────┐                   ┌─────────────┐
    │ DHT11 │                   │  DHT11模組   │
    └┬─┬─┬─┬┘                   │ ┌───────┐   │
     │ │ │ │                    │ │ DHT11 │   │
     │ │ │ │                    │ └───────┘   │
     1 2 3 4                    │  S  +  -    │
     │ │   │                    └──┬──┬──┬────┘
     │ │   │                       │  │  │
    需加 4.7K~10K                  DATA VCC GND
    上拉電阻                       (只有3隻腳，更簡單！)

二、DHT11 vs DHT22 比較

規格比較表

規格 DHT11 DHT22 (AM2302)
外觀 藍色 白色
溫度範圍 0°C ~ 50°C -40°C ~ 80°C
溫度精度 ±2°C ±0.5°C
濕度範圍 20% ~ 80% RH 0% ~ 100% RH
濕度精度 ±5% RH ±2% RH
取樣間隔 1 秒 2 秒
價格 便宜（約 30-50 元） 較貴（約 80-150 元）
適用場景 室內、一般用途 精密量測、戶外

三、工作原理

濕度感測原理

電容式濕度感測：

┌─────────────────────────────────────────┐
│                                         │
│   濕度感測元件結構：                     │
│                                         │
│      電極 ─────┬─────                   │
│                │                        │
│      吸濕材料  █████  ← 會吸收空氣中水分 │
│                │                        │
│      電極 ─────┴─────                   │
│                                         │
│   原理：                                │
│   - 吸濕材料吸收水分後，介電常數改變     │
│   - 電容值隨之改變                       │
│   - 測量電容值 → 換算成濕度值            │
│                                         │
└─────────────────────────────────────────┘

溫度感測原理

NTC 熱敏電阻：

     阻值
      ↑
      │
  高  │╲
      │ ╲
      │  ╲
      │   ╲
  低  │    ╲────
      └──────────→ 溫度
        低    高

原理：
- NTC = Negative Temperature Coefficient（負溫度係數）
- 溫度升高 → 電阻降低
- 測量電阻值 → 換算成溫度值

資料傳輸格式

DHT 單線通訊協定：

主機（Arduino）發送起始訊號：
    ____          ____________________
        |________|                     （拉低 18ms，再拉高）

感測器回應：
         ____    ____    ____    ____
    ____|    |__|    |__|    |__|    |__

    回應訊號    資料位元（40 bits）

資料格式（40 bits）：
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│ 濕度整數  │ 濕度小數  │ 溫度整數  │ 溫度小數  │  校驗碼   │
│  8 bits  │  8 bits  │  8 bits  │  8 bits  │  8 bits  │
└──────────┴──────────┴──────────┴──────────┴──────────┘

校驗碼 = 前四個位元組相加的低 8 位

六、Arduino 程式範例

範例 1：基本讀取

/*
 * DHT11/DHT22 基本讀取範例
 * 每 2 秒讀取一次溫溼度並顯示在序列監視器
 */

#include <DHT.h>

// 設定 DHT 感測器
#define DHT_PIN 2       // DATA 腳位接 D2
#define DHT_TYPE DHT11  // 使用 DHT11，若是 DHT22 改成 DHT22

DHT dht(DHT_PIN, DHT_TYPE);

void setup() {
  Serial.begin(9600);
  Serial.println("DHT 溫溼度感測器測試");
  Serial.println("--------------------");

  dht.begin();  // 初始化感測器
}

void loop() {
  // 讀取濕度（相對濕度 %）
  float humidity = dht.readHumidity();

  // 讀取溫度（攝氏 °C）
  float temperature = dht.readTemperature();

  // 檢查是否讀取失敗
  if (isnan(humidity) || isnan(temperature)) {
    Serial.println("讀取 DHT 感測器失敗！");
    delay(2000);
    return;
  }

  // 顯示結果
  Serial.print("濕度：");
  Serial.print(humidity);
  Serial.print(" %\t");

  Serial.print("溫度：");
  Serial.print(temperature);
  Serial.println(" °C");

  delay(2000);  // DHT11 最快每秒讀一次，DHT22 每 2 秒
}

範例 2：讀取華氏溫度與體感溫度

/*
 * 讀取攝氏、華氏溫度與體感溫度（Heat Index）
 */

#include <DHT.h>

#define DHT_PIN 2
#define DHT_TYPE DHT11

DHT dht(DHT_PIN, DHT_TYPE);

void setup() {
  Serial.begin(9600);
  Serial.println("溫溼度完整讀取");
  dht.begin();
}

void loop() {
  float humidity = dht.readHumidity();
  float tempC = dht.readTemperature();       // 攝氏
  float tempF = dht.readTemperature(true);   // 華氏

  if (isnan(humidity) || isnan(tempC) || isnan(tempF)) {
    Serial.println("讀取失敗！");
    delay(2000);
    return;
  }

  // 計算體感溫度（Heat Index）
  float heatIndexC = dht.computeHeatIndex(tempC, humidity, false);
  float heatIndexF = dht.computeHeatIndex(tempF, humidity);

  Serial.println("================");
  Serial.print("濕度：");
  Serial.print(humidity);
  Serial.println(" %");

  Serial.print("溫度：");
  Serial.print(tempC);
  Serial.print(" °C / ");
  Serial.print(tempF);
  Serial.println(" °F");

  Serial.print("體感溫度：");
  Serial.print(heatIndexC);
  Serial.print(" °C / ");
  Serial.print(heatIndexF);
  Serial.println(" °F");

  delay(2000);
}

範例 3：溫溼度警報系統

/*
 * 溫溼度警報系統
 * - 溫度過高或濕度異常時亮警示燈
 */

#include <DHT.h>

#define DHT_PIN 2
#define DHT_TYPE DHT11

#define LED_RED 5     // 紅燈：溫度過高
#define LED_YELLOW 6  // 黃燈：濕度過低
#define LED_GREEN 7   // 綠燈：正常

// 警報門檻值
#define TEMP_HIGH 30.0    // 溫度上限（°C）
#define HUMIDITY_LOW 40.0 // 濕度下限（%）

DHT dht(DHT_PIN, DHT_TYPE);

void setup() {
  Serial.begin(9600);

  pinMode(LED_RED, OUTPUT);
  pinMode(LED_YELLOW, OUTPUT);
  pinMode(LED_GREEN, OUTPUT);

  // 開機測試：所有燈閃一下
  digitalWrite(LED_RED, HIGH);
  digitalWrite(LED_YELLOW, HIGH);
  digitalWrite(LED_GREEN, HIGH);
  delay(500);
  digitalWrite(LED_RED, LOW);
  digitalWrite(LED_YELLOW, LOW);
  digitalWrite(LED_GREEN, LOW);

  dht.begin();
  Serial.println("溫溼度警報系統啟動");
}

void loop() {
  float humidity = dht.readHumidity();
  float temperature = dht.readTemperature();

  if (isnan(humidity) || isnan(temperature)) {
    Serial.println("感測器錯誤！");
    // 錯誤時紅燈閃爍
    digitalWrite(LED_RED, HIGH);
    delay(200);
    digitalWrite(LED_RED, LOW);
    delay(200);
    return;
  }

  // 顯示讀數
  Serial.print("溫度：");
  Serial.print(temperature);
  Serial.print("°C  濕度：");
  Serial.print(humidity);
  Serial.print("%  狀態：");

  // 判斷狀態並控制 LED
  bool tempAlert = (temperature > TEMP_HIGH);
  bool humidityAlert = (humidity < HUMIDITY_LOW);

  if (tempAlert || humidityAlert) {
    digitalWrite(LED_GREEN, LOW);

    if (tempAlert) {
      digitalWrite(LED_RED, HIGH);
      Serial.print("溫度過高! ");
    } else {
      digitalWrite(LED_RED, LOW);
    }

    if (humidityAlert) {
      digitalWrite(LED_YELLOW, HIGH);
      Serial.print("濕度過低! ");
    } else {
      digitalWrite(LED_YELLOW, LOW);
    }
    Serial.println();
  } else {
    // 正常狀態
    digitalWrite(LED_RED, LOW);
    digitalWrite(LED_YELLOW, LOW);
    digitalWrite(LED_GREEN, HIGH);
    Serial.println("正常");
  }

  delay(2000);
}

範例 4：搭配 LCD 顯示

/*
 * DHT + LCD 顯示溫溼度
 * LCD 使用 I2C 介面（位址 0x27）
 */

#include <DHT.h>
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

#define DHT_PIN 2
#define DHT_TYPE DHT11

DHT dht(DHT_PIN, DHT_TYPE);
LiquidCrystal_I2C lcd(0x27, 16, 2);  // I2C 位址 0x27，16x2 LCD

// 自訂字元：溫度計圖示
byte thermometer[8] = {
  B00100,
  B01010,
  B01010,
  B01010,
  B01110,
  B11111,
  B11111,
  B01110
};

// 自訂字元：水滴圖示
byte droplet[8] = {
  B00100,
  B00100,
  B01010,
  B01010,
  B10001,
  B10001,
  B10001,
  B01110
};

void setup() {
  Serial.begin(9600);

  dht.begin();

  lcd.init();
  lcd.backlight();
  lcd.createChar(0, thermometer);
  lcd.createChar(1, droplet);

  lcd.setCursor(0, 0);
  lcd.print("DHT Sensor Ready");
  delay(2000);
  lcd.clear();
}

void loop() {
  float humidity = dht.readHumidity();
  float temperature = dht.readTemperature();

  lcd.setCursor(0, 0);

  if (isnan(humidity) || isnan(temperature)) {
    lcd.print("Sensor Error!   ");
    lcd.setCursor(0, 1);
    lcd.print("                ");
    delay(2000);
    return;
  }

  // 第一行：溫度
  lcd.write(byte(0));  // 溫度計圖示
  lcd.print(" Temp: ");
  lcd.print(temperature, 1);
  lcd.print((char)223);  // 度數符號
  lcd.print("C ");

  // 第二行：濕度
  lcd.setCursor(0, 1);
  lcd.write(byte(1));  // 水滴圖示
  lcd.print(" Humi: ");
  lcd.print(humidity, 1);
  lcd.print("%  ");

  delay(2000);
}

範例 5：資料記錄（每分鐘取樣）

/*
 * 溫溼度資料記錄器
 * 每分鐘記錄一次，輸出 CSV 格式
 * 可用序列監視器的「儲存輸出」功能存檔
 */

#include <DHT.h>

#define DHT_PIN 2
#define DHT_TYPE DHT11

DHT dht(DHT_PIN, DHT_TYPE);

unsigned long sampleCount = 0;
unsigned long lastSampleTime = 0;
const unsigned long SAMPLE_INTERVAL = 60000;  // 60 秒

void setup() {
  Serial.begin(9600);
  dht.begin();

  // 輸出 CSV 標題
  Serial.println("Sample,Time(s),Temperature(C),Humidity(%)");

  // 立即取第一筆
  takeSample();
}

void loop() {
  unsigned long currentTime = millis();

  if (currentTime - lastSampleTime >= SAMPLE_INTERVAL) {
    takeSample();
    lastSampleTime = currentTime;
  }
}

void takeSample() {
  float humidity = dht.readHumidity();
  float temperature = dht.readTemperature();

  sampleCount++;

  Serial.print(sampleCount);
  Serial.print(",");
  Serial.print(millis() / 1000);
  Serial.print(",");

  if (isnan(humidity) || isnan(temperature)) {
    Serial.println("ERROR,ERROR");
    return;
  }

  Serial.print(temperature, 1);
  Serial.print(",");
  Serial.println(humidity, 1);
}

範例 6：智慧溫室控制（完整範例）

/*
 * 智慧溫室環境控制系統
 *
 * 功能：
 * - 溫度過高（>28°C）→ 開啟風扇
 * - 溫度降低（<26°C）→ 關閉風扇（遲滯控制）
 * - 濕度過低（<50%）→ 開啟霧化器
 * - 濕度足夠（>60%）→ 關閉霧化器（遲滯控制）
 */

#include <DHT.h>

#define DHT_PIN 2
#define DHT_TYPE DHT11

#define FAN_RELAY 7       // 風扇繼電器
#define HUMIDIFIER_RELAY 8 // 霧化器繼電器

// 溫度控制門檻（遲滯控制）
#define TEMP_HIGH 28.0    // 高於此溫度開風扇
#define TEMP_LOW 26.0     // 低於此溫度關風扇

// 濕度控制門檻（遲滯控制）
#define HUMIDITY_LOW 50.0  // 低於此濕度開霧化器
#define HUMIDITY_HIGH 60.0 // 高於此濕度關霧化器

DHT dht(DHT_PIN, DHT_TYPE);

bool fanState = false;
bool humidifierState = false;

void setup() {
  Serial.begin(9600);

  pinMode(FAN_RELAY, OUTPUT);
  pinMode(HUMIDIFIER_RELAY, OUTPUT);

  digitalWrite(FAN_RELAY, LOW);
  digitalWrite(HUMIDIFIER_RELAY, LOW);

  dht.begin();

  Serial.println("=== 智慧溫室環境控制系統 ===");
  Serial.println("溫度控制：28°C 開風扇，26°C 關風扇");
  Serial.println("濕度控制：50% 開霧化器，60% 關霧化器");
  Serial.println("============================");
}

void loop() {
  float humidity = dht.readHumidity();
  float temperature = dht.readTemperature();

  if (isnan(humidity) || isnan(temperature)) {
    Serial.println("[錯誤] 無法讀取感測器！");
    delay(2000);
    return;
  }

  // === 溫度控制（遲滯） ===
  if (temperature >= TEMP_HIGH && !fanState) {
    fanState = true;
    digitalWrite(FAN_RELAY, HIGH);
    Serial.println("[動作] 溫度過高，開啟風扇");
  }
  else if (temperature <= TEMP_LOW && fanState) {
    fanState = false;
    digitalWrite(FAN_RELAY, LOW);
    Serial.println("[動作] 溫度正常，關閉風扇");
  }

  // === 濕度控制（遲滯） ===
  if (humidity <= HUMIDITY_LOW && !humidifierState) {
    humidifierState = true;
    digitalWrite(HUMIDIFIER_RELAY, HIGH);
    Serial.println("[動作] 濕度過低，開啟霧化器");
  }
  else if (humidity >= HUMIDITY_HIGH && humidifierState) {
    humidifierState = false;
    digitalWrite(HUMIDIFIER_RELAY, LOW);
    Serial.println("[動作] 濕度足夠，關閉霧化器");
  }

  // === 顯示目前狀態 ===
  Serial.print("[狀態] ");
  Serial.print("溫度：");
  Serial.print(temperature, 1);
  Serial.print("°C  濕度：");
  Serial.print(humidity, 1);
  Serial.print("%  風扇：");
  Serial.print(fanState ? "ON" : "OFF");
  Serial.print("  霧化器：");
  Serial.println(humidifierState ? "ON" : "OFF");

  delay(2000);
}

多顆 DHT 感測器

/*
 * 同時使用多顆 DHT 感測器
 * 例如：室內、室外各一顆
 */

#include <DHT.h>

#define DHT_INDOOR_PIN 2
#define DHT_OUTDOOR_PIN 3

DHT dhtIndoor(DHT_INDOOR_PIN, DHT11);
DHT dhtOutdoor(DHT_OUTDOOR_PIN, DHT22);  // 戶外用 DHT22 精度較高

void setup() {
  Serial.begin(9600);
  dhtIndoor.begin();
  dhtOutdoor.begin();
}

void loop() {
  // 讀取室內
  float tempIn = dhtIndoor.readTemperature();
  float humIn = dhtIndoor.readHumidity();

  // 讀取室外
  float tempOut = dhtOutdoor.readTemperature();
  float humOut = dhtOutdoor.readHumidity();

  Serial.println("=== 溫溼度比較 ===");
  Serial.print("室內：");
  Serial.print(tempIn);
  Serial.print("°C / ");
  Serial.print(humIn);
  Serial.println("%");

  Serial.print("室外：");
  Serial.print(tempOut);
  Serial.print("°C / ");
  Serial.print(humOut);
  Serial.println("%");

  Serial.print("溫差：");
  Serial.print(tempIn - tempOut);
  Serial.println("°C");

  delay(3000);
}

平均值濾波（減少雜訊）

/*
 * 使用移動平均減少讀值跳動
 */

#include <DHT.h>

#define DHT_PIN 2
#define DHT_TYPE DHT11
#define SAMPLE_COUNT 5  // 取 5 次平均

DHT dht(DHT_PIN, DHT_TYPE);

float tempSamples[SAMPLE_COUNT];
float humiSamples[SAMPLE_COUNT];
int sampleIndex = 0;
bool bufferFull = false;

void setup() {
  Serial.begin(9600);
  dht.begin();

  // 初始化陣列
  for (int i = 0; i < SAMPLE_COUNT; i++) {
    tempSamples[i] = 0;
    humiSamples[i] = 0;
  }
}

void loop() {
  float temp = dht.readTemperature();
  float humi = dht.readHumidity();

  if (isnan(temp) || isnan(humi)) {
    delay(2000);
    return;
  }

  // 存入樣本
  tempSamples[sampleIndex] = temp;
  humiSamples[sampleIndex] = humi;

  sampleIndex++;
  if (sampleIndex >= SAMPLE_COUNT) {
    sampleIndex = 0;
    bufferFull = true;
  }

  // 計算平均值
  if (bufferFull) {
    float avgTemp = 0, avgHumi = 0;
    for (int i = 0; i < SAMPLE_COUNT; i++) {
      avgTemp += tempSamples[i];
      avgHumi += humiSamples[i];
    }
    avgTemp /= SAMPLE_COUNT;
    avgHumi /= SAMPLE_COUNT;

    Serial.print("即時值：");
    Serial.print(temp, 1);
    Serial.print("°C / ");
    Serial.print(humi, 1);
    Serial.print("%  平均值：");
    Serial.print(avgTemp, 1);
    Serial.print("°C / ");
    Serial.print(avgHumi, 1);
    Serial.println("%");
  }

  delay(2000);
}

八、常見問題排解

問題 1：讀取失敗（顯示 nan）

檢查步驟：

□ 1. 接線正確嗎？VCC、GND、DATA 都有接？
□ 2. VCC 接的是 5V 還是 3.3V？（建議用 5V）
□ 3. 裸裝版有加上拉電阻嗎？
□ 4. 程式中 DHT_TYPE 設定正確嗎？（DHT11 或 DHT22）
□ 5. 腳位設定正確嗎？
□ 6. 感測器有損壞嗎？（換一顆試試）

問題 2：數值不穩定/跳動

可能原因與解決方法：

1. 電源不穩
   → 在 VCC 和 GND 之間加 0.1μF 電容

2. 訊號線太長
   → 縮短杜邦線長度
   → 加強上拉電阻（改用 4.7K）

3. 感測器反應時間
   → DHT11 最快每 1 秒讀一次
   → DHT22 最快每 2 秒讀一次
   → 讀太快會得到錯誤值

4. 環境干擾
   → 遠離馬達、繼電器等產生電磁干擾的元件

問題 3：濕度永遠顯示 99% 或 1%

可能原因：

1. 感測器損壞或受潮
   → 更換新的感測器

2. 接線錯誤（VCC 和 DATA 接反）
   → 檢查接線

3. 環境極端（如密閉空間）
   → 確認環境是否正常

問題 4：溫度明顯偏差

可能原因：

1. DHT11 本身精度只有 ±2°C
   → 這是正常現象，精度需求高請用 DHT22

2. 感測器靠近發熱元件
   → 遠離 Arduino、馬達等會發熱的元件

3. 陽光直射
   → 避免陽光直射感測器

4. 需要校正
   → 與標準溫度計比較，程式中加減補償值

   float temperature = dht.readTemperature();
   temperature = temperature - 1.5;  // 補償 -1.5°C

基本用法

#include <DHT.h>

// 1. 定義腳位和型號
#define DHT_PIN 2
#define DHT_TYPE DHT11  // 或 DHT22

// 2. 建立物件
DHT dht(DHT_PIN, DHT_TYPE);

void setup() {
  // 3. 初始化
  dht.begin();
}

void loop() {
  // 4. 讀取數值
  float h = dht.readHumidity();        // 濕度 %
  float t = dht.readTemperature();     // 溫度 °C
  float f = dht.readTemperature(true); // 溫度 °F

  // 5. 檢查錯誤
  if (isnan(h) || isnan(t)) {
    // 讀取失敗
  }

  // 6. 計算體感溫度
  float hi = dht.computeHeatIndex(t, h, false); // °C
}
