第二組：溫溼度控制組 操作手冊

任務說明

本組負責智慧溫室的溫溼度感測與控制功能，包含：

  • 使用 DHT11 感測器測量溫度與濕度
  • 使用繼電器控制風扇（降溫）和霧化器（加濕）
  • 當溫度過高時自動啟動風扇
  • 當濕度過低時自動啟動霧化器

這是溫室環境控制最核心的功能之一！

🌡️ 你知道嗎？
溫度和濕度是影響植物生長最重要的兩個環境因素。溫度過高會導致植物蒸散作用過強而脫水，溫度過低則會減緩生長甚至凍傷。濕度過低會使葉片乾枯，過高則容易滋生病菌。智慧溫室透過自動監控與調節，可以維持最適合植物生長的環境！

  4. 實現基於溫溼度的自動控制邏輯
  5. 學習遲滯控制（Hysteresis）避免頻繁開關
  6. 整合多個感測器與執行器

請確認你的繼電器類型！

程式碼範例

範例 1：DHT11 溫溼度讀取

學習重點：DHT11 感測器初始化、讀取溫度與濕度數值、處理讀取失敗的情況

/*
 * 01_DHT11_Basic.ino
 * DHT11 溫溼度感測器基礎讀取
 * 功能：每 2 秒讀取並顯示溫溼度
 */

#include <DHT.h>

#define DHT_PIN 2       // DHT11 資料腳位
#define DHT_TYPE DHT11  // 感測器類型

DHT dht(DHT_PIN, DHT_TYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();

  Serial.println("=====================================");
  Serial.println("   DHT11 溫溼度感測器測試程式");
  Serial.println("=====================================");
  Serial.println();
}

void loop() {
  // 等待 2 秒（DHT11 最快取樣速度為 1Hz）
  delay(2000);

  // 讀取濕度
  float humidity = dht.readHumidity();
  // 讀取溫度（攝氏）
  float temperature = dht.readTemperature();

  // 檢查是否讀取失敗
  if (isnan(humidity) || isnan(temperature)) {
    Serial.println("❌ 錯誤：無法讀取 DHT11 感測器！");
    Serial.println("   請檢查接線是否正確");
    return;
  }

  // 計算體感溫度（Heat Index）
  float heatIndex = dht.computeHeatIndex(temperature, humidity, false);

  // 顯示結果
  Serial.print("🌡️ 溫度: ");
  Serial.print(temperature);
  Serial.print(" °C  |  ");

  Serial.print("💧 濕度: ");
  Serial.print(humidity);
  Serial.print(" %  |  ");

  Serial.print("🌡️ 體感溫度: ");
  Serial.print(heatIndex);
  Serial.println(" °C");
}
🔍 程式解說
• DHT dht(pin, type)：建立 DHT 物件
• dht.begin()：初始化感測器
• dht.readTemperature()：讀取溫度（攝氏）
• dht.readHumidity()：讀取濕度（%）
• isnan()：檢查是否為無效數值（讀取失敗時會回傳 NaN）

範例 2：繼電器控制測試

學習重點：繼電器工作原理、digitalWrite() 控制繼電器、高/低電平觸發差異

/*
 * 02_Relay_Control.ino
 * 繼電器控制測試
 * 功能：每 3 秒切換繼電器狀態
 */

#define RELAY_FAN 7       // 風扇繼電器
#define RELAY_HUMIDIFIER 8  // 霧化器繼電器
#define LED_FAN 5         // 風扇狀態 LED
#define LED_HUMIDIFIER 6  // 霧化器狀態 LED

// 設定繼電器觸發電平（根據你的繼電器模組調整）
// true = 高電平觸發（HIGH 開啟）
// false = 低電平觸發（LOW 開啟）
#define RELAY_ACTIVE_HIGH true

void setup() {
  pinMode(RELAY_FAN, OUTPUT);
  pinMode(RELAY_HUMIDIFIER, OUTPUT);
  pinMode(LED_FAN, OUTPUT);
  pinMode(LED_HUMIDIFIER, OUTPUT);

  // 初始狀態：全部關閉
  relayOff(RELAY_FAN);
  relayOff(RELAY_HUMIDIFIER);
  digitalWrite(LED_FAN, LOW);
  digitalWrite(LED_HUMIDIFIER, LOW);

  Serial.begin(9600);
  Serial.println("=====================================");
  Serial.println("      繼電器控制測試程式");
  Serial.println("=====================================");
  Serial.println();
  Serial.println("每 3 秒切換一次狀態，請聽繼電器喀嗒聲");
  Serial.println();
}

void loop() {
  // 測試風扇繼電器
  Serial.println("🔴 風扇繼電器 ON");
  relayOn(RELAY_FAN);
  digitalWrite(LED_FAN, HIGH);
  delay(3000);

  Serial.println("⚫ 風扇繼電器 OFF");
  relayOff(RELAY_FAN);
  digitalWrite(LED_FAN, LOW);
  delay(1000);

  // 測試霧化器繼電器
  Serial.println("🔵 霧化器繼電器 ON");
  relayOn(RELAY_HUMIDIFIER);
  digitalWrite(LED_HUMIDIFIER, HIGH);
  delay(3000);

  Serial.println("⚫ 霧化器繼電器 OFF");
  relayOff(RELAY_HUMIDIFIER);
  digitalWrite(LED_HUMIDIFIER, LOW);
  delay(1000);

  Serial.println("------------------------");
}

// 開啟繼電器
void relayOn(int pin) {
  if (RELAY_ACTIVE_HIGH) {
    digitalWrite(pin, HIGH);
  } else {
    digitalWrite(pin, LOW);
  }
}

// 關閉繼電器
void relayOff(int pin) {
  if (RELAY_ACTIVE_HIGH) {
    digitalWrite(pin, LOW);
  } else {
    digitalWrite(pin, HIGH);
  }
}
⚠️ 重要提醒
繼電器模組有兩種觸發方式：
• 高電平觸發：送 HIGH 訊號時繼電器吸合（通電）
• 低電平觸發：送 LOW 訊號時繼電器吸合（通電）
請確認你的繼電器模組是哪種類型，並修改 RELAY_ACTIVE_HIGH 設定！

範例 3：溫度控制風扇

學習重點：根據溫度判斷啟動風扇、設定溫度門檻值、自動控制邏輯

/*
 * 03_Temp_Fan.ino
 * 溫度控制風扇
 * 功能：當溫度超過設定值時自動開啟風扇
 */

#include <DHT.h>

#define DHT_PIN 2
#define DHT_TYPE DHT11
#define RELAY_FAN 7
#define LED_FAN 5

// 溫度門檻設定（使用遲滯控制避免頻繁開關）
#define TEMP_ON 28.0   // 溫度高於此值開啟風扇
#define TEMP_OFF 26.0  // 溫度低於此值關閉風扇

#define RELAY_ACTIVE_HIGH true

DHT dht(DHT_PIN, DHT_TYPE);
bool fanRunning = false;  // 風扇目前狀態

void setup() {
  pinMode(RELAY_FAN, OUTPUT);
  pinMode(LED_FAN, OUTPUT);
  relayOff(RELAY_FAN);
  digitalWrite(LED_FAN, LOW);

  dht.begin();
  Serial.begin(9600);

  Serial.println("=====================================");
  Serial.println("     溫度控制風扇系統");
  Serial.println("=====================================");
  Serial.print("開啟溫度: ");
  Serial.print(TEMP_ON);
  Serial.println(" °C");
  Serial.print("關閉溫度: ");
  Serial.print(TEMP_OFF);
  Serial.println(" °C");
  Serial.println("=====================================");
}

void loop() {
  delay(2000);

  float temperature = dht.readTemperature();

  if (isnan(temperature)) {
    Serial.println("❌ 感測器讀取失敗");
    return;
  }

  // 遲滯控制邏輯
  if (temperature >= TEMP_ON && !fanRunning) {
    // 溫度過高，開啟風扇
    fanRunning = true;
    relayOn(RELAY_FAN);
    digitalWrite(LED_FAN, HIGH);
    Serial.print("🌡️ 溫度 ");
    Serial.print(temperature);
    Serial.println(" °C → 🔴 風扇開啟！");
  }
  else if (temperature <= TEMP_OFF && fanRunning) {
    // 溫度回復正常，關閉風扇
    fanRunning = false;
    relayOff(RELAY_FAN);
    digitalWrite(LED_FAN, LOW);
    Serial.print("🌡️ 溫度 ");
    Serial.print(temperature);
    Serial.println(" °C → ⚫ 風扇關閉");
  }
  else {
    // 維持原狀態
    Serial.print("🌡️ 溫度 ");
    Serial.print(temperature);
    Serial.print(" °C → 風扇: ");
    Serial.println(fanRunning ? "運轉中 🔴" : "關閉 ⚫");
  }
}

void relayOn(int pin) {
  digitalWrite(pin, RELAY_ACTIVE_HIGH ? HIGH : LOW);
}

void relayOff(int pin) {
  digitalWrite(pin, RELAY_ACTIVE_HIGH ? LOW : HIGH);
}
🔍 遲滯控制（Hysteresis）說明
如果只設定一個門檻值（例如 28°C），當溫度在 27.9°C 和 28.1°C 之間波動時，風扇會頻繁開關，這對設備壽命不利。

遲滯控制使用兩個門檻值：
• 開啟門檻（28°C）：溫度高於此值才開啟
• 關閉門檻（26°C）：溫度低於此值才關閉
• 在兩者之間時維持原狀態

這樣就能避免在臨界溫度時頻繁切換！

範例 4：濕度控制霧化器

學習重點：根據濕度判斷啟動霧化器、避免頻繁開關（遲滯控制）

/*
 * 04_Humidity_Humidifier.ino
 * 濕度控制霧化器
 * 功能：當濕度低於設定值時自動開啟霧化器
 */

#include <DHT.h>

#define DHT_PIN 2
#define DHT_TYPE DHT11
#define RELAY_HUMIDIFIER 8
#define LED_HUMIDIFIER 6

// 濕度門檻設定
#define HUMIDITY_ON 50.0   // 濕度低於此值開啟霧化器
#define HUMIDITY_OFF 65.0  // 濕度高於此值關閉霧化器

#define RELAY_ACTIVE_HIGH true

DHT dht(DHT_PIN, DHT_TYPE);
bool humidifierRunning = false;

void setup() {
  pinMode(RELAY_HUMIDIFIER, OUTPUT);
  pinMode(LED_HUMIDIFIER, OUTPUT);
  relayOff(RELAY_HUMIDIFIER);
  digitalWrite(LED_HUMIDIFIER, LOW);

  dht.begin();
  Serial.begin(9600);

  Serial.println("=====================================");
  Serial.println("     濕度控制霧化器系統");
  Serial.println("=====================================");
  Serial.print("開啟濕度: < ");
  Serial.print(HUMIDITY_ON);
  Serial.println(" %");
  Serial.print("關閉濕度: > ");
  Serial.print(HUMIDITY_OFF);
  Serial.println(" %");
  Serial.println("=====================================");
}

void loop() {
  delay(2000);

  float humidity = dht.readHumidity();

  if (isnan(humidity)) {
    Serial.println("❌ 感測器讀取失敗");
    return;
  }

  // 遲滯控制邏輯（注意：濕度是低於門檻時開啟）
  if (humidity <= HUMIDITY_ON && !humidifierRunning) {
    // 濕度過低，開啟霧化器
    humidifierRunning = true;
    relayOn(RELAY_HUMIDIFIER);
    digitalWrite(LED_HUMIDIFIER, HIGH);
    Serial.print("💧 濕度 ");
    Serial.print(humidity);
    Serial.println(" % → 🔵 霧化器開啟！");
  }
  else if (humidity >= HUMIDITY_OFF && humidifierRunning) {
    // 濕度回復正常，關閉霧化器
    humidifierRunning = false;
    relayOff(RELAY_HUMIDIFIER);
    digitalWrite(LED_HUMIDIFIER, LOW);
    Serial.print("💧 濕度 ");
    Serial.print(humidity);
    Serial.println(" % → ⚫ 霧化器關閉");
  }
  else {
    Serial.print("💧 濕度 ");
    Serial.print(humidity);
    Serial.print(" % → 霧化器: ");
    Serial.println(humidifierRunning ? "運轉中 🔵" : "關閉 ⚫");
  }
}

void relayOn(int pin) {
  digitalWrite(pin, RELAY_ACTIVE_HIGH ? HIGH : LOW);
}

void relayOff(int pin) {
  digitalWrite(pin, RELAY_ACTIVE_HIGH ? LOW : HIGH);
}

範例 5：完整溫溼度控制系統

學習重點：整合溫度與濕度控制、多重條件判斷、狀態顯示與監控

/*
 * 05_Climate_Control.ino
 * 完整溫溼度控制系統
 * 功能：
 *   - 自動控制風扇（降溫）
 *   - 自動控制霧化器（加濕）
 *   - 即時顯示環境狀態
 *   - 遲滯控制避免頻繁切換
 */

#include <DHT.h>

// ===== 腳位定義 =====
#define DHT_PIN 2
#define DHT_TYPE DHT11
#define RELAY_FAN 7
#define RELAY_HUMIDIFIER 8
#define LED_FAN 5
#define LED_HUMIDIFIER 6

// ===== 控制參數 =====
// 溫度控制（°C）
#define TEMP_HIGH 28.0    // 高於此溫度開風扇
#define TEMP_LOW 25.0     // 低於此溫度關風扇

// 濕度控制（%）
#define HUMIDITY_LOW 50.0   // 低於此濕度開霧化器
#define HUMIDITY_HIGH 70.0  // 高於此濕度關霧化器

// 繼電器觸發電平
#define RELAY_ACTIVE_HIGH true

// ===== 全域變數 =====
DHT dht(DHT_PIN, DHT_TYPE);
bool fanRunning = false;
bool humidifierRunning = false;
unsigned long lastReadTime = 0;
const unsigned long READ_INTERVAL = 2000;  // 讀取間隔

void setup() {
  // 初始化腳位
  pinMode(RELAY_FAN, OUTPUT);
  pinMode(RELAY_HUMIDIFIER, OUTPUT);
  pinMode(LED_FAN, OUTPUT);
  pinMode(LED_HUMIDIFIER, OUTPUT);

  // 初始狀態：全部關閉
  setRelay(RELAY_FAN, false);
  setRelay(RELAY_HUMIDIFIER, false);
  digitalWrite(LED_FAN, LOW);
  digitalWrite(LED_HUMIDIFIER, LOW);

  dht.begin();
  Serial.begin(9600);

  printHeader();
}

void loop() {
  // 使用 millis() 取代 delay()，讓程式更有彈性
  if (millis() - lastReadTime < READ_INTERVAL) {
    return;
  }
  lastReadTime = millis();

  // 讀取感測器
  float temperature = dht.readTemperature();
  float humidity = dht.readHumidity();

  // 檢查讀取是否成功
  if (isnan(temperature) || isnan(humidity)) {
    Serial.println("❌ 感測器讀取失敗！請檢查接線。");
    return;
  }

  // ===== 溫度控制邏輯 =====
  if (temperature >= TEMP_HIGH && !fanRunning) {
    fanRunning = true;
    setRelay(RELAY_FAN, true);
    digitalWrite(LED_FAN, HIGH);
  }
  else if (temperature <= TEMP_LOW && fanRunning) {
    fanRunning = false;
    setRelay(RELAY_FAN, false);
    digitalWrite(LED_FAN, LOW);
  }

  // ===== 濕度控制邏輯 =====
  if (humidity <= HUMIDITY_LOW && !humidifierRunning) {
    humidifierRunning = true;
    setRelay(RELAY_HUMIDIFIER, true);
    digitalWrite(LED_HUMIDIFIER, HIGH);
  }
  else if (humidity >= HUMIDITY_HIGH && humidifierRunning) {
    humidifierRunning = false;
    setRelay(RELAY_HUMIDIFIER, false);
    digitalWrite(LED_HUMIDIFIER, LOW);
  }

  // 顯示狀態
  printStatus(temperature, humidity);
}

// 設定繼電器狀態
void setRelay(int pin, bool on) {
  if (RELAY_ACTIVE_HIGH) {
    digitalWrite(pin, on ? HIGH : LOW);
  } else {
    digitalWrite(pin, on ? LOW : HIGH);
  }
}

// 顯示啟動標題
void printHeader() {
  Serial.println();
  Serial.println("╔═══════════════════════════════════════════════╗");
  Serial.println("║     智慧溫室 - 溫溼度控制系統 v1.0            ║");
  Serial.println("╠═══════════════════════════════════════════════╣");
  Serial.print("║  溫度控制: ");
  Serial.print(TEMP_LOW);
  Serial.print("°C ~ ");
  Serial.print(TEMP_HIGH);
  Serial.println("°C                  ║");
  Serial.print("║  濕度控制: ");
  Serial.print(HUMIDITY_LOW);
  Serial.print("% ~ ");
  Serial.print(HUMIDITY_HIGH);
  Serial.println("%                    ║");
  Serial.println("╚═══════════════════════════════════════════════╝");
  Serial.println();
  Serial.println("溫度(°C) | 濕度(%) | 風扇 | 霧化器 | 狀態");
  Serial.println("---------|---------|------|--------|------------------");
}

// 顯示即時狀態
void printStatus(float temp, float hum) {
  // 溫度
  Serial.print("  ");
  if (temp < 10) Serial.print(" ");
  Serial.print(temp, 1);
  Serial.print("   |  ");

  // 濕度
  if (hum < 10) Serial.print(" ");
  Serial.print(hum, 1);
  Serial.print("   |  ");

  // 風扇狀態
  Serial.print(fanRunning ? "ON " : "OFF");
  Serial.print("  |   ");

  // 霧化器狀態
  Serial.print(humidifierRunning ? "ON " : "OFF");
  Serial.print("   | ");

  // 環境狀態判斷
  if (temp > TEMP_HIGH) {
    Serial.print("🔥 過熱");
  } else if (temp < 20) {
    Serial.print("❄️ 偏冷");
  } else {
    Serial.print("✅ 溫度正常");
  }

  Serial.print(" ");

  if (hum < HUMIDITY_LOW) {
    Serial.print("🏜️ 過乾");
  } else if (hum > 85) {
    Serial.print("💦 過濕");
  } else {
    Serial.print("✅ 濕度正常");
  }

  Serial.println();
}

範例 6：資料平滑處理（進階）

學習重點：使用移動平均減少感測器雜訊

/*
 * 06_Smooth_Reading.ino
 * 感測器資料平滑處理
 * 功能：使用移動平均濾波減少讀數跳動
 */

#include <DHT.h>

#define DHT_PIN 2
#define DHT_TYPE DHT11
#define NUM_SAMPLES 5  // 取樣數量

DHT dht(DHT_PIN, DHT_TYPE);

// 儲存歷史讀數
float tempHistory[NUM_SAMPLES];
float humHistory[NUM_SAMPLES];
int historyIndex = 0;
bool bufferFull = false;

void setup() {
  dht.begin();
  Serial.begin(9600);

  // 初始化歷史陣列
  for (int i = 0; i < NUM_SAMPLES; i++) {
    tempHistory[i] = 0;
    humHistory[i] = 0;
  }

  Serial.println("感測器資料平滑處理");
  Serial.println("原始值 → 平滑值");
}

void loop() {
  delay(2000);

  float rawTemp = dht.readTemperature();
  float rawHum = dht.readHumidity();

  if (isnan(rawTemp) || isnan(rawHum)) {
    Serial.println("讀取失敗");
    return;
  }

  // 更新歷史記錄
  tempHistory[historyIndex] = rawTemp;
  humHistory[historyIndex] = rawHum;
  historyIndex = (historyIndex + 1) % NUM_SAMPLES;

  if (historyIndex == 0) bufferFull = true;

  // 計算平均值
  float avgTemp = 0, avgHum = 0;
  int count = bufferFull ? NUM_SAMPLES : historyIndex;

  for (int i = 0; i < count; i++) {
    avgTemp += tempHistory[i];
    avgHum += humHistory[i];
  }
  avgTemp /= count;
  avgHum /= count;

  // 顯示比較
  Serial.print("溫度: ");
  Serial.print(rawTemp, 1);
  Serial.print(" → ");
  Serial.print(avgTemp, 1);
  Serial.print("°C | 濕度: ");
  Serial.print(rawHum, 1);
  Serial.print(" → ");
  Serial.print(avgHum, 1);
  Serial.println("%");
}

常見問題

Q1：DHT11 讀取失敗

  • 檢查接線是否正確
  • 確認使用的是「模組版」還是「裸元件版」
  • 模組版：三腳（S、+、-），已含提升電阻
  • 裸元件版：四腳，需自行接 10K 提升電阻
  • 確認腳位定義與實際接線相符

Q2：繼電器沒反應

  • 確認繼電器電源（VCC、GND）接線正確
  • 確認 IN 腳位接線
  • 檢查繼電器是「高電平觸發」還是「低電平觸發」
  • 聽繼電器是否有「喀嗒」聲

Q3：數值不穩定或跳動大

  • DHT11 精度有限（溫度 ±2°C，濕度 ±5%）
  • 可以多次讀取取平均值
  • 避免感測器直接被風吹到

Q4：繼電器頻繁開關

  • 加入遲滯（Hysteresis）控制
  • 設定開啟門檻和關閉門檻之間的差距
  • 例如：28°C 開風扇，26°C 關風扇

⚡ 繼電器工作原理與安全須知

繼電器內部構造：
            ┌─線圈─┐
   IN ──→  │ ═══ │──→ 控制電路（5V DC）
            └─────┘
               ↓ 電磁力
            ┌─────┐
   COM ────│  ⚡  │
            │  ↓  │
   NO ─────│接通 │──→ 被控制電路（可達 220V AC）
   NC ─────│斷開 │
            └─────┘

NO = Normally Open（常開）：平時斷開，通電接通
NC = Normally Closed（常閉）：平時接通，通電斷開
COM = Common（共用端）

繼電器模組接腳說明

接腳 名稱 說明
VCC 電源正極 接 Arduino 5V
GND 電源負極 接 Arduino GND
IN 控制訊號 接 Arduino 數位腳位
COM 共用端 接被控制設備的電源
NO 常開接點 繼電器動作時接通
NC 常閉接點 繼電器動作時斷開
⚠️ 安全警告
• 繼電器可控制高壓電器（110V/220V），操作時請務必斷電
• 教學時建議使用低壓設備（如 12V LED 燈條）進行測試
• 若要控制家用電器，請由專業人員協助接線
• 使用時注意繼電器的額定電流，不可超載

高/低電平觸發的判斷方法

判斷你的繼電器是高電平還是低電平觸發：

方法 1：看模組標示
         通常會印 "High Level Trigger" 或 "Low Level Trigger"

方法 2：實際測試
         1. VCC 接 5V，GND 接地
         2. IN 腳位接 5V → 聽到喀嗒聲 = 高電平觸發
         3. IN 腳位接 GND → 聽到喀嗒聲 = 低電平觸發

方法 3：看電路設計
         模組上有光耦或有 LED 在 IN 端 → 通常是低電平觸發
         直接使用電晶體驅動 → 通常是高電平觸發

🔄 遲滯控制（Hysteresis）深入解說

遲滯控制是工業控制中非常重要的技術，可以避免設備頻繁開關造成的損耗。

沒有遲滯控制的問題：

設定門檻: 28°C

溫度  28.2°C → 開  (超過門檻)
      27.8°C → 關  (低於門檻)
      28.1°C → 開  (又超過)
      27.9°C → 關  (又低於)
      ...（頻繁開關！）

有遲滯控制後：

開啟門檻: 28°C | 關閉門檻: 25°C

溫度  28.2°C → 開  (超過 28°C)
      27.5°C → 維持開啟 (在 25~28°C 之間)
      26.0°C → 維持開啟 (還沒低於 25°C)
      24.8°C → 關  (低於 25°C)
      26.0°C → 維持關閉 (還沒超過 28°C)
      ...（穩定控制！）

遲滯帶寬設定建議

應用場景 建議遲滯帶寬 範例
溫度控制（風扇） 2-3°C 28°C 開 / 25°C 關
溫度控制（暖氣） 2-3°C 18°C 開 / 21°C 關
濕度控制（加濕） 10-15% 50% 開 / 65% 關
濕度控制（除濕） 10-15% 80% 開 / 65% 關

🏡 溫室環境控制原理

理想溫室環境：
┌────────────────────────────────┐
│    溫度：22-28°C               │
│    濕度：60-80%                │
│                                │
│    溫度過高 → 啟動風扇/開窗    │
│    溫度過低 → 啟動暖氣         │
│    濕度過低 → 啟動霧化器       │
│    濕度過高 → 加強通風         │
└────────────────────────────────┘

溫溼度的關聯性

溫度和濕度是相互影響的：

1. 溫度上升 → 相對濕度下降
   （空氣能容納更多水蒸氣，相同水量下濕度百分比降低）

2. 溫度下降 → 相對濕度上升
   （可能造成結露，植物葉片上出現水珠）

3. 開風扇降溫 → 同時會降低濕度
   （通風會帶走水蒸氣）

4. 開霧化器加濕 → 可能會略微降溫
   （蒸發吸熱效應）

因此設計控制邏輯時，需要考慮這些交互作用！

PID（比例-積分-微分）控制可以實現更平滑的溫度調節，避免溫度大幅波動。

// PID 控制基本概念
float error = targetTemp - currentTemp;      // 誤差
float integral = integral + error * dt;      // 積分項
float derivative = (error - lastError) / dt; // 微分項

float output = Kp * error + Ki * integral + Kd * derivative;
// output 可用於 PWM 控制風扇轉速
