關於 DataCube 資料立方體

什麼是 DataCube？

DataCube（資料立方體）是一種多維度資料組織架構，特別適用於地理空間資料和時序資料的管理與分析。在智慧農業領域，DataCube 讓我們能夠有效整合衛星影像、無人機空拍、感測器數據等多源資料。

一句話解釋

DataCube 就像一個「三維資料櫃」：X 軸是經度、Y 軸是緯度、Z 軸是時間，每個格子存放著該時空位置的觀測數據。

DataCube 的核心概念

三維資料結構

                    時間軸 (T)
                      ↑
                      │   2024-01    2024-02    2024-03
                      │  ┌─────────┐┌─────────┐┌─────────┐
                      │  │ ■ ■ ■ ■ ││ ■ ■ ■ ■ ││ ■ ■ ■ ■ │
                      │  │ ■ ■ ■ ■ ││ ■ ■ ■ ■ ││ ■ ■ ■ ■ │
                      │  │ ■ ■ ■ ■ ││ ■ ■ ■ ■ ││ ■ ■ ■ ■ │
                      │  └─────────┘└─────────┘└─────────┘
                      │
                      └──────────────────────────────────→ 空間軸 (X, Y)

■ = 像素值 (NDVI、溫度、濕度等)

為什麼需要 DataCube？

傳統資料管理的問題

農場 A/
├── 2024-01-15_drone_image.tif
├── 2024-01-15_ndvi.tif
├── 2024-02-20_drone_image.tif
├── 2024-02-20_ndvi.tif
├── 2024-03-10_satellite.tif
├── sensor_data_2024Q1.csv
└── ... (數百個散亂的檔案)

問題：

  • 檔案散亂，難以管理
  • 不同格式、不同解析度難以整合
  • 時序分析需要大量手動處理
  • 跨區域比較非常困難

DataCube 的解決方案

DataCube/
└── farm_monitoring/
    ├── dimensions: [time, x, y]
    ├── variables:
    │   ├── ndvi: (time, x, y)
    │   ├── temperature: (time, x, y)
    │   ├── humidity: (time, x, y)
    │   └── soil_moisture: (time, x, y)
    └── coordinates:
        ├── time: [2024-01-01, 2024-01-02, ...]
        ├── x: [120.5, 120.501, ...]
        └── y: [24.0, 24.001, ...]

優點：

  • 統一的資料結構
  • 自動對齊時空座標
  • 高效的切片與聚合運算
  • 支援大規模平行處理

Python 實作

使用 xarray 建立 DataCube

xarray 是 Python 中處理多維陣列資料的強大套件，特別適合建立 DataCube。

import numpy as np
import xarray as xr
import pandas as pd

# 建立時間序列
times = pd.date_range('2024-01-01', periods=12, freq='M')

# 定義空間座標 (經緯度)
lons = np.linspace(120.0, 120.1, 100)  # 經度
lats = np.linspace(24.0, 24.1, 100)    # 緯度

# 建立隨機 NDVI 資料 (模擬)
ndvi_data = np.random.uniform(0.2, 0.8, size=(12, 100, 100))

# 建立 DataCube (xarray Dataset)
datacube = xr.Dataset(
    {
        'ndvi': (['time', 'lat', 'lon'], ndvi_data),
    },
    coords={
        'time': times,
        'lat': lats,
        'lon': lons,
    },
    attrs={
        'title': '農場植生指標監測',
        'source': '無人機空拍',
        'crs': 'EPSG:4326',
    }
)

print(datacube)

智慧農業應用案例

案例 1：作物生長監測

def monitor_crop_growth(datacube, threshold=0.4):
    """監測作物生長狀態"""

    # 計算 NDVI 變化率
    ndvi_diff = datacube.ndvi.diff(dim='time')

    # 標記生長異常區域
    abnormal = ndvi_diff < -0.1  # NDVI 下降超過 0.1

    # 統計異常面積
    abnormal_ratio = abnormal.sum() / abnormal.size * 100

    return {
        'abnormal_areas': abnormal,
        'abnormal_ratio': float(abnormal_ratio),
    }

result = monitor_crop_growth(datacube)
print(f"異常區域比例: {result['abnormal_ratio']:.2f}%")

案例 2：灌溉需求分析

def analyze_irrigation_need(datacube):
    """分析灌溉需求"""

    # 取得最新資料
    latest = datacube.isel(time=-1)

    # 定義缺水條件
    dry_condition = (
        (latest.soil_moisture < 30) &  # 土壤濕度低
        (latest.temperature > 30) &    # 溫度高
        (latest.ndvi > 0.3)            # 有作物
    )

    # 計算需灌溉面積
    need_irrigation = dry_condition.sum()

    return {
        'irrigation_map': dry_condition,
        'area_count': int(need_irrigation),
    }

案例 3：產量預測

def predict_yield(datacube, model):
    """基於 DataCube 進行產量預測"""

    # 提取特徵
    features = xr.Dataset({
        'ndvi_max': datacube.ndvi.max(dim='time'),
        'ndvi_mean': datacube.ndvi.mean(dim='time'),
        'temp_mean': datacube.temperature.mean(dim='time'),
        'growing_days': (datacube.ndvi > 0.4).sum(dim='time'),
    })

    # 轉換為訓練格式
    X = features.to_array().values.reshape(4, -1).T

    # 預測
    yield_pred = model.predict(X)

    return yield_pred.reshape(features.ndvi_max.shape)

Open Data Cube (ODC)

什麼是 Open Data Cube？

Open Data Cube 是一個開源的地球觀測資料管理與分析平台，被多個國家採用於國家級地理資訊系統。

ODC 主要功能

  • 資料索引：自動管理大量衛星影像
  • 資料載入：依需求載入時空子集
  • 資料融合：不同衛星、不同解析度自動對齊
  • 分析工具：內建常用地理空間分析功能

ODC 使用範例

import datacube

# 連接 Data Cube
dc = datacube.Datacube(app='farm_analysis')

# 查詢可用資料
products = dc.list_products()
print(products)

# 載入 Sentinel-2 資料
data = dc.load(
    product='sentinel2_l2a',
    x=(120.0, 120.1),
    y=(24.0, 24.1),
    time=('2024-01-01', '2024-12-31'),
    measurements=['red', 'green', 'blue', 'nir'],
    output_crs='EPSG:4326',
    resolution=(-0.0001, 0.0001)
)

# 計算 NDVI
data['ndvi'] = (data.nir - data.red) / (data.nir + data.red)

總結

DataCube 核心概念

維度 = 時間 + 空間 (X, Y)
變數 = NDVI, 溫度, 濕度, ...
座標 = 時間戳記 + 經緯度
切片 = 取出特定時空範圍的資料
聚合 = 計算平均、最大、最小等統計值

何時使用 DataCube

  • 需要分析時序地理資料
  • 整合多源遙測資料
  • 進行大規模空間分析
  • 建立自動化監測系統

何時不適合

  • 單次影像分析
  • 小規模資料處理
  • 即時串流資料
