關於 Arduino Uno 的各種電位與訊號類別

本文檔整理 Arduino Uno 課程中所介紹的各種電位與訊號類別，幫助學習者快速了解 Arduino 開發中常用的訊號類型與通訊方式。

一、訊號類別總覽

Arduino Uno 主要支援以下三種訊號類型：

訊號類型 特性 常用場景
數位訊號 二進制，只有 0 或 1（低電位/高電位） LED 開關、按鈕輸入
類比訊號 連續數值（0-1023），易受雜訊影響 電位器、光敏電阻、各類感測器
PWM 訊號 透過調整脈衝寬度模擬類比訊號 LED 調光、馬達速度控制

二、數位訊號（Digital Signal）

2.1 基本概念

  • 電位狀態：只有兩種狀態
  • 高電位（HIGH）：5V，代表邏輯 1
  • 低電位（LOW）：0V，代表邏輯 0
  • 特點：不易受雜訊干擾，穩定可靠
  • 腳位標記：Arduino Uno 的 D0-D13 為數位腳位

2.2 數位輸出應用範例

// LED 燈控制範例
int LED_PIN = 11;

void setup() {
  pinMode(LED_PIN, OUTPUT);  // 設定為輸出腳位
}

void loop() {
  digitalWrite(LED_PIN, HIGH);  // 輸出高電位，LED 亮起
  delay(1000);
  digitalWrite(LED_PIN, LOW);   // 輸出低電位，LED 熄滅
  delay(1000);
}

2.3 數位輸入應用範例

// 按鈕開關讀取範例
int BUTTON_PIN = 2;
int LED_PIN = 11;

void setup() {
  pinMode(BUTTON_PIN, INPUT);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  int buttonState = digitalRead(BUTTON_PIN);
  if (buttonState == HIGH) {
    digitalWrite(LED_PIN, HIGH);
  } else {
    digitalWrite(LED_PIN, LOW);
  }
}

2.4 常見數位訊號元件

元件 類型 說明
LED 燈 輸出 發光二極體，需搭配 220Ω 電阻
有源蜂鳴器 輸出 通電即發出固定頻率聲音
食人魚燈 輸出 高亮度 LED 模組
雷射頭 輸出 半導體雷射發射模組
按鈕開關 輸入 需搭配 10KΩ 電阻避免浮動
傾斜開關 輸入 偵測物體角度變化
觸摸開關 輸入 電容式觸摸感測
限位開關 輸入 微動開關，偵測機械位置

三、類比訊號（Analog Signal）

3.1 基本概念

  • 數值範圍：0-1023（10 位元解析度）
  • 電壓對應：0V 對應 0，5V 對應 1023
  • 特點：連續數值，可表達多種狀態，但易受雜訊影響
  • 腳位標記：Arduino Uno 的 A0-A5 為類比輸入腳位

3.2 類比輸入應用範例

// 電位器讀取範例
int POT_PIN = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int potValue = analogRead(POT_PIN);  // 讀取類比值 (0-1023)
  Serial.println(potValue);
  delay(100);
}

3.3 常見類比訊號元件

元件 說明 數值特性
B10K 電位器 可變電阻，旋轉調節阻值 線性變化，0-1023
光敏電阻 光照強度感測，暗時電阻高 非線性，約 0-768
水位感測器 電阻式水位偵測 水位越高，數值越大
震動感測器 偵測震動或撞擊 震動時數值變化
火焰感測器 紅外線偵測火焰 偵測到火焰時數值變化
搖桿元件 X/Y 軸各一組類比輸入 中心約 512，範圍 0-1023

四、PWM 訊號（Pulse Width Modulation）

4.1 基本概念

  • 原理：透過快速切換高低電位，調整「占空比」來模擬類比效果
  • 占空比：高電位時間佔整個週期的比例
  • 數值範圍：0-255（8 位元）
  • 腳位標記：Arduino Uno 上標記 ~ 的腳位支援 PWM（3, 5, 6, 9, 10, 11）

4.2 PWM 輸出範例

// LED 漸變光範例
int LED_PIN = 11;  // PWM 腳位
int POT_PIN = A0;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  int potValue = analogRead(POT_PIN);           // 讀取電位器 (0-1023)
  int pwmValue = map(potValue, 0, 1023, 0, 255); // 轉換為 PWM 值 (0-255)
  analogWrite(LED_PIN, pwmValue);                // 輸出 PWM 訊號
}

4.3 PWM 應用場景

應用 說明
LED 調光 控制 LED 亮度漸變
RGB LED 彩色控制 混合 R、G、B 三色產生多種顏色
無源蜂鳴器 產生不同頻率的聲音
舵機（伺服馬達） 精確控制轉動角度
馬達速度控制 調整馬達轉速

4.4 RGB LED 範例

int RED_PIN = 9;
int GREEN_PIN = 10;
int BLUE_PIN = 11;

void setup() {
  pinMode(RED_PIN, OUTPUT);
  pinMode(GREEN_PIN, OUTPUT);
  pinMode(BLUE_PIN, OUTPUT);
}

void loop() {
  // 紅色 (255, 0, 0)
  analogWrite(RED_PIN, 255);
  analogWrite(GREEN_PIN, 0);
  analogWrite(BLUE_PIN, 0);
  delay(1000);

  // 綠色 (0, 255, 0)
  analogWrite(RED_PIN, 0);
  analogWrite(GREEN_PIN, 255);
  analogWrite(BLUE_PIN, 0);
  delay(1000);

  // 藍色 (0, 0, 255)
  analogWrite(RED_PIN, 0);
  analogWrite(GREEN_PIN, 0);
  analogWrite(BLUE_PIN, 255);
  delay(1000);
}

五、通訊協議

Arduino Uno 支援多種通訊方式，用於與其他裝置或模組進行資料傳輸。

5.1 串列通訊（Serial / UART）

  • 腳位：D0（RX 接收）、D1（TX 發送）
  • 特點：依序傳送數據，廣泛兼容，穩定
  • 應用：與電腦通訊、藍牙模組、GPS 模組
void setup() {
  Serial.begin(9600);  // 初始化串列通訊，鮑率 9600
}

void loop() {
  Serial.println("Hello World!");
  delay(1000);
}

5.2 SPI 傳輸

SPI（Serial Peripheral Interface）是一種高速全雙工通訊協議。

訊號線 腳位 說明
SCLK D13 時鐘線，決定傳輸時間點
MOSI D11 主控端輸出，從端輸入
MISO D12 主控端輸入，從端輸出
SS D10 片選，控制與哪個從端溝通

特點：

  • 適合多設備雙向傳輸
  • 高效率、高靈活度
  • 適用於：SD 卡模組、點矩陣顯示器、部分感測器

5.3 I2C 傳輸

I2C（Inter-Integrated Circuit）只需兩條線即可連接多個裝置。

訊號線 腳位 說明
SDA A4 資料線，雙向傳輸資料
SCL A5 時鐘線，由主控端控制傳輸順序

特點：

  • 每個從端裝置有唯一位址（如 0x3C、0x40、0x68）
  • 主控端根據位址決定與誰溝通
  • 所需線材少、擴充性強
  • 適用於：LCD 1602 顯示器、RTC 時鐘模組、各類 I2C 感測器

八、訊號類型選擇指南

  1. 需要開/關控制 → 使用數位訊號
  2. 需要讀取連續變化的數值 → 使用類比訊號
  3. 需要控制亮度、速度、角度等 → 使用 PWM 訊號
  4. 需要連接多個裝置共用通訊 → 使用 I2C 通訊
  5. 需要高速傳輸大量資料 → 使用 SPI 通訊
  6. 需要與電腦或其他開發板通訊 → 使用串列通訊

8.1 口訣記憶法

六字口訣：「開連調，多快聊」

口訣 對應 訊號類型
開 開關控制 數位訊號
連 連續變化 類比訊號
調 調整亮度/速度 PWM 訊號
多 多裝置共用 I2C
快 快速大量傳輸 SPI
聊 聊天（與電腦對話） 串列通訊

8.2 生活聯想法

訊號類型 生活比喻 說明
數位 電燈開關 只有「開」或「關」兩種狀態
類比 水龍頭 可以轉大轉小，連續變化
PWM 電風扇調速 弱/中/強，模擬漸變效果
I2C 公車路線 一條路，多站牌（位址），輪流上下車
SPI 高速公路 四線道，速度快，各走各的
串列 講電話 一句一句講，你來我往

8.3 關鍵字配對法

數位 = 0 或 1 = 開關
類比 = 0~1023 = 感測
PWM  = 0~255  = 調光
I2C  = 2線多機 = 省線
SPI  = 4線高速 = 快傳
串列 = TX/RX  = 對話

8.4 情境判斷口訣

「開關數位，感測類比，調整 PWM」

「省線 I2C，快傳 SPI，對話串列」
