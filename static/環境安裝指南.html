一、基礎軟體安裝

1. Python 安裝 (必要) - 2025 新版安裝方式

建議版本：Python 3.9 (遙測分析課程的 GDAL 套件需要)

重要說明：Python 官方從 2025 年開始採用新的「Python Install Manager」安裝方式。
這個新方式讓您可以同時安裝多個 Python 版本，並輕鬆切換使用！

步驟 1：下載並安裝 Python Install Manager

  1. 前往 Python 官網：https://www.python.org/downloads/
  2. 點擊 「Download Python」 按鈕下載安裝程式
  3. 執行安裝程式，依照提示完成安裝：
    • 詢問是否移除舊版 py launcher → 選擇 y (建議)
    • 是否加入 PATH → 選擇 y
    • 是否安裝最新版 Python → 可選 y 或 n (我們之後會安裝 3.9)
  4. 重新開啟終端機（重要！PATH 變更需要重開才生效）

步驟 2：安裝 Python 3.9 (課程必需)

# 開啟 cmd 或 PowerShell，執行以下指令安裝 Python 3.9
py install 3.9

# 驗證安裝成功
py -3.9 --version
# 應顯示：Python 3.9.x

步驟 3：查看已安裝的 Python 版本

# 列出所有已安裝的 Python 版本
py list

# 範例輸出：
#  PythonCore\3.14    C:\Users\xxx\AppData\Local\Python\PythonCore\3.14
#  PythonCore\3.9     C:\Users\xxx\AppData\Local\Python\PythonCore\3.9

Python Install Manager 常用指令

指令說明
py install 3.9安裝 Python 3.9
py list列出已安裝的版本
py -3.9使用 Python 3.9 執行
py -3.9 -m venv venv用 Python 3.9 建立虛擬環境
py uninstall 3.14移除 Python 3.14
py help查看所有指令說明

二、Python 虛擬環境建立

建立虛擬環境 (建議每個課程獨立建立)

重要：本課程需要使用 Python 3.9 建立虛擬環境，請務必使用 py -3.9 指令！ 
# 進入課程目錄
cd D:\Course\Smart_Agri_Course

# 使用 Python 3.9 建立虛擬環境 (重要!)
py -3.9 -m venv venv

# 啟動虛擬環境 (Windows)
venv\Scripts\activate

# 啟動後會看到 (venv) 前綴
# 確認虛擬環境使用的是 Python 3.9
python --version
# 應顯示：Python 3.9.x

離開虛擬環境

deactivate

虛擬環境注意事項

  • 虛擬環境建立後，python 和 pip 指令會自動指向該環境的 Python 版本
  • 如果不小心用錯版本建立了虛擬環境，請刪除 venv 資料夾後重新建立
  • 每次開啟新的終端機，都需要重新執行 venv\Scripts\activate 啟動環境

Day 4-5：農業遙測影像分析 (重要!)

此課程需要特別處理 GDAL 安裝，且必須使用 Python 3.9

為什麼需要 Python 3.9？
GDAL 的預編譯 .whl 檔案是針對特定 Python 版本編譯的。
檔案名稱中的 cp39 表示「CPython 3.9」，只能在 Python 3.9 環境中使用。 
# 1. 確保虛擬環境使用 Python 3.9
python --version
# 應顯示：Python 3.9.x
# 如果不是 3.9，請刪除 venv 資料夾，用 py -3.9 -m venv venv 重新建立

# 2. 先安裝 GDAL (使用 .whl 檔案)
pip install 04_DOCUMENT/installers/GDAL-3.3.0-cp39-cp39-win_amd64.whl

# 3. 安裝其他套件
pip install -r 04_DOCUMENT/requirements/05_rs_analysis.txt

# 4. 驗證 GDAL 安裝
python -c "from osgeo import gdal; print(gdal.__version__)"

GDAL 安裝常見問題：

  • 如果出現 DLL load failed 錯誤，請確認虛擬環境是用 Python 3.9 建立的
  • .whl 檔案名稱 cp39 表示 Python 3.9 專用，不相容其他版本
  • 如果不確定虛擬環境的 Python 版本，執行 python --version 檢查

六、常見問題排解

Q0: 什麼是 Python Install Manager？和以前有什麼不同？

從 2025 年開始，Python 官方改變了 Windows 的安裝方式：

  • 以前：需要下載特定版本的安裝程式 (如 python-3.9.13-amd64.exe)
  • 現在：統一使用 Python Install Manager，可用指令安裝任意版本

優點：

  • 可以同時安裝多個 Python 版本
  • 用 py -3.9 或 py -3.14 輕鬆切換版本
  • 不會有版本衝突的問題

Q1: 如何確認 Python 3.9 已安裝成功？

# 列出所有已安裝的版本
py list

# 直接測試 Python 3.9
py -3.9 --version

Q2: pip install 出現權限錯誤

pip install --user <套件名稱>

Q3: GDAL 安裝失敗

  • 確認虛擬環境是用 py -3.9 -m venv venv 建立的
  • 使用提供的 .whl 檔案安裝，不要用 pip install gdal
  • 如果版本不對，刪除 venv 資料夾重新建立

Q4: 虛擬環境用錯 Python 版本怎麼辦？

# 1. 先離開虛擬環境
deactivate

# 2. 刪除原本的 venv 資料夾
rmdir /s /q venv

# 3. 用正確版本重新建立
py -3.9 -m venv venv

# 4. 重新啟動
venv\Scripts\activate

# 5. 確認版本
python --version

Q5: 執行 py 指令出現「找不到命令」錯誤

  • 請確認已重新開啟終端機（安裝後 PATH 需要重開才生效）
  • 如果仍有問題，請重新執行 Python 安裝程式，確認選擇「Add to PATH」

Q6: TensorFlow 安裝很慢

pip install tensorflow==2.10.0 -i https://pypi.tuna.tsinghua.edu.cn/simple

Q7: Ollama 模型下載失敗

  • 確認網路連線正常
  • 可嘗試較小的模型：ollama pull gemma3:2b 或 ollama pull llama3.2:1b
  • 建議下載的模型：
  • gemma3 - 對話模型（建議使用）
  • llama3.2 - 對話模型（備選）
  • nomic-embed-text - 嵌入模型（RAG 範例必需）
