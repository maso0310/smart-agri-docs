關於 TWD97 座標與 WGS84 座標系統

座標系統是地理資訊系統（GIS）的基礎。在台灣進行農業測量、定位導航時，經常會遇到 TWD97 和 WGS84 兩種座標系統。了解它們的差異與轉換方法，對於正確處理空間資料至關重要。

一、座標系統基礎概念

什麼是座標系統

座標系統定義了如何用數字來描述地球表面上的位置，主要包含三個要素：

  • 大地基準（Datum）：定義地球的形狀和大小
  • 橢球體（Ellipsoid）：數學模型近似地球形狀
  • 投影方式（Projection）：將球面座標轉換到平面

地理座標 vs 投影座標

類型 單位 特點 範例
地理座標 度（°） 經緯度，球面座標 121.5654°E, 25.0330°N
投影座標 公尺（m） 平面座標，適合計算 E: 302500, N: 2770500

二、WGS84 座標系統

定義與特點

WGS84（World Geodetic System 1984）是全球通用的大地座標系統：

項目 說明
全名 1984 世界大地座標系統
建立單位 美國國防部
EPSG 代碼 EPSG:4326（地理座標）
座標原點 地球質心
應用 GPS、Google Maps、航空導航

WGS84 橢球參數

# WGS84 橢球體參數
半長軸 (a) = 6,378,137.0 m
半短軸 (b) = 6,356,752.314245 m
扁率 (f)   = 1 / 298.257223563
第一離心率平方 (e²) = 0.00669437999014

WGS84 座標表示方式

# 度 (Decimal Degrees)
緯度: 25.0330°
經度: 121.5654°

# 度分秒 (DMS)
緯度: 25° 01' 58.8" N
經度: 121° 33' 55.4" E

# 度分 (DM)
緯度: 25° 1.98' N
經度: 121° 33.92' E

三、TWD97 座標系統

定義與特點

TWD97（Taiwan Datum 1997）是台灣現行的國家座標系統：

項目 說明
全名 1997 台灣大地基準
建立單位 內政部國土測繪中心
採用橢球 GRS80（與 WGS84 幾乎相同）
投影方式 橫麥卡托投影（TM）二度分帶
EPSG 代碼 EPSG:3826（TM2 121分帶）

TWD97 投影參數

# TWD97 TM2（二度分帶）投影參數
中央經線: 121°E（台灣本島）/ 119°E（澎湖）
原點緯度: 0°（赤道）
假東距 (False Easting): 250,000 m
假北距 (False Northing): 0 m
尺度因子 (Scale Factor): 0.9999

TWD97 座標原點詳解

TWD97 座標系統的原點設計是其重要特徵，直接影響座標值的計算與解讀：

1. 地理原點（投影原點）

參數 數值 說明
原點緯度 0°（赤道） 橫麥卡托投影的標準設置
中央經線 121°E 通過台灣本島中心的經線
原點位置 赤道與東經 121° 交點 實際位於印度尼西亞海域

2. 假原點（False Origin）

為了避免負座標值，TWD97 使用「假原點」（偏移量）：

  • 假東距（False Easting）：250,000 公尺
    • 使台灣本島的 X 座標都是正值
    • 東經 121° 中央經線上的點 X = 250,000
    • 中央經線以東的點 X > 250,000
    • 中央經線以西的點 X < 250,000
  • 假北距（False Northing）：0 公尺
    • 赤道上的點 Y = 0
    • 台灣位於北半球，所有 Y 座標皆為正值（約 2,400,000 ~ 2,900,000）

3. 台灣各區域的中央經線

為了減少投影變形，台灣採用「二度分帶」系統，不同區域使用不同中央經線：

區域 中央經線 EPSG 代碼 假東距
台灣本島 121°E EPSG:3826 250,000 m
澎湖群島 119°E EPSG:3825 250,000 m
金門、馬祖 117°E 或 119°E EPSG:3824 或 3825 250,000 m

4. 原點的實際意義

為什麼原點在赤道？
橫麥卡托投影（TM）的標準設計是以赤道為緯度原點，這樣可以：
  • 保持投影的數學一致性
  • 簡化座標轉換公式
  • 與國際標準接軌
雖然原點不在台灣境內，但通過「假東距」和「假北距」的設計，確保台灣地區的所有座標值都是正值且易於使用。

5. 座標範例說明

# 台北市中心（台北 101 附近）
WGS84: 121.5654°E, 25.0330°N
TWD97: X = 302,500 m, Y = 2,770,500 m

# 座標解讀：
X = 302,500 m
  → 比假東距 250,000 多了 52,500 m
  → 表示在中央經線（121°E）以東約 52.5 km

Y = 2,770,500 m
  → 從赤道（0°）向北約 2,770.5 km
  → 對應北緯約 25°

6. 與其他座標系統的原點比較

座標系統 原點位置 假原點
WGS84 地球質心 無（使用經緯度）
TWD97（121°分帶） 赤道 × 東經 121° E: 250,000 m, N: 0 m
TWD67（舊系統） 中央山脈基準點 不同的偏移值
UTM（國際通用） 赤道 × 各帶中央經線 E: 500,000 m, N: 0 m（北半球）

為什麼使用 TWD97

  • 最佳化：針對台灣地區設計，變形最小
  • 實用單位：使用公尺，便於計算距離、面積
  • 法定座標：政府地籍、都市計畫使用
  • 相容性：與舊系統 TWD67 可轉換

四、TWD97 與 WGS84 的差異

主要差異比較

項目 WGS84 TWD97
類型 地理座標系統 投影座標系統
單位 度 公尺
適用範圍 全球 台灣地區
用途 GPS、全球定位 測量、地籍、GIS
橢球體 WGS84 GRS80

橢球體差異（極小）

參數 WGS84 GRS80 差異
半長軸 a 6,378,137 m 6,378,137 m 0
扁率倒數 1/f 298.257223563 298.257222101 0.000001462
實務上：WGS84 和 TWD97 的大地基準幾乎相同，主要差異在於 TWD97 多了投影轉換。

五、座標轉換

轉換流程

WGS84 經緯度 ←→ TWD97 TM2

轉換步驟：
1. WGS84 → TWD97：經緯度 → TM 投影計算 → E, N 座標
2. TWD97 → WGS84：E, N 座標 → TM 反投影 → 經緯度

Python 轉換程式

import math

class CoordinateConverter:
    """TWD97 與 WGS84 座標轉換器"""

    def __init__(self):
        # GRS80 橢球參數
        self.a = 6378137.0  # 半長軸
        self.f = 1 / 298.257222101  # 扁率
        self.b = self.a * (1 - self.f)  # 半短軸

        # 計算離心率
        self.e2 = (self.a**2 - self.b**2) / self.a**2  # 第一離心率平方
        self.ep2 = (self.a**2 - self.b**2) / self.b**2  # 第二離心率平方

        # TWD97 TM2 投影參數
        self.lon0 = 121.0  # 中央經線（度）
        self.k0 = 0.9999   # 尺度因子
        self.dx = 250000   # 假東距
        self.dy = 0        # 假北距

    def wgs84_to_twd97(self, lat, lon):
        """
        WGS84 經緯度轉 TWD97 TM2

        參數:
            lat: 緯度（度）
            lon: 經度（度）

        回傳:
            (E, N): TWD97 座標（公尺）
        """
        # 轉弧度
        lat_rad = math.radians(lat)
        lon_rad = math.radians(lon)
        lon0_rad = math.radians(self.lon0)

        # 計算參數
        N = self.a / math.sqrt(1 - self.e2 * math.sin(lat_rad)**2)
        T = math.tan(lat_rad)**2
        C = self.ep2 * math.cos(lat_rad)**2
        A = (lon_rad - lon0_rad) * math.cos(lat_rad)

        # 子午線弧長
        M = self.a * (
            (1 - self.e2/4 - 3*self.e2**2/64 - 5*self.e2**3/256) * lat_rad
            - (3*self.e2/8 + 3*self.e2**2/32 + 45*self.e2**3/1024) * math.sin(2*lat_rad)
            + (15*self.e2**2/256 + 45*self.e2**3/1024) * math.sin(4*lat_rad)
            - (35*self.e2**3/3072) * math.sin(6*lat_rad)
        )

        # 計算 E, N
        E = self.dx + self.k0 * N * (
            A + (1-T+C) * A**3 / 6
            + (5-18*T+T**2+72*C-58*self.ep2) * A**5 / 120
        )

        N_coord = self.dy + self.k0 * (
            M + N * math.tan(lat_rad) * (
                A**2 / 2
                + (5-T+9*C+4*C**2) * A**4 / 24
                + (61-58*T+T**2+600*C-330*self.ep2) * A**6 / 720
            )
        )

        return E, N_coord

    def twd97_to_wgs84(self, E, N):
        """
        TWD97 TM2 轉 WGS84 經緯度

        參數:
            E: 東距（公尺）
            N: 北距（公尺）

        回傳:
            (lat, lon): WGS84 座標（度）
        """
        # 移除假座標
        x = E - self.dx
        y = N - self.dy

        # 計算底點緯度
        M = y / self.k0
        mu = M / (self.a * (1 - self.e2/4 - 3*self.e2**2/64 - 5*self.e2**3/256))

        e1 = (1 - math.sqrt(1 - self.e2)) / (1 + math.sqrt(1 - self.e2))

        phi1 = mu + (3*e1/2 - 27*e1**3/32) * math.sin(2*mu)
        phi1 += (21*e1**2/16 - 55*e1**4/32) * math.sin(4*mu)
        phi1 += (151*e1**3/96) * math.sin(6*mu)
        phi1 += (1097*e1**4/512) * math.sin(8*mu)

        # 計算參數
        N1 = self.a / math.sqrt(1 - self.e2 * math.sin(phi1)**2)
        T1 = math.tan(phi1)**2
        C1 = self.ep2 * math.cos(phi1)**2
        R1 = self.a * (1 - self.e2) / (1 - self.e2 * math.sin(phi1)**2)**1.5
        D = x / (N1 * self.k0)

        # 計算緯度
        lat = phi1 - (N1 * math.tan(phi1) / R1) * (
            D**2 / 2
            - (5 + 3*T1 + 10*C1 - 4*C1**2 - 9*self.ep2) * D**4 / 24
            + (61 + 90*T1 + 298*C1 + 45*T1**2 - 252*self.ep2 - 3*C1**2) * D**6 / 720
        )

        # 計算經度
        lon = self.lon0 + math.degrees(
            (D - (1 + 2*T1 + C1) * D**3 / 6
             + (5 - 2*C1 + 28*T1 - 3*C1**2 + 8*self.ep2 + 24*T1**2) * D**5 / 120)
            / math.cos(phi1)
        )

        lat = math.degrees(lat)

        return lat, lon


# 使用範例
converter = CoordinateConverter()

# WGS84 轉 TWD97
lat, lon = 25.0330, 121.5654  # 台北
e, n = converter.wgs84_to_twd97(lat, lon)
print(f"WGS84: ({lat}, {lon})")
print(f"TWD97: E={e:.3f}, N={n:.3f}")

# TWD97 轉 WGS84
lat2, lon2 = converter.twd97_to_wgs84(e, n)
print(f"轉回 WGS84: ({lat2:.6f}, {lon2:.6f})")

使用 pyproj 套件（推薦）

from pyproj import Transformer, CRS

# 建立轉換器
# WGS84 (EPSG:4326) ←→ TWD97 TM2 (EPSG:3826)
wgs84_to_twd97 = Transformer.from_crs("EPSG:4326", "EPSG:3826", always_xy=True)
twd97_to_wgs84 = Transformer.from_crs("EPSG:3826", "EPSG:4326", always_xy=True)

# WGS84 轉 TWD97
lon, lat = 121.5654, 25.0330
e, n = wgs84_to_twd97.transform(lon, lat)
print(f"TWD97: E={e:.3f}, N={n:.3f}")

# TWD97 轉 WGS84
lon2, lat2 = twd97_to_wgs84.transform(e, n)
print(f"WGS84: ({lat2:.6f}, {lon2:.6f})")

# 批次轉換
import numpy as np
lons = np.array([121.5, 121.6, 121.7])
lats = np.array([25.0, 25.1, 25.2])
es, ns = wgs84_to_twd97.transform(lons, lats)

六、度分秒轉換

def dms_to_dd(degrees, minutes, seconds, direction='N'):
    """度分秒轉十進位度"""
    dd = degrees + minutes/60 + seconds/3600
    if direction in ['S', 'W']:
        dd = -dd
    return dd

def dd_to_dms(dd):
    """十進位度轉度分秒"""
    direction = 'N' if dd >= 0 else 'S'
    dd = abs(dd)
    degrees = int(dd)
    minutes = int((dd - degrees) * 60)
    seconds = (dd - degrees - minutes/60) * 3600
    return degrees, minutes, seconds, direction

# 範例
lat_dms = (25, 1, 58.8, 'N')  # 25° 01' 58.8" N
lat_dd = dms_to_dd(*lat_dms)
print(f"十進位度: {lat_dd:.6f}°")

d, m, s, dir = dd_to_dms(25.033)
print(f"度分秒: {d}° {m}' {s:.1f}\" {dir}")

八、農業應用注意事項

GPS 設備座標設定

  • 大多數 GPS 預設輸出 WGS84
  • RTK 設備可能可設定輸出 TWD97
  • 確認設備與軟體使用相同座標系統

GIS 軟體設定

# QGIS Python 設定座標系統
from qgis.core import QgsCoordinateReferenceSystem

# 設定為 TWD97
crs_twd97 = QgsCoordinateReferenceSystem("EPSG:3826")

# 設定為 WGS84
crs_wgs84 = QgsCoordinateReferenceSystem("EPSG:4326")

常見問題

問題 原因 解決方法
圖層無法對齊 座標系統不同 統一轉換為同一系統
位置偏移數百公尺 使用錯誤的座標系統 確認 EPSG 代碼
面積計算錯誤 使用地理座標計算 轉為投影座標再計算
最佳實務：儲存原始 GPS 資料（WGS84），處理分析時轉為 TWD97，輸出成果時標註座標系統。
