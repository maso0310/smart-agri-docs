智慧溫室分組教學 - 任務總覽

課程簡介

本課程將學生分成六組，每組使用一套 Arduino + 麵包板，各自負責智慧溫室系統的不同功能模組。透過分組合作，學生可以深入了解各項技術，最後整合成完整的智慧溫室系統。

各組任務概述

第一組：光線控制組 🌞

項目 內容
主要任務 環境光線感測與自動補光控制
核心元件 光敏電阻(LDR)、電位器、LED
學習重點 類比輸入、PWM輸出、map()函數
最終目標 製作自動補光系統原型

功能說明： - 使用光敏電阻感測環境光線強度 - 電位器設定光線門檻值 - 光線不足時自動開啟補光燈 - LED亮度與環境光線成反比

第二組：溫溼度控制組 🌡️

項目 內容
主要任務 溫溼度感測與環境調控
核心元件 DHT11感測器、繼電器、LED（模擬風扇/霧化器）
學習重點 數位感測器、繼電器控制、遲滯控制
最終目標 製作自動溫溼度控制系統

功能說明： - DHT11 感測溫度與濕度 - 溫度過高時啟動風扇（繼電器控制） - 濕度過低時啟動霧化器 - 包含遲滯控制避免頻繁開關

第三組：土壤水份控制組 💧

項目 內容
主要任務 土壤濕度感測與自動灌溉
核心元件 土壤濕度感測器、繼電器、LED（模擬抽水馬達）
學習重點 感測器校正、安全保護機制、millis()時間管理
最終目標 製作自動灌溉系統原型

功能說明： - 土壤濕度感測器偵測土壤乾燥程度 - 土壤過乾時自動啟動澆水 - 最大澆水時間限制（安全保護） - 澆水間隔冷卻時間

第四組：螢幕顯示組 📺

項目 內容
主要任務 資訊顯示與人機介面
核心元件 LCD 1602（I2C）、8x8 LED點矩陣（MAX7219）
學習重點 I2C通訊、自訂字元、圖形顯示
最終目標 製作溫室監控面板

功能說明： - LCD 顯示溫度、濕度、土壤等數值 - 自訂符號（溫度計、水滴、太陽等圖示） - LED 點矩陣顯示狀態圖案 - 多頁面自動切換顯示

第五組：遠端遙控組 🎮

項目 內容
主要任務 紅外線遙控與機械控制
核心元件 紅外線接收器、伺服馬達、步進馬達
學習重點 紅外線解碼、馬達控制、平滑移動
最終目標 製作遙控通風窗/窗簾系統

功能說明： - 紅外線接收器解碼遙控器訊號 - 伺服馬達控制通風窗角度（0°-90°） - 步進馬達控制窗簾開合 - 預設位置快速切換

第六組：網路控制組 🌐

項目 內容
主要任務 物聯網連線與雲端通訊
核心元件 ESP-01 WiFi模組
學習重點 WiFi連線、MQTT協定、JSON資料格式
最終目標 手機即時監控溫室資料

功能說明： - ESP-01 連接 WiFi 網路 - 透過 MQTT 發送模擬感測器資料 - 發送到公開 Broker（broker.hivemq.com） - 手機使用 IoT MQTT Panel 即時查看

學習進度建議

第一階段：基礎認識（範例 1-2）

  • 認識元件與接線
  • 基本輸入輸出操作
  • 序列埠監視器使用

第二階段：功能實作（範例 3-4）

  • 感測器數值讀取與處理
  • 控制邏輯設計
  • 門檻值與狀態判斷

第三階段：系統整合（範例 5）

  • 完整功能整合
  • 安全保護機制
  • 狀態顯示與監控

第四階段：跨組整合（進階）

  • 組間資料交換
  • 系統整合測試
  • 完整溫室展示

注意事項

安全提醒

  • ⚠️ ESP-01 使用 3.3V，不可接 5V
  • ⚠️ 繼電器控制 AC 電源時務必注意安全
  • ⚠️ 馬達可能需要外接電源，注意電流限制

常見問題排除

  1. 程式上傳失敗 → 檢查 COM Port 選擇
  2. 感測器讀值異常 → 檢查接線與腳位定義
  3. WiFi 連不上 → 確認 2.4GHz、密碼正確
  4. MQTT 無法連線 → 檢查網路、Broker 位址

教學建議

  • 每組先獨立完成基礎範例
  • 確認各組都能成功後再進行整合
  • 整合時可先用序列埠模擬資料交換
  • 最後再進行完整的系統串接

延伸學習

完成本課程後，可以進一步學習： - 進階感測器：CO2、pH值、EC值感測 - 進階控制：PID控制、模糊控制 - 雲端平台：ThingSpeak、Blynk、自架伺服器 - 機器學習：環境預測、異常偵測 - 商業應用：實際溫室案例研究

本教材適用於 Arduino 入門至中階學習者 建議搭配實體元件進行操作練習
