一、什麼是 Vibe Coding？

"Fully giving in to the vibes, embracing exponentials, and forgetting that the code even exists."
— Andrej Karpathy, 2025 年 2 月

Vibe Coding（氛圍編程）是由 OpenAI 共同創辦人、前 Tesla AI 負責人 Andrej Karpathy 於 2025 年 2 月提出的概念。 這個詞已被 Collins Dictionary 選為 2025 年度詞彙。

核心概念

傳統編程 Vibe Coding
手動撰寫每一行程式碼 用自然語言描述需求，AI 生成程式碼
需要深入了解語法和框架 專注於「要做什麼」而非「怎麼做」
逐行除錯和修改 描述問題，讓 AI 修正
專業開發者專屬 非程式背景者也能建構應用

Karpathy 的實踐方式

Karpathy 使用 Cursor IDE 搭配 Anthropic 的 Claude 模型，透過對話甚至語音指令來建構專案（如 MenuGen）。他幾乎不碰鍵盤，完全讓 LLM 生成所有程式碼。

2025 年重大里程碑：
  • Y Combinator 2025 冬季梯次中，25% 的新創公司的程式碼有 95% 是 AI 生成的
  • GitHub 上約 30% 的新程式碼來自 Copilot 建議
  • Collins Dictionary 將「Vibe Coding」選為 2025 年度詞彙

三、IDE 類工具詳細比較

Cursor 熱門

官網：cursor.com

基於 VS Code 分支的 AI 原生 IDE，被 Karpathy 用於示範 Vibe Coding。

項目說明
AI 模型Claude 3.5/4, GPT-4, 自研模型
Context 長度200K tokens
核心功能Composer (多檔案編輯)、Tab 補全、Chat、.cursorrules 自訂規則
優勢控制精準、VS Code 生態相容、結構化指令支援
劣勢需手動添加 context、學習曲線較高

價格：

  • Free：2,000 次補全/月
  • Pro：$20/月 — 500 次快速請求
  • Business：$40/user/月 — 團隊功能

Windsurf 新星

官網：windsurf.com (原 Codeium)

主打自動化和速度的 AI IDE，Cascade 代理能自動理解整個程式庫。

項目說明
AI 模型自研 SWE-1.5 + Claude/GPT
Context 長度150K tokens
核心功能Cascade Agent、自動檔案選取、即時 UI 預覽、一鍵部署
優勢速度快 (30-40% 低延遲)、自動理解 codebase、UI 預覽
劣勢生態系統較新、Context 長度略短

價格：

  • Free：基本功能
  • Pro：$15/月 — 500 次快速請求 (比 Cursor 便宜 25%)
  • Teams：$30/user/月

VS Code + GitHub Copilot

官網：github.com/features/copilot

最穩定、最廣泛使用的 AI 程式助手，與 GitHub 深度整合。

項目說明
AI 模型OpenAI Codex / GPT-4
核心功能Inline 補全、Chat、Workspace Agent、PR 摘要
優勢穩定可靠、廣泛語言支援、GitHub 整合
劣勢Inline 補全不如 Cursor/Windsurf 聰明

價格：

  • Free：有限功能
  • Pro：$10/月 — 無限補全和對話 (最便宜)
  • Business：$19/user/月
  • Enterprise：$39/user/月

四、網頁應用建構工具比較

Lovable 最易上手

官網：lovable.dev

設計師友善的 AI 應用建構平台，結合自然語言與設計工具。

項目說明
定位No-code / Low-code 混合
技術棧React + Tailwind + shadcn/ui
後端支援Supabase (有限)
優勢UI 精美、學習曲線最低、適合 MVP
劣勢後端功能有限、複雜邏輯較難處理

價格：Free 基本功能 / Pro $39/月

Bolt.new 開源

官網：bolt.new

開源的全端應用建構器，支援本地和雲端 LLM。

項目說明
定位Prompt → Full Stack App
技術棧多框架支援 (React, Vue, Angular)
後端支援Supabase 內建
優勢開源透明、Diffs 增量更新快、可自架
劣勢企業支援有限

價格：Free / Open Source

v0 (Vercel) 前端專精

官網：v0.dev

Vercel 推出的 AI 元件生成器，專注高品質 React 元件。

項目說明
定位UI 元件生成器
技術棧React + Tailwind + shadcn/ui
後端支援無
優勢元件品質極高、程式碼乾淨、Next.js 完美整合
劣勢僅前端、無後端自動化

價格：Free 基本 / Pro $20/月

Replit Agent 全能環境

官網：replit.com

雲端完整開發環境，從編碼到部署一站完成。

項目說明
定位雲端 IDE + AI Agent
核心功能Autonomous Agent 3.0、內建 DB/Auth/Hosting
優勢全功能環境、從想法到部署一站完成
劣勢純雲端、無法整合本地開發環境

價格：Free / Core $25/月 / Teams $40/user/月

五、終端機/CLI 工具比較

Claude Code (Anthropic) 推理最強

官網：claude.ai

終端機為主的 AI 編程代理，以深度推理和多步驟任務見長。

項目說明

核心功能Terminal Agent、多檔案推理、本地環境整合

劣勢需熟悉終端機、無 GUI

價格：按使用量計費 $20-$100/月

Gemini CLI (Google)

Google 的終端機 AI 工具，與 GCP 深度整合。

項目說明

優勢Google 生態整合、多模態能力
劣勢相對較新、社群資源較少

九、限制與注意事項

重要研究發現

2025 年 7 月 METR 發表的研究指出：有經驗的開發者使用 AI 工具（如 Cursor、Claude）完成任務的時間反而多了 19%，儘管他們自認為快了 20%。

但對於新手開發者，使用 GitHub Copilot 等工具可提升 26% 的生產力。

Vibe Coding 的限制

限制 說明 建議
複雜邏輯處理 超過 90% 的自動生成應用無法正常運作 適合原型/簡單應用，複雜邏輯需人工介入
安全性風險 可能產生未被察覺的安全漏洞 務必進行安全審查，勿直接部署到生產環境
程式碼理解 開發者可能不理解 AI 生成的程式碼 保持學習，理解生成的程式碼邏輯
風格同質化 多數工具使用 Tailwind + shadcn，導致 UI 相似 需額外客製化設計
維護困難 「Vibe Coding 宿醉」— 接手 AI 生成的程式碼困難 建立文件、保持程式碼品質標準

適合 vs 不適合

適合使用 Vibe Coding 不建議使用 Vibe Coding
快速原型 / MVP 金融交易系統
週末 side project 醫療健康應用
內部工具 高安全性需求系統
學習和探索 大規模生產環境
靜態網站 / 部落格 需長期維護的企業軟體

十、入門建議

給完全初學者

  1. 從 Lovable 或 Bolt.new 開始 — 無需安裝，瀏覽器內操作
  2. 嘗試建立一個簡單的個人網站或 Todo App
  3. 觀察 AI 生成的程式碼，開始理解基本結構

給有程式基礎者

  1. 安裝 Cursor 或 Windsurf — 熟悉 AI 輔助 IDE
  2. 設定 .cursorrules 或專案規則，引導 AI 風格
  3. 練習用自然語言描述需求，觀察 AI 如何解讀

給資深開發者

  1. 嘗試 Claude Code — 體驗終端機內的深度推理
  2. 將 AI 融入現有工作流程，處理重複性任務
  3. 專注於 AI 不擅長的：架構設計、安全審查、程式碼品質

快速開始指令

# 安裝 Claude Code (需要 Node.js)
npm install -g @anthropic-ai/claude-code

# 在專案目錄執行
claude

# 或使用 Cursor (下載安裝後)
# 開啟專案，按 Cmd/Ctrl + K 開始對話
