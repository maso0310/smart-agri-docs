關於光達與雷達的差異

光達（LiDAR）和雷達（Radar）都是主動式遙測技術，透過發射電磁波並接收反射訊號來偵測目標。兩者在智慧農業、自動駕駛、地形測量等領域都有廣泛應用，但各有其特點與適用場景。

一、基本概念

LiDAR - 光達

LiDAR（Light Detection and Ranging，光學雷達）使用雷射光進行測距：

  • 發射雷射脈衝（通常為近紅外光）
  • 測量光線往返時間（Time of Flight, ToF）
  • 計算距離：距離 = (光速 × 時間) / 2
  • 透過掃描機構或多光束產生 3D 點雲

Radar - 雷達

Radar（Radio Detection and Ranging，無線電探測測距）使用無線電波進行偵測：

  • 發射微波或毫米波脈衝
  • 測量電波往返時間
  • 可測量目標的距離、速度、角度
  • 利用都卜勒效應偵測移動物體
核心差異：LiDAR 使用光波（波長：nm ~ μm 級），Radar 使用無線電波（波長：mm ~ cm 級）

四、優缺點分析

LiDAR 優勢

  • 高精度 3D 建模：產生密集點雲，精確描繪物體輪廓
  • 高角度解析度：可清晰區分相鄰物體
  • 直接測量距離：無需複雜演算法即可獲得精確距離
  • 細節豐富：可辨識物體形狀、邊緣
  • 不受光線影響：日夜均可工作

LiDAR 劣勢

  • 天候敏感：雨、霧、雪、沙塵會衰減訊號
  • 成本較高：尤其是高性能機械式
  • 無法直接測速：需多幀比對計算
  • 對透明物體困難：玻璃、水面反射特性不同

Radar 優勢

  • 全天候工作：雨、霧、雪、沙塵影響小
  • 直接測速：都卜勒效應可測移動目標速度
  • 成本低：技術成熟、量產規模大
  • 體積小巧：易於整合
  • 穿透能力：可穿透部分遮蔽物

Radar 劣勢

  • 解析度較低：難以精確描繪物體形狀
  • 點雲稀疏：資料密度遠低於 LiDAR
  • 多路徑干擾：金屬表面反射造成假目標
  • 分類困難：難以僅憑雷達區分物體類型

融合方式

  • 互補性：LiDAR 提供精確距離，Radar 提供速度，Camera 提供顏色

  • 全天候：不同天候條件下互相補充
  • 提升準確率：多源資訊交叉驗證

八、資料處理與分析

LiDAR 點雲處理

import numpy as np
import open3d as o3d

# 讀取點雲資料
pcd = o3d.io.read_point_cloud("farm_scan.pcd")
print(f"點數量: {len(pcd.points)}")

# 下採樣（減少點數）
pcd_down = pcd.voxel_down_sample(voxel_size=0.1)

# 移除離群點
pcd_clean, ind = pcd_down.remove_statistical_outlier(
    nb_neighbors=20,
    std_ratio=2.0
)

# 地面分割（使用 RANSAC）
plane_model, inliers = pcd_clean.segment_plane(
    distance_threshold=0.1,
    ransac_n=3,
    num_iterations=1000
)
ground = pcd_clean.select_by_index(inliers)
non_ground = pcd_clean.select_by_index(inliers, invert=True)

# 計算作物高度
ground_height = np.mean(np.asarray(ground.points)[:, 2])
crop_points = np.asarray(non_ground.points)
crop_heights = crop_points[:, 2] - ground_height
print(f"平均作物高度: {np.mean(crop_heights):.2f} m")
print(f"最大作物高度: {np.max(crop_heights):.2f} m")

# 視覺化
ground.paint_uniform_color([0.5, 0.3, 0])  # 褐色
non_ground.paint_uniform_color([0, 0.8, 0])  # 綠色
o3d.visualization.draw_geometries([ground, non_ground])

Radar 資料處理

import numpy as np
import matplotlib.pyplot as plt

class RadarProcessor:
    """毫米波雷達資料處理"""

    def __init__(self, num_chirps=128, num_samples=256):
        self.num_chirps = num_chirps
        self.num_samples = num_samples

    def range_fft(self, raw_data):
        """距離維 FFT"""
        return np.fft.fft(raw_data, axis=1)

    def doppler_fft(self, range_data):
        """都卜勒維 FFT（測速度）"""
        return np.fft.fftshift(
            np.fft.fft(range_data, axis=0),
            axes=0
        )

    def cfar_detection(self, rd_map, guard_cells=2, train_cells=4, threshold=10):
        """
        CFAR 目標偵測
        Constant False Alarm Rate
        """
        detections = []
        rows, cols = rd_map.shape

        for i in range(train_cells + guard_cells, rows - train_cells - guard_cells):
            for j in range(train_cells + guard_cells, cols - train_cells - guard_cells):
                # 計算訓練區平均值
                train_sum = 0
                train_count = 0
                for di in range(-train_cells - guard_cells, train_cells + guard_cells + 1):
                    for dj in range(-train_cells - guard_cells, train_cells + guard_cells + 1):
                        if abs(di) > guard_cells or abs(dj) > guard_cells:
                            train_sum += rd_map[i + di, j + dj]
                            train_count += 1

                noise_level = train_sum / train_count

                if rd_map[i, j] > noise_level * threshold:
                    detections.append({
                        'range_idx': j,
                        'doppler_idx': i,
                        'amplitude': rd_map[i, j]
                    })

        return detections

LiDAR + Radar 融合範例

import numpy as np

class SensorFusion:
    """簡單的 LiDAR-Radar 融合"""

    def __init__(self):
        # 感測器外參（相對位置）
        self.lidar_to_vehicle = np.eye(4)
        self.radar_to_vehicle = np.eye(4)

    def associate_detections(self, lidar_objects, radar_objects, max_distance=2.0):
        """
        關聯 LiDAR 和 Radar 偵測結果
        使用最近鄰匹配
        """
        associations = []

        for lid_obj in lidar_objects:
            lid_pos = np.array(lid_obj['position'])
            min_dist = float('inf')
            best_match = None

            for rad_obj in radar_objects:
                rad_pos = np.array(rad_obj['position'])
                dist = np.linalg.norm(lid_pos[:2] - rad_pos[:2])  # 2D 距離

                if dist < min_dist and dist < max_distance:
                    min_dist = dist
                    best_match = rad_obj

            if best_match:
                # 融合：LiDAR 提供位置，Radar 提供速度
                fused = {
                    'position': lid_obj['position'],  # 使用 LiDAR 位置（更精確）
                    'velocity': best_match.get('velocity', 0),  # 使用 Radar 速度
                    'size': lid_obj.get('size'),  # 使用 LiDAR 尺寸
                    'confidence': (lid_obj['confidence'] + best_match['confidence']) / 2
                }
                associations.append(fused)
            else:
                # 只有 LiDAR 偵測到
                associations.append(lid_obj)

        return associations

十、選擇建議

選 LiDAR 的情況

  • 需要精確的 3D 環境建模
  • 作物結構、高度測量
  • 複雜環境的障礙物偵測
  • 精準定位與導航
  • 主要在良好天候下作業

選 Radar 的情況

  • 需要全天候作業能力
  • 預算有限
  • 主要偵測移動物體
  • 簡單的距離偵測需求
  • 惡劣環境（雨、霧、灰塵）

最佳方案：融合系統

對於高要求的自動駕駛農機，建議採用多感測器融合：

  • LiDAR：提供精確 3D 感知
  • Radar：全天候偵測與測速
  • Camera：物體分類與細節識別
  • GNSS/RTK：絕對定位
  • IMU：姿態與運動估計
