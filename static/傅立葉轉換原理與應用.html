📊 傅立葉轉換原理與應用

📖 什麼是傅立葉轉換（Fourier Transform）？

傅立葉轉換是一種數學工具，能將時域（或空間域）的訊號轉換到頻域，讓我們看到訊號中包含哪些「頻率成分」。

白話文：就像把一首複雜的音樂，分解成不同音高（頻率）的單音一樣！

在影像處理中，傅立葉轉換可以：

  • 🔍 分析影像的頻率特徵（紋理、邊緣、週期性）
  • 🎚️ 進行頻域濾波（高通、低通、帶通濾波）
  • 📐 偵測週期性結構（作物行、紋理圖案）
  • 🖼️ 影像壓縮與去雜訊

💡 為什麼需要傅立葉轉換？

想像你聽到一段複雜的音樂：

時域觀點（原始訊號）：
  • 看到音波隨時間變化的波形
  • 很難分辨包含哪些樂器
  • 難以理解音樂的結構
頻域觀點（傅立葉轉換後）：
  • 看到每個頻率的強度（頻譜）
  • 清楚知道有低音鼓（低頻）、吉他（中頻）、鈸（高頻）
  • 容易分析和處理特定頻率

在影像中：
  • 低頻 = 平滑區域、整體結構（天空、土壤背景）
  • 高頻 = 邊緣、細節、紋理（葉脈、作物邊界）

🔍 傅立葉轉換的核心概念

1️⃣ 時域 vs. 頻域

觀點 時域（空間域） 頻域
描述 訊號隨時間/位置的變化 訊號包含的頻率成分
影像中 像素值的分布（亮度） 頻率成分的強度（頻譜）
橫軸 時間 t 或位置 x 頻率 f 或波數 k
看到什麼 「何時發生」 「發生多快」
適合分析 訊號的時序、位置 週期性、頻率特徵

2️⃣ 傅立葉轉換的數學原理

一維傅立葉轉換（1D Fourier Transform）

適用：音訊訊號、一維時間序列

F(ω) = ∫-∞∞ f(t) · e-iωt dt

離散傅立葉轉換（DFT）：

F(k) = Σn=0N-1 f(n) · e-i2πkn/N

其中：f(t) = 原始訊號，F(ω) = 頻域表示，ω = 角頻率，i = 虛數單位

二維傅立葉轉換（2D Fourier Transform）

適用：影像處理（將 2D 影像轉換到頻域）

F(u, v) = ∫∫ f(x, y) · e-i2π(ux+vy) dx dy

離散版本（2D DFT）：

F(u, v) = Σx=0M-1 Σy=0N-1 f(x, y) · e-i2π(ux/M + vy/N)

其中：f(x, y) = 影像像素值，F(u, v) = 頻譜，(u, v) = 頻率座標

🤔 不懂數學也能理解！

傅立葉轉換的本質：

  • 把複雜的訊號，拆解成「許多不同頻率的正弦波」的組合
  • e-iωt 其實就是一個「旋轉的向量」（尤拉公式：eiθ = cos(θ) + i·sin(θ)）
  • 積分/求和：計算原始訊號與每個頻率正弦波的「相似度」
  • 結果：告訴你每個頻率成分有「多強」

⚡ 快速傅立葉轉換（FFT）

什麼是 FFT？

FFT（Fast Fourier Transform）是一種演算法，用來快速計算 DFT。

方法 計算複雜度 N=1024 需要的運算次數
DFT（直接計算） O(N²) ~1,048,576 次
FFT（快速演算法） O(N log N) ~10,240 次
速度提升 約 100 倍！

結論：實務上我們都用 FFT，而不是直接算 DFT！

🖼️ 影像的傅立葉轉換

頻譜圖的解讀

典型的頻譜圖特徵

中心 = 低頻（DC 分量）

  • 代表影像的平均亮度、整體色調
  • 通常是頻譜中最亮的點

遠離中心 = 高頻

  • 代表邊緣、紋理、細節
  • 變化越快的部分，頻率越高

方向性

  • 水平線的影像 → 頻譜中出現垂直的亮線
  • 垂直線的影像 → 頻譜中出現水平的亮線
  • 原因：正弦波與影像的內積

🌾 智慧農業應用實例

🌱 1. 作物行週期性偵測

問題：無人機影像中偵測規律排列的作物行。

方法：2D FFT 找出空間頻率的峰值。

應用：自動計算行距、種植密度。

🍃 2. 葉片紋理分析

問題：區分健康葉片與病害葉片的紋理。

方法：分析頻譜特徵，健康葉片紋理更規律。

應用：早期病害檢測。

📏 3. 影像去雜訊

問題：感測器雜訊、高頻干擾。

方法：頻域低通濾波，保留低頻去除高頻雜訊。

應用：影像品質提升。

🔍 4. 邊緣強化

問題：影像對比度低，邊緣不清楚。

方法：頻域高通濾波，增強高頻成分。

應用：葉片輪廓提取、果實分割。

🌾 5. 土壤質地分析

問題：分析土壤表面的粗糙度。

方法：頻譜能量分布，粗糙土壤高頻能量高。

應用：土壤分類、耕作品質評估。

📊 6. 雜草偵測

問題：區分作物與雜草的空間分布模式。

方法：作物有規律週期，雜草隨機分布。

應用：精準除草、變量噴灑。

💻 Python 實作範例

範例 1：基本的 2D FFT 操作

import numpy as np
import cv2
import matplotlib.pyplot as plt

# 讀取影像並轉灰階
image = cv2.imread('crop_field.jpg', cv2.IMREAD_GRAYSCALE)

# === 步驟 1：執行 2D FFT ===
# np.fft.fft2() 計算 2D 傅立葉轉換
fft = np.fft.fft2(image)

# === 步驟 2：將零頻率移到中心 ===
# 預設零頻率在四個角，不方便觀察
fft_shifted = np.fft.fftshift(fft)

# === 步驟 3：計算幅度譜（用於視覺化）===
# 取絕對值（去除相位），再取 log 增強對比
magnitude_spectrum = 20 * np.log(np.abs(fft_shifted) + 1)

# === 視覺化 ===
plt.figure(figsize=(12, 6))

plt.subplot(1, 2, 1)
plt.imshow(image, cmap='gray')
plt.title('原始影像（空間域）')
plt.axis('off')

plt.subplot(1, 2, 2)
plt.imshow(magnitude_spectrum, cmap='gray')
plt.title('幅度譜（頻域）')
plt.axis('off')

plt.tight_layout()
plt.show()

# === 反轉換回空間域 ===
# 先移回零頻率位置
fft_ishifted = np.fft.ifftshift(fft_shifted)
# 執行反傅立葉轉換
image_back = np.fft.ifft2(fft_ishifted)
# 取實部（去除微小的虛部誤差）
image_back = np.abs(image_back)

print(f"原始影像形狀：{image.shape}")
print(f"FFT 形狀：{fft.shape}")
print(f"還原誤差：{np.mean(np.abs(image - image_back)):.6f}")

範例 2：頻域低通濾波（去雜訊）

import numpy as np
import cv2
import matplotlib.pyplot as plt

def lowpass_filter(image, radius=30):
    """
    頻域低通濾波：保留低頻，去除高頻雜訊

    參數：
        image: 輸入影像（灰階）
        radius: 截止半徑（像素），越小保留越少高頻
    """
    # 執行 FFT
    fft = np.fft.fft2(image)
    fft_shifted = np.fft.fftshift(fft)

    # 建立圓形遮罩（低通濾波器）
    rows, cols = image.shape
    crow, ccol = rows // 2, cols // 2  # 中心點

    # 創建遮罩（中心為 1，外圍為 0）
    mask = np.zeros((rows, cols), np.uint8)
    cv2.circle(mask, (ccol, crow), radius, 1, -1)

    # 應用遮罩（只保留低頻）
    fft_filtered = fft_shifted * mask

    # 反轉換回空間域
    fft_ishifted = np.fft.ifftshift(fft_filtered)
    image_filtered = np.fft.ifft2(fft_ishifted)
    image_filtered = np.abs(image_filtered)

    return image_filtered, fft_filtered

# 使用範例
image = cv2.imread('noisy_image.jpg', cv2.IMREAD_GRAYSCALE)

# 測試不同的截止半徑
radii = [10, 30, 60]
results = []

for r in radii:
    filtered, fft_filtered = lowpass_filter(image, radius=r)
    results.append((r, filtered, fft_filtered))

# 視覺化
fig, axes = plt.subplots(2, 4, figsize=(16, 8))

# 原始影像
axes[0, 0].imshow(image, cmap='gray')
axes[0, 0].set_title('原始影像')
axes[0, 0].axis('off')

# 原始頻譜
fft_original = np.fft.fftshift(np.fft.fft2(image))
axes[1, 0].imshow(20*np.log(np.abs(fft_original)+1), cmap='gray')
axes[1, 0].set_title('原始頻譜')
axes[1, 0].axis('off')

# 顯示不同半徑的結果
for i, (r, filtered, fft_filtered) in enumerate(results, 1):
    axes[0, i].imshow(filtered, cmap='gray')
    axes[0, i].set_title(f'低通濾波 (r={r})')
    axes[0, i].axis('off')

    axes[1, i].imshow(20*np.log(np.abs(fft_filtered)+1), cmap='gray')
    axes[1, i].set_title(f'濾波後頻譜 (r={r})')
    axes[1, i].axis('off')

plt.tight_layout()
plt.show()

範例 3：頻域高通濾波（邊緣強化）

import numpy as np
import cv2

def highpass_filter(image, radius=30):
    """
    頻域高通濾波：保留高頻，去除低頻（邊緣強化）
    """
    fft = np.fft.fft2(image)
    fft_shifted = np.fft.fftshift(fft)

    rows, cols = image.shape
    crow, ccol = rows // 2, cols // 2

    # 創建遮罩（中心為 0，外圍為 1）
    mask = np.ones((rows, cols), np.uint8)
    cv2.circle(mask, (ccol, crow), radius, 0, -1)

    # 應用遮罩
    fft_filtered = fft_shifted * mask

    # 反轉換
    fft_ishifted = np.fft.ifftshift(fft_filtered)
    image_filtered = np.fft.ifft2(fft_ishifted)
    image_filtered = np.abs(image_filtered)

    return image_filtered

# 使用範例
image = cv2.imread('leaf.jpg', cv2.IMREAD_GRAYSCALE)
edges = highpass_filter(image, radius=20)

# 正規化到 0-255
edges = cv2.normalize(edges, None, 0, 255, cv2.NORM_MINMAX)
edges = edges.astype(np.uint8)

# 顯示結果
cv2.imshow('Original', image)
cv2.imshow('High-pass Filtered (Edges)', edges)
cv2.waitKey(0)
cv2.destroyAllWindows()

範例 4：偵測作物行週期性

import numpy as np
import cv2
import matplotlib.pyplot as plt
from scipy.signal import find_peaks

def detect_crop_row_spacing(image):
    """
    利用 FFT 偵測作物行的週期性（行距）
    """
    # 轉灰階
    if len(image.shape) == 3:
        gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
    else:
        gray = image

    # 執行 FFT
    fft = np.fft.fft2(gray)
    fft_shifted = np.fft.fftshift(fft)
    magnitude = np.abs(fft_shifted)

    # 取中心水平線的頻譜（假設作物行是垂直的）
    rows, cols = magnitude.shape
    center_row = magnitude[rows//2, :]

    # 找峰值（忽略 DC 分量）
    center_col = cols // 2
    # 只看右半邊（對稱的）
    right_half = center_row[center_col+10:]  # 跳過 DC 附近

    # 找峰值
    peaks, properties = find_peaks(right_half, height=np.max(right_half)*0.1)

    if len(peaks) == 0:
        print("未偵測到明顯的週期性")
        return None

    # 第一個峰值對應最主要的空間頻率
    main_peak = peaks[0]

    # 計算對應的行距（像素）
    # 空間頻率 = peak / (cols/2)
    # 週期（行距）= 1 / 空間頻率
    spatial_freq = main_peak / (cols / 2)
    row_spacing = 1.0 / spatial_freq if spatial_freq > 0 else 0

    print(f"偵測到的主要週期：{row_spacing:.1f} 像素")

    # 視覺化
    fig, axes = plt.subplots(1, 3, figsize=(15, 5))

    # 原始影像
    axes[0].imshow(gray, cmap='gray')
    axes[0].set_title('原始影像')
    axes[0].axis('off')

    # 頻譜
    axes[1].imshow(20*np.log(magnitude+1), cmap='gray')
    axes[1].set_title('2D 頻譜')
    axes[1].axis('off')

    # 中心線頻譜與峰值
    axes[2].plot(right_half)
    axes[2].plot(peaks, right_half[peaks], 'rx', markersize=10)
    axes[2].set_title('水平方向頻譜（偵測垂直週期）')
    axes[2].set_xlabel('頻率（像素）')
    axes[2].set_ylabel('幅度')
    axes[2].grid(True)

    plt.tight_layout()
    plt.show()

    return row_spacing

# 使用範例
image = cv2.imread('crop_rows.jpg')
spacing = detect_crop_row_spacing(image)

if spacing:
    print(f"作物行距：約 {spacing:.1f} 像素")

⚙️ 參數與技巧

常用函數與參數

函數 用途 備註
np.fft.fft2(image) 2D 快速傅立葉轉換 輸入灰階影像，輸出複數矩陣
np.fft.ifft2(fft) 2D 反傅立葉轉換 從頻域轉回空間域
np.fft.fftshift(fft) 將零頻率移到中心 方便視覺化和濾波操作
np.fft.ifftshift(fft) 反向移動零頻率 反轉換前要先移回去
np.abs(fft) 計算幅度（magnitude） 視覺化頻譜用
np.angle(fft) 計算相位（phase） 通常用於特殊分析
cv2.dft() OpenCV 的 DFT 需要特殊格式，一般用 NumPy

最佳實踐技巧

✅ 提升效果的技巧

  1. 前處理：
    • 視窗函數（Hamming, Hanning）減少邊緣效應
    • 去均值（減去平均值）突出變化
    • 正規化到 [0, 1]
  2. 視覺化：
    • 使用對數尺度：20*np.log(magnitude+1)
    • 必須 +1 避免 log(0)
    • fftshift 將低頻移到中心方便觀察
  3. 濾波器設計：
    • 理想濾波器：硬截止（可能產生振鈴效應）
    • 巴特沃斯濾波器：平滑過渡（推薦）
    • 高斯濾波器：最平滑（最常用）
  4. 效能優化：
    • 影像大小最好是 2 的冪次（256, 512, 1024...）
    • 不符合時可以用 padding 補零
    • 使用 scipy.fftpack 可能更快

📊 頻域濾波器類型

常見濾波器比較

濾波器 保留頻率 效果 應用
低通濾波（LPF） 低頻 平滑、去雜訊 去除感測器雜訊
高通濾波（HPF） 高頻 強化邊緣、細節 邊緣偵測、銳化
帶通濾波（BPF） 特定頻率範圍 保留特定紋理 週期性特徵提取
帶拒濾波（BSF） 除了特定頻率 去除特定干擾 去除週期性雜訊

⚠️ 傅立葉轉換的限制

❌ 使用限制

  • 無時頻資訊：只知道「有哪些頻率」，不知道「何時發生」（用小波轉換解決）
  • 邊緣效應：影像邊界會產生人工高頻（用視窗函數緩解）
  • 計算量大：即使 FFT 也很耗資源（尤其大圖或 3D 資料）
  • 相位難解釋：相位譜通常很混亂，難以直觀理解
  • 非平穩訊號：訊號特性隨時間變化時，FFT 效果不佳

替代與補充技術

技術 優勢 適用場景
小波轉換（Wavelet） 同時有時頻資訊 非平穩訊號、影像壓縮（JPEG 2000）
離散餘弦轉換（DCT） 只用實數、壓縮效果好 JPEG 壓縮、影音編碼
Gabor 濾波器 頻率 + 方向 + 位置 紋理分析、特徵提取
短時傅立葉（STFT） 局部時頻分析 語音處理、動態訊號

🎯 總結

傅立葉轉換的核心價值：
  • ✅ 從「空間/時間域」切換到「頻域」觀點
  • ✅ 容易分析週期性、紋理、頻率特徵
  • ✅ 頻域濾波比空間域更直觀、更有效
  • ✅ 許多演算法的理論基礎（卷積定理、採樣定理）
智慧農業典型應用：
  1. 作物行偵測：利用空間週期性
  2. 紋理分析：健康 vs. 病害葉片區分
  3. 影像增強：頻域濾波去雜訊、銳化
  4. 品質檢測：頻譜特徵分類
何時使用傅立葉轉換：
  • 需要分析週期性或頻率特徵
  • 進行頻域濾波（比空間域更彈性）
  • 偵測規律性結構（網格、條紋）
  • 影像壓縮或編碼
何時不適用：
  • 需要保留空間資訊（改用 Gabor 或小波）
  • 處理非平穩訊號（改用 STFT 或小波）
  • 只需要簡單空間濾波（用卷積更快）

📚 延伸學習資源

  • 進階主題：
    • 卷積定理（Convolution Theorem）：空間域卷積 = 頻域相乘
    • 採樣定理（Nyquist-Shannon）：防止混疊（aliasing）
    • 視窗函數（Windowing）：減少頻譜洩漏
    • 功率譜密度（PSD）：能量分布分析
  • 相關技術：
    • 離散餘弦轉換（DCT）
    • 小波轉換（Wavelet Transform）
    • Hilbert-Huang 轉換（HHT）
    • Z 轉換（數位訊號處理）
  • Python 套件：
    • numpy.fft：基本 FFT 操作
    • scipy.fftpack：更多選項
    • scipy.signal：訊號處理工具
    • pywt：小波轉換
