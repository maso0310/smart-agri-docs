關於繼電器模組

前言：為什麼需要繼電器？

Arduino 的輸出腳位只能提供 5V / 40mA 的微小電力，這對於控制 LED 燈已經足夠，但如果想控制：

  • 110V 的電燈或風扇
  • 12V 的抽水馬達
  • 5V 但需要大電流的霧化器

Arduino 就無法直接驅動了。這時候就需要繼電器（Relay）來當作「電子開關」！

一、繼電器是什麼？

一句話解釋

繼電器就是一個「用小電流控制大電流」的電子開關。

生活比喻

想像繼電器是一個「遙控門鎖」：

┌─────────────────────────────────────────────────────┐
│                                                     │
│  你（Arduino）  ──按遙控器──→  門鎖  ──開門──→  大門  │
│   （小力氣）      （小電流）  （繼電器） （大電流） （負載）│
│                                                     │
└─────────────────────────────────────────────────────┘

你不需要親自去推開沉重的大門，
只要按一下遙控器（送出小電流），
門鎖（繼電器）就會幫你開門（接通大電流）。

二、繼電器的工作原理

內部結構

繼電器內部構造：

        控制端（Arduino 接這邊）
              │
              ▼
         ┌─────────┐
         │  線圈   │ ← 通電時產生磁力
         │  ████   │
         └────┬────┘
              │ 磁力吸引
              ▼
         ┌─────────┐
    NC ──┤  彈簧片  ├── COM（共用端）
         │    ↕    │
    NO ──┤         │
         └─────────┘
              │
              ▼
        負載端（馬達、燈泡接這邊）

工作流程

【未通電狀態】
                    彈簧片在上方
線圈 ○              ┌───●───┐ NC（常閉）
（無磁力）          │       │
                   │   ○   │ COM（共用）
                   │       │
                   └───○───┘ NO（常開）

結果：COM 與 NC 接通，COM 與 NO 斷開

【通電狀態】
                    彈簧片被吸到下方
線圈 ●              ┌───○───┐ NC（常閉）
（產生磁力）        │       │
                   │   ●   │ COM（共用）
                   │   │   │
                   └───●───┘ NO（常開）

結果：COM 與 NO 接通，COM 與 NC 斷開

重要名詞

名詞 英文 說明
COM Common 共用端，負載的一端接這裡
NO Normally Open 常開端，平時斷開，通電後接通
NC Normally Closed 常閉端，平時接通，通電後斷開

三、繼電器模組介紹

為什麼用模組而不是單顆繼電器？

單顆繼電器需要額外的：
- 驅動電晶體（Arduino 無法直接驅動線圈）
- 保護二極體（防止反向電壓損壞 Arduino）
- 指示 LED（顯示狀態）

繼電器模組把這些都整合好了，接線更簡單！

常見繼電器模組外觀

單路繼電器模組：

     高壓側（危險！）              低壓側（安全）
    ┌─────────────────────────────────────────┐
    │                                         │
    │   NC  COM  NO              VCC GND IN   │
    │    ○   ○   ○                ○   ○   ○   │
    │    │   │   │                │   │   │   │
    │  ┌─┴───┴───┴─┐            ┌─┴───┴───┴─┐ │
    │  │ 接負載    │            │ 接Arduino │ │
    │  │(馬達/燈泡)│            │           │ │
    │  └───────────┘            └───────────┘ │
    │                                         │
    │   [====繼電器====]    ●LED    [電路板]  │
    │                      狀態燈              │

模組腳位說明

腳位 說明 接線
VCC 電源正極 接 Arduino 5V
GND 電源負極 接 Arduino GND
IN 控制訊號輸入 接 Arduino 數位腳位
COM 共用端 接負載的一端
NO 常開端 接電源（通電時接通）
NC 常閉端 接電源（斷電時接通）

四、高電平觸發 vs 低電平觸發

繼電器模組有兩種觸發方式，購買前一定要確認！

高電平觸發（High Level Trigger）

控制訊號：HIGH (5V) → 繼電器動作（吸合）
控制訊號：LOW  (0V) → 繼電器不動作（釋放）

程式邏輯：
digitalWrite(RELAY_PIN, HIGH);  // 繼電器 ON
digitalWrite(RELAY_PIN, LOW);   // 繼電器 OFF

低電平觸發（Low Level Trigger）

控制訊號：LOW  (0V) → 繼電器動作（吸合）
控制訊號：HIGH (5V) → 繼電器不動作（釋放）

程式邏輯：
digitalWrite(RELAY_PIN, LOW);   // 繼電器 ON
digitalWrite(RELAY_PIN, HIGH);  // 繼電器 OFF

如何判斷模組類型？

方法 1：看模組標示
┌─────────────────────┐
│ High/Low Level      │ ← 有些模組會標示
│ Trigger: High       │
└─────────────────────┘

方法 2：看電路板跳線帽
┌─────────────────────┐
│  [H] [L]            │ ← 有跳線帽可切換
│   ●───○             │    ● 位置 = 目前模式
└─────────────────────┘

方法 3：實際測試
1. 接好 VCC、GND
2. IN 腳接 5V → LED 亮 = 高電平觸發
3. IN 腳接 GND → LED 亮 = 低電平觸發

比較表

特性 高電平觸發 低電平觸發
觸發電壓 HIGH (5V) LOW (0V)
Arduino 開機時 預設 LOW，繼電器關閉 預設 LOW，繼電器開啟！
程式直覺性 HIGH=ON，較直覺 LOW=ON，較不直覺
抗干擾能力 較弱 較強
常見程度 較少 較常見

低電平觸發的開機問題

⚠️ 重要提醒：

低電平觸發模組在 Arduino 開機時，
腳位預設為 LOW，會導致繼電器短暫啟動！

解決方法：
1. 在 setup() 最開始就設定腳位為 HIGH
2. 或使用上拉電阻

void setup() {
  pinMode(RELAY_PIN, OUTPUT);
  digitalWrite(RELAY_PIN, HIGH);  // 先關閉繼電器！
}

六、Arduino 程式範例

範例 1：基本開關控制（高電平觸發）

/*
 * 繼電器基本控制 - 高電平觸發版
 * 每 2 秒切換一次繼電器狀態
 */

const int RELAY_PIN = 7;  // 繼電器接在 D7

void setup() {
  pinMode(RELAY_PIN, OUTPUT);
  digitalWrite(RELAY_PIN, LOW);  // 初始狀態：關閉

  Serial.begin(9600);
  Serial.println("繼電器控制測試（高電平觸發）");
}

void loop() {
  // 開啟繼電器
  digitalWrite(RELAY_PIN, HIGH);
  Serial.println("繼電器：ON");
  delay(2000);

  // 關閉繼電器
  digitalWrite(RELAY_PIN, LOW);
  Serial.println("繼電器：OFF");
  delay(2000);
}

範例 2：基本開關控制（低電平觸發）

/*
 * 繼電器基本控制 - 低電平觸發版
 * 注意：LOW = ON, HIGH = OFF
 */

const int RELAY_PIN = 7;

// 定義方便閱讀的常數
#define RELAY_ON  LOW
#define RELAY_OFF HIGH

void setup() {
  pinMode(RELAY_PIN, OUTPUT);
  digitalWrite(RELAY_PIN, RELAY_OFF);  // 重要：先關閉！

  Serial.begin(9600);
  Serial.println("繼電器控制測試（低電平觸發）");
}

void loop() {
  digitalWrite(RELAY_PIN, RELAY_ON);
  Serial.println("繼電器：ON");
  delay(2000);

  digitalWrite(RELAY_PIN, RELAY_OFF);
  Serial.println("繼電器：OFF");
  delay(2000);
}

範例 3：按鈕控制繼電器

/*
 * 使用按鈕切換繼電器狀態
 * 按一下開，再按一下關
 */

const int RELAY_PIN = 7;
const int BUTTON_PIN = 2;

bool relayState = false;
bool lastButtonState = HIGH;

void setup() {
  pinMode(RELAY_PIN, OUTPUT);
  pinMode(BUTTON_PIN, INPUT_PULLUP);  // 使用內部上拉電阻

  digitalWrite(RELAY_PIN, LOW);

  Serial.begin(9600);
  Serial.println("按鈕控制繼電器");
}

void loop() {
  bool currentButtonState = digitalRead(BUTTON_PIN);

  // 偵測按鈕按下（從 HIGH 變成 LOW）
  if (lastButtonState == HIGH && currentButtonState == LOW) {
    delay(50);  // 消除彈跳

    // 切換繼電器狀態
    relayState = !relayState;
    digitalWrite(RELAY_PIN, relayState ? HIGH : LOW);

    Serial.print("繼電器狀態：");
    Serial.println(relayState ? "ON" : "OFF");
  }

  lastButtonState = currentButtonState;
}

範例 4：溫度自動控制風扇

/*
 * 溫度超過門檻時自動開啟風扇
 * 使用 DHT11 感測器 + 繼電器控制風扇
 */

#include <DHT.h>

const int DHT_PIN = 2;
const int RELAY_PIN = 7;
const float TEMP_THRESHOLD = 28.0;  // 溫度門檻（攝氏）

DHT dht(DHT_PIN, DHT11);

void setup() {
  pinMode(RELAY_PIN, OUTPUT);
  digitalWrite(RELAY_PIN, LOW);

  dht.begin();
  Serial.begin(9600);
  Serial.println("溫度自動控制風扇");
}

void loop() {
  float temperature = dht.readTemperature();

  if (isnan(temperature)) {
    Serial.println("讀取 DHT11 失敗！");
    delay(2000);
    return;
  }

  Serial.print("溫度：");
  Serial.print(temperature);
  Serial.print("°C → ");

  if (temperature > TEMP_THRESHOLD) {
    digitalWrite(RELAY_PIN, HIGH);
    Serial.println("風扇 ON");
  } else {
    digitalWrite(RELAY_PIN, LOW);
    Serial.println("風扇 OFF");
  }

  delay(2000);
}

範例 5：帶有遲滯控制（防止頻繁切換）

/*
 * 遲滯控制（Hysteresis）
 * 避免溫度在門檻附近時繼電器頻繁開關
 *
 * 開啟門檻：28°C
 * 關閉門檻：26°C
 *
 * 溫度曲線：
 *           ON ──────────────┐
 *                            │
 *     28°C  ─ ─ ─ ─ ─ ─ ─ ─ ┼ ─ ─ 開啟點
 *                            │
 *     27°C        (不動作區) │
 *                            │
 *     26°C  ─ ─ ─ ─ ─ ─ ─ ─ ┼ ─ ─ 關閉點
 *                            │
 *          OFF ──────────────┘
 */

#include <DHT.h>

const int DHT_PIN = 2;
const int RELAY_PIN = 7;

const float TEMP_ON = 28.0;   // 高於此溫度開啟
const float TEMP_OFF = 26.0;  // 低於此溫度關閉

DHT dht(DHT_PIN, DHT11);
bool fanState = false;

void setup() {
  pinMode(RELAY_PIN, OUTPUT);
  digitalWrite(RELAY_PIN, LOW);

  dht.begin();
  Serial.begin(9600);
  Serial.println("遲滯溫度控制");
}

void loop() {
  float temperature = dht.readTemperature();

  if (isnan(temperature)) {
    delay(2000);
    return;
  }

  // 遲滯控制邏輯
  if (temperature >= TEMP_ON && !fanState) {
    fanState = true;
    digitalWrite(RELAY_PIN, HIGH);
    Serial.print(temperature);
    Serial.println("°C - 超過上限，開啟風扇");
  }
  else if (temperature <= TEMP_OFF && fanState) {
    fanState = false;
    digitalWrite(RELAY_PIN, LOW);
    Serial.print(temperature);
    Serial.println("°C - 低於下限，關閉風扇");
  }
  else {
    Serial.print(temperature);
    Serial.print("°C - 維持狀態：");
    Serial.println(fanState ? "ON" : "OFF");
  }

  delay(2000);
}

IN2 → Arduino D5
IN3 → Arduino D6
IN4 → Arduino D7

多路繼電器程式範例

/*
 * 4 路繼電器依序控制
 */

const int RELAY_PINS[] = {4, 5, 6, 7};
const int NUM_RELAYS = 4;

void setup() {
  for (int i = 0; i < NUM_RELAYS; i++) {
    pinMode(RELAY_PINS[i], OUTPUT);
    digitalWrite(RELAY_PINS[i], LOW);
  }

  Serial.begin(9600);
  Serial.println("4 路繼電器控制");
}

void loop() {
  // 依序開啟
  for (int i = 0; i < NUM_RELAYS; i++) {
    digitalWrite(RELAY_PINS[i], HIGH);
    Serial.print("繼電器 ");
    Serial.print(i + 1);
    Serial.println(" ON");
    delay(500);
  }

  delay(1000);

  // 依序關閉
  for (int i = 0; i < NUM_RELAYS; i++) {
    digitalWrite(RELAY_PINS[i], LOW);
    Serial.print("繼電器 ");
    Serial.print(i + 1);
    Serial.println(" OFF");
    delay(500);
  }

  delay(1000);
}

八、繼電器規格解讀

常見規格標示

繼電器本體標示解讀：

┌─────────────────────────┐
│                         │
│    SRD-05VDC-SL-C       │
│                         │
│    10A 250VAC           │
│    10A 30VDC            │
│                         │
└─────────────────────────┘

SRD = 廠牌型號
05VDC = 線圈電壓 5V DC
SL = 單組常開常閉
C = 有常閉接點

10A 250VAC = 交流最大 10A / 250V
10A 30VDC = 直流最大 10A / 30V

規格選擇要點

參數 說明 建議
線圈電壓 驅動繼電器的電壓 Arduino 用選 5V
接點容量 能承受的最大負載 選比實際負載大 20% 以上
接點形式 NO/NC/COM 組合 一般用 1C（單刀雙擲）

負載電流計算

計算公式：

電流 (A) = 功率 (W) ÷ 電壓 (V)

範例：
- 60W 燈泡 / 110V = 0.55A ✓ 10A 繼電器 OK
- 1500W 電暖器 / 110V = 13.6A ✗ 10A 繼電器不夠！

安全建議：
- 實際負載不要超過繼電器額定的 80%
- 10A 繼電器建議控制 8A 以下負載

九、安全注意事項

危險警告

⚠️ 高壓電危險 ⚠️

1. 110V/220V 市電可能致命！
2. 沒有電工經驗請勿操作高壓電路
3. 操作前務必斷電
4. 使用絕緣工具
5. 高壓側和低壓側要確實隔離

常見安全問題

問題 原因 解決方法
繼電器發熱 負載過大 更換更大容量繼電器
接點燒蝕 頻繁開關或超載 減少開關次數、加裝滅弧電路
Arduino 重啟 繼電器切換時產生雜訊 加裝退耦電容、分開電源
干擾其他電路 電磁干擾 繼電器遠離敏感元件

保護措施

建議的保護電路：

1. 退耦電容（穩定電源）
   VCC ──┬── 繼電器模組 VCC
         │
        ═╧═ 100μF 電解電容
         │
   GND ──┴── 繼電器模組 GND

2. 獨立電源供應（大負載時）

   USB        Arduino        繼電器模組
    │            │               │
    └──→ 5V ────┤               │
                 │        獨立 5V 電源
                 │               │
    GND ────────┴───────────────┘（共地）

十、固態繼電器（SSR）

與機械繼電器的比較

十一、常見問題排解

問題 1：繼電器不動作

檢查步驟：

□ 1. VCC、GND 有接嗎？
□ 2. IN 腳有接到 Arduino 腳位嗎？
□ 3. 確認觸發電平（高/低電平觸發）
□ 4. 用三用電表量 IN 腳電壓
□ 5. 模組上的 LED 有亮嗎？
□ 6. 聽聽看有沒有「喀」聲

問題 2：繼電器一直動作/不停切換

可能原因：

1. 低電平觸發 + Arduino 開機預設 LOW
   → 在 setup() 先設 HIGH

2. 浮動腳位
   → 加上拉/下拉電阻

3. 電源不穩
   → 加退耦電容、使用獨立電源

問題 3：Arduino 不斷重啟

原因：繼電器切換時產生電源雜訊

解決方法：
1. 在繼電器模組 VCC-GND 間加 100μF 電容
2. 使用獨立電源供應繼電器
3. 繼電器模組遠離 Arduino
4. 控制線使用較短的杜邦線

問題 4：負載無法正常運作

檢查步驟：

□ 1. COM、NO/NC 接線正確嗎？
□ 2. 負載電源有接嗎？
□ 3. 負載電流是否超過繼電器額定值？
□ 4. 用三用電表量 COM-NO 之間的導通狀態
