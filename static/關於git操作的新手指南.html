Git 操作新手指南

一、什麼是 Git？

Git 是一個版本控制系統，可以追蹤檔案的變更歷史，讓你能夠：

  • 記錄每次修改的內容
  • 隨時回復到之前的版本
  • 多人協作開發不衝突
  • 備份程式碼到雲端（GitHub）
名詞 說明
Repository (Repo) 儲存庫，一個專案的所有檔案和歷史紀錄
Commit 提交，記錄一次檔案變更
Branch 分支，獨立的開發線
Remote 遠端，雲端上的儲存庫（如 GitHub）
Clone 複製遠端儲存庫到本機
Push 將本機變更上傳到遠端
Pull 將遠端變更下載到本機

二、安裝 Git

Windows

  1. 下載：https://git-scm.com/download/win
  2. 安裝時保持預設選項即可
  3. 安裝完成後重新開啟終端機

驗證安裝

git --version

顯示類似 git version 2.43.0 表示安裝成功

三、初次設定

安裝 Git 後，需要設定使用者名稱和信箱（只需設定一次）：

git config --global user.name "你的名字"
git config --global user.email "你的信箱@example.com"

查看目前設定

git config --list

四、基本操作流程

情境 1：建立新的 Git 專案

# 1. 進入專案資料夾
cd D:\Course\my_project

# 2. 初始化 Git 儲存庫
git init

# 3. 查看狀態
git status

情境 2：從 GitHub 下載專案

# 複製遠端儲存庫
git clone https://github.com/username/repository.git

# 進入專案資料夾
cd repository

五、Git 核心指令

查看狀態

git status

顯示：
- 紅色：未追蹤或已修改但未暫存的檔案
- 綠色：已暫存等待提交的檔案

暫存檔案 (Stage)

# 暫存單一檔案
git add 檔案名稱.py

# 暫存所有變更
git add .

# 暫存特定類型檔案
git add *.py

提交變更 (Commit)

# 提交並附上訊息
git commit -m "新增登入功能"

# 查看提交歷史
git log

# 簡潔版歷史
git log --oneline

完整流程範例

# 1. 修改檔案後，查看狀態
git status

# 2. 暫存所有變更
git add .

# 3. 提交變更
git commit -m "修正 bug：使用者無法登入的問題"

# 4. 確認提交成功
git log --oneline

六、連結 GitHub

建立 GitHub 帳號

  1. 前往 https://github.com
  2. 註冊帳號

建立新的遠端儲存庫

  1. 點擊右上角 + → New repository
  2. 輸入儲存庫名稱
  3. 選擇 Public（公開）或 Private（私人）
  4. 點擊 Create repository

將本機專案連結到 GitHub

# 1. 新增遠端儲存庫連結
git remote add origin https://github.com/你的帳號/儲存庫名稱.git

# 2. 第一次推送（-u 設定預設上游分支）
git push -u origin main

# 3. 之後推送只需
git push

從 GitHub 下載更新

git pull

七、分支操作 (Branch)

分支讓你可以在不影響主線的情況下開發新功能。

查看分支

# 查看本機分支
git branch

# 查看所有分支（含遠端）
git branch -a

建立與切換分支

# 建立新分支
git branch feature-login

# 切換到該分支
git checkout feature-login

# 建立並切換（合併上面兩步）
git checkout -b feature-login

合併分支

# 1. 先切換到主分支
git checkout main

# 2. 合併其他分支
git merge feature-login

# 3. 刪除已合併的分支（可選）
git branch -d feature-login

八、VS Code 中使用 Git

VS Code 內建 Git 支援，可以用圖形介面操作。

開啟原始檔控制面板

  • 點擊左側邊欄的分支圖示
  • 或按 Ctrl + Shift + G

常用操作

操作 說明
+ 號 暫存檔案 (git add)
- 號 取消暫存
✓ 打勾 提交變更 (git commit)
... 選單 更多操作 (push, pull, 等)

查看檔案變更

點擊已修改的檔案，VS Code 會顯示差異比較（Diff）

九、.gitignore 檔案

.gitignore 用來指定不要追蹤的檔案或資料夾。

建立 .gitignore

在專案根目錄建立 .gitignore 檔案：

# 虛擬環境
venv/
.venv/

# Python 快取
__pycache__/
*.pyc

# IDE 設定
.vscode/
.idea/

# 系統檔案
.DS_Store
Thumbs.db

# 環境變數（含敏感資訊）
.env

# 大型資料檔案
*.csv
*.xlsx
data/

常用 .gitignore 範本

  • Python：https://github.com/github/gitignore/blob/main/Python.gitignore

十、常見問題排解

Q1: git push 要求輸入帳號密碼

解決：使用 Personal Access Token (PAT)

  1. GitHub → Settings → Developer settings → Personal access tokens
  2. 產生新的 Token
  3. 推送時密碼欄位輸入 Token

Q2: 不小心 commit 了不該提交的檔案

# 取消最近一次 commit（保留檔案變更）
git reset --soft HEAD~1

# 從暫存區移除檔案（不刪除檔案）
git reset HEAD 檔案名稱

Q3: 想放棄目前的修改

# 放棄單一檔案的修改
git checkout -- 檔案名稱

# 放棄所有修改（危險！）
git checkout -- .

Q4: push 被拒絕 (rejected)

原因：遠端有你沒有的變更

# 先拉取遠端變更
git pull

# 解決衝突後再推送
git push

Q5: 合併時發生衝突 (Conflict)

  1. 打開衝突的檔案，會看到類似：
    ```
    <<<<<<< HEAD
    你的版本
    =======
    別人的版本

    branch-name
    ```

  2. 手動編輯，保留需要的內容
  3. 刪除衝突標記 (<<<<<<<, =======, >>>>>>>)
  4. 暫存並提交：
    cmd git add . git commit -m "解決合併衝突"
