關於伺服馬達

前言：伺服馬達能做什麼？

伺服馬達（Servo Motor）是一種可以精確控制角度的馬達，廣泛應用於：

  • 機器手臂的關節
  • 遙控車的轉向機構
  • 機器人的頭部/眼睛
  • 智慧溫室的通風窗控制
  • 自動門鎖、閘門

和一般馬達不同，伺服馬達不是「轉不停」，而是「轉到你要的角度就停住」！

一、伺服馬達是什麼？

一句話解釋

伺服馬達是一種可以精確轉動到指定角度並保持在該位置的馬達。

生活比喻

想像伺服馬達是一個「聽話的門把」：

┌─────────────────────────────────────────────────────┐
│                                                     │
│  你：「轉到 90 度！」                                │
│                                                     │
│  門把：「好的！」  ──→  轉到 90 度，然後固定住       │
│                                                     │
│  你：「轉到 45 度！」                                │
│                                                     │
│  門把：「好的！」  ──→  轉到 45 度，然後固定住       │
│                                                     │
│  不管外力怎麼推，它都會努力維持在你指定的角度！      │
│                                                     │
└─────────────────────────────────────────────────────┘

二、伺服馬達的工作原理

內部結構

伺服馬達內部組成：

┌─────────────────────────────────────┐
│                                     │
│   ┌─────┐                           │
│   │馬達 │──→ 提供轉動力            │
│   └──┬──┘                           │
│      │                              │
│   ┌──┴──┐                           │
│   │齒輪組│──→ 減速增加扭力          │
│   └──┬──┘                           │
│      │                              │
│   ┌──┴──┐                           │
│   │電位器│──→ 感測目前角度          │
│   └──┬──┘                           │
│      │                              │
│   ┌──┴──┐                           │
│   │控制板│──→ 比較目標與現在角度    │
│   └─────┘      調整馬達轉動          │
│                                     │
└─────────────────────────────────────┘

PWM 控制原理

伺服馬達使用 PWM（脈衝寬度調變）訊號控制角度：

週期：20ms（50Hz）

0 度位置（脈衝寬度 1ms）：
    ┌─┐                   ┌─┐
    │ │                   │ │
────┘ └───────────────────┘ └─────
    1ms      19ms          1ms
    ←──────20ms──────→

90 度位置（脈衝寬度 1.5ms）：
    ┌──┐                  ┌──┐
    │  │                  │  │
────┘  └──────────────────┘  └────
   1.5ms    18.5ms        1.5ms

180 度位置（脈衝寬度 2ms）：
    ┌───┐                 ┌───┐
    │   │                 │   │
────┘   └─────────────────┘   └───
    2ms      18ms          2ms

脈衝寬度與角度對應：
┌────────────┬────────────┐
│  脈衝寬度   │    角度    │
├────────────┼────────────┤
│   1.0 ms   │    0°      │
│   1.5 ms   │   90°      │
│   2.0 ms   │   180°     │
└────────────┴────────────┘

控制迴路

伺服馬達控制流程：

                    ┌─────────────┐
  PWM 訊號 ────────→│   控制板    │
  （目標角度）       │             │
                    │  比較器     │────→ 馬達轉動
                    │   ↑   ↓    │
                    │   │   │    │
                    └───┼───┼────┘
                        │   │
                    ┌───┴───┴────┐
                    │   電位器    │
                    │ （目前角度）│
                    └────────────┘

當目標角度 ≠ 目前角度 → 馬達轉動
當目標角度 = 目前角度 → 馬達停止並保持

電源需求計算

電源計算範例：

SG90 規格：
- 空載電流：約 100mA
- 負載電流：約 300-400mA
- 堵轉電流：約 600-700mA

Arduino 5V 腳位最大輸出：約 500mA

計算：
- 1 顆 SG90：300mA → Arduino 可直接供電 ✓
- 2 顆 SG90：600mA → 超過限制，需外接電源 ✗
- 3 顆以上：絕對需要外接電源 ✗

建議：
- 單顆 SG90 輕負載 → 可用 Arduino 5V
- 其他情況 → 使用 5V 2A 以上的外接電源

五、Arduino Servo 程式庫

程式庫介紹

Arduino 內建 Servo 程式庫：

優點：
- 不需額外安裝，Arduino IDE 內建
- 使用簡單，一行程式碼設定角度
- 自動處理 PWM 時序

限制：
- 最多同時控制 12 顆伺服馬達（Uno）
- 使用時會停用 D9、D10 的 PWM 功能（analogWrite）

基本用法

#include <Servo.h>

Servo myServo;  // 建立 Servo 物件

void setup() {
  myServo.attach(9);  // 連接到 D9 腳位
}

void loop() {
  myServo.write(0);    // 轉到 0 度
  delay(1000);

  myServo.write(90);   // 轉到 90 度
  delay(1000);

  myServo.write(180);  // 轉到 180 度
  delay(1000);
}

Servo 程式庫函數

函數 說明 範例
attach(pin) 連接伺服馬達到指定腳位 servo.attach(9);
attach(pin, min, max) 連接並設定脈衝範圍（微秒） servo.attach(9, 544, 2400);
write(angle) 設定角度（0-180） servo.write(90);
writeMicroseconds(us) 直接設定脈衝寬度（微秒） servo.writeMicroseconds(1500);
read() 讀取目前角度設定值 int pos = servo.read();
attached() 檢查是否已連接 if(servo.attached())
detach() 斷開連接（釋放腳位） servo.detach();

範例 1：基本角度控制

/*
 * 伺服馬達基本控制
 * 依序轉動到 0°、90°、180°
 */

#include <Servo.h>

Servo myServo;
const int SERVO_PIN = 9;

void setup() {
  myServo.attach(SERVO_PIN);
  Serial.begin(9600);
  Serial.println("伺服馬達測試");
}

void loop() {
  Serial.println("轉到 0 度");
  myServo.write(0);
  delay(1000);

  Serial.println("轉到 90 度");
  myServo.write(90);
  delay(1000);

  Serial.println("轉到 180 度");
  myServo.write(180);
  delay(1000);
}

範例 2：平滑轉動（掃描）

/*
 * 伺服馬達平滑掃描
 * 從 0 度慢慢轉到 180 度，再轉回來
 */

#include <Servo.h>

Servo myServo;
const int SERVO_PIN = 9;

void setup() {
  myServo.attach(SERVO_PIN);
}

void loop() {
  // 從 0 度轉到 180 度
  for (int angle = 0; angle <= 180; angle++) {
    myServo.write(angle);
    delay(15);  // 調整此值改變轉速
  }

  // 從 180 度轉回 0 度
  for (int angle = 180; angle >= 0; angle--) {
    myServo.write(angle);
    delay(15);
  }
}

範例 3：電位器控制角度

/*
 * 使用電位器控制伺服馬達角度
 * 旋轉電位器 → 伺服馬達跟著轉
 */

#include <Servo.h>

Servo myServo;
const int SERVO_PIN = 9;
const int POT_PIN = A0;

void setup() {
  myServo.attach(SERVO_PIN);
  Serial.begin(9600);
}

void loop() {
  // 讀取電位器值（0-1023）
  int potValue = analogRead(POT_PIN);

  // 對應到角度（0-180）
  int angle = map(potValue, 0, 1023, 0, 180);

  // 設定伺服馬達角度
  myServo.write(angle);

  // 顯示數值
  Serial.print("電位器：");
  Serial.print(potValue);
  Serial.print("  角度：");
  Serial.println(angle);

  delay(20);
}

範例 4：按鈕控制開關門

/*
 * 按鈕控制伺服馬達開關
 * 模擬門或閘門的開關動作
 */

#include <Servo.h>

Servo doorServo;
const int SERVO_PIN = 9;
const int BUTTON_PIN = 2;

const int ANGLE_CLOSED = 0;    // 關閉角度
const int ANGLE_OPEN = 90;     // 開啟角度

bool doorOpen = false;
bool lastButtonState = HIGH;

void setup() {
  doorServo.attach(SERVO_PIN);
  pinMode(BUTTON_PIN, INPUT_PULLUP);

  doorServo.write(ANGLE_CLOSED);  // 初始為關閉
  Serial.begin(9600);
  Serial.println("門控制系統");
}

void loop() {
  bool currentButtonState = digitalRead(BUTTON_PIN);

  // 偵測按鈕按下
  if (lastButtonState == HIGH && currentButtonState == LOW) {
    delay(50);  // 消除彈跳

    doorOpen = !doorOpen;  // 切換狀態

    if (doorOpen) {
      // 開門（平滑轉動）
      Serial.println("開門中...");
      for (int a = ANGLE_CLOSED; a <= ANGLE_OPEN; a++) {
        doorServo.write(a);
        delay(15);
      }
      Serial.println("門已開啟");
    } else {
      // 關門（平滑轉動）
      Serial.println("關門中...");
      for (int a = ANGLE_OPEN; a >= ANGLE_CLOSED; a--) {
        doorServo.write(a);
        delay(15);
      }
      Serial.println("門已關閉");
    }
  }

  lastButtonState = currentButtonState;
}

範例 5：紅外線遙控伺服馬達

/*
 * 使用紅外線遙控器控制伺服馬達
 * 按 + 增加角度，按 - 減少角度
 */

#include <Servo.h>
#include <IRremote.h>

Servo myServo;
const int SERVO_PIN = 9;
const int IR_PIN = 11;

int currentAngle = 90;  // 初始角度
const int STEP = 10;    // 每次增減角度

// 定義遙控器按鍵碼（需根據你的遙控器調整）
#define IR_BUTTON_PLUS  0xFFA857   // + 按鈕
#define IR_BUTTON_MINUS 0xFFE01F   // - 按鈕
#define IR_BUTTON_OK    0xFF02FD   // OK 按鈕（回中心）

void setup() {
  myServo.attach(SERVO_PIN);
  myServo.write(currentAngle);

  IrReceiver.begin(IR_PIN, ENABLE_LED_FEEDBACK);

  Serial.begin(9600);
  Serial.println("紅外線遙控伺服馬達");
  Serial.println("+ : 增加角度");
  Serial.println("- : 減少角度");
  Serial.println("OK: 回到 90 度");
}

void loop() {
  if (IrReceiver.decode()) {
    uint32_t code = IrReceiver.decodedIRData.decodedRawData;

    switch (code) {
      case IR_BUTTON_PLUS:
        currentAngle = min(currentAngle + STEP, 180);
        Serial.print("增加角度：");
        break;

      case IR_BUTTON_MINUS:
        currentAngle = max(currentAngle - STEP, 0);
        Serial.print("減少角度：");
        break;

      case IR_BUTTON_OK:
        currentAngle = 90;
        Serial.print("回到中心：");
        break;
    }

    myServo.write(currentAngle);
    Serial.println(currentAngle);

    IrReceiver.resume();
  }
}

範例 6：溫度控制通風窗

/*
 * 智慧溫室通風窗控制
 * 根據溫度自動調整通風窗開度
 */

#include <Servo.h>
#include <DHT.h>

#define DHT_PIN 2
#define DHT_TYPE DHT11
#define SERVO_PIN 9

DHT dht(DHT_PIN, DHT_TYPE);
Servo ventServo;

// 溫度與通風窗開度對應
// 25°C 以下：關閉（0°）
// 25-28°C：微開（45°）
// 28-32°C：半開（90°）
// 32°C 以上：全開（180°）

const float TEMP_LOW = 25.0;
const float TEMP_MID = 28.0;
const float TEMP_HIGH = 32.0;

int currentAngle = 0;
int targetAngle = 0;

void setup() {
  Serial.begin(9600);
  dht.begin();
  ventServo.attach(SERVO_PIN);
  ventServo.write(0);

  Serial.println("=== 智慧通風窗控制 ===");
}

void loop() {
  float temperature = dht.readTemperature();

  if (isnan(temperature)) {
    Serial.println("感測器錯誤！");
    delay(2000);
    return;
  }

  // 根據溫度決定目標角度
  if (temperature < TEMP_LOW) {
    targetAngle = 0;    // 關閉
  } else if (temperature < TEMP_MID) {
    targetAngle = 45;   // 微開
  } else if (temperature < TEMP_HIGH) {
    targetAngle = 90;   // 半開
  } else {
    targetAngle = 180;  // 全開
  }

  // 平滑轉動到目標角度
  if (currentAngle != targetAngle) {
    moveServoSmooth(currentAngle, targetAngle);
    currentAngle = targetAngle;
  }

  // 顯示狀態
  Serial.print("溫度：");
  Serial.print(temperature, 1);
  Serial.print("°C  通風窗：");
  Serial.print(currentAngle);
  Serial.print("°（");
  if (targetAngle == 0) Serial.print("關閉");
  else if (targetAngle == 45) Serial.print("微開");
  else if (targetAngle == 90) Serial.print("半開");
  else Serial.print("全開");
  Serial.println("）");

  delay(5000);  // 每 5 秒檢查一次
}

// 平滑轉動函數
void moveServoSmooth(int from, int to) {
  if (from < to) {
    for (int a = from; a <= to; a++) {
      ventServo.write(a);
      delay(20);
    }
  } else {
    for (int a = from; a >= to; a--) {
      ventServo.write(a);
      delay(20);
    }
  }
}

範例 7：多顆伺服馬達控制

/*
 * 控制多顆伺服馬達
 * 例如：機器手臂的多個關節
 */

#include <Servo.h>

// 建立多個 Servo 物件
Servo servo1;  // 底座旋轉
Servo servo2;  // 手臂上下
Servo servo3;  // 夾爪開合

const int SERVO1_PIN = 9;
const int SERVO2_PIN = 10;
const int SERVO3_PIN = 11;

void setup() {
  servo1.attach(SERVO1_PIN);
  servo2.attach(SERVO2_PIN);
  servo3.attach(SERVO3_PIN);

  // 初始位置
  servo1.write(90);   // 底座朝前
  servo2.write(45);   // 手臂抬起
  servo3.write(0);    // 夾爪張開

  Serial.begin(9600);
  Serial.println("多軸伺服控制");
}

void loop() {
  Serial.println("動作：向左轉並夾取");

  // 底座向左轉
  for (int a = 90; a <= 135; a++) {
    servo1.write(a);
    delay(20);
  }

  // 手臂下降
  for (int a = 45; a >= 20; a--) {
    servo2.write(a);
    delay(20);
  }

  // 夾爪閉合
  for (int a = 0; a <= 60; a++) {
    servo3.write(a);
    delay(20);
  }

  delay(2000);

  Serial.println("動作：抬起並歸位");

  // 手臂抬起
  for (int a = 20; a <= 45; a++) {
    servo2.write(a);
    delay(20);
  }

  // 底座歸位
  for (int a = 135; a >= 90; a--) {
    servo1.write(a);
    delay(20);
  }

  // 夾爪張開
  for (int a = 60; a >= 0; a--) {
    servo3.write(a);
    delay(20);
  }

  delay(2000);
}

七、進階技巧

使用 writeMicroseconds() 精確控制

/*
 * 使用微秒精確控制
 * 比 write() 更精確（write 只能整數度）
 */

#include <Servo.h>

Servo myServo;

void setup() {
  myServo.attach(9);
}

void loop() {
  // 標準脈衝範圍：544-2400 微秒
  // 對應角度：0-180 度

  myServo.writeMicroseconds(544);   // 約 0 度
  delay(1000);

  myServo.writeMicroseconds(1472);  // 約 90 度
  delay(1000);

  myServo.writeMicroseconds(2400);  // 約 180 度
  delay(1000);

  // 可以控制到小數點角度
  // 例如 45.5 度 ≈ 1008 微秒
  myServo.writeMicroseconds(1008);
  delay(1000);
}

校正伺服馬達範圍

/*
 * 有些伺服馬達的實際角度範圍不是標準的 0-180
 * 可以使用 attach() 的額外參數來校正
 */

#include <Servo.h>

Servo myServo;

void setup() {
  // 預設值：attach(pin, 544, 2400)
  // 如果你的伺服馬達範圍不對，可以調整

  // 例如：實測 0 度時需要 600μs，180 度時需要 2300μs
  myServo.attach(9, 600, 2300);

  // 這樣 write(0) 會輸出 600μs
  // write(180) 會輸出 2300μs
}

void loop() {
  myServo.write(0);
  delay(1000);
  myServo.write(180);
  delay(1000);
}

避免抖動的技巧

/*
 * 伺服馬達有時會在靜止時抖動
 * 可以用 detach() 來停止訊號
 */

#include <Servo.h>

Servo myServo;
const int SERVO_PIN = 9;

void setup() {
  Serial.begin(9600);
}

void loop() {
  // 需要動作時才 attach
  myServo.attach(SERVO_PIN);

  myServo.write(90);
  delay(500);  // 等待到達位置

  // 到達後 detach 可減少抖動和耗電
  myServo.detach();

  Serial.println("已到達 90 度，停止訊號");
  delay(3000);

  // 再次動作
  myServo.attach(SERVO_PIN);
  myServo.write(0);
  delay(500);
  myServo.detach();

  Serial.println("已到達 0 度，停止訊號");
  delay(3000);
}

八、常見問題排解

問題 1：伺服馬達不動

檢查步驟：

□ 1. 電源有接嗎？（VCC 和 GND）
□ 2. 訊號線有接到 PWM 腳位嗎？
□ 3. 程式有呼叫 attach() 嗎？
□ 4. 有足夠電流嗎？（多顆馬達需外接電源）
□ 5. 馬達是否損壞？（聽聽看有沒有聲音）
□ 6. 嘗試用 writeMicroseconds(1500) 測試

問題 2：伺服馬達抖動

可能原因與解決方法：

1. 電源不穩定
   → 加電容穩壓（100μF）
   → 使用外接穩定電源

2. PWM 訊號干擾
   → 訊號線不要太長
   → 遠離馬達和電源線

3. 機械負載過重
   → 減輕負載或使用更大扭力馬達

4. 程式不斷發送 write()
   → 只在需要改變角度時發送
   → 到位後用 detach() 停止訊號

5. 馬達品質問題
   → 更換品質較好的馬達

問題 3：角度不準確

可能原因與解決方法：

1. 伺服馬達個體差異
   → 使用 attach(pin, min, max) 校正範圍
   → 實測後調整脈衝寬度參數

2. 機械間隙（齒輪磨損）
   → 正常現象，塑膠齒輪較明顯
   → 高精度需求請用金屬齒輪款

3. 超出可動範圍
   → 確認馬達規格（有些只能 0-120°）
   → 不要超出實際可動範圍

4. 負載過重導致無法到位
   → 減輕負載或更換大扭力馬達

問題 4：Arduino 重啟或不穩定

原因：伺服馬達瞬間電流過大

解決方法：

1. 使用外接電源供應伺服馬達
   ┌──────────┐
   │外接電源5V ├──→ 伺服馬達 VCC
   │    GND   ├──→ 伺服馬達 GND ←─┬─ Arduino GND
   └──────────┘                   │
                                  共地！

2. 在電源端加大電容（470μF~1000μF）

3. 避免多顆馬達同時啟動
   → 程式中加入延遲，逐一啟動

九、360 度連續旋轉伺服馬達

與標準伺服馬達的差異

┌──────────────────────┬───────────────────────┐
│    標準伺服馬達       │  360度連續旋轉伺服     │
├──────────────────────┼───────────────────────┤
│ 控制角度（0-180°）   │ 控制轉速和方向         │
│ 轉到位置後停止       │ 持續旋轉               │
│ 用於精確定位         │ 用於輪子、風扇等       │
└──────────────────────┴───────────────────────┘

360 度伺服的控制方式

/*
 * 360 度連續旋轉伺服馬達控制
 * write(90) = 停止
 * write(0) = 全速順時針
 * write(180) = 全速逆時針
 */

#include <Servo.h>

Servo contServo;

void setup() {
  contServo.attach(9);
  Serial.begin(9600);
}

void loop() {
  Serial.println("順時針旋轉");
  contServo.write(0);     // 全速順時針
  delay(2000);

  Serial.println("停止");
  contServo.write(90);    // 停止
  delay(1000);

  Serial.println("逆時針旋轉");
  contServo.write(180);   // 全速逆時針
  delay(2000);

  Serial.println("停止");
  contServo.write(90);    // 停止
  delay(1000);

  Serial.println("慢速順時針");
  contServo.write(80);    // 慢速順時針
  delay(2000);

  contServo.write(90);    // 停止
  delay(1000);
}

十、接線速查表

SG90 接線

SG90 線材 顏色 接到 Arduino
VCC 紅色 5V
GND 棕色/黑色 GND
Signal 橙色/黃色/白色 D9（或其他 PWM 腳位）

Arduino Uno PWM 腳位

Arduino Uno 可用於伺服馬達的腳位：

建議使用：D9、D10（Servo 程式庫優先使用）

其他可用：D3、D5、D6、D11

注意：使用 Servo 程式庫後，D9、D10 的 analogWrite() 會失效

程式速查表

#include <Servo.h>

Servo myServo;           // 建立物件

// 基本操作
myServo.attach(9);       // 連接到 D9
myServo.write(90);       // 轉到 90 度
myServo.read();          // 讀取目前角度
myServo.detach();        // 斷開連接

// 進階操作
myServo.attach(9, 600, 2400);      // 指定脈衝範圍
myServo.writeMicroseconds(1500);   // 直接指定脈衝寬度
myServo.attached();                 // 檢查是否連接

// 常用數值
// 0 度 ≈ 544μs（預設最小值）
// 90 度 ≈ 1472μs
// 180 度 ≈ 2400μs（預設最大值）
