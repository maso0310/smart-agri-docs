什麼是 GitHub

GitHub 是全球最大的程式碼託管平台，可以用來：
- 儲存和管理程式碼
- 與他人協作開發
- 下載開源專案
- 學習他人的程式碼

GitHub 運作概念
===============

    你的電腦                    GitHub 雲端
   ┌─────────┐                ┌─────────────┐
   │  本地   │  ◄── 下載 ──── │   儲存庫    │
   │  資料夾 │  ─── 上傳 ───► │ Repository  │
   └─────────┘                └─────────────┘

   可以下載別人分享的專案
   也可以上傳自己的專案讓別人使用

註冊帳號

步驟 1：前往 GitHub 官網

  1. 開啟瀏覽器，前往 https://github.com
  2. 點擊右上角「Sign up」

步驟 2：填寫資料

註冊資訊
========
• Email：填寫你的電子郵件
• Password：設定密碼（至少 8 個字元）
• Username：選擇一個使用者名稱（英文）

步驟 3：驗證信箱

  • GitHub 會寄送驗證信到你的信箱
  • 點擊信中的連結完成驗證

下載專案

方法 1：直接下載 ZIP（最簡單）

步驟：
1. 進入專案頁面
2. 點擊綠色的「Code」按鈕
3. 選擇「Download ZIP」
4. 解壓縮下載的檔案

┌──────────────────────┐
│  < > Code  ▼         │
├──────────────────────┤
│  📋 Clone            │
│  HTTPS               │
│  ┌────────────────┐  │
│  │ https://github │  │
│  └────────────────┘  │
│                      │
│  ─────────────────   │
│  📥 Download ZIP ◄───┼── 點這裡下載
└──────────────────────┘

方法 2：使用 Git 指令（進階）

# 首先安裝 Git
# Windows: https://git-scm.com/download/win
# Mac: brew install git
# Linux: sudo apt install git

# 複製專案到本地
git clone https://github.com/使用者名稱/專案名稱.git

# 範例：
git clone https://github.com/raspberrypi/pico-examples.git

方法 3：在樹莓派上下載

# 樹莓派已預裝 Git，可直接使用
cd ~/Documents

# 下載專案
git clone https://github.com/專案網址.git

# 進入專案資料夾
cd 專案名稱

搜尋專案

GitHub 搜尋語法
==============

在 GitHub 搜尋欄輸入：

1. 基本搜尋
   arduino sensor        ← 搜尋 Arduino 感測器專案

2. 指定語言
   raspberry pi language:python  ← 只搜尋 Python 專案

3. 依星星數排序
   mqtt stars:>100       ← 搜尋超過 100 星的 MQTT 專案

4. 指定時間
   iot created:>2023-01-01  ← 搜尋 2023 年後建立的 IoT 專案

判斷專案品質

好專案的特徵
===========

✓ ⭐ Stars 數量多（受歡迎）
✓ 📅 最近有更新（持續維護）
✓ 📖 有完整的 README 說明
✓ 📋 有 Issues 討論區活躍
✓ 📜 有明確的 License（授權）
✓ 🔢 有版本號（Release）

警告訊號
========
✗ 好幾年沒更新
✗ 沒有說明文件
✗ Issues 累積很多沒人回
✗ 沒有授權說明

常見問題

Q1: GitHub 需要付費嗎？

免費帳號就可以：
- 下載任何公開專案
- 建立無限數量的公開儲存庫
- 建立私人儲存庫（有協作人數限制）

Q2: 下載的專案可以商用嗎？

需要查看專案的 License（授權）：

授權類型 商用 需要標註來源 需要開源
MIT ✓ ✓ ✗
Apache 2.0 ✓ ✓ ✗
GPL ✓ ✓ ✓
CC BY ✓ ✓ ✗

Q3: 如何回報專案問題？

  1. 進入專案頁面
  2. 點擊「Issues」標籤
  3. 點擊「New Issue」
  4. 描述你遇到的問題
  5. 送出等待回覆

Q4: 專案下載後如何使用？

通常步驟：
1. 解壓縮下載的 ZIP
2. 閱讀 README.md 說明
3. 依照說明安裝相依套件
4. 執行程式
