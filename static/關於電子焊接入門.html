關於電子焊接入門

焊接是電子製作的基本技能。掌握正確的焊接技巧，可以讓你的電路穩定耐用，也是從麵包板原型走向成品的必經之路。

一、為什麼要學焊接？

1.1 焊接的目的

目的 說明
電氣連接 讓電流能穩定通過接點
機械固定 將元件牢固地固定在電路板上
永久連接 比麵包板更穩定、更持久
專業成品 從原型到實際產品的必要步驟

1.2 焊接 vs 麵包板

特性 麵包板 焊接電路
穩定性 易鬆脫 非常穩固
適合場景 測試、原型 成品、長期使用
修改難度 隨時可改 需要拆焊
體積 較大 可以很小
振動耐受 差 佳
成本 可重複使用 需要材料

1.3 什麼時候該焊接？

  • 專案進入最終版本
  • 需要長時間運作的設備
  • 會移動或有振動的裝置
  • 空間受限需要縮小體積
  • 戶外或惡劣環境使用

三、焊接基本原理

3.1 焊接三要素

良好焊接需要三者配合：

        溫度
         /\
        /  \
       /    \
      / 良好  \
     /  焊接   \
    /___________\
   時間 ←────→ 焊錫量
要素 說明 常見問題
溫度 足夠熔化焊錫與加熱焊點 溫度不足=冷焊
時間 加熱時間適當 太久=燒壞元件
焊錫量 適量的焊錫 太多=短路、太少=虛焊

3.2 熱傳導原理

正確的加熱方式：

    烙鐵頭
       ↓
    ┌──────┐
    │加熱點│ ──→ 同時接觸焊盤和元件腳
    └──┬───┘
       │
    ═══╪═══  ← 焊盤（PCB 上的銅箔）
       │
    ───┴───  ← 元件腳

要點： 烙鐵頭要同時接觸焊盤和元件腳，讓兩者都被加熱

3.3 良好焊點的特徵

焊點形狀比較：

良好焊點          焊錫過多          焊錫過少          冷焊
   ∩                ●                 .              ∩
  / \              /|\               / \            | |
 /   \            / | \             /   \           | |
─────────       ─────────         ─────────       ─────────
光滑、圓錐形    圓球狀、可能短路   覆蓋不完全      粗糙、無光澤
焊點狀態 外觀 原因
良好 光滑、有光澤、圓錐形 正確操作
冷焊 粗糙、無光澤、灰暗 溫度不足或移動太快
過熱 焊盤脫落、燒焦 加熱時間過長
虛焊 看似焊上但不導電 未正確加熱
橋接 兩焊點連在一起 焊錫過多

四、焊接操作步驟

4.1 焊接前準備

  1. 設定溫度
  2. 有鉛焊錫：320-350°C

  3. 無鉛焊錫：350-380°C

  4. 清潔烙鐵頭
    ```
    使用濕海綿或銅絲球清潔

銅絲球（推薦） 濕海綿
╱╲╱╲ ▓▓▓▓
╱╲╱╲╱╲ ▓▓▓▓
╱╲╱╲╱╲╱╲ ▓▓▓▓
不降溫、清潔力強 會降溫、需保持濕潤
```

  1. 上錫（Tinning）
  2. 新烙鐵頭或清潔後要先上一層薄錫

  3. 保護烙鐵頭不氧化

  4. 固定工件

  5. 使用第三手或夾具固定電路板
  6. 確保焊接時不會移動

4.2 標準焊接流程

步驟圖解：

步驟 1：接觸          步驟 2：送錫          步驟 3：移開

    烙鐵               烙鐵  焊錫
      ↓                  ↓  ↓               完成！
   ┌──┐              ┌──┐                    ∩
   │  │              │  │≋≋               ╱   ╲
═══╪══════         ═══╪═══════          ══════════
   │                   │

同時接觸焊盤        焊錫接觸加熱點         良好焊點
和元件腳            讓焊錫自然流動
（1-2秒預熱）       （1-2秒）

詳細步驟：

  1. 接觸（1-2 秒）
  2. 烙鐵頭同時接觸焊盤和元件腳

  3. 預熱焊接點

  4. 送錫（1-2 秒）

  5. 焊錫絲接觸焊點（不是烙鐵頭）

  6. 讓焊錫自然流動覆蓋

  7. 移開焊錫

  8. 先移開焊錫絲

  9. 移開烙鐵

  10. 最後移開烙鐵
  11. 保持靜止讓焊錫凝固

總時間：3-5 秒

4.3 常見焊接情境

直插元件（Through-Hole）

LED、電阻、電容等：

    元件
      │
      │    ← 元件腳穿過孔
══════╪══════  ← PCB 正面
      │
    ──┴──    ← PCB 背面，在這裡焊接
      ∩
    焊點

步驟：
1. 元件腳從正面穿過孔
2. 背面稍微彎曲固定
3. 在背面焊接
4. 剪掉多餘的腳（留 1-2mm）

導線焊接

導線接到焊盤：

1. 先將導線     2. 上錫到       3. 焊接到
   剝皮絞緊        導線上          焊盤

   ══════        ══∩∩══         ══∩∩══
      │            ↓               │
   ───┴───      ──────          ═══╪═══
   露出銅絲      鍍上薄錫         完成焊接

元件維修（拆焊）

使用吸錫器：

1. 加熱焊點     2. 吸錫器就位    3. 按下釋放

    烙鐵            烙鐵  吸錫器
      ↓               ↓    ↓         元件可
   ┌──∩──┐        ┌──∩──┐ ○        取下了！
═══╧════════    ═══╧═══════      ═══════════

五、焊接技巧與訣竅

5.1 提升焊接品質的技巧

技巧 說明
保持烙鐵頭清潔 每次焊接後都要清潔
使用適量焊錫 寧少勿多，不夠可以補
預熱焊點 確保焊盤和元件腳都被加熱
焊錫接觸焊點 不是接觸烙鐵頭
不要移動 焊錫凝固前保持靜止
適當的速度 太快冷焊，太慢燒壞

5.2 常見錯誤與解決

問題 原因 解決方法
焊錫不沾 氧化、溫度不足 使用助焊劑、提高溫度
冷焊（灰暗粗糙） 溫度不足或移動 重新加熱讓焊錫流動
焊盤脫落 加熱過久 縮短加熱時間
橋接短路 焊錫過多 用吸錫線移除多餘焊錫
元件損壞 過熱 使用散熱夾、縮短時間
煙霧刺眼 助焊劑燃燒 使用排煙風扇、保持通風

5.3 特殊情況處理

難焊的表面

處理氧化焊盤：

1. 用砂紙輕磨     2. 塗助焊劑     3. 正常焊接

   ▓▓▓▓▓           ≋≋≋≋≋          ∩
   ─────  →        ─────   →     ─────
   氧化表面        塗上助焊劑      良好焊點

多腳 IC 焊接

IC 焊接順序：

    ┌─────────────┐
    │  IC 晶片    │
    │             │
    └┬─┬─┬─┬─┬─┬─┬┘
     1 2 3 4 5 6 7
     ↓           ↓
    先焊對角兩腳固定
    再依序焊其他腳

步驟：
1. 先焊對角的兩隻腳固定位置
2. 確認對齊後焊其餘的腳
3. 使用較細的烙鐵頭
4. 可使用拖焊技巧

九、常見問題 FAQ

Q1：初學者該買有鉛還是無鉛焊錫？

建議有鉛焊錫（63/37）。
- 熔點較低，較容易操作
- 流動性好，焊點較漂亮
- 使用後記得洗手

Q2：烙鐵要多少瓦比較好？

40-60W 溫控烙鐵最適合。
- 功率太低：加熱慢，容易冷焊
- 功率太高：容易燒壞元件
- 有溫控最重要

Q3：為什麼焊錫不沾？

常見原因：
1. 烙鐵頭氧化 → 清潔後上錫
2. 焊盤氧化 → 用砂紙輕磨或加助焊劑
3. 溫度不足 → 提高溫度
4. 焊錫品質差 → 換品質好的焊錫

Q4：焊接時煙霧有毒嗎？

助焊劑燃燒的煙霧會刺激呼吸道。
- 保持通風
- 使用排煙風扇
- 不要直接吸入煙霧
- 長時間焊接建議戴口罩

Q5：如何練習焊接？

最佳練習方式：
1. 找廢棄電路板練習拆焊
2. 買便宜的焊接練習套件
3. 在洞洞板上焊接 LED 和電阻
4. 逐步挑戰更複雜的專案

Q6：元件焊反了怎麼辦？

拆焊重焊：
1. 用吸錫器或吸錫線移除焊錫
2. 加熱後輕輕取出元件
3. 清理焊孔
4. 正確方向重新焊接

十一、重點總結

必記要點

  1. 溫度適當 - 有鉛 320-350°C，無鉛 350-380°C
  2. 同時加熱 - 烙鐵頭接觸焊盤和元件腳
  3. 焊錫接觸焊點 - 不是接觸烙鐵頭
  4. 時間控制 - 總共 3-5 秒，太久會燒壞
  5. 保持清潔 - 烙鐵頭要經常清潔和上錫

良好焊點檢查

✓ 光滑有光澤
✓ 圓錐形覆蓋完整
✓ 焊錫量適中
✓ 無冷焊或橋接
✓ 元件腳可見輪廓

安全守則

✓ 使用烙鐵架
✓ 保持通風
✓ 使用後洗手
✓ 不用時關閉電源
✓ 遠離易燃物
