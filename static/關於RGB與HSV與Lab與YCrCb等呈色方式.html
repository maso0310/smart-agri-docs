關於 RGB、HSV、Lab、YCrCb 等呈色方式

色彩空間（Color Space）是描述和組織顏色的數學模型。在影像處理、電腦視覺和農業影像分析中，選擇適當的色彩空間對於分割、偵測和分類任務至關重要。

一、色彩空間概述

為什麼需要不同色彩空間

  • RGB：適合顯示和儲存
  • HSV/HSL：直覺描述顏色，適合色彩分割
  • Lab：感知均勻，適合顏色比較
  • YCrCb：亮度與色度分離，適合壓縮

色彩空間分類

類型色彩空間特點
加色型RGB, sRGB螢幕顯示
減色型CMYK印刷
感知型HSV, HSL, Lab接近人類感知
亮度色度分離YCbCr, YUV視訊壓縮

二、RGB 色彩空間

原理

RGB（Red, Green, Blue）是基於人眼三種視錐細胞的加色模型：

  • R（紅）：0-255
  • G（綠）：0-255
  • B（藍）：0-255

特點

優點缺點
硬體直接支援、廣泛使用 三個通道相關性高
無需轉換即可顯示 不符合人類色彩感知
計算簡單 亮度與色彩混合

三、HSV/HSL 色彩空間

HSV 原理

HSV（Hue, Saturation, Value）以更直覺的方式描述顏色：

  • H（色相）：顏色種類，0-360°（OpenCV 中 0-179）
  • S（飽和度）：顏色純度，0-255
  • V（明度）：亮暗程度，0-255

色相環

HSV 色相值對照（OpenCV）：
┌─────────────────────────────────┐
│   0° = 紅色      (H ≈ 0)        │
│  30° = 橙色      (H ≈ 15)       │
│  60° = 黃色      (H ≈ 30)       │
│  90° = 黃綠      (H ≈ 45)       │
│ 120° = 綠色      (H ≈ 60)       │
│ 150° = 青綠      (H ≈ 75)       │
│ 180° = 青色      (H ≈ 90)       │
│ 210° = 藍色      (H ≈ 105)      │
│ 240° = 靛色      (H ≈ 120)      │
│ 270° = 紫色      (H ≈ 135)      │
│ 300° = 洋紅      (H ≈ 150)      │
│ 330° = 玫紅      (H ≈ 165)      │
└─────────────────────────────────┘
注意：OpenCV 的 H 範圍是 0-179（= 原始值/2）

HSV 顏色分割

import cv2
import numpy as np

def color_segmentation(image, color='green'):
    """
    使用 HSV 進行顏色分割
    """
    # 轉換為 HSV
    hsv = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)

    # 常用顏色範圍
    color_ranges = {
        'red':    ([0, 100, 100], [10, 255, 255]),     # 紅色（低）
        'red2':   ([160, 100, 100], [179, 255, 255]),  # 紅色（高）
        'orange': ([10, 100, 100], [25, 255, 255]),
        'yellow': ([25, 100, 100], [35, 255, 255]),
        'green':  ([35, 100, 100], [85, 255, 255]),
        'blue':   ([100, 100, 100], [130, 255, 255]),
        'purple': ([130, 100, 100], [160, 255, 255]),
    }

    lower, upper = color_ranges.get(color, ([0, 0, 0], [179, 255, 255]))
    lower = np.array(lower)
    upper = np.array(upper)

    # 建立遮罩
    mask = cv2.inRange(hsv, lower, upper)

    # 套用遮罩
    result = cv2.bitwise_and(image, image, mask=mask)

    return mask, result

# 植物綠色分割範例
img = cv2.imread('plant.jpg')
mask, green_only = color_segmentation(img, 'green')

四、Lab 色彩空間

原理

CIE Lab（或 CIELAB）是感知均勻的色彩空間：

  • L（明度）：0-100，黑到白
  • a：-128 到 +127，綠色到紅色
  • b：-128 到 +127，藍色到黃色

特點

  • 感知均勻：數值差異對應視覺差異
  • 設備獨立：不依賴特定硬體
  • 涵蓋所有可見色

農業應用：葉綠素相關分析

import cv2
import numpy as np

def analyze_leaf_greenness(image):
    """
    使用 Lab 分析葉片綠度
    a* 通道與葉綠素含量相關
    """
    # 轉換為 Lab
    lab = cv2.cvtColor(image, cv2.COLOR_BGR2LAB)

    # 分離通道
    L, a, b = cv2.split(lab)

    # a* 通道：負值表示綠色，正值表示紅色
    # OpenCV 中 a 的範圍是 0-255（128 為中點）

    # 計算綠度指標
    greenness = 128 - a.astype(float)  # 越大越綠

    # 統計分析
    mean_greenness = np.mean(greenness)
    std_greenness = np.std(greenness)

    return {
        'mean_greenness': mean_greenness,
        'std_greenness': std_greenness,
        'greenness_map': greenness
    }

# 使用範例
img = cv2.imread('leaf.jpg')
result = analyze_leaf_greenness(img)
print(f"平均綠度: {result['mean_greenness']:.2f}")

色彩差異計算（Delta E）

def delta_e_cie76(lab1, lab2):
    """
    計算兩個 Lab 顏色的差異（CIE76）
    """
    L1, a1, b1 = lab1
    L2, a2, b2 = lab2
    return np.sqrt((L2-L1)**2 + (a2-a1)**2 + (b2-b1)**2)

# 差異解讀
# ΔE < 1：難以察覺
# 1-2：細微差異
# 2-10：可察覺差異
# 10-49：明顯差異
# ΔE >= 100：完全不同顏色

五、YCrCb 色彩空間

原理

YCrCb（或 YCbCr）分離亮度與色度：

  • Y（亮度）：明暗資訊
  • Cr（紅色色度）：紅色與亮度的差異
  • Cb（藍色色度）：藍色與亮度的差異

轉換公式

Y  =  0.299R + 0.587G + 0.114B
Cb = -0.169R - 0.331G + 0.500B + 128
Cr =  0.500R - 0.419G - 0.081B + 128

膚色偵測範例

import cv2
import numpy as np

def skin_detection_ycrcb(image):
    """
    使用 YCrCb 進行膚色偵測
    """
    # 轉換為 YCrCb
    ycrcb = cv2.cvtColor(image, cv2.COLOR_BGR2YCrCb)

    # 膚色範圍（經驗值）
    lower = np.array([0, 133, 77])
    upper = np.array([255, 173, 127])

    # 建立遮罩
    mask = cv2.inRange(ycrcb, lower, upper)

    # 形態學處理
    kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))
    mask = cv2.morphologyEx(mask, cv2.MORPH_OPEN, kernel)
    mask = cv2.morphologyEx(mask, cv2.MORPH_CLOSE, kernel)

    return mask

應用場景

  • 視訊壓縮（JPEG、MPEG）
  • 膚色偵測
  • 照明變化不敏感的分析

CMYK（印刷用）

def rgb_to_cmyk(r, g, b):
    """RGB 轉 CMYK"""
    r, g, b = r/255, g/255, b/255
    k = 1 - max(r, g, b)
    if k == 1:
        return 0, 0, 0, 1
    c = (1-r-k) / (1-k)
    m = (1-g-k) / (1-k)
    y = (1-b-k) / (1-k)
    return c, m, y, k

七、色彩空間比較

色彩空間優點缺點適用場景
RGB 直接使用、廣泛支援 通道相關、光照敏感 顯示、儲存
HSV 直覺描述、色相獨立 不均勻、H 在低 S 時不穩定 顏色分割、物體追蹤
Lab 感知均勻、設備獨立 計算複雜 顏色比較、色彩校正
YCrCb 亮度分離、壓縮友善 不夠直覺 壓縮、膚色偵測

八、農業應用範例

植物健康分析

import cv2
import numpy as np

def plant_health_analysis(image):
    """
    綜合使用多種色彩空間分析植物健康
    """
    results = {}

    # 1. HSV - 綠色覆蓋率
    hsv = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)
    green_mask = cv2.inRange(hsv, (35, 40, 40), (85, 255, 255))
    green_ratio = np.sum(green_mask > 0) / green_mask.size
    results['green_coverage'] = green_ratio

    # 2. Lab - 綠度指標
    lab = cv2.cvtColor(image, cv2.COLOR_BGR2LAB)
    L, a, b = cv2.split(lab)
    greenness = 128 - a[green_mask > 0].astype(float)
    results['mean_greenness'] = np.mean(greenness) if len(greenness) > 0 else 0

    # 3. RGB - 計算植被指數
    B, G, R = cv2.split(image)
    R, G, B = R.astype(float), G.astype(float), B.astype(float)

    # 過綠指數 (ExG)
    exg = 2*G - R - B
    results['ExG'] = np.mean(exg[green_mask > 0]) if np.any(green_mask > 0) else 0

    # 綠紅差異指數
    grdi = (G - R) / (G + R + 1e-6)
    results['GRDI'] = np.mean(grdi[green_mask > 0]) if np.any(green_mask > 0) else 0

    return results

# 使用範例
img = cv2.imread('crop_field.jpg')
health = plant_health_analysis(img)
print(f"綠色覆蓋率: {health['green_coverage']:.2%}")
print(f"平均綠度: {health['mean_greenness']:.2f}")
print(f"過綠指數: {health['ExG']:.2f}")

果實成熟度判斷

def fruit_ripeness(image, fruit_mask):
    """
    根據顏色判斷果實成熟度
    """
    # 只分析果實區域
    hsv = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)
    h, s, v = cv2.split(hsv)

    # 取得果實區域的色相
    fruit_hue = h[fruit_mask > 0]

    if len(fruit_hue) == 0:
        return 'unknown'

    mean_hue = np.mean(fruit_hue)

    # 以蘋果為例判斷成熟度
    if mean_hue < 15 or mean_hue > 165:  # 紅色區域
        return 'ripe'
    elif 15 <= mean_hue < 35:  # 橙黃色
        return 'nearly_ripe'
    elif 35 <= mean_hue < 85:  # 綠色
        return 'unripe'
    else:
        return 'unknown'
