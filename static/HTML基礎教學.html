🌐 HTML 基礎教學

網頁結構的基礎 - 超文本標記語言

📚 什麼是 HTML？

HTML (HyperText Markup Language) 是建立網頁的標準語言。它使用「標籤」來描述網頁的結構和內容。

🏗️ 網頁的骨架

HTML 定義了網頁的結構，就像房子的骨架一樣。

🏷️ 標籤語言

使用 <標籤> 來標記內容的意義和結構。

第一個 HTML 頁面

<!-- 這是一個完整的 HTML 文件 --> <!DOCTYPE html> <html lang="zh-TW"> <head> <meta charset="UTF-8"> <title>我的第一個網頁</title> </head> <body> <h1>歡迎來到我的網頁！</h1> <p>這是我的第一個 HTML 頁面。</p> </body> </html>
💡 HTML 文件結構：
• <!DOCTYPE html>：聲明這是 HTML5 文件
• <html>：整個網頁的根元素
• <head>：網頁的設定資訊（標題、編碼等）
• <body>：網頁的可見內容

🏷️ 常用 HTML 標籤

文字相關標籤

標籤 說明 範例
<h1> ~ <h6> 標題（h1 最大，h6 最小） <h1>主標題</h1>
<p> 段落 <p>這是一段文字</p>
<strong> 粗體（重要文字） <strong>重要</strong>
<em> 斜體（強調） <em>強調</em>
<br> 換行 第一行<br>第二行
<hr> 水平線 <hr>
<h1>智慧農業系統</h1> <h2>系統功能介紹</h2> <p> 本系統使用 <strong>AI 技術</strong> 進行作物分析， 能夠 <em>即時監測</em> 農田狀態。 </p> <hr> <h3>主要功能</h3>

連結與圖片

<!-- 超連結 --> <a href="https://example.com">點擊前往</a> <!-- 新分頁開啟 --> <a href="page.html" target="_blank">新分頁開啟</a> <!-- 圖片 --> <img src="photo.jpg" alt="圖片說明"> <!-- 設定圖片大小 --> <img src="crop.jpg" alt="作物照片" width="300">

清單

<!-- 無序清單（項目符號） --> <ul> <li>蘋果</li> <li>香蕉</li> <li>橘子</li> </ul> <!-- 有序清單（數字編號） --> <ol> <li>收集資料</li> <li>訓練模型</li> <li>部署應用</li> </ol>

📊 表格

<table border="1"> <!-- 表頭 --> <thead> <tr> <th>作物</th> <th>產量</th> <th>狀態</th> </tr> </thead> <!-- 表格內容 --> <tbody> <tr> <td>水稻</td> <td>500 公斤</td> <td>健康</td> </tr> <tr> <td>玉米</td> <td>300 公斤</td> <td>需注意</td> </tr> </tbody> </table>
💡 表格結構：
• <table>：整個表格
• <tr>：表格的一列 (table row)
• <th>：表頭儲存格 (table header)
• <td>：一般儲存格 (table data)

📝 表單

表單用於收集使用者輸入的資料。

<form action="/submit" method="POST"> <!-- 文字輸入 --> <label for="name">姓名：</label> <input type="text" id="name" name="name" placeholder="請輸入姓名"> <!-- 數字輸入 --> <label for="temp">溫度：</label> <input type="number" id="temp" name="temp" min="0" max="50"> <!-- 滑桿 --> <label for="humidity">濕度：</label> <input type="range" id="humidity" min="0" max="100"> <!-- 下拉選單 --> <label for="crop">作物類型：</label> <select id="crop" name="crop"> <option value="rice">水稻</option> <option value="corn">玉米</option> <option value="wheat">小麥</option> </select> <!-- 核取方塊 --> <input type="checkbox" id="notify" name="notify"> <label for="notify">接收通知</label> <!-- 單選按鈕 --> <input type="radio" id="auto" name="mode" value="auto"> <label for="auto">自動模式</label> <input type="radio" id="manual" name="mode" value="manual"> <label for="manual">手動模式</label> <!-- 提交按鈕 --> <button type="submit">送出</button> </form>

常用 input 類型

type 說明 範例
text 單行文字 姓名、地址
password 密碼（隱藏字元） 登入密碼
number 數字 溫度、數量
email 電子郵件 會驗證 @ 符號
date 日期選擇器 選擇日期
file 檔案上傳 上傳圖片
color 顏色選擇器 選擇顏色

📦 區塊元素與行內元素

<div> 區塊元素

佔據整行，用來建立區塊容器。像一個大箱子，可以包含其他元素。

<div class="container"> <h2>區塊標題</h2> <p>區塊內容</p> </div>

<span> 行內元素

不換行，用來標記一小段文字。像一個小標籤，可以套用樣式。

<p> 這是 <span class="highlight">重要</span> 的文字 </p>

🏷️ HTML5 語意化標籤

HTML5 引入了語意化標籤，讓網頁結構更清楚，也有助於 SEO。

<body>
<header> 頁首（Logo、導航）</header>
<nav> 導航選單 </nav>
<main>
<article> 文章內容 </article>
<section> 章節 </section>
<aside> 側邊欄 </aside>
</main>
<footer> 頁尾（版權、聯絡）</footer>
</body>
<header> <h1>智慧農業平台</h1> <nav> <a href="/">首頁</a> <a href="/monitor">監測</a> <a href="/analysis">分析</a> </nav> </header> <main> <article> <h2>今日農場報告</h2> <section> <h3>溫度狀況</h3> <p>目前溫度 25°C...</p> </section> </article> </main> <footer> <p>© 2024 智慧農業系統</p> </footer>

⚙️ 常用屬性

屬性 說明 範例
id 唯一識別碼（頁面中只能有一個） <div id="main">
class 類別名稱（可重複使用） <p class="info">
style 行內 CSS 樣式 <p style="color: red">
title 滑鼠懸停時的提示文字 <abbr title="全稱">
data-* 自訂資料屬性 <div data-value="100">
<!-- id 與 class 的使用 --> <div id="sensor-panel" class="panel active"> <p class="reading" data-sensor="temp">溫度: 25°C</p> <p class="reading" data-sensor="humidity">濕度: 60%</p> </div>
