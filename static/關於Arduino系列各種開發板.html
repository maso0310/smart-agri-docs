Arduino 系列各種開發板

前言

Arduino 有許多不同型號的開發板，各有不同的特性和用途。本文介紹常見的開發板，幫助你選擇適合的型號。

官方 Arduino 開發板

Arduino Leonardo

規格 數值
微控制器 ATmega32U4
工作電壓 5V
數位 I/O 20 個（7 個可 PWM）
類比輸入 12 個
Flash 記憶體 32 KB
SRAM 2.5 KB
時脈速度 16 MHz
USB 介面 Micro-USB（原生 USB）
尺寸 68.6 x 53.3 mm

特點：

  • 原生 USB 支援：可模擬鍵盤、滑鼠
  • 不需要額外的 USB 轉 Serial 晶片

適用場景：

  • 自製鍵盤/滑鼠
  • 遊戲控制器
  • USB HID 設備
  • 自動化腳本（模擬鍵盤輸入）

範例：模擬鍵盤

#include <Keyboard.h>

void setup() {
  Keyboard.begin();
}

void loop() {
  if (digitalRead(2) == LOW) {
    Keyboard.print("Hello World!");
    delay(1000);
  }
}

Arduino Due

規格 數值
微控制器 AT91SAM3X8E（32 位元 ARM）
工作電壓 3.3V ⚠️
數位 I/O 54 個（12 個可 PWM）
類比輸入 12 個
類比輸出 2 個（DAC）
Flash 記憶體 512 KB
SRAM 96 KB
時脈速度 84 MHz
尺寸 101.5 x 53.3 mm

特點：

  • 32 位元 ARM 處理器：效能遠超 8 位元板
  • 真正的類比輸出（DAC）
  • 運算速度快

注意事項：

  • ⚠️ 工作電壓是 3.3V，不能接 5V 訊號！
  • 部分 5V 的擴充板/模組無法直接使用

適用場景：

  • 需要高運算效能
  • 音訊處理
  • 訊號處理
  • 需要真正類比輸出

微控制器 ESP8266（32 位元）
工作電壓 3.3V ⚠️

類比輸入 1 個（0-1V）

常見型號：

  • NodeMCU：有 USB，方便開發
  • D1 Mini：更小，適合專案
  • ESP-01：最小，只有 2 個 GPIO

特點：

  • 內建 WiFi
  • 效能比 Arduino Uno 強很多
  • 便宜

注意事項：

  • ⚠️ 工作電壓是 3.3V
  • GPIO 腳位編號與 Arduino 不同
  • 類比輸入範圍只有 0-1V

適用場景：

  • 物聯網 (IoT) 專案
  • WiFi 遠端控制
  • 智慧家庭
  • 資料上傳雲端

混用時的注意事項

5V Arduino 接 3.3V 模組（如 ESP-01）：

Arduino TX (5V) ──[分壓電路]── ESP-01 RX (3.3V)
Arduino RX (5V) ──────────── ESP-01 TX (3.3V)  ← 這方向 OK

分壓電路：
5V ── R1(1kΩ) ──┬── 3.3V 輸出
                │
           R2(2kΩ)
                │
               GND

3.3V 模組接 5V 感測器：

  • 需要使用電平轉換模組
  • 或選擇 3.3V 相容的感測器

常見問題

Q1: 初學者該買哪一款？

A: Arduino Uno。資源最多、教學最完整、接腳間距大方便接線。

Q2: 想做物聯網該買哪一款？

A: ESP32 或 NodeMCU。內建 WiFi，不需要額外模組。

Q3: Arduino Nano 和 Uno 哪個好？

A: 核心規格相同，差別在體積。需要插麵包板選 Nano，需要方便接杜邦線選 Uno。

Q4: 副廠板能用嗎？

A: 可以，功能一樣。但可能需要安裝 CH340 驅動程式，品質也較不穩定。

Q5: ESP32 和 Arduino 哪個好？

A:

  • 需要 WiFi/藍牙 → ESP32
  • 純學習/簡單專案 → Arduino Uno（資源多、問題好解決）
  • 兩者都會是最好的

總結

入門推薦

第一塊板：Arduino Uno（學習基礎）
         ↓
第二塊板：ESP8266/NodeMCU（學習物聯網）
         ↓
第三塊板：ESP32（進階專案）

一句話選擇指南

  • 什麼都不會 → Arduino Uno
  • 要連網 → ESP32 / NodeMCU
  • 要很多腳位 → Arduino Mega
  • 要做鍵盤滑鼠 → Arduino Leonardo
  • 要最小體積 → Arduino Pro Mini / ESP-01
  • 要最強效能 → ESP32
