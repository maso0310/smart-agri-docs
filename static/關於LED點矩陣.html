關於 LED 點矩陣

前言：LED 點矩陣能做什麼？

LED 點矩陣（LED Matrix）是由多個 LED 排列成矩陣形式的顯示裝置，可以用來：

  • 顯示數字、文字
  • 顯示簡單圖案、表情符號
  • 製作跑馬燈效果
  • 顯示動畫
  • 作為狀態指示器

相較於 LCD 螢幕，LED 點矩陣更亮、更醒目，適合遠距離觀看！

一、LED 點矩陣是什麼？

一句話解釋

LED 點矩陣是將多顆 LED 排列成網格狀，透過控制每顆 LED 的亮滅來顯示圖案的顯示裝置。

常見規格

二、為什麼需要 MAX7219 驅動晶片？

問題：腳位不夠

如果直接控制 8x8 LED 矩陣：

傳統接法需要的腳位：
- 8 條行線（Row）
- 8 條列線（Column）
- 總共需要 16 個腳位！

而且還需要：
- 限流電阻 x 64
- 複雜的掃描程式

Arduino Uno 只有 14 個數位腳位，根本不夠！

解決方案：MAX7219

使用 MAX7219 驅動晶片：

    Arduino              MAX7219              LED 矩陣
    ┌───────┐           ┌─────────┐          ┌────────┐
    │       │           │         │          │ ●●●●●● │
    │   DIN ├───────────┤ DIN     ├──────────┤ ●●●●●● │
    │    CS ├───────────┤ CS      │內建驅動  │ ●●●●●● │
    │   CLK ├───────────┤ CLK     │和掃描    │ ●●●●●● │
    │       │           │         │          │ ●●●●●● │
    │    5V ├───────────┤ VCC     │          │ ●●●●●● │
    │   GND ├───────────┤ GND     │          │ ●●●●●● │
    │       │           │         │          │ ●●●●●● │
    └───────┘           └─────────┘          └────────┘

優點：
✓ 只需要 3 個腳位（DIN, CS, CLK）
✓ 內建掃描電路，不佔用 Arduino 運算資源
✓ 內建限流電阻
✓ 可調整亮度（16 階）
✓ 可串接多個模組

┌───────┐    ┌────────┐    ┌────────┐    ┌────────┐

可以串接 8 個以上的模組！
仍然只需要 3 個控制腳位

每一行（Row）可以用 1 個位元組（8 bits）表示：

行 1: ● ● ● ● ● ● ● ●  = 0b11111111 = 0xFF
行 2: ● ● ● ● ● ● ● ●  = 0b11111111 = 0xFF
行 3: ● ● ● ● ● ● ● ●  = 0b11111111 = 0xFF

行 5: ○ ○ ● ● ● ● ○ ○  = 0b00111100 = 0x3C

四、接線方式

單一模組接線

Arduino Uno 與 MAX7219 LED 點矩陣接線：

    Arduino UNO              MAX7219 模組
    ┌─────────┐             ┌─────────────┐
    │         │             │    [LED]    │
    │      5V ├─────────────┤ VCC         │
    │         │             │             │
    │     GND ├─────────────┤ GND         │
    │         │             │             │
    │     D12 ├─────────────┤ DIN         │  ← 資料輸入
    │         │             │             │
    │     D11 ├─────────────┤ CLK         │  ← 時脈
    │         │             │             │
    │     D10 ├─────────────┤ CS          │  ← 晶片選擇
    │         │             │             │
    └─────────┘             └─────────────┘

    只需要 5 條線！

    DIN → DOUT → DIN → DOUT → DIN → DOUT → DIN
    資料從第一個模組傳到最後一個

電源注意事項

⚠️ 電源需求計算：

每個 MAX7219 模組：
- 工作電流：約 10-50mA（視亮度而定）
- 最大電流：約 320mA（全亮時）

4 個模組全亮：約 1.3A
Arduino 5V 腳位最大輸出：約 500mA

解決方案：
- 少量模組（1-2 個）：可用 Arduino 5V
- 多量模組（3 個以上）：需要外接 5V 電源

外接電源接法：
┌──────────┐
│ 5V 2A    │
│ 電源供應 ├───→ 模組 VCC
│          │
│   GND  ──┼───→ 模組 GND ←─┬─ Arduino GND
└──────────┘                │
                            共地！

六、Arduino 程式範例

範例 1：基本測試（LedControl）

/*
 * MAX7219 LED 點矩陣基本測試
 * 依序點亮每顆 LED
 */

#include <LedControl.h>

// 建立 LedControl 物件
// 參數：DIN, CLK, CS, 模組數量
LedControl lc = LedControl(12, 11, 10, 1);

void setup() {
  // 初始化模組 0
  lc.shutdown(0, false);   // 喚醒模組（預設是省電模式）
  lc.setIntensity(0, 8);   // 設定亮度（0-15）
  lc.clearDisplay(0);      // 清除顯示
}

void loop() {
  // 依序點亮每顆 LED
  for (int row = 0; row < 8; row++) {
    for (int col = 0; col < 8; col++) {
      lc.setLed(0, row, col, true);   // 點亮
      delay(50);
      lc.setLed(0, row, col, false);  // 熄滅
    }
  }
}

範例 5：跑馬燈效果（MD_Parola）

/*
 * LED 點矩陣跑馬燈
 * 使用 MD_Parola 程式庫
 */

#include <MD_Parola.h>
#include <MD_MAX72xx.h>
#include <SPI.h>

// 定義硬體類型
#define HARDWARE_TYPE MD_MAX72XX::FC16_HW

// 定義腳位
#define MAX_DEVICES 4  // 模組數量
#define CLK_PIN   13
#define DATA_PIN  11
#define CS_PIN    10

// 建立 Parola 物件
MD_Parola display = MD_Parola(HARDWARE_TYPE, DATA_PIN, CLK_PIN, CS_PIN, MAX_DEVICES);

void setup() {
  display.begin();
  display.setIntensity(5);  // 亮度 0-15
  display.displayClear();

  // 設定跑馬燈效果
  display.displayScroll(
    "Hello Arduino!",  // 文字
    PA_CENTER,         // 對齊方式
    PA_SCROLL_LEFT,    // 捲動方向
    100                // 速度（毫秒）
  );
}

void loop() {
  if (display.displayAnimate()) {
    display.displayReset();
  }
}

範例 6：顯示感測器數值

/*
 * 在 LED 點矩陣上顯示溫度
 */

#include <MD_Parola.h>
#include <MD_MAX72xx.h>
#include <DHT.h>

#define HARDWARE_TYPE MD_MAX72XX::FC16_HW
#define MAX_DEVICES 4
#define DATA_PIN  11
#define CLK_PIN   13
#define CS_PIN    10
#define DHT_PIN   2

MD_Parola display = MD_Parola(HARDWARE_TYPE, DATA_PIN, CLK_PIN, CS_PIN, MAX_DEVICES);
DHT dht(DHT_PIN, DHT11);

char message[20];
unsigned long lastUpdate = 0;

void setup() {
  display.begin();
  display.setIntensity(5);
  dht.begin();

  display.displayText("Starting...", PA_CENTER, 50, 0, PA_SCROLL_LEFT, PA_SCROLL_LEFT);
}

void loop() {
  if (display.displayAnimate()) {
    // 每 5 秒更新一次
    if (millis() - lastUpdate > 5000) {
      float temp = dht.readTemperature();
      float humi = dht.readHumidity();

      if (!isnan(temp) && !isnan(humi)) {
        sprintf(message, "T:%.1fC H:%.0f%%", temp, humi);
      } else {
        sprintf(message, "Sensor Error!");
      }

      display.displayText(message, PA_CENTER, 50, 0, PA_SCROLL_LEFT, PA_SCROLL_LEFT);
      lastUpdate = millis();
    }

    display.displayReset();
  }
}

  if (display.displayAnimate()) {
    currentEffect = (currentEffect + 1) % numEffects;
    showNextEffect();
  }
}

void showNextEffect() {
  display.displayText(
    effectNames[currentEffect],
    PA_CENTER,
    50,
    2000,  // 暫停時間
    effects[currentEffect],
    effects[currentEffect]
  );
}

範例 8：互動式亮度控制

/*
 * 使用電位器控制 LED 點矩陣亮度
 */

#include <LedControl.h>

LedControl lc = LedControl(12, 11, 10, 1);
const int POT_PIN = A0;

byte pattern[8] = {
  B11111111,
  B10000001,
  B10111101,
  B10100101,
  B10100101,
  B10111101,
  B10000001,
  B11111111
};

void setup() {
  lc.shutdown(0, false);
  lc.clearDisplay(0);

  // 顯示固定圖案
  for (int row = 0; row < 8; row++) {
    lc.setRow(0, row, pattern[row]);
  }

  Serial.begin(9600);
}

void loop() {
  // 讀取電位器
  int potValue = analogRead(POT_PIN);

  // 對應到亮度（0-15）
  int brightness = map(potValue, 0, 1023, 0, 15);

  // 設定亮度
  lc.setIntensity(0, brightness);

  Serial.print("亮度：");
  Serial.println(brightness);

  delay(100);
}

九、常見問題排解

問題 1：完全不亮

檢查步驟：

□ 1. 電源接好了嗎？（VCC → 5V, GND → GND）
□ 2. 控制線接對了嗎？（DIN, CLK, CS）
□ 3. 程式有執行 shutdown(0, false) 嗎？
     → MAX7219 預設是省電模式（關閉）
□ 4. 亮度設定是 0 嗎？
     → setIntensity(0, 8) 設定亮度
□ 5. 模組數量設定正確嗎？

問題 2：顯示亂碼或鏡像

可能原因與解決方法：

1. 硬體類型設定錯誤
   → 嘗試不同的 HARDWARE_TYPE

2. 模組方向裝反
   → 物理旋轉模組
   → 或用程式翻轉

3. 串接順序錯誤
   → 檢查 DIN → DOUT 的連接順序

問題 3：多模組只有部分亮

檢查步驟：

□ 1. 電源是否足夠？
     → 多模組需要外接電源

□ 2. 串接線是否鬆動？
     → 檢查 DOUT → DIN 連接

□ 3. MAX_DEVICES 數量正確嗎？
     → 要和實際模組數量一致

問題 4：亮度不均勻

可能原因：

1. 電源不足
   → 使用外接電源
   → 縮短電源線

2. 接線電阻
   → 使用較粗的電源線
   → 在每個模組 VCC-GND 加電容

3. LED 品質差異
   → 正常現象，低價模組常見
