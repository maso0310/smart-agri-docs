關於 RTK 定位技術

RTK（Real-Time Kinematic，即時動態定位）是一種高精度 GNSS 定位技術，可達到公分級甚至毫米級的定位精度。在智慧農業中，RTK 技術是實現自動駕駛農機、精準施肥、變量噴灑等應用的關鍵基礎。

一、GNSS 定位基礎

什麼是 GNSS

GNSS（Global Navigation Satellite System，全球導航衛星系統）是所有衛星定位系統的總稱：

系統名稱 營運國家 衛星數量 覆蓋範圍
GPS 美國 31 顆 全球
GLONASS 俄羅斯 24 顆 全球
Galileo 歐盟 30 顆 全球
BeiDou（北斗） 中國 35 顆 全球
QZSS 日本 4 顆 亞太區域

定位原理

GNSS 定位基於三邊測量原理：

  1. 接收器接收來自多顆衛星的訊號
  2. 計算訊號從衛星到接收器的傳播時間
  3. 時間 × 光速 = 距離
  4. 至少需要 4 顆衛星（3 顆定位 + 1 顆校正時間）

一般手機 GPS 精度約 3-10 公尺，無法滿足精準農業需求。

二、RTK 技術原理

差分定位概念

RTK 使用差分定位技術消除大部分誤差：

  1. 在已知位置架設基準站（Base Station）
  2. 基準站計算實際位置與衛星定位的差異（校正值）
  3. 透過無線電或網路將校正值即時傳送給移動站（Rover）
  4. 移動站套用校正值，獲得高精度位置

RTK 工作模式

     衛星群
    ↙  ↓  ↘
   /   |   \
  ↓    ↓    ↓
┌────┐    ┌────┐
│基準站│←→│移動站│  ← 即時通訊傳送校正值
└────┘    └────┘
  │         │
已知座標   計算精確位置

載波相位測量

RTK 的關鍵技術是載波相位測量：

  • 碼相位：測量訊號碼的到達時間（精度：公尺級）
  • 載波相位：測量載波波長的相位（精度：公分級）

GPS L1 載波波長約 19 cm，透過精確測量相位可達到毫米級精度。

整數模糊度解算

載波相位測量的挑戰是整數模糊度（Integer Ambiguity）問題：

  • 接收器只能測量相位的小數部分
  • 需要確定訊號經過了幾個完整波長
  • 固定解（Fixed Solution）：成功解算整數模糊度，精度最高
  • 浮動解（Float Solution）：未能確定整數，精度較低

五、農業 RTK 應用

1. 自動駕駛農機

RTK 是農機自動駕駛的核心技術：

  • 直線導引：確保作業路徑筆直，減少重疊與漏作
  • 自動轉向：公分級精度的路徑追蹤
  • 地頭迴轉：精確的迴轉路徑規劃
  • 夜間作業：不依賴視覺導航

2. 變量作業

應用 精度需求 說明
變量施肥 10-30 cm 依處方圖調整施肥量
變量噴藥 10-30 cm 精準噴灑減少農藥用量
變量播種 2-5 cm 精準株距控制
精準收穫 10-30 cm 產量地圖記錄

3. 農地測量與管理

  • 田區邊界測量：精確記錄農地範圍
  • 地形測量：整地、排水規劃
  • 樣點定位：土壤取樣點精確定位
  • 設施定位：灌溉設施、感測器布設

4. 無人機應用

  • 精準航測：高精度正射影像
  • 精準噴灑：RTK 導航的植保無人機
  • 地面控制點減少：PPK/RTK 減少 GCP 需求

七、實作範例

NMEA 訊息解析

GNSS 接收器通常輸出 NMEA 0183 格式的資料：

import serial
import pynmea2

def parse_gnss_data(port='/dev/ttyUSB0', baudrate=115200):
    """
    解析 GNSS NMEA 訊息
    """
    ser = serial.Serial(port, baudrate, timeout=1)

    while True:
        line = ser.readline().decode('ascii', errors='replace').strip()

        if line.startswith('$'):
            try:
                msg = pynmea2.parse(line)

                # GGA - 定位資訊
                if isinstance(msg, pynmea2.GGA):
                    print(f"時間: {msg.timestamp}")
                    print(f"緯度: {msg.latitude:.8f}")
                    print(f"經度: {msg.longitude:.8f}")
                    print(f"高度: {msg.altitude} m")
                    print(f"定位品質: {msg.gps_qual}")
                    # 0=無效, 1=GPS, 2=DGPS, 4=RTK Fixed, 5=RTK Float
                    print(f"衛星數: {msg.num_sats}")
                    print(f"HDOP: {msg.horizontal_dil}")
                    print("-" * 40)

            except pynmea2.ParseError:
                continue

NTRIP 客戶端連接

import socket
import base64

class NTRIPClient:
    """
    NTRIP 客戶端 - 連接網路 RTK 服務
    """
    def __init__(self, host, port, mountpoint, user, password):
        self.host = host
        self.port = port
        self.mountpoint = mountpoint
        self.user = user
        self.password = password
        self.socket = None

    def connect(self):
        """建立連接"""
        self.socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        self.socket.connect((self.host, self.port))

        # 建立認證字串
        auth = base64.b64encode(
            f"{self.user}:{self.password}".encode()
        ).decode()

        # 發送請求
        request = (
            f"GET /{self.mountpoint} HTTP/1.1\r\n"
            f"Host: {self.host}\r\n"
            f"Ntrip-Version: Ntrip/2.0\r\n"
            f"User-Agent: NTRIP PythonClient\r\n"
            f"Authorization: Basic {auth}\r\n"
            f"\r\n"
        )
        self.socket.send(request.encode())

        # 讀取回應
        response = self.socket.recv(1024).decode()
        if 'ICY 200 OK' in response or '200 OK' in response:
            print("NTRIP 連接成功！")
            return True
        else:
            print(f"連接失敗: {response}")
            return False

    def send_gga(self, gga_sentence):
        """發送 GGA 訊息給伺服器（回報位置）"""
        if self.socket:
            self.socket.send(gga_sentence.encode())

    def receive_rtcm(self):
        """接收 RTCM 校正資料"""
        if self.socket:
            return self.socket.recv(4096)
        return None

座標轉換

import math

def wgs84_to_twd97(lat, lon):
    """
    WGS84 經緯度轉 TWD97 二度分帶座標
    """
    # 中央經線 121 度
    lon0 = 121.0 * math.pi / 180

    # WGS84 橢球參數
    a = 6378137.0           # 半長軸
    f = 1 / 298.257223563   # 扁率

    # 轉弧度
    lat_rad = lat * math.pi / 180
    lon_rad = lon * math.pi / 180

    # 計算參數
    e2 = 2 * f - f * f
    e4 = e2 * e2
    e6 = e4 * e2

    N = a / math.sqrt(1 - e2 * math.sin(lat_rad)**2)
    T = math.tan(lat_rad)**2
    C = e2 / (1 - e2) * math.cos(lat_rad)**2
    A = (lon_rad - lon0) * math.cos(lat_rad)

    # 子午線弧長
    M = a * (
        (1 - e2/4 - 3*e4/64 - 5*e6/256) * lat_rad
        - (3*e2/8 + 3*e4/32 + 45*e6/1024) * math.sin(2*lat_rad)
        + (15*e4/256 + 45*e6/1024) * math.sin(4*lat_rad)
        - (35*e6/3072) * math.sin(6*lat_rad)
    )

    # 計算 E, N
    k0 = 0.9999  # 中央經線尺度因子

    E = k0 * N * (
        A + (1-T+C) * A**3 / 6
        + (5-18*T+T**2+72*C-58*e2/(1-e2)) * A**5 / 120
    ) + 250000  # 假東距

    N_coord = k0 * (
        M + N * math.tan(lat_rad) * (
            A**2 / 2
            + (5-T+9*C+4*C**2) * A**4 / 24
            + (61-58*T+T**2+600*C-330*e2/(1-e2)) * A**6 / 720
        )
    )

    return E, N_coord

# 範例
lat, lon = 25.0330, 121.5654  # 台北
e, n = wgs84_to_twd97(lat, lon)
print(f"TWD97: E={e:.3f}, N={n:.3f}")

八、RTK 使用注意事項

影響定位品質的因素

  • 天空遮蔽：建築物、樹木會遮擋衛星訊號
  • 多路徑效應：訊號反射造成誤差
  • 基線長度：與基準站距離越遠，精度越低
  • 衛星幾何分布：PDOP 值越低越好
  • 電離層活動：太陽活動影響電離層

最佳實踐

  1. 確保天線有良好的天空視野（仰角 > 15°）
  2. 使用抗多路徑天線
  3. 基線長度盡量控制在 10 km 以內
  4. 等待固定解再開始作業
  5. 定期檢查基準站座標是否正確
  6. 記錄原始觀測資料以備事後處理

常見問題排解

問題 可能原因 解決方法
無法獲得固定解 衛星數不足、基線過長 改善天線位置、縮短基線
定位跳動 多路徑效應 遠離反射面、使用抑制天線
校正資料中斷 通訊問題 檢查網路/電台連線
座標偏移 座標系統不一致 確認使用相同座標框架
