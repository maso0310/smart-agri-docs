1. YOLO 簡介

YOLO（You Only Look Once） 是一種革命性的即時物件偵測演算法。與傳統方法需要掃描圖片多次不同，YOLO 只需要「看一眼」就能同時偵測出圖片中所有物件的位置和類別。

為什麼選擇 YOLO？

  • 速度快：可達到 30-60+ FPS 的即時偵測
  • 準確度高：最新版本 mAP 可達 50% 以上
  • 易於使用：Ultralytics 提供簡潔的 API
  • 開源免費：可商用的開源授權
  • 社群活躍：豐富的文件和社群支援

物件偵測 vs 圖像分類

任務 輸入 輸出 範例
圖像分類 一張圖片 類別標籤 「這是一顆蘋果」
物件偵測 一張圖片 多個物件的位置 + 類別 「左邊有蘋果、右邊有橘子」
語意分割 一張圖片 每個像素的類別 「這些像素是蘋果」

2. YOLO 版本演進

YOLOv1 (2015) 經典

Joseph Redmon 發表的開創性論文，首次實現端到端的即時物件偵測。

  • 將圖片分成 7×7 網格
  • 每個網格預測 2 個邊界框
  • 速度 45 FPS，但準確度較低

YOLOv2/YOLO9000 (2016)

引入 Batch Normalization、Anchor Boxes，支援 9000+ 類別偵測。

YOLOv3 (2018)

多尺度預測、更深的網路（Darknet-53），準確度大幅提升。

YOLOv4 (2020)

Alexey Bochkovskiy 接手開發，引入 CSPNet、Mish 激活函數、資料增強技術。

YOLOv5 (2020) 推薦使用

Ultralytics 開發，使用 PyTorch 實現，易於使用和部署。

  • 多種尺寸：n/s/m/l/x
  • 完整的訓練工具鏈
  • 支援 ONNX、TensorRT、CoreML 等格式匯出

YOLOv8 (2023) 最新版本

Ultralytics 最新力作，支援偵測、分割、姿態估計、追蹤等多種任務。

  • Anchor-free 設計
  • 更高的準確度和速度
  • 統一的 CLI 和 Python API
  • 內建資料增強和超參數調優

YOLO11 (2024) 最新

Ultralytics 最新版本，效能進一步提升。

版本選擇建議

使用場景 推薦版本 原因
初學入門 YOLOv8 API 簡潔、文件完整
生產部署 YOLOv5 / YOLOv8 穩定、社群支援好
邊緣裝置 YOLOv8n / YOLOv5n 模型小、速度快
高精度需求 YOLOv8x / YOLO11 準確度最高

3. 工作原理

核心概念

1. 網格劃分 (Grid Division)

YOLO 將輸入圖片劃分成 S×S 的網格（如 13×13）。每個網格負責偵測中心點落在該網格內的物件。

2. 邊界框預測 (Bounding Box)

每個網格預測多個邊界框，包含：

  • x, y：邊界框中心座標（相對於網格）
  • w, h：邊界框寬度和高度（相對於圖片）
  • confidence：物件存在的信心度

3. 類別預測 (Class Prediction)

每個邊界框預測各類別的機率分布，判斷物件屬於哪個類別。

4. 非極大值抑制 (NMS)

同一個物件可能被多個邊界框偵測到。NMS 會保留信心度最高的框，去除重疊的框。

邊界框格式：x, y, w, h

(x, y) = 中心點

關鍵術語

術語 說明
IoU (Intersection over Union) 預測框與真實框的重疊程度，用於評估偵測準確度
Confidence Score 模型對預測結果的信心度 (0-1)
Anchor Box 預設的邊界框形狀，幫助模型學習不同比例的物件
mAP (mean Average Precision) 物件偵測的主要評估指標
FPS (Frames Per Second) 每秒可處理的圖片數，衡量速度

5. 快速開始

6. 資料集準備

YOLO 資料集格式

YOLO 使用特定的資料集結構和標籤格式：

dataset/ ├── images/ │ ├── train/ │ │ ├── image001.jpg │ │ ├── image002.jpg │ │ └── ... │ └── val/ │ ├── image101.jpg │ └── ... ├── labels/ │ ├── train/ │ │ ├── image001.txt │ │ ├── image002.txt │ │ └── ... │ └── val/ │ ├── image101.txt │ └── ... └── data.yaml

標籤檔格式

每張圖片對應一個 .txt 標籤檔，每行代表一個物件：

# 格式：class_id x_center y_center width height # 所有數值都是相對於圖片尺寸的比例 (0-1) 0 0.45 0.32 0.12 0.18 1 0.72 0.65 0.08 0.15 0 0.21 0.48 0.15 0.22

座標格式說明

  • class_id：類別編號（從 0 開始）
  • x_center：邊界框中心 x 座標 / 圖片寬度
  • y_center：邊界框中心 y 座標 / 圖片高度
  • width：邊界框寬度 / 圖片寬度
  • height：邊界框高度 / 圖片高度

建立 data.yaml 設定檔

# data.yaml path: /path/to/dataset # 資料集根目錄 train: images/train # 訓練圖片路徑 (相對於 path) val: images/val # 驗證圖片路徑 test: images/test # 測試圖片路徑 (可選) # 類別設定 names: 0: healthy_apple 1: diseased_apple 2: rotten_apple # 或使用列表格式 # names: ['healthy_apple', 'diseased_apple', 'rotten_apple']

資料集分割腳本

import os import shutil import random from pathlib import Path def split_dataset(source_images, source_labels, output_dir, train_ratio=0.8, val_ratio=0.1, test_ratio=0.1): """ 將資料集分割為訓練、驗證、測試集 """ # 建立目錄結構 for split in ['train', 'val', 'test']: (Path(output_dir) / 'images' / split).mkdir(parents=True, exist_ok=True) (Path(output_dir) / 'labels' / split).mkdir(parents=True, exist_ok=True) # 取得所有圖片檔案 images = [f for f in os.listdir(source_images) if f.endswith(('.jpg', '.jpeg', '.png'))] random.shuffle(images) # 計算分割點 n = len(images) train_end = int(n * train_ratio) val_end = train_end + int(n * val_ratio) splits = { 'train': images[:train_end], 'val': images[train_end:val_end], 'test': images[val_end:] } # 複製檔案 for split, files in splits.items(): for img_file in files: # 複製圖片 src_img = Path(source_images) / img_file dst_img = Path(output_dir) / 'images' / split / img_file shutil.copy(src_img, dst_img) # 複製標籤 label_file = Path(img_file).stem + '.txt' src_label = Path(source_labels) / label_file dst_label = Path(output_dir) / 'labels' / split / label_file if src_label.exists(): shutil.copy(src_label, dst_label) print(f"訓練集: {len(splits['train'])} 張") print(f"驗證集: {len(splits['val'])} 張") print(f"測試集: {len(splits['test'])} 張") # 使用範例 split_dataset( source_images='raw_data/images', source_labels='raw_data/labels', output_dir='dataset' )

使用 Python 轉換標註格式

def convert_voc_to_yolo(xml_path, output_path, class_names): """ 將 Pascal VOC 格式轉換為 YOLO 格式 """ import xml.etree.ElementTree as ET tree = ET.parse(xml_path) root = tree.getroot() # 取得圖片尺寸 size = root.find('size') img_w = int(size.find('width').text) img_h = int(size.find('height').text) yolo_lines = [] for obj in root.findall('object'): class_name = obj.find('name').text if class_name not in class_names: continue class_id = class_names.index(class_name) bbox = obj.find('bndbox') xmin = float(bbox.find('xmin').text) ymin = float(bbox.find('ymin').text) xmax = float(bbox.find('xmax').text) ymax = float(bbox.find('ymax').text) # 轉換為 YOLO 格式 x_center = (xmin + xmax) / 2 / img_w y_center = (ymin + ymax) / 2 / img_h width = (xmax - xmin) / img_w height = (ymax - ymin) / img_h yolo_lines.append(f"{class_id} {x_center:.6f} {y_center:.6f} {width:.6f} {height:.6f}") with open(output_path, 'w') as f: f.write('\n'.join(yolo_lines))

訓練注意事項

  • 確保資料集標籤正確，錯誤標籤會嚴重影響訓練結果
  • 小資料集建議使用更小的模型（如 yolov8n）避免過擬合
  • 監控驗證集的 mAP，如果開始下降表示過擬合
  • GPU 記憶體不足時，減小 batch size 或 imgsz

訓練輸出說明

9. 模型評估

驗證模型

from ultralytics import YOLO # 載入訓練好的模型 model = YOLO('runs/train/exp/weights/best.pt') # 在驗證集上評估 metrics = model.val() # 查看指標 print(f"mAP50: {metrics.box.map50:.4f}") # mAP@IoU=0.5 print(f"mAP50-95: {metrics.box.map:.4f}") # mAP@IoU=0.5:0.95 print(f"Precision: {metrics.box.mp:.4f}") # 平均精確率 print(f"Recall: {metrics.box.mr:.4f}") # 平均召回率

評估指標說明

指標 說明 理想值
mAP50 IoU 閾值 0.5 時的平均精確率 越高越好，通常 > 0.7
mAP50-95 IoU 從 0.5 到 0.95（間隔 0.05）的平均 更嚴格的指標，通常 > 0.5
Precision 預測為正例中的真正例比例 > 0.8
Recall 真正例中被正確預測的比例 > 0.8

批次處理

from ultralytics import YOLO from pathlib import Path import json def batch_inference(model_path, images_dir, output_json): """批次處理圖片並輸出 JSON 結果""" model = YOLO(model_path) all_results = [] image_paths = list(Path(images_dir).glob('*.jpg')) for img_path in image_paths: results = model(img_path, verbose=False) detections = [] for box in results[0].boxes: detections.append({ 'class': model.names[int(box.cls[0])], 'confidence': float(box.conf[0]), 'bbox': box.xyxy[0].tolist() }) all_results.append({ 'image': img_path.name, 'detections': detections }) with open(output_json, 'w', encoding='utf-8') as f: json.dump(all_results, f, ensure_ascii=False, indent=2) return all_results # 使用 results = batch_inference('best.pt', 'test_images/', 'results.json')

即時影像偵測

from ultralytics import YOLO import cv2 def realtime_detection(model_path, camera_id=0): """即時攝影機偵測""" model = YOLO(model_path) cap = cv2.VideoCapture(camera_id) while True: ret, frame = cap.read() if not ret: break # 進行偵測 results = model(frame, verbose=False) # 繪製結果 annotated_frame = results[0].plot() # 顯示 FPS fps = 1000 / results[0].speed['inference'] cv2.putText(annotated_frame, f'FPS: {fps:.1f}', (10, 30), cv2.FONT_HERSHEY_SIMPLEX, 1, (0, 255, 0), 2) cv2.imshow('YOLO Detection', annotated_frame) if cv2.waitKey(1) & 0xFF == ord('q'): break cap.release() cv2.destroyAllWindows() realtime_detection('best.pt')

11. 效能優化

提升準確度

  • 增加訓練資料：更多樣化的資料能提升泛化能力
  • 資料增強：使用 mosaic、mixup、色彩增強等
  • 使用更大的模型：YOLOv8m/l/x 通常比 n/s 準確
  • 增加訓練週期：確保模型充分學習
  • 調整超參數：學習率、批次大小等
  • 使用 TTA（測試時增強）：推論時使用多種增強取平均

提升速度

  • 使用更小的模型：YOLOv8n 速度最快
  • 減小輸入尺寸：640 → 320，速度大幅提升
  • 模型量化：INT8 量化減少計算量
  • 使用 TensorRT：NVIDIA GPU 最佳化
  • 批次處理：同時處理多張圖片

模型量化範例

from ultralytics import YOLO model = YOLO('best.pt') # INT8 量化匯出 model.export( format='onnx', int8=True, data='data.yaml' # 需要校準資料 ) # FP16 半精度 model.export( format='engine', half=True )

案例 1：水果品質分級

from ultralytics import YOLO import cv2 class FruitQualityGrader: """水果品質自動分級系統""" def __init__(self, model_path): self.model = YOLO(model_path) self.grade_mapping = { 'healthy': 'A級 - 優質', 'minor_defect': 'B級 - 良好', 'major_defect': 'C級 - 次級', 'rotten': '廢棄' } def grade(self, image_path): """對單張圖片進行分級""" results = self.model(image_path, verbose=False) detections = [] for box in results[0].boxes: class_name = self.model.names[int(box.cls[0])] confidence = float(box.conf[0]) grade = self.grade_mapping.get(class_name, '未知') detections.append({ 'class': class_name, 'grade': grade, 'confidence': confidence, 'bbox': box.xyxy[0].tolist() }) return detections def process_batch(self, image_dir, output_csv): """批次處理並輸出統計""" import pandas as pd from pathlib import Path results = [] for img_path in Path(image_dir).glob('*.jpg'): detections = self.grade(img_path) for det in detections: det['image'] = img_path.name results.append(det) df = pd.DataFrame(results) df.to_csv(output_csv, index=False) # 統計各等級數量 print("=== 分級統計 ===") print(df['grade'].value_counts()) return df # 使用範例 grader = FruitQualityGrader('apple_grader.pt') grader.process_batch('harvest_images/', 'grading_results.csv')

案例 2：病蟲害偵測

from ultralytics import YOLO import cv2 from datetime import datetime class PestDetector: """作物病蟲害偵測系統""" PEST_INFO = { 'aphid': { 'name': '蚜蟲', 'severity': '中', 'treatment': '建議使用生物防治或低毒農藥' }, 'spider_mite': { 'name': '紅蜘蛛', 'severity': '高', 'treatment': '立即使用殺蟎劑，注意通風' }, 'powdery_mildew': { 'name': '白粉病', 'severity': '中', 'treatment': '改善通風，使用硫磺類殺菌劑' } } def __init__(self, model_path): self.model = YOLO(model_path) def detect(self, image_path): """偵測並生成報告""" results = self.model(image_path, verbose=False) report = { 'timestamp': datetime.now().isoformat(), 'image': image_path, 'findings': [], 'alert_level': '正常' } for box in results[0].boxes: class_name = self.model.names[int(box.cls[0])] pest_info = self.PEST_INFO.get(class_name, {}) finding = { 'pest': pest_info.get('name', class_name), 'confidence': float(box.conf[0]), 'severity': pest_info.get('severity', '未知'), 'treatment': pest_info.get('treatment', '請諮詢專家'), 'location': box.xyxy[0].tolist() } report['findings'].append(finding) # 更新警戒等級 if pest_info.get('severity') == '高': report['alert_level'] = '緊急' elif pest_info.get('severity') == '中' and report['alert_level'] != '緊急': report['alert_level'] = '注意' return report def print_report(self, report): """印出格式化報告""" print(f"=== 病蟲害偵測報告 ===") print(f"時間: {report['timestamp']}") print(f"警戒等級: {report['alert_level']}") print(f"發現 {len(report['findings'])} 個問題") for i, finding in enumerate(report['findings'], 1): print(f"\n問題 {i}:") print(f" 類型: {finding['pest']}") print(f" 嚴重程度: {finding['severity']}") print(f" 建議處置: {finding['treatment']}") # 使用範例 detector = PestDetector('pest_detector.pt') report = detector.detect('field_image.jpg') detector.print_report(report)

案例 3：作物計數

from ultralytics import YOLO import numpy as np class CropCounter: """作物/果實計數系統""" def __init__(self, model_path): self.model = YOLO(model_path) def count(self, image_path, conf_threshold=0.3): """計算圖片中的物件數量""" results = self.model(image_path, conf=conf_threshold, verbose=False) counts = {} for box in results[0].boxes: class_name = self.model.names[int(box.cls[0])] counts[class_name] = counts.get(class_name, 0) + 1 return counts def estimate_yield(self, image_path, avg_weight_kg=0.2): """估算產量""" counts = self.count(image_path) total_count = sum(counts.values()) estimated_weight = total_count * avg_weight_kg return { 'counts': counts, 'total': total_count, 'estimated_weight_kg': estimated_weight } # 使用範例 counter = CropCounter('tomato_detector.pt') result = counter.estimate_yield('greenhouse_image.jpg', avg_weight_kg=0.15) print(f"偵測到 {result['total']} 顆番茄") print(f"預估重量: {result['estimated_weight_kg']:.2f} 公斤")

農業應用建議

  • 訓練資料要涵蓋不同光線、角度、生長階段
  • 實際場景測試很重要，實驗室效果不等於田間效果
  • 考慮使用邊緣裝置（如 Jetson Nano）在現場運行
  • 定期更新模型，適應季節變化和新病蟲害
  • 結合其他感測器資料（如溫濕度）可提升判斷準確度
