📚 什麼是 LangChain？

LangChain 是一個用於建立 LLM（大型語言模型）應用的框架。它讓你能夠將 AI 模型與各種工具、資料來源串接，建立能夠「思考」和「行動」的智慧代理人。

🧠

LLM 整合

支援 OpenAI、Ollama 等多種模型

🔧 定義工具

工具是 Agent 可以使用的函式，讓 AI 能夠執行實際任務。

from langchain.tools import tool @tool def get_sensor_data(sensor_type: str) -> str: """ 取得農場感測器數據 Args: sensor_type: 感測器類型 (temperature, humidity, soil_moisture) Returns: 感測器數據字串 """ # 模擬感測器數據 data = { 'temperature': '目前溫度: 28.5°C', 'humidity': '目前濕度: 65%', 'soil_moisture': '土壤濕度: 45%' } return data.get(sensor_type, '未知的感測器類型') @tool def control_irrigation(action: str, duration: int = 10) -> str: """ 控制灌溉系統 Args: action: 動作 (start 或 stop) duration: 灌溉時間（分鐘） Returns: 執行結果 """ if action == 'start': return f'灌溉系統已啟動，預計運行 {duration} 分鐘' elif action == 'stop': return '灌溉系統已停止' return '未知的動作' @tool def analyze_crop_image(image_path: str) -> str: """ 分析作物影像，判斷健康狀態 Args: image_path: 影像路徑 Returns: 分析結果 """ # 這裡可以整合 YOLO 或其他模型 return '影像分析結果: 作物健康狀態良好，NDVI 值 0.72，無明顯病蟲害' # 將工具收集起來 tools = [get_sensor_data, control_irrigation, analyze_crop_image]
🤖 建立 Agent
from langchain_ollama import ChatOllama from langchain.agents import create_tool_calling_agent, AgentExecutor from langchain_core.prompts import ChatPromptTemplate # 使用 Ollama 本地模型 llm = ChatOllama( model="llama3.2", # 或其他支援的模型 temperature=0 ) # 定義系統提示 system_prompt = """你是一個智慧農業助手，專門協助農民管理農場。 你可以使用以下工具來幫助使用者: - get_sensor_data: 取得感測器數據 - control_irrigation: 控制灌溉系統 - analyze_crop_image: 分析作物影像 請根據使用者的需求，選擇適當的工具來完成任務。 在回答時使用繁體中文，並提供具體的建議。""" # 建立提示模板 prompt = ChatPromptTemplate.from_messages([ ("system", system_prompt), ("human", "{input}"), ("placeholder", "{agent_scratchpad}") ]) # 建立 Agent agent = create_tool_calling_agent(llm, tools, prompt) agent_executor = AgentExecutor( agent=agent, tools=tools, verbose=True, # 顯示思考過程 handle_parsing_errors=True )
💬 使用 Agent
# 與 Agent 對話 response = agent_executor.invoke({ "input": "現在農場的溫度和濕度是多少？需要灌溉嗎？" }) print(response["output"]) # Agent 會自動： # 1. 呼叫 get_sensor_data("temperature") 取得溫度 # 2. 呼叫 get_sensor_data("humidity") 取得濕度 # 3. 根據數據判斷是否需要灌溉 # 4. 如果需要，呼叫 control_irrigation("start") # 5. 回報結果給使用者
💡 對話範例：
使用者：「幫我檢查作物狀態並決定要不要澆水」

Agent 思考過程：
→ 呼叫 get_sensor_data("soil_moisture") 取得土壤濕度
→ 發現土壤濕度 45%（偏低）
→ 呼叫 control_irrigation("start", 15) 開始灌溉
→ 回覆：「土壤濕度目前為 45%，略低於理想值。已啟動灌溉系統，預計運行 15 分鐘。」
🌾 農業 Agent 完整範例
from langchain_ollama import ChatOllama from langchain.tools import tool from langchain.agents import create_tool_calling_agent, AgentExecutor from langchain_core.prompts import ChatPromptTemplate # ===== 定義工具 ===== @tool def get_weather_forecast() -> str: """取得天氣預報""" return "今日：晴，最高溫32°C，降雨機率10%。明日：多雲，最高溫28°C，降雨機率60%" @tool def get_all_sensors() -> dict: """取得所有感測器數據""" return { "temperature": 28.5, "humidity": 65, "soil_moisture": 42, "light": 850 } @tool def generate_daily_report() -> str: """產生每日農場報告""" return """ === 農場每日報告 === 日期: 2024-01-15 作物狀態: 健康 今日灌溉: 2次，共45分鐘 用水量: 150公升 建議: 明日降雨機率高，建議減少灌溉 """ tools = [get_weather_forecast, get_all_sensors, generate_daily_report] # ===== 建立 Agent ===== llm = ChatOllama(model="llama3.2", temperature=0) prompt = ChatPromptTemplate.from_messages([ ("system", """你是智慧農業管理助手。 能夠監控農場狀態、分析數據、提供建議。 請用繁體中文回答，並提供具體可行的建議。"""), ("human", "{input}"), ("placeholder", "{agent_scratchpad}") ]) agent = create_tool_calling_agent(llm, tools, prompt) agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True) # ===== 主程式 ===== def chat(): print("歡迎使用智慧農業助手！輸入 'exit' 離開") while True: user_input = input("\\n你: ") if user_input.lower() == 'exit': break response = agent_executor.invoke({"input": user_input}) print(f"\\n助手: {response['output']}") if __name__ == "__main__": chat()
