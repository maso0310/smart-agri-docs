前言：為什麼需要 I/O 擴展？

- 8 個 LED 燈（跑馬燈效果）

什麼是移位暫存器？

用生活例子理解

想像一個 傳話遊戲：

【傳統方式：每人一條電話線】
老師 ─── 學生1
老師 ─── 學生2
老師 ─── 學生3
老師 ─── 學生4
...
老師需要很多條電話線！

【移位暫存器方式：只要一條線】
老師 ──→ 學生1 ──→ 學生2 ──→ 學生3 ──→ 學生4
老師依序傳話給學生1
學生1 傳給學生2
學生2 傳給學生3...
最後老師喊「發布！」
所有學生同時執行各自收到的指令

技術名稱

  • 串進並出 (SIPO)：資料一個一個「串」著進去，最後「並」排同時輸出
  • 用於輸出擴展（控制 LED、繼電器等）

  • 代表 IC：74HC595

  • 並進串出 (PISO)：資料「並」排同時輸入，一個一個「串」著讀出

  • 用於輸入擴展（讀取按鈕、開關等）
  • 代表 IC：74HC165

水桶比喻

【74HC595 - 串進並出】

想像 8 個水桶排成一排，每個水桶底部有開關：

步驟 1：依序倒水（傳送資料）
        水 → [桶1] → [桶2] → [桶3] → ... → [桶8]
             有水    沒水    有水          沒水
              1       0       1             0

步驟 2：喊「開！」（鎖存訊號）
        所有水桶的開關同時打開
        有水的桶出水（輸出 HIGH）
        沒水的桶不出水（輸出 LOW）

74HC595 - 最常用的輸出擴展 IC

為什麼選 74HC595？

優點 說明
便宜 一顆只要 $5-15
簡單 只需要 3 條線
可串聯 串 2 顆變 16 輸出，串 3 顆變 24 輸出...
有鎖存 輸出不會閃爍
Arduino 內建支援 shiftOut() 函數直接用

實際應用場景

【場景 1：跑馬燈】
用 3 個腳位控制 8 個 LED 的跑馬燈效果

【場景 2：數碼管時鐘】
用 3 個腳位控制 4 位數的七段顯示器

【場景 3：LED 矩陣】
用 3 個腳位控制 8x8 的 LED 點陣（需要 2 顆 595）

【場景 4：繼電器陣列】
用 3 個腳位控制 8 個繼電器（智慧家居）

74HC595 長什麼樣？

實體外觀：長得像一隻黑色蜈蚣，有 16 隻腳

        ┌───────────┐
   Q1 ──┤ 1  ●   16 ├── VCC (接 5V 電源)
   Q2 ──┤ 2      15 ├── Q0
   Q3 ──┤ 3      14 ├── DS (資料輸入)     ← Arduino 接這裡
   Q4 ──┤ 4      13 ├── OE (輸出開關)     ← 接 GND（永遠開啟）
   Q5 ──┤ 5      12 ├── STCP (鎖存時脈)   ← Arduino 接這裡
   Q6 ──┤ 6      11 ├── SHCP (移位時脈)   ← Arduino 接這裡
   Q7 ──┤ 7      10 ├── MR (重置)         ← 接 5V（不重置）
  GND ──┤ 8       9 ├── Q7' (串聯用)
        └───────────┘

●：第一腳的標記（凹槽或圓點）
Q0-Q7：8 個輸出腳位，接 LED 或其他元件

腳位功能說明（白話版）

腳位 名稱 白話說明
14 DS 資料入口：Arduino 從這裡一個一個送資料進去
11 SHCP 節拍器：每敲一下，資料往裡面移動一格
12 STCP 發布鍵：按一下，內部資料同時輸出到 Q0-Q7
13 OE 總開關：接 GND 表示「開啟輸出」
10 MR 重置鍵：接 5V 表示「不要重置」
9 Q7' 串聯出口：要接第二顆 595 時用
15, 1-7 Q0-Q7 8 個輸出：接 LED、繼電器等

程式範例 1：最簡單的跑馬燈

// 74HC595 跑馬燈 - 初學者版本

// 定義腳位（可以改成其他腳位）
const int dataPin = 11;   // DS：資料
const int clockPin = 12;  // SHCP：節拍
const int latchPin = 13;  // STCP：發布

void setup() {
  // 設定這三個腳位為輸出
  pinMode(dataPin, OUTPUT);
  pinMode(clockPin, OUTPUT);
  pinMode(latchPin, OUTPUT);
}

void loop() {
  // 依序點亮 LED 0 到 LED 7
  for (int i = 0; i < 8; i++) {
    // 計算要輸出的值
    // i=0 時：00000001（第 0 顆亮）
    // i=1 時：00000010（第 1 顆亮）
    // i=2 時：00000100（第 2 顆亮）
    // ...以此類推
    byte ledPattern = 1 << i;  // 位元左移

    // 發送資料到 595
    sendTo595(ledPattern);

    // 等待 200 毫秒
    delay(200);
  }
}

// 發送一個 byte 到 74HC595
void sendTo595(byte data) {
  // 步驟 1：按住發布鍵（拉低 STCP）
  digitalWrite(latchPin, LOW);

  // 步驟 2：送出資料
  // shiftOut 是 Arduino 內建函數，會自動處理節拍
  // MSBFIRST 表示從最高位元開始送
  shiftOut(dataPin, clockPin, MSBFIRST, data);

  // 步驟 3：放開發布鍵（拉高 STCP），資料輸出到 Q0-Q7
  digitalWrite(latchPin, HIGH);
}

程式範例 2：個別控制每個輸出

// 像 digitalWrite 一樣控制 74HC595 的每個輸出

const int dataPin = 11;
const int clockPin = 12;
const int latchPin = 13;

// 用一個變數記住目前 8 個輸出的狀態
byte outputState = 0;  // 00000000，全部關閉

void setup() {
  pinMode(dataPin, OUTPUT);
  pinMode(clockPin, OUTPUT);
  pinMode(latchPin, OUTPUT);

  Serial.begin(9600);
  Serial.println("74HC595 個別控制範例");
}

// 設定某一個輸出
void setOutput(int pin, bool state) {
  // pin: 0-7，對應 Q0-Q7
  // state: true=HIGH, false=LOW

  if (state) {
    // 把第 pin 位設為 1
    outputState |= (1 << pin);
  } else {
    // 把第 pin 位設為 0
    outputState &= ~(1 << pin);
  }

  // 更新輸出
  digitalWrite(latchPin, LOW);
  shiftOut(dataPin, clockPin, MSBFIRST, outputState);
  digitalWrite(latchPin, HIGH);
}

void loop() {
  Serial.println("點亮 Q0");
  setOutput(0, HIGH);
  delay(500);

  Serial.println("點亮 Q3");
  setOutput(3, HIGH);
  delay(500);

  Serial.println("關閉 Q0");
  setOutput(0, LOW);
  delay(500);

  Serial.println("點亮 Q7");
  setOutput(7, HIGH);
  delay(500);

  Serial.println("全部關閉");
  outputState = 0;
  digitalWrite(latchPin, LOW);
  shiftOut(dataPin, clockPin, MSBFIRST, outputState);
  digitalWrite(latchPin, HIGH);
  delay(1000);
}

程式範例 3：各種 LED 效果

// 74HC595 LED 效果集

const int dataPin = 11;
const int clockPin = 12;
const int latchPin = 13;

void setup() {
  pinMode(dataPin, OUTPUT);
  pinMode(clockPin, OUTPUT);
  pinMode(latchPin, OUTPUT);
}

void sendTo595(byte data) {
  digitalWrite(latchPin, LOW);
  shiftOut(dataPin, clockPin, MSBFIRST, data);
  digitalWrite(latchPin, HIGH);
}

void loop() {
  // 效果 1：左移跑馬燈
  // LED: ●○○○○○○○ → ○●○○○○○○ → ○○●○○○○○ ...
  for (int i = 0; i < 8; i++) {
    sendTo595(1 << i);
    delay(100);
  }

  // 效果 2：右移跑馬燈
  // LED: ○○○○○○○● → ○○○○○○●○ → ○○○○○●○○ ...
  for (int i = 7; i >= 0; i--) {
    sendTo595(1 << i);
    delay(100);
  }

  // 效果 3：累加點亮
  // LED: ●○○○○○○○ → ●●○○○○○○ → ●●●○○○○○ ...
  for (int i = 0; i < 8; i++) {
    sendTo595((1 << (i + 1)) - 1);  // 產生 1, 11, 111, 1111...
    delay(150);
  }

  // 效果 4：由中間向外展開
  // LED: ○○○●●○○○ → ○○●●●●○○ → ○●●●●●●○ → ●●●●●●●●
  for (int i = 0; i < 4; i++) {
    byte pattern = 0;
    for (int j = 3 - i; j <= 4 + i; j++) {
      pattern |= (1 << j);
    }
    sendTo595(pattern);
    delay(150);
  }

  // 效果 5：全亮閃爍
  for (int i = 0; i < 3; i++) {
    sendTo595(0xFF);  // 11111111，全亮
    delay(200);
    sendTo595(0x00);  // 00000000，全滅
    delay(200);
  }

  delay(500);
}

74HC595 串聯（擴展到 16、24、32... 個輸出）

為什麼要串聯？

一顆 74HC595 = 8 個輸出
想要 16 個輸出？串聯 2 顆！
想要 24 個輸出？串聯 3 顆！
想要 32 個輸出？串聯 4 顆！

而且！不管串幾顆，Arduino 永遠只要用 3 個腳位！

串聯原理

74HC595 有一個特殊腳位 Q7'（第 9 腳）
它會輸出「被擠出去」的資料

想像排隊買票：
[入口] → [位置1] → [位置2] → ... → [位置8] → [出口]

當第 9 個人進來，第 1 個人就從出口被擠出去
這個「出口」(Q7') 可以接到下一顆 595 的「入口」(DS)

串聯接線圖

Arduino          74HC595 #1              74HC595 #2
                 (控制 LED 0-7)          (控制 LED 8-15)

  D11 ─────────── DS (14)
                  Q7' (9) ─────────────── DS (14)

  D12 ──────┬──── SHCP (11)              SHCP (11) ────┘
            └──────────────────────────────────────────┘

  D13 ──────┬──── STCP (12)              STCP (12) ────┘
            └──────────────────────────────────────────┘

時脈線和鎖存線是共用的！

串聯程式範例

// 2 個 74HC595 串聯，控制 16 個 LED

const int dataPin = 11;
const int clockPin = 12;
const int latchPin = 13;

void setup() {
  pinMode(dataPin, OUTPUT);
  pinMode(clockPin, OUTPUT);
  pinMode(latchPin, OUTPUT);
}

// 發送 16 位元資料
void sendTo595x2(uint16_t data) {
  digitalWrite(latchPin, LOW);

  // 重點！先送高位元組（給第二顆 595）
  // 因為資料會被「擠」過去
  shiftOut(dataPin, clockPin, MSBFIRST, (data >> 8) & 0xFF);  // 高 8 位
  shiftOut(dataPin, clockPin, MSBFIRST, data & 0xFF);         // 低 8 位

  digitalWrite(latchPin, HIGH);
}

void loop() {
  // 16 個 LED 的跑馬燈
  for (int i = 0; i < 16; i++) {
    sendTo595x2(1 << i);
    delay(100);
  }
}

74HC164 - 無鎖存的移位暫存器

74HC164 是什麼？

74HC164 和 74HC595 一樣是「串進並出」移位暫存器，但有一個關鍵差異：沒有鎖存功能。

【74HC595 vs 74HC164 的差異】

74HC595（有鎖存）：
資料移入時 → 輸出保持不變
全部移完後 → 按發布鍵，輸出一次更新
結果：輸出穩定，不會閃爍

74HC164（無鎖存）：
資料移入時 → 輸出立即跟著變化
每移一個位元 → 輸出就跳一次
結果：輸出會「跑動」，可能會閃爍

為什麼還要用 74HC164？

比較項目 74HC595 74HC164
腳位數 16 腳 14 腳（更小）
控制線 3 條（資料、時脈、鎖存） 2 條（資料、時脈）
鎖存功能 有 無
輸出穩定性 穩定（等全部資料送完才更新） 會跳動（每送一位就更新）
價格 $5-15 $3-10（更便宜）
適用場景 LED 顯示、需要穩定輸出 驅動其他 IC、不需要穩定輸出

程式範例

// 74HC164 跑馬燈（注意：輸出會有短暫跳動）

const int dataPin = 11;   // A（資料）
const int clockPin = 12;  // CP（時脈）

void setup() {
  pinMode(dataPin, OUTPUT);
  pinMode(clockPin, OUTPUT);
}

// 發送資料到 74HC164
// 注意：沒有鎖存，輸出會在移位過程中變化
void sendTo164(byte data) {
  // 從 MSB 開始送，送 8 個位元
  for (int i = 7; i >= 0; i--) {
    // 設定資料線
    digitalWrite(dataPin, (data >> i) & 1);

    // 產生時脈脈衝
    digitalWrite(clockPin, HIGH);
    delayMicroseconds(1);
    digitalWrite(clockPin, LOW);
  }
}

void loop() {
  // 跑馬燈
  for (int i = 0; i < 8; i++) {
    sendTo164(1 << i);
    delay(200);
  }
}

74HC164 vs 74HC595：怎麼選？

選 74HC595 的情況：
├─ 控制 LED 顯示器（跑馬燈、數碼管）
├─ 需要穩定、不閃爍的輸出
├─ 串聯多顆時要同步更新
└─ 大多數專案的首選

選 74HC164 的情況：
├─ 腳位非常緊張，想省 1 條線
├─ 驅動不需要穩定輸出的元件
├─ 當作其他 IC 的資料輸入（如驅動 LCD）
├─ 預算很緊，想省一點錢
└─ 更新頻率很快，閃爍看不出來

一般建議：直接用 74HC595，多 1 條線但好用很多！

74HC165 - 輸入擴展 IC

什麼時候需要輸入擴展？

【場景】你想做一個有 16 個按鈕的遊戲控制器
      Arduino Uno 只有 14 個數位腳位
      扣掉 LCD、其他感測器，根本不夠用！

【解決方案】使用 74HC165
           只需要 3 個腳位，就能讀取 8 個按鈕
           串聯 2 顆就能讀取 16 個按鈕！

74HC595 74HC165
方向 Arduino → 元件（輸出） 元件 → Arduino（輸入）
類型 串進並出 (SIPO) 並進串出 (PISO)
用途 控制 LED、繼電器 讀取按鈕、開關
資料流 Arduino 送資料出去 Arduino 讀取資料進來

工作原理（白話版）

【步驟 1：載入】
按下 SH/LD（拉低），把 D0-D7 的狀態「拍照」存起來

按鈕狀態：[按][放][按][按][放][放][按][放]
內部暫存：[ 1][ 0][ 1][ 1][ 0][ 0][ 1][ 0]

【步驟 2：讀取】
放開 SH/LD（拉高），開始讀取
每敲一下節拍（CLK），從 Q7 讀出一個位元
讀完 8 次，就知道全部按鈕的狀態了

Arduino 接線

Arduino          74HC165              按鈕

    D8 ─────────── SH/LD (1)
    D9 ─────────── CLK (2)
    D10 ────────── Q7 (9)

    GND ────────── CLK INH (15)
    5V ─────────── VCC (16)
    GND ────────── GND (8)

                   D0 (11) ←── 按鈕0 ←── 5V (用上拉電阻)
                   D1 (12) ←── 按鈕1 ←── 5V
                   D2 (13) ←── 按鈕2 ←── 5V
                   ...
                   D7 (6)  ←── 按鈕7 ←── 5V

注意：按鈕另一端接 GND
     沒按時輸入為 HIGH（因為上拉）
     按下時輸入為 LOW

程式範例：讀取 8 個按鈕

// 74HC165 讀取 8 個按鈕

const int loadPin = 8;   // SH/LD
const int clockPin = 9;  // CLK
const int dataPin = 10;  // Q7

void setup() {
  Serial.begin(9600);
  pinMode(loadPin, OUTPUT);
  pinMode(clockPin, OUTPUT);
  pinMode(dataPin, INPUT);

  // 預設狀態
  digitalWrite(loadPin, HIGH);
  digitalWrite(clockPin, LOW);

  Serial.println("74HC165 按鈕讀取器");
  Serial.println("按下任何按鈕查看狀態...");
}

// 讀取 8 個輸入
byte readButtons() {
  byte result = 0;

  // 步驟 1：載入（拍照）
  digitalWrite(loadPin, LOW);
  delayMicroseconds(5);
  digitalWrite(loadPin, HIGH);

  // 步驟 2：讀取 8 個位元
  for (int i = 0; i < 8; i++) {
    // 讀取目前的位元
    result <<= 1;  // 先左移騰出空間
    if (digitalRead(dataPin)) {
      result |= 1;  // 如果是 HIGH，設為 1
    }

    // 敲節拍，讓下一個位元出現
    digitalWrite(clockPin, HIGH);
    delayMicroseconds(5);
    digitalWrite(clockPin, LOW);
  }

  return result;
}

void loop() {
  byte buttons = readButtons();

  // 顯示二進位狀態
  Serial.print("按鈕狀態: ");
  for (int i = 7; i >= 0; i--) {
    Serial.print((buttons >> i) & 1);
  }
  Serial.print("  ");

  // 顯示哪些按鈕被按下（LOW = 按下，因為上拉電阻）
  for (int i = 0; i < 8; i++) {
    if (!(buttons & (1 << i))) {
      Serial.print("按鈕");
      Serial.print(i);
      Serial.print("按下 ");
    }
  }
  Serial.println();

  delay(200);
}

// MCP23017 控制 LED
// 需要安裝 Adafruit MCP23017 函式庫

#include <Wire.h>
#include <Adafruit_MCP23X17.h>

Adafruit_MCP23X17 mcp;

void setup() {
  Serial.begin(9600);

  // 初始化 MCP23017（位址 0x20）
  if (!mcp.begin_I2C()) {
    Serial.println("找不到 MCP23017！");
    while (1);

  for (int i = 8; i < 16; i++) {
    mcp.pinMode(i, INPUT_PULLUP);

  Serial.println("MCP23017 準備完成！");
}

void loop() {
  // 跑馬燈
  for (int i = 0; i < 8; i++) {
    mcp.digitalWrite(i, HIGH);

    if (mcp.digitalRead(i) == LOW) {
      Serial.print("按鈕 ");
      Serial.print(i - 8);
      Serial.println(" 被按下");
    }
  }
}

程式範例

// ADS1115 高精度 ADC 讀取
// 需要安裝 Adafruit ADS1X15 函式庫

#include <Wire.h>
#include <Adafruit_ADS1X15.h>

Adafruit_ADS1115 ads;  // 16 位元版本

void setup() {
  Serial.begin(9600);
  Serial.println("ADS1115 高精度 ADC 測試");

  // 初始化（位址 0x48）
  if (!ads.begin()) {
    Serial.println("找不到 ADS1115！");
    while (1);
  }

  // 設定增益（影響測量範圍和精度）
  // GAIN_TWOTHIRDS: ±6.144V（預設，最大範圍）
  // GAIN_ONE:       ±4.096V
  // GAIN_TWO:       ±2.048V
  // GAIN_FOUR:      ±1.024V
  // GAIN_EIGHT:     ±0.512V
  // GAIN_SIXTEEN:   ±0.256V（最高精度）
  ads.setGain(GAIN_ONE);  // ±4.096V
}

void loop() {
  // 讀取 4 個通道
  int16_t adc0 = ads.readADC_SingleEnded(0);
  int16_t adc1 = ads.readADC_SingleEnded(1);
  int16_t adc2 = ads.readADC_SingleEnded(2);
  int16_t adc3 = ads.readADC_SingleEnded(3);

  // 轉換成電壓（GAIN_ONE 時，每格 = 0.125mV）
  float volts0 = ads.computeVolts(adc0);
  float volts1 = ads.computeVolts(adc1);
  float volts2 = ads.computeVolts(adc2);
  float volts3 = ads.computeVolts(adc3);

  Serial.println("-------------------");
  Serial.print("A0: "); Serial.print(adc0); Serial.print(" ("); Serial.print(volts0, 4); Serial.println("V)");
  Serial.print("A1: "); Serial.print(adc1); Serial.print(" ("); Serial.print(volts1, 4); Serial.println("V)");
  Serial.print("A2: "); Serial.print(adc2); Serial.print(" ("); Serial.print(volts2, 4); Serial.println("V)");
  Serial.print("A3: "); Serial.print(adc3); Serial.print(" ("); Serial.print(volts3, 4); Serial.println("V)");

  delay(1000);
}

// PCA9685 控制 16 個伺服馬達
// 需要安裝 Adafruit PWM Servo Driver 函式庫

#include <Wire.h>
#include <Adafruit_PWMServoDriver.h>

Adafruit_PWMServoDriver pwm = Adafruit_PWMServoDriver();

// 伺服馬達的脈衝範圍（依實際馬達調整）
#define SERVO_MIN  150  // 最小脈衝（約 0 度）
#define SERVO_MAX  600  // 最大脈衝（約 180 度）

void setup() {
  Serial.begin(9600);
  Serial.println("PCA9685 伺服馬達控制");

  pwm.begin();
  pwm.setPWMFreq(50);  // 伺服馬達通常用 50Hz
}

// 設定伺服馬達角度
void setServoAngle(uint8_t channel, int angle) {
  // 將角度（0-180）轉換成脈衝值
  int pulse = map(angle, 0, 180, SERVO_MIN, SERVO_MAX);
  pwm.setPWM(channel, 0, pulse);
}

void loop() {
  // 讓所有 16 個伺服馬達依序轉動
  for (int servo = 0; servo < 16; servo++) {
    Serial.print("伺服 "); Serial.print(servo); Serial.println(" 轉動");

    setServoAngle(servo, 0);    // 轉到 0 度
    delay(500);
    setServoAngle(servo, 90);   // 轉到 90 度
    delay(500);
    setServoAngle(servo, 180);  // 轉到 180 度
    delay(500);
    setServoAngle(servo, 90);   // 回到 90 度
    delay(500);
  }
}

- 74HC595 接 8 個 LED（由下到上排列）

const int dataPin = 11;
const int clockPin = 12;
const int latchPin = 13;
const int micPin = A0;

void setup() {
  pinMode(dataPin, OUTPUT);
  pinMode(clockPin, OUTPUT);
  pinMode(latchPin, OUTPUT);
}

void sendTo595(byte data) {
  digitalWrite(latchPin, LOW);
  shiftOut(dataPin, clockPin, MSBFIRST, data);
  digitalWrite(latchPin, HIGH);
}

void loop() {
  // 讀取麥克風（0-1023）
  int volume = analogRead(micPin);

  // 轉換成 0-8 的等級
  int level = map(volume, 0, 1023, 0, 8);

  // 產生對應的 LED 圖案
  // level=0: 00000000
  // level=1: 00000001
  // level=2: 00000011
  // level=3: 00000111
  // ...
  byte pattern = (1 << level) - 1;

  sendTo595(pattern);
  delay(50);
}

用途：顯示 0000 到 9999 的數字

const int dataPin = 11;
const int clockPin = 12;
const int latchPin = 13;

// 七段顯示器段碼（共陰極）
//     a
//    ───
//   f│ │b
//    ─g─
//   e│ │c
//    ───  ● dp
//     d
const byte digits[] = {
  0b00111111,  // 0
  0b00000110,  // 1
  0b01011011,  // 2
  0b01001111,  // 3
  0b01100110,  // 4
  0b01101101,  // 5
  0b01111101,  // 6
  0b00000111,  // 7
  0b01111111,  // 8
  0b01101111   // 9

  pinMode(clockPin, OUTPUT);
  pinMode(latchPin, OUTPUT);
}

// 顯示 4 位數
void displayNumber(int number) {
  // 拆解成 4 個數字
  int d0 = number % 10;         // 個位
  int d1 = (number / 10) % 10;  // 十位
  int d2 = (number / 100) % 10; // 百位
  int d3 = (number / 1000) % 10;// 千位

  // 先送最左邊的數字（會被推到最後一顆 595）
  shiftOut(dataPin, clockPin, MSBFIRST, digits[d3]);
  shiftOut(dataPin, clockPin, MSBFIRST, digits[d2]);
  shiftOut(dataPin, clockPin, MSBFIRST, digits[d1]);
  shiftOut(dataPin, clockPin, MSBFIRST, digits[d0]);
  digitalWrite(latchPin, HIGH);
}

void loop() {
  static int count = 0;

  displayNumber(count);
  count++;
  if (count > 9999) count = 0;

  delay(100);
}

專案 3：8 按鈕遊戲控制器

用途：用 74HC165 做一個有 8 個按鈕的遊戲控制器

const int loadPin = 8;
const int clockPin = 9;
const int dataPin = 10;

// 按鈕名稱
const char* buttonNames[] = {
  "上", "下", "左", "右", "A", "B", "START", "SELECT"
};

byte lastState = 0xFF;  // 上次的狀態（全部沒按）

void setup() {
  Serial.begin(9600);
  pinMode(loadPin, OUTPUT);
  pinMode(clockPin, OUTPUT);
  pinMode(dataPin, INPUT);

  digitalWrite(loadPin, HIGH);
  digitalWrite(clockPin, LOW);

  Serial.println("遊戲控制器就緒！");
}

byte readButtons() {
  byte result = 0;

  digitalWrite(loadPin, LOW);
  delayMicroseconds(5);
  digitalWrite(loadPin, HIGH);

  for (int i = 0; i < 8; i++) {
    result <<= 1;
    if (digitalRead(dataPin)) result |= 1;
    digitalWrite(clockPin, HIGH);
    delayMicroseconds(5);
    digitalWrite(clockPin, LOW);
  }

  return result;
}

void loop() {
  byte currentState = readButtons();

  // 檢查每個按鈕的變化
  for (int i = 0; i < 8; i++) {
    bool wasPressed = !(lastState & (1 << i));
    bool isPressed = !(currentState & (1 << i));

    if (isPressed && !wasPressed) {
      // 剛按下
      Serial.print("按下: ");
      Serial.println(buttonNames[i]);
    } else if (!isPressed && wasPressed) {
      // 剛放開
      Serial.print("放開: ");
      Serial.println(buttonNames[i]);
    }
  }

  lastState = currentState;
  delay(20);  // 防抖動
}

擴展的極限與實際考量

可以無限擴展嗎？

很多初學者會問：「用擴展 IC 是不是可以無限接下去？」答案是：理論上可以，實際上有限制。

【理論上】
74HC595 可以無限串聯：
Arduino → 595 #1 → 595 #2 → 595 #3 → ... → 595 #100 → ...
用 3 條線就能控制 800 個輸出！聽起來很美好...

【實際上】會遇到這些限制：

1. 電源供應能力
   └─ 每顆 595 + 8 個 LED ≈ 需要 100-200mA
   └─ 10 顆就要 1-2A，Arduino 的 5V 腳位只能輸出 500mA
   └─ 超過就要外接電源

2. 更新速度變慢
   └─ 串聯 10 顆 = 要送 80 位元
   └─ shiftOut() 每位元約 4μs，80 位元 ≈ 320μs
   └─ 如果要快速動畫效果，會有延遲感

3. 信號完整性
   └─ 時脈信號經過太多 IC 會衰減
   └─ 超過 10-20 顆可能會出現資料錯誤
   └─ 需要加緩衝器（Buffer）

4. Arduino 記憶體
   └─ 每 8 個輸出需要 1 byte 儲存狀態
   └─ 100 顆 595 = 100 bytes（還好）
   └─ 但程式邏輯複雜度會增加

5. I2C 位址限制（針對 I2C 擴展 IC）
   └─ MCP23017 只有 8 個位址 = 最多 8 顆 = 128 個 I/O
   └─ ADS1115 只有 4 個位址 = 最多 4 顆 = 16 通道

實際的合理數量

擴展方式 建議最大數量 理由
74HC595 串聯 4-8 顆（32-64 輸出） 更新速度、信號品質
74HC165 串聯 4-8 顆（32-64 輸入） 同上
MCP23017 (I2C) 8 顆（128 I/O） 位址數量限制
ADS1115 (I2C) 4 顆（16 通道） 位址數量限制
PCA9685 (I2C) 62 顆（992 PWM） 位址數量限制

如何控制擴展出去的每個腳位？

核心概念：位元操作

使用 74HC595 或 74HC164 時，你是用「一個 byte（8 位元）」來控制「8 個輸出」。

【傳統 Arduino】
digitalWrite(2, HIGH);  // 只控制 1 個腳位，很直覺

【使用 74HC595】
                          Q7 Q6 Q5 Q4 Q3 Q2 Q1 Q0
byte outputState = 0b00000000;  // 8 個輸出的狀態
                     │  │  │  │  │  │  │  │
                    LED7...              ...LED0

要點亮 Q0：outputState = 0b00000001;  → 只有 Q0 是 HIGH
要點亮 Q3：outputState = 0b00001000;  → 只有 Q3 是 HIGH
要點亮 Q0 和 Q3：outputState = 0b00001001; → Q0 和 Q3 都是 HIGH

位元操作速查表

操作 語法 說明
設定某位元為 1 state |= (1 << n) 把第 n 位設為 HIGH
設定某位元為 0 state &= ~(1 << n) 把第 n 位設為 LOW
切換某位元 state ^= (1 << n) 把第 n 位反轉
讀取某位元 (state >> n) & 1 取得第 n 位的值

實作：像 digitalWrite 一樣控制 74HC595

// 把 74HC595 包裝成類似 digitalWrite 的用法

const int dataPin = 11;
const int clockPin = 12;
const int latchPin = 13;

// 儲存目前 8 個輸出的狀態
byte shiftRegisterState = 0;

void setup() {
  pinMode(dataPin, OUTPUT);
  pinMode(clockPin, OUTPUT);
  pinMode(latchPin, OUTPUT);
}

// 更新 74HC595 的輸出
void updateShiftRegister() {
  digitalWrite(latchPin, LOW);
  shiftOut(dataPin, clockPin, MSBFIRST, shiftRegisterState);
  digitalWrite(latchPin, HIGH);
}

// 模擬 digitalWrite 的函數
// pin: 0-7，對應 Q0-Q7
// value: HIGH 或 LOW
void shiftWrite(int pin, int value) {
  if (pin < 0 || pin > 7) return;  // 檢查範圍

  if (value == HIGH) {
    // 把第 pin 位設為 1
    shiftRegisterState |= (1 << pin);
  } else {
    // 把第 pin 位設為 0
    shiftRegisterState &= ~(1 << pin);
  }

  updateShiftRegister();
}

// 模擬 digitalRead（讀取目前設定的狀態）
int shiftRead(int pin) {
  if (pin < 0 || pin > 7) return -1;
  return (shiftRegisterState >> pin) & 1;
}

void loop() {
  // 現在可以像用普通腳位一樣使用了！

  shiftWrite(0, HIGH);  // 點亮 Q0
  delay(500);

  shiftWrite(3, HIGH);  // 點亮 Q3（Q0 還是亮的）
  delay(500);

  shiftWrite(0, LOW);   // 關閉 Q0（Q3 還是亮的）
  delay(500);

  shiftWrite(7, HIGH);  // 點亮 Q7
  delay(500);

  // 全部關閉
  for (int i = 0; i < 8; i++) {
    shiftWrite(i, LOW);
  }
  delay(1000);
}

實作：控制多顆串聯的 74HC595

// 控制 2 顆串聯的 74HC595（16 個輸出）

const int dataPin = 11;
const int clockPin = 12;
const int latchPin = 13;

// 用 16 位元儲存 16 個輸出的狀態
uint16_t shiftRegisterState = 0;

void setup() {
  pinMode(dataPin, OUTPUT);
  pinMode(clockPin, OUTPUT);
  pinMode(latchPin, OUTPUT);
}

void updateShiftRegister() {
  digitalWrite(latchPin, LOW);
  // 先送高 8 位（給第 2 顆 595）
  shiftOut(dataPin, clockPin, MSBFIRST, (shiftRegisterState >> 8) & 0xFF);
  // 再送低 8 位（給第 1 顆 595）
  shiftOut(dataPin, clockPin, MSBFIRST, shiftRegisterState & 0xFF);
  digitalWrite(latchPin, HIGH);
}

// 控制 16 個輸出中的任何一個
// pin: 0-15
void shiftWrite16(int pin, int value) {
  if (pin < 0 || pin > 15) return;

  if (value == HIGH) {
    shiftRegisterState |= (1 << pin);
  } else {
    shiftRegisterState &= ~(1 << pin);
  }

  updateShiftRegister();
}

void loop() {
  // 0-7 是第一顆 595 的 Q0-Q7
  // 8-15 是第二顆 595 的 Q0-Q7

  shiftWrite16(0, HIGH);   // 第 1 顆的 Q0
  delay(200);

  shiftWrite16(8, HIGH);   // 第 2 顆的 Q0
  delay(200);

  shiftWrite16(15, HIGH);  // 第 2 顆的 Q7
  delay(200);

  // 跑馬燈效果
  shiftRegisterState = 0;
  for (int i = 0; i < 16; i++) {
    shiftWrite16(i, HIGH);
    delay(100);
    shiftWrite16(i, LOW);
  }
}

進階：用類別封裝（物件導向）

// ShiftRegister595 類別 - 更優雅的封裝方式

class ShiftRegister595 {
private:
  int dataPin, clockPin, latchPin;
  int numChips;  // 串聯幾顆
  byte* states;  // 動態陣列儲存狀態

public:
  // 建構函數
  ShiftRegister595(int data, int clock, int latch, int chips = 1) {
    dataPin = data;
    clockPin = clock;
    latchPin = latch;
    numChips = chips;
    states = new byte[chips];

    // 初始化
    pinMode(dataPin, OUTPUT);
    pinMode(clockPin, OUTPUT);
    pinMode(latchPin, OUTPUT);

    // 全部設為 0
    for (int i = 0; i < numChips; i++) {
      states[i] = 0;
    }
  }

  // 更新輸出
  void update() {
    digitalWrite(latchPin, LOW);
    // 從最後一顆開始送
    for (int i = numChips - 1; i >= 0; i--) {
      shiftOut(dataPin, clockPin, MSBFIRST, states[i]);
    }
    digitalWrite(latchPin, HIGH);
  }

  // 設定單一腳位
  void write(int pin, bool value) {
    if (pin < 0 || pin >= numChips * 8) return;

    int chipIndex = pin / 8;
    int bitIndex = pin % 8;

    if (value) {
      states[chipIndex] |= (1 << bitIndex);
    } else {
      states[chipIndex] &= ~(1 << bitIndex);
    }

    update();
  }

  // 讀取目前設定
  bool read(int pin) {
    if (pin < 0 || pin >= numChips * 8) return false;
    int chipIndex = pin / 8;
    int bitIndex = pin % 8;
    return (states[chipIndex] >> bitIndex) & 1;
  }

  // 全部設定
  void writeAll(uint32_t value) {
    for (int i = 0; i < numChips; i++) {
      states[i] = (value >> (i * 8)) & 0xFF;
    }
    update();
  }

  // 全部清除
  void clear() {
    for (int i = 0; i < numChips; i++) {
      states[i] = 0;
    }
    update();
  }

  // 取得總腳位數
  int getPinCount() {
    return numChips * 8;
  }
};

// 使用範例
ShiftRegister595 sr(11, 12, 13, 2);  // 2 顆串聯 = 16 個輸出

void setup() {
  // 類別建構時已初始化
}

void loop() {
  // 超級簡潔的使用方式！
  sr.write(0, HIGH);
  sr.write(8, HIGH);
  sr.write(15, HIGH);
  delay(1000);

  sr.clear();
  delay(500);

  // 跑馬燈
  for (int i = 0; i < sr.getPinCount(); i++) {
    sr.write(i, HIGH);
    delay(50);
    sr.write(i, LOW);
  }
}

使用秘訣

【提升效能的技巧】

1. 批次更新
   錯誤：每改一個腳位就更新一次
   shiftWrite(0, HIGH);  // 更新
   shiftWrite(1, HIGH);  // 又更新
   shiftWrite(2, HIGH);  // 又更新...

   正確：先設定好全部，最後一次更新
   shiftRegisterState |= 0b00000111;  // 一次設定 3 個位元
   updateShiftRegister();              // 只更新 1 次

2. 使用 SPI 加速
   shiftOut() 是軟體模擬，速度有限
   改用 SPI.transfer() 可以快 10 倍以上

3. 善用位元運算
   設定連續的位元：state |= 0b00001111;  // 一次設定 4 個
   清除連續的位元：state &= 0b11110000;  // 一次清除 4 個

常見問題

Q1: 74HC595 輸出會閃爍？

原因：沒有正確使用鎖存（latch）功能

解決：

// 正確寫法
digitalWrite(latchPin, LOW);   // 1. 先關閉鎖存
shiftOut(...);                  // 2. 送資料
digitalWrite(latchPin, HIGH);  // 3. 最後打開鎖存，資料一次輸出

Q2: 74HC595 輸出電流不夠亮？

說明：74HC595 每腳最大只能輸出 35mA

解決方案：
- 使用電晶體放大電流
- 使用 ULN2803（達林頓陣列 IC）
- 使用 TPIC6B595（大電流版的 595）

Q3: 串聯多顆時，最後一顆不正常？

檢查清單：
1. Q7'（第 9 腳）有沒有接到下一顆的 DS（第 14 腳）？
2. SHCP 和 STCP 有沒有全部連在一起？
3. 發送資料的順序對不對？（先送最後一顆的資料）

Q4: I2C 和移位暫存器怎麼選？

需求 選擇
速度要快、成本要低 移位暫存器 (74HC595/165)
接線要簡單、功能要多 I2C (MCP23017)
學習用、練習用 移位暫存器（便宜好上手）

Q5: shiftOut 的 MSBFIRST 和 LSBFIRST 是什麼？

MSB = Most Significant Bit = 最高位元（最左邊的 1）
LSB = Least Significant Bit = 最低位元（最右邊的 1）

數字 0b10110010：
     ^───────── MSB（最高位）
            ^── LSB（最低位）

MSBFIRST：先送 1，再送 0，再送 1，再送 1...（從左到右）
LSBFIRST：先送 0，再送 1，再送 0，再送 0...（從右到左）

一般用 MSBFIRST，比較直覺
