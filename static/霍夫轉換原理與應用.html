📐 霍夫轉換原理與應用

📖 什麼是霍夫轉換（Hough Transform）？

霍夫轉換是一種強大的影像處理技術，專門用來偵測影像中的幾何形狀，例如直線、圓形、橢圓等。即使這些形狀被部分遮擋或有雜訊干擾，霍夫轉換仍然能夠準確偵測。

在智慧農業中，霍夫轉換常用於：

  • 🌾 偵測農田中的作物行（crop rows）
  • 🚜 自動導航系統的路徑偵測
  • 🍎 水果輪廓偵測（圓形識別）
  • 📏 溫室結構分析（偵測支架、管線）

💡 霍夫轉換的核心概念

想像你在一張照片中尋找「直線」：

傳統方法：
  • 逐一檢查每個像素點
  • 判斷附近的點是否排成一直線
  • 效率低，容易受雜訊影響
霍夫轉換的聰明做法：
  • 把問題反過來想：「如果有一條直線，哪些點會在上面？」
  • 在「參數空間」中進行投票
  • 得票最多的參數就是最可能的直線！
這就像是民主選舉：每個點都為可能經過它的直線投票，得票最高的直線就是答案！

🔍 霍夫轉換如何運作？

1️⃣ 霍夫直線偵測（Hough Line Transform）

基本原理

一條直線可以用兩種方式表示：

笛卡爾座標：y = mx + b
(m = 斜率, b = 截距)

極座標（霍夫空間）：ρ = x·cos(θ) + y·sin(θ)
(ρ = 原點到直線的距離, θ = 法線與x軸夾角)

為什麼用極座標？

  • 可以表示垂直線（笛卡爾座標中斜率 = ∞）
  • 參數空間有界（θ: 0-180°, ρ: 有限範圍）
  • 更穩定、更適合投票機制

  1. 邊緣偵測

    先用 Canny 邊緣偵測找出影像中的邊緣點（白色像素）。

    import cv2
edges = cv2.Canny(image, 50, 150)

  2. 建立累加器（Accumulator）

    創建一個二維陣列，橫軸是 θ（角度），縱軸是 ρ（距離）。

    初始值全部為 0。

  3. 投票過程

    對於每個邊緣點 (x, y)：

    • 遍歷所有可能的角度 θ（例如 0° 到 180°）
    • 計算對應的 ρ = x·cos(θ) + y·sin(θ)
    • 在累加器的 (θ, ρ) 位置 +1（投票）

  4. 找出峰值

    累加器中值最大的位置，代表通過最多邊緣點的直線參數。

    設定一個閾值，只保留得票數超過閾值的直線。

  5. 繪製結果

    將偵測到的 (ρ, θ) 轉回 (x, y) 座標，畫在原圖上。

2️⃣ 霍夫圓形偵測（Hough Circle Transform）

基本原理

圓形可以用三個參數表示：

(x - a)² + (y - b)² = r²

a, b = 圓心座標
r = 半徑

挑戰：三維參數空間（a, b, r），計算量大！

解決方案：使用霍夫梯度法（Hough Gradient Method），分兩階段偵測：

  1. 找圓心候選位置（利用梯度方向）
  2. 根據圓心候選位置找半徑

🌾 智慧農業應用實例

🚜 1. 自動駕駛農機導航

應用：偵測作物行（crop rows）的直線，計算導航路徑。

方法：霍夫直線偵測

優勢：即使部分遮擋仍能準確偵測路徑

🍎 2. 水果分級與計數

應用：偵測蘋果、柳橙等圓形水果的輪廓。

方法：霍夫圓形偵測

優勢：自動計數、測量大小

🏡 3. 溫室結構檢測

應用：偵測溫室骨架、管線是否變形。

方法：霍夫直線偵測

優勢：自動化結構健康檢查

🌱 4. 種植行距測量

應用：檢查作物種植是否整齊，行距是否一致。

方法：霍夫直線偵測

優勢：精準農業品質控制

💧 5. 灌溉管線偵測

應用：無人機影像中偵測灌溉管線位置。

方法：霍夫直線偵測

優勢：管線維護、漏水點定位

📏 6. 葉片形態測量

應用：測量圓形或橢圓形葉片的大小。

方法：霍夫圓形/橢圓偵測

優勢：生長監測、病害診斷

💻 Python OpenCV 實作

實例 1：偵測作物行（直線偵測）

import cv2
import numpy as np

# 讀取影像
image = cv2.imread('crop_field.jpg')
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

# 步驟 1：邊緣偵測
edges = cv2.Canny(gray, 50, 150, apertureSize=3)

# 步驟 2：霍夫直線偵測（標準方法）
lines = cv2.HoughLines(edges, rho=1, theta=np.pi/180, threshold=100)

# 繪製偵測到的直線
if lines is not None:
    for line in lines:
        rho, theta = line[0]
        a = np.cos(theta)
        b = np.sin(theta)
        x0 = a * rho
        y0 = b * rho
        x1 = int(x0 + 1000 * (-b))
        y1 = int(y0 + 1000 * (a))
        x2 = int(x0 - 1000 * (-b))
        y2 = int(y0 - 1000 * (a))
        cv2.line(image, (x1, y1), (x2, y2), (0, 0, 255), 2)

# 顯示結果
cv2.imshow('Detected Lines', image)
cv2.waitKey(0)
cv2.destroyAllWindows()

實例 2：偵測水果（圓形偵測）

import cv2
import numpy as np

# 讀取影像
image = cv2.imread('apples.jpg')
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

# 高斯模糊（減少雜訊）
blurred = cv2.GaussianBlur(gray, (9, 9), 2)

# 霍夫圓形偵測
circles = cv2.HoughCircles(
    blurred,
    cv2.HOUGH_GRADIENT,      # 偵測方法
    dp=1,                     # 累加器解析度比例
    minDist=50,               # 圓心之間最小距離
    param1=100,               # Canny 邊緣偵測的高閾值
    param2=30,                # 累加器閾值（越小偵測越多圓）
    minRadius=20,             # 最小半徑
    maxRadius=100             # 最大半徑
)

# 繪製偵測到的圓形
if circles is not None:
    circles = np.uint16(np.around(circles))
    for i in circles[0, :]:
        center = (i[0], i[1])
        radius = i[2]
        # 畫圓心
        cv2.circle(image, center, 2, (0, 255, 0), 3)
        # 畫圓周
        cv2.circle(image, center, radius, (255, 0, 0), 3)

    print(f"偵測到 {len(circles[0])} 個圓形（水果）")

# 顯示結果
cv2.imshow('Detected Circles', image)
cv2.waitKey(0)
cv2.destroyAllWindows()

實例 3：機率霍夫轉換（更快、更精準）

import cv2
import numpy as np

# 讀取影像
image = cv2.imread('greenhouse.jpg')
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
edges = cv2.Canny(gray, 50, 150, apertureSize=3)

# 機率霍夫轉換（Probabilistic Hough Transform）
# 優點：更快、直接返回線段端點座標
lines = cv2.HoughLinesP(
    edges,
    rho=1,                    # 距離解析度（像素）
    theta=np.pi/180,          # 角度解析度（弧度）
    threshold=50,             # 累加器閾值
    minLineLength=100,        # 最小線段長度
    maxLineGap=10             # 線段間最大間隔
)

# 繪製偵測到的線段
if lines is not None:
    for line in lines:
        x1, y1, x2, y2 = line[0]
        cv2.line(image, (x1, y1), (x2, y2), (0, 255, 0), 2)

    print(f"偵測到 {len(lines)} 條線段")

cv2.imshow('Probabilistic Hough Lines', image)
cv2.waitKey(0)
cv2.destroyAllWindows()

⚙️ 參數調整指南

霍夫直線偵測參數

參數 說明 建議值 調整原則
rho 距離解析度（像素） 1 通常保持 1，越小越精確但越慢
theta 角度解析度（弧度） π/180 (1度) 越小越精確，可用 π/360 (0.5度)
threshold 累加器閾值 50-150 越大偵測越嚴格，線越少但越可靠
minLineLength 最小線段長度 50-200 過濾短線段雜訊
maxLineGap 線段最大間隔 5-20 允許斷裂的線段連接

霍夫圓形偵測參數

參數 說明 建議值 調整原則
dp 累加器解析度比例 1-2 1 = 與原圖相同；2 = 一半解析度（更快）
minDist 圓心最小距離 物體直徑 避免偵測到重疊的圓
param1 Canny 高閾值 100-200 邊緣偵測敏感度
param2 累加器閾值 20-50 越小偵測越多圓（包括假陽性）
minRadius 最小半徑 依目標物體 過濾太小的圓
maxRadius 最大半徑 依目標物體 過濾太大的圓；0 = 不限制

🎯 實戰技巧與最佳實踐

✅ 提升偵測準確度的技巧

  1. 前處理很重要：
    • 使用高斯模糊去除雜訊
    • 調整對比度和亮度
    • 使用形態學操作（開運算、閉運算）
  2. 邊緣偵測優化：
    • Canny 閾值要根據影像調整
    • 可以先用自適應閾值二值化
  3. 參數調整策略：
    • 先用寬鬆參數看效果，再逐步收緊
    • threshold 從小到大調整
    • 使用滑動條（cv2.createTrackbar）即時調整
  4. 後處理過濾：
    • 過濾重複或相似的線段/圓形
    • 根據角度範圍過濾不合理的結果
    • 使用 RANSAC 等方法進一步精煉

完整範例：作物行偵測與導航角度計算

import cv2
import numpy as np

def detect_crop_rows(image_path):
    """
    偵測作物行並計算導航角度
    """
    # 讀取影像
    image = cv2.imread(image_path)
    original = image.copy()

    # 轉灰階
    gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

    # 高斯模糊
    blurred = cv2.GaussianBlur(gray, (5, 5), 0)

    # 邊緣偵測
    edges = cv2.Canny(blurred, 50, 150, apertureSize=3)

    # 霍夫直線偵測
    lines = cv2.HoughLinesP(
        edges,
        rho=1,
        theta=np.pi/180,
        threshold=80,
        minLineLength=150,
        maxLineGap=20
    )

    if lines is None:
        print("未偵測到直線")
        return None

    # 過濾並計算角度
    angles = []
    valid_lines = []

    for line in lines:
        x1, y1, x2, y2 = line[0]

        # 計算角度（與水平線的夾角）
        angle = np.arctan2(y2 - y1, x2 - x1) * 180 / np.pi

        # 只保留接近垂直的線（作物行通常是垂直或接近垂直）
        if abs(angle - 90) < 30 or abs(angle + 90) < 30:
            angles.append(angle)
            valid_lines.append(line[0])
            # 繪製偵測到的線
            cv2.line(image, (x1, y1), (x2, y2), (0, 255, 0), 2)

    if len(angles) == 0:
        print("未偵測到有效的作物行")
        return None

    # 計算平均角度（導航方向）
    avg_angle = np.mean(angles)

    # 在影像上標註結果
    cv2.putText(image, f'Rows detected: {len(valid_lines)}',
                (10, 30), cv2.FONT_HERSHEY_SIMPLEX, 1, (255, 0, 0), 2)
    cv2.putText(image, f'Navigation angle: {avg_angle:.1f} deg',
                (10, 70), cv2.FONT_HERSHEY_SIMPLEX, 1, (255, 0, 0), 2)

    # 顯示結果
    combined = np.hstack([original, image])
    cv2.imshow('Crop Row Detection', combined)
    cv2.waitKey(0)
    cv2.destroyAllWindows()

    return {
        'num_rows': len(valid_lines),
        'avg_angle': avg_angle,
        'lines': valid_lines
    }

# 使用範例
result = detect_crop_rows('crop_field.jpg')
if result:
    print(f"偵測到 {result['num_rows']} 條作物行")
    print(f"建議導航角度：{result['avg_angle']:.1f}°")

⚠️ 霍夫轉換的限制與替代方案

❌ 霍夫轉換的限制

  • 計算量大：對於大圖或高解析度影像可能很慢，尤其是圓形偵測
  • 參數敏感：需要仔細調整參數才能獲得好結果
  • 雜訊敏感：影像雜訊多時容易產生假陽性
  • 形狀限制：只能偵測特定幾何形狀（直線、圓、橢圓），無法偵測不規則形狀
  • 重疊問題：多個物體重疊時偵測困難

替代方案與補充技術

技術 適用場景 優點 缺點
RANSAC 直線/平面擬合 抗雜訊能力強 需要迭代，較慢
輪廓偵測 任意形狀 不限形狀，靈活 需要好的二值化
深度學習 複雜場景 準確度高，泛化好 需要大量訓練資料
LSD 線段偵測 快速直線偵測 比霍夫轉換快 功能較單一

🎯 總結

霍夫轉換的核心價值：
  • ✅ 能在雜訊和部分遮擋下偵測幾何形狀
  • ✅ 不需要完整的形狀輪廓
  • ✅ 演算法穩定、可靠
  • ✅ 參數可調整以適應不同場景
智慧農業最佳應用場景：
  1. 作物行偵測：自動駕駛農機導航
  2. 水果計數：產量估計、品質分級
  3. 結構檢測：溫室、灌溉系統維護
  4. 病害分析：葉片形態變化監測
使用建議：
  • 簡單場景：霍夫轉換 + 適當前處理
  • 複雜場景：霍夫轉換 + 深度學習混合使用
  • 即時需求：使用機率霍夫轉換（HoughLinesP）
  • 高精度需求：霍夫轉換 + RANSAC 精煉
