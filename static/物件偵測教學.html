物件偵測（Object Detection）教學

什麼是物件偵測？

物件偵測是讓電腦「找出圖片中有什麼東西，以及它們在哪裡」的技術。

農業應用場景

  • 作物辨識：辨識不同種類的蔬果
  • 病蟲害偵測：找出葉片上的病斑或害蟲
  • 成熟度判斷：辨識水果的成熟程度
  • 雜草偵測：區分作物與雜草
  • 產量估計：計算樹上果實數量

我們使用的工具：YOLOv8

YOLO（You Only Look Once）是目前最流行的物件偵測模型之一。我們使用最新的 YOLOv8，因為：

  • 速度快：即時偵測
  • 準確度高：效果優秀
  • 易於使用：幾行程式碼就能完成
  • 訓練快速：小資料集幾分鐘就能訓練完

訓練自己的模型

資料集結構

YOLO 需要特定的資料集格式：

datasets/
└── my_dataset/
    ├── images/
    │   ├── train/          # 訓練圖片（80%）
    │   │   ├── img001.jpg
    │   │   ├── img002.jpg
    │   │   └── ...
    │   └── val/            # 驗證圖片（20%）
    │       ├── img101.jpg
    │       └── ...
    ├── labels/
    │   ├── train/          # 訓練標註
    │   │   ├── img001.txt
    │   │   ├── img002.txt
    │   │   └── ...
    │   └── val/            # 驗證標註
    │       ├── img101.txt
    │       └── ...
    └── data.yaml           # 資料集設定檔

標註格式

每張圖片對應一個 .txt 標註檔，格式為：

<類別編號> <中心x> <中心y> <寬度> <高度>

所有座標都是相對於圖片大小的比例（0~1）。

範例（img001.txt）：

0 0.5 0.5 0.3 0.4
1 0.2 0.3 0.15 0.2

這表示：

  • 第一個物件：類別 0，在圖片中央，寬 30%、高 40%
  • 第二個物件：類別 1，在圖片左上方，寬 15%、高 20%

data.yaml 設定檔

# 資料集路徑
train: datasets/my_dataset/images/train
val: datasets/my_dataset/images/val

# 類別數量
nc: 3

# 類別名稱
names: ['apple', 'banana', 'orange']

訓練參數說明

model.train(
    data='data.yaml',      # 資料集設定檔
    epochs=50,             # 訓練輪數（小資料集 30-50 就夠）
    imgsz=640,             # 圖片大小（越大越準但越慢）
    batch=16,              # 批次大小（記憶體不夠就調小）
    patience=10,           # 早停耐心值
    device='cpu',          # 使用 CPU 或 GPU（'0' 表示第一張顯卡）
)

常見問題

Q1: 訓練時出現 CUDA out of memory？

把 batch 調小：

model.train(data='data.yaml', epochs=50, batch=8)  # 或 batch=4

Q2: 偵測效果不好？

  1. 增加訓練圖片數量（建議每類至少 50-100 張）
  2. 增加訓練輪數（epochs）
  3. 確認標註正確
  4. 使用資料增強

Q3: 如何提高速度？

  1. 使用較小的模型：yolov8n.pt（nano）
  2. 降低輸入圖片大小：imgsz=320
  3. 使用 GPU 訓練
