關於 LoRa 通訊

LoRa（Long Range）是一種低功耗廣域網路（LPWAN）無線通訊技術，特別適合物聯網應用。在智慧農業中，LoRa 可實現遠距離、低功耗的感測器資料傳輸。

一、LoRa 基本概念

什麼是 LoRa

LoRa 是由 Semtech 公司開發的展頻調變技術：

  • LoRa：物理層技術（調變方式）
  • LoRaWAN：網路協議層（MAC 層規範）

核心特點

特性說明
傳輸距離鄉村 10-15 km，都市 2-5 km
功耗極低，電池可用數年
頻段Sub-GHz 免許可頻段
資料速率0.3 - 50 kbps
適用場景低資料量、長距離、電池供電

頻寬（BW）

  • 125 kHz：標準設定，平衡距離與速率
  • 250 kHz：較高速率，距離較短
  • 500 kHz：最高速率，距離最短

編碼率（CR）

  • 4/5：最少冗餘，速度快
  • 4/6、4/7：中等
  • 4/8：最多冗餘，抗干擾強

七、Arduino 程式範例

發送端

#include <SPI.h>
#include <LoRa.h>

// 腳位定義 (依模組調整)
#define SS    18
#define RST   14
#define DIO0  26

void setup() {
    Serial.begin(115200);

    LoRa.setPins(SS, RST, DIO0);

    // 初始化 LoRa (923 MHz for AS923)
    if (!LoRa.begin(923E6)) {
        Serial.println("LoRa 初始化失敗!");
        while (1);
    }

    // 設定參數
    LoRa.setSpreadingFactor(7);    // SF7-SF12
    LoRa.setSignalBandwidth(125E3); // 125kHz
    LoRa.setCodingRate4(5);         // 4/5
    LoRa.setTxPower(14);            // 14 dBm

    Serial.println("LoRa 發送端就緒");
}

void loop() {
    // 模擬感測器資料
    float temperature = 25.5;
    float humidity = 65.0;
    int soilMoisture = 45;

    // 建立資料封包
    String packet = String(temperature) + "," +
                    String(humidity) + "," +
                    String(soilMoisture);

    // 發送
    LoRa.beginPacket();
    LoRa.print(packet);
    LoRa.endPacket();

    Serial.println("已發送: " + packet);

    delay(60000); // 每分鐘發送一次
}

接收端

#include <SPI.h>
#include <LoRa.h>

#define SS    18
#define RST   14
#define DIO0  26

void setup() {
    Serial.begin(115200);

    LoRa.setPins(SS, RST, DIO0);

    if (!LoRa.begin(923E6)) {
        Serial.println("LoRa 初始化失敗!");
        while (1);
    }

    LoRa.setSpreadingFactor(7);
    LoRa.setSignalBandwidth(125E3);

    Serial.println("LoRa 接收端就緒");
}

void loop() {
    int packetSize = LoRa.parsePacket();

    if (packetSize) {
        String received = "";

        while (LoRa.available()) {
            received += (char)LoRa.read();
        }

        int rssi = LoRa.packetRssi();
        float snr = LoRa.packetSnr();

        Serial.println("收到: " + received);
        Serial.println("RSSI: " + String(rssi) + " dBm");
        Serial.println("SNR: " + String(snr) + " dB");
        Serial.println("---");
    }
}

八、農業應用案例

分散式感測網路

農場感測網路架構：

    [土壤感測器A] ────┐
                      │
    [氣象站B] ────────┼───→ [LoRa閘道器] ───→ [樹莓派] ───→ [雲端]
                      │         │                │
    [水位感測器C] ────┘         │          MQTT/HTTP
                               WiFi

    特點：
    - 節點電池供電，可運作 1-2 年
    - 每個節點每 10 分鐘回報一次
    - 閘道器覆蓋半徑 5 公里

適用場景

  • 大範圍農地土壤濕度監測
  • 溫室環境資料收集
  • 水塔/蓄水池水位監控
  • 氣象資料收集站
  • 病蟲害偵測器回報
