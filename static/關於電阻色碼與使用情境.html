電阻色碼判讀與使用情境

什麼是電阻？

電阻是電子電路中最基本的元件之一，用於限制電流或分配電壓。電阻的單位是歐姆（Ω），常見的單位還有：
- KΩ（千歐姆）：1 KΩ = 1,000 Ω
- MΩ（百萬歐姆）：1 MΩ = 1,000,000 Ω

電阻色碼系統

電阻上的彩色環帶代表其阻值，這套系統稱為「色碼」。常見的有 4 環電阻和 5 環電阻。

色碼對照表

顏色 數值 乘數 誤差（第4/5環）
黑色 0 ×1 -
棕色 1 ×10 ±1%
紅色 2 ×100 ±2%
橙色 3 ×1K -
黃色 4 ×10K -
綠色 5 ×100K ±0.5%
藍色 6 ×1M ±0.25%
紫色 7 ×10M ±0.1%
灰色 8 - ±0.05%
白色 9 - -
金色 - ×0.1 ±5%
銀色 - ×0.01 ±10%

色碼記憶口訣

黑棕紅橙黃，綠藍紫灰白

對應數字 0-9

英文口訣：Black Bears Run Over Yellow Grass Behind Violet Gardens Wildly
（黑熊跑過黃草，在紫色花園後面狂奔）

4 環電阻判讀

4 環電阻是最常見的類型，判讀方式如下：

第1環    第2環    第3環（乘數）   第4環（誤差）
 ↓        ↓           ↓              ↓
[色環1] [色環2]    [色環3]        [色環4]
  ↓        ↓           ↓              ↓
 十位     個位       乘以多少        精確度

判讀步驟

  1. 找出誤差環：金色或銀色通常是誤差環，放在最右邊
  2. 從左往右讀：第1環×10 + 第2環 = 基本數值
  3. 乘以第3環：基本數值 × 乘數 = 實際阻值

實例解析

例1：棕黑紅金
- 第1環（棕）= 1
- 第2環（黑）= 0
- 第3環（紅）= ×100
- 第4環（金）= ±5%
- 計算：(1×10 + 0) × 100 = 1,000Ω = 1KΩ

例2：紅紫橙金
- 第1環（紅）= 2
- 第2環（紫）= 7
- 第3環（橙）= ×1,000
- 第4環（金）= ±5%
- 計算：(2×10 + 7) × 1,000 = 27,000Ω = 27KΩ

例3：黃紫金金
- 第1環（黃）= 4
- 第2環（紫）= 7
- 第3環（金）= ×0.1
- 第4環（金）= ±5%
- 計算：(4×10 + 7) × 0.1 = 4.7Ω

5 環電阻判讀

5 環電阻精確度更高，多一位有效數字：

第1環    第2環    第3環    第4環（乘數）   第5環（誤差）
 ↓        ↓        ↓           ↓              ↓
[色環1] [色環2] [色環3]     [色環4]        [色環5]
  ↓        ↓        ↓           ↓              ↓
百位     十位     個位       乘以多少         精確度

實例解析

例：棕黑黑紅棕
- 第1環（棕）= 1
- 第2環（黑）= 0
- 第3環（黑）= 0
- 第4環（紅）= ×100
- 第5環（棕）= ±1%
- 計算：(100 + 0 + 0) × 100 = 10,000Ω = 10KΩ

電阻使用情境

情境一：LED 限流電阻

為什麼需要？
LED 直接接電源會燒毀，需要電阻限制電流。

計算公式

R = (電源電壓 - LED 壓降) / LED 工作電流

例：5V 電源，紅色 LED（壓降 2V），工作電流 20mA
R = (5V - 2V) / 0.02A = 150Ω

實際使用 220Ω（較安全，LED 稍暗但壽命長）

接線方式

Arduino 5V ──[220Ω]──[LED 長腳(+)]──[LED 短腳(-)]── GND

情境二：上拉電阻（Pull-up）

為什麼需要？
按鈕未按下時，輸入腳位會「浮動」（不確定是 HIGH 或 LOW），造成誤判。

接線方式

        VCC (5V)
          │
        [10KΩ] ← 上拉電阻
          │
          ├──────→ Arduino 數位腳位
          │
        [按鈕]
          │
         GND

工作原理
- 按鈕未按：腳位透過電阻接到 VCC → 讀取 HIGH
- 按鈕按下：腳位直接接到 GND → 讀取 LOW

情境三：下拉電阻（Pull-down）

接線方式

         VCC (5V)
          │
        [按鈕]
          │
          ├──────→ Arduino 數位腳位
          │
        [10KΩ] ← 下拉電阻
          │
         GND

工作原理
- 按鈕未按：腳位透過電阻接到 GND → 讀取 LOW
- 按鈕按下：腳位直接接到 VCC → 讀取 HIGH

情境四：分壓電路

為什麼需要？
將較高電壓轉換為較低電壓，例如將 5V 訊號轉為 3.3V。

電路結構

        Vin (5V)
          │
        [R1]
          │
          ├──────→ Vout
          │
        [R2]
          │
         GND

計算公式

Vout = Vin × R2 / (R1 + R2)

例：5V 轉 3.3V
Vout = 5V × R2 / (R1 + R2) = 3.3V
解得 R2/R1 = 2

使用 R1 = 10KΩ, R2 = 20KΩ（或 2 個 10KΩ 串聯）
實際 Vout = 5V × 20K / 30K = 3.33V

情境五：光敏電阻分壓

為什麼需要？
光敏電阻（LDR）阻值隨光線變化，需要用分壓電路轉換為電壓變化。

接線方式

        VCC (5V)
          │
        [光敏電阻] ← 隨光線變化（亮時低阻，暗時高阻）
          │
          ├──────→ Arduino A0（類比輸入）
          │
        [10KΩ] ← 固定電阻
          │
         GND

讀取原理
- 光線強：LDR 阻值低 → A0 電壓高 → analogRead() 值高
- 光線弱：LDR 阻值高 → A0 電壓低 → analogRead() 值低

情境六：I2C 上拉電阻

為什麼需要？
I2C 通訊使用開漏極（Open-drain）架構，需要上拉電阻將訊號拉高。

接線方式

      VCC (3.3V 或 5V)
          │
    ┌─────┴─────┐
  [4.7KΩ]    [4.7KΩ]
    │           │
   SDA         SCL

常用阻值
- 標準模式（100kHz）：10KΩ
- 快速模式（400kHz）：4.7KΩ
- 高速模式（1MHz+）：2.2KΩ

注意：許多 I2C 模組（如 LCD I2C、OLED）已內建上拉電阻，不需額外添加。

電阻功率

電阻會消耗功率並發熱，選用時需注意功率額定。

常見功率規格

功率 外觀尺寸 適用場合
1/8W (0.125W) 很小 低功耗電路
1/4W (0.25W) 常見 一般 Arduino 專案
1/2W (0.5W) 較大 電流較大的電路
1W 大 大功率電路
2W+ 很大 功率電路、負載電阻

功率計算

P = I² × R = V² / R

例：220Ω 電阻通過 20mA
P = 0.02² × 220 = 0.088W

使用 1/4W 電阻即可（有足夠餘量）

購買一組「電阻包」最划算，通常包含：
- E12 系列（每個數量級 12 種阻值）
- 常見範圍：10Ω ~ 1MΩ
- 每種 10~20 個
- 約 400~600 個

常備電阻

建議多買一些最常用的：
- 220Ω - LED 必備
- 1KΩ - 通用限流
- 10KΩ - 分壓、上/下拉
- 4.7KΩ - I2C 上拉

常見問題

Q: 電阻有方向嗎？
普通電阻沒有方向，可以任意接。但要注意色碼判讀方向。

Q: 找不到精確阻值怎麼辦？
- 串聯：R總 = R1 + R2（阻值相加）
- 並聯：1/R總 = 1/R1 + 1/R2（常用於降低阻值）

Q: 色環看不清楚怎麼辦？
1. 用三用電表測量最準確
2. 調整光線角度
3. 使用放大鏡

Q: 電阻燒毀的徵兆？
- 變色（燒焦）
- 有焦味
- 阻值異常（用電表測）
- 表面有裂痕

延伸學習

  1. 可變電阻（電位器）：可調整阻值的電阻
  2. 熱敏電阻（NTC/PTC）：阻值隨溫度變化
  3. 光敏電阻（LDR）：阻值隨光線變化
  4. 壓敏電阻（VDR）：保護電路用
  5. SMD 電阻：表面貼裝，體積小
