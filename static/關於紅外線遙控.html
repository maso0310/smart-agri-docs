關於紅外線遙控

前言：紅外線遙控能做什麼？

紅外線遙控（IR Remote Control）是最常見的無線控制方式之一，你家裡的電視、冷氣、音響遙控器幾乎都是使用紅外線技術。

在 Arduino 專案中，我們可以：
- 用現成的遙控器控制 Arduino
- 讓 Arduino 讀取遙控器訊號
- 實現遠端控制 LED、馬達、家電等

成本低廉、使用簡單，是入門無線控制的最佳選擇！

一、紅外線遙控是什麼？

一句話解釋

紅外線遙控是利用人眼看不見的紅外線光，傳送控制訊號的無線通訊方式。

生活比喻

想像紅外線遙控是一種「看不見的手電筒摩斯密碼」：

┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  遙控器                              電視                   │
│  ┌─────┐                            ┌─────┐                │
│  │     │  ─ ── ─ ─ ── ─ ─ ─ ──→    │     │                │
│  │ [按] │    紅外線閃爍             │     │                │
│  │ [鈕] │   （人眼看不見）           │ 接收│                │
│  └─────┘                            └─────┘                │
│                                                             │
│  按下按鈕 → 紅外線 LED 快速閃爍                             │
│  閃爍的模式（長短）= 不同的指令代碼                         │
│  接收器解讀閃爍模式 → 執行對應動作                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘

紅外線的特性

紅外線（Infrared, IR）：

可見光譜：
紫 藍 綠 黃 橙 紅 │ 紅外線
←────────────────┼────────→
      可見光      │  不可見

波長：約 700nm ~ 1mm
遙控器常用：940nm（近紅外線）

特點：
✓ 人眼看不見（但手機相機可以看到！）
✓ 傳輸距離短（通常 5-10 公尺）
✓ 需要直線對準（無法穿牆）
✓ 不受無線電波干擾
✓ 成本極低

調變原理（38kHz 載波）

為什麼需要 38kHz 調變？

問題：環境中有很多紅外線干擾（太陽光、燈光）

解決：用 38kHz 頻率「閃爍」紅外線
     接收器只接收 38kHz 的訊號，濾除其他干擾

原始訊號：
    ┌───┐   ┌─┐   ┌───────┐
    │   │   │ │   │       │
────┘   └───┘ └───┘       └────

調變後（38kHz 載波）：
    ┌┬┬┬┐   ┌┬┐   ┌┬┬┬┬┬┬┬┐
    │││││   │││   │││││││││
────┘└┴┴└───┘└└───┘└┴┴┴┴┴┴┴└────
    ↑↑↑↑     ↑↑     ↑↑↑↑↑↑↑
   38kHz   38kHz    38kHz

接收器輸出（解調後）：
    ┌───┐   ┌─┐   ┌───────┐
    │   │   │ │   │       │    ← 和原始訊號相同
────┘   └───┘ └───┘       └────

常見編碼協定

不同廠牌使用不同的編碼協定：

┌────────────┬─────────────┬────────────────────┐
│   協定     │   常見廠牌   │      特點          │
├────────────┼─────────────┼────────────────────┤
│ NEC        │ 通用遙控器  │ 最常見、32位元     │
│ Sony       │ Sony        │ 12/15/20位元       │
│ RC5        │ Philips     │ 雙相位編碼         │
│ RC6        │ Philips     │ RC5 改良版         │
│ Samsung    │ Samsung     │ 類似 NEC           │
│ Panasonic  │ Panasonic   │ 48位元             │
└────────────┴─────────────┴────────────────────┘

Arduino 套件附贈的小遙控器通常使用 NEC 協定

NEC 協定詳解

NEC 協定訊號格式：

引導碼        地址碼      地址反碼      命令碼      命令反碼
┌────────┬────────────┬────────────┬────────────┬────────────┐
│9ms HIGH│ 8 bits     │ 8 bits     │ 8 bits     │ 8 bits     │
│4.5ms LOW│           │            │            │            │
└────────┴────────────┴────────────┴────────────┴────────────┘

位元編碼：
邏輯 0：562μs HIGH + 562μs LOW（共 1.125ms）
邏輯 1：562μs HIGH + 1687μs LOW（共 2.25ms）

總長度：約 67.5ms
重複碼：9ms HIGH + 2.25ms LOW + 562μs HIGH（按住按鈕時發送）

三、紅外線接收器介紹

VS1838B（最常用）

VS1838B 紅外線接收器：

正面（圓弧面朝向你）：
       ┌─────┐
       │  ●  │  ← 接收窗（對準遙控器）
       │     │
       └──┬──┘
         │││
         │││
         OUT VCC GND
         (1) (2) (3)

規格：
- 工作電壓：2.7V ~ 5.5V
- 載波頻率：38kHz
- 接收角度：±45°
- 接收距離：約 18 公尺
- 輸出：解調後的數位訊號（低電平有效）

五、IRremote 程式庫安裝

安裝步驟

Arduino IDE 安裝 IRremote 程式庫：

1. 開啟 Arduino IDE

2. 點選選單：草稿碼 → 匯入程式庫 → 管理程式庫
   (Sketch → Include Library → Manage Libraries)

3. 在搜尋框輸入「IRremote」

4. 找到「IRremote」by shirriff, z3t0, ArminJo
   ┌────────────────────────────────────────┐
   │ IRremote                               │
   │ by shirriff, z3t0, ArminJo             │
   │ Version: 4.x.x                         │
   │                          [安裝] ←點這  │
   └────────────────────────────────────────┘

5. 安裝完成！

⚠️ 注意：版本 3.x 和 4.x 語法有差異
   本文範例使用 4.x 版本語法

版本差異注意

// IRremote 3.x 舊版語法
#include <IRremote.h>
IRrecv irrecv(11);
decode_results results;
irrecv.enableIRIn();
if (irrecv.decode(&results)) {
  Serial.println(results.value, HEX);
  irrecv.resume();
}

// IRremote 4.x 新版語法（推薦）
#include <IRremote.hpp>
IrReceiver.begin(11, ENABLE_LED_FEEDBACK);
if (IrReceiver.decode()) {
  Serial.println(IrReceiver.decodedIRData.decodedRawData, HEX);
  IrReceiver.resume();
}

六、Arduino 程式範例

範例 1：接收並顯示遙控器碼

/*
 * 紅外線接收器測試
 * 顯示遙控器按鍵的代碼
 */

#include <IRremote.hpp>

const int IR_RECEIVE_PIN = 11;

void setup() {
  Serial.begin(9600);
  Serial.println("IR 接收器測試");
  Serial.println("請按遙控器按鈕...");
  Serial.println();

  // 初始化 IR 接收器
  IrReceiver.begin(IR_RECEIVE_PIN, ENABLE_LED_FEEDBACK);
}

void loop() {
  // 檢查是否收到訊號
  if (IrReceiver.decode()) {

    // 顯示協定類型
    Serial.print("協定：");
    Serial.println(getProtocolString(IrReceiver.decodedIRData.protocol));

    // 顯示原始資料（HEX）
    Serial.print("代碼：0x");
    Serial.println(IrReceiver.decodedIRData.decodedRawData, HEX);

    // 顯示命令碼
    Serial.print("命令：0x");
    Serial.println(IrReceiver.decodedIRData.command, HEX);

    // 顯示地址碼
    Serial.print("地址：0x");
    Serial.println(IrReceiver.decodedIRData.address, HEX);

    Serial.println("-------------------");

    // 準備接收下一個訊號
    IrReceiver.resume();
  }
}

範例 2：辨識遙控器按鍵

/*
 * 辨識常見 Arduino 套件遙控器的按鍵
 * 請先用範例 1 找出你的遙控器代碼
 */

#include <IRremote.hpp>

const int IR_RECEIVE_PIN = 11;

// 定義遙控器按鍵代碼（根據你的遙控器調整）
// 這些是常見 Arduino 套件遙控器的代碼
#define IR_BUTTON_0     0xE916FF00
#define IR_BUTTON_1     0xF30CFF00
#define IR_BUTTON_2     0xE718FF00
#define IR_BUTTON_3     0xA15EFF00
#define IR_BUTTON_4     0xF708FF00
#define IR_BUTTON_5     0xE31CFF00
#define IR_BUTTON_6     0xA55AFF00
#define IR_BUTTON_7     0xBD42FF00
#define IR_BUTTON_8     0xAD52FF00
#define IR_BUTTON_9     0xB54AFF00
#define IR_BUTTON_STAR  0xE619FF00  // *
#define IR_BUTTON_HASH  0xF20DFF00  // #
#define IR_BUTTON_UP    0xE718FF00
#define IR_BUTTON_DOWN  0xAD52FF00
#define IR_BUTTON_LEFT  0xF708FF00
#define IR_BUTTON_RIGHT 0xA55AFF00
#define IR_BUTTON_OK    0xE31CFF00

void setup() {
  Serial.begin(9600);
  Serial.println("遙控器按鍵辨識");

  IrReceiver.begin(IR_RECEIVE_PIN, ENABLE_LED_FEEDBACK);
}

void loop() {
  if (IrReceiver.decode()) {
    uint32_t code = IrReceiver.decodedIRData.decodedRawData;

    Serial.print("收到：0x");
    Serial.print(code, HEX);
    Serial.print(" → ");

    // 辨識按鍵
    switch (code) {
      case IR_BUTTON_0: Serial.println("按鍵 0"); break;
      case IR_BUTTON_1: Serial.println("按鍵 1"); break;
      case IR_BUTTON_2: Serial.println("按鍵 2"); break;
      case IR_BUTTON_3: Serial.println("按鍵 3"); break;
      case IR_BUTTON_4: Serial.println("按鍵 4"); break;
      case IR_BUTTON_5: Serial.println("按鍵 5"); break;
      case IR_BUTTON_6: Serial.println("按鍵 6"); break;
      case IR_BUTTON_7: Serial.println("按鍵 7"); break;
      case IR_BUTTON_8: Serial.println("按鍵 8"); break;
      case IR_BUTTON_9: Serial.println("按鍵 9"); break;
      case IR_BUTTON_STAR: Serial.println("按鍵 *"); break;
      case IR_BUTTON_HASH: Serial.println("按鍵 #"); break;
      case 0xFFFFFFFF: Serial.println("（重複碼）"); break;
      default: Serial.println("未知按鍵"); break;
    }

    IrReceiver.resume();
  }
}

範例 3：遙控器控制 LED

/*
 * 使用遙控器控制 LED
 * 按 1：開 LED
 * 按 2：關 LED
 * 按 3-9：調整亮度
 */

#include <IRremote.hpp>

const int IR_RECEIVE_PIN = 11;
const int LED_PIN = 9;  // PWM 腳位

// 遙控器代碼（請根據你的遙控器調整）
#define IR_BUTTON_1  0xF30CFF00
#define IR_BUTTON_2  0xE718FF00
#define IR_BUTTON_3  0xA15EFF00
#define IR_BUTTON_4  0xF708FF00
#define IR_BUTTON_5  0xE31CFF00
#define IR_BUTTON_6  0xA55AFF00
#define IR_BUTTON_7  0xBD42FF00
#define IR_BUTTON_8  0xAD52FF00
#define IR_BUTTON_9  0xB54AFF00

int brightness = 0;

void setup() {
  Serial.begin(9600);
  pinMode(LED_PIN, OUTPUT);

  IrReceiver.begin(IR_RECEIVE_PIN, ENABLE_LED_FEEDBACK);

  Serial.println("遙控器控制 LED");
  Serial.println("1=開, 2=關, 3-9=亮度");
}

void loop() {
  if (IrReceiver.decode()) {
    uint32_t code = IrReceiver.decodedIRData.decodedRawData;

    switch (code) {
      case IR_BUTTON_1:
        brightness = 255;
        Serial.println("LED 開啟");
        break;

      case IR_BUTTON_2:
        brightness = 0;
        Serial.println("LED 關閉");
        break;

      case IR_BUTTON_3:
        brightness = 30;
        Serial.println("亮度：12%");
        break;

      case IR_BUTTON_4:
        brightness = 60;
        Serial.println("亮度：24%");
        break;

      case IR_BUTTON_5:
        brightness = 90;
        Serial.println("亮度：35%");
        break;

      case IR_BUTTON_6:
        brightness = 128;
        Serial.println("亮度：50%");
        break;

      case IR_BUTTON_7:
        brightness = 180;
        Serial.println("亮度：70%");
        break;

      case IR_BUTTON_8:
        brightness = 220;
        Serial.println("亮度：86%");
        break;

      case IR_BUTTON_9:
        brightness = 255;
        Serial.println("亮度：100%");
        break;
    }

    analogWrite(LED_PIN, brightness);
    IrReceiver.resume();
  }
}

範例 4：遙控器控制伺服馬達

/*
 * 使用遙控器控制伺服馬達角度
 * ↑：增加角度
 * ↓：減少角度
 * OK：回到 90 度
 * 數字 1-9：快速跳到特定角度
 */

#include <IRremote.hpp>
#include <Servo.h>

const int IR_RECEIVE_PIN = 11;
const int SERVO_PIN = 9;

// 遙控器代碼（請根據你的遙控器調整）
#define IR_UP     0xE718FF00
#define IR_DOWN   0xAD52FF00
#define IR_OK     0xE31CFF00
#define IR_1      0xF30CFF00
#define IR_2      0xE718FF00
#define IR_3      0xA15EFF00
#define IR_4      0xF708FF00
#define IR_5      0xE31CFF00
#define IR_6      0xA55AFF00
#define IR_7      0xBD42FF00
#define IR_8      0xAD52FF00
#define IR_9      0xB54AFF00

Servo myServo;
int angle = 90;
const int STEP = 10;

void setup() {
  Serial.begin(9600);
  myServo.attach(SERVO_PIN);
  myServo.write(angle);

  IrReceiver.begin(IR_RECEIVE_PIN, ENABLE_LED_FEEDBACK);

  Serial.println("遙控器控制伺服馬達");
  Serial.println("↑/↓=調整角度, OK=90度");
}

void loop() {
  if (IrReceiver.decode()) {
    uint32_t code = IrReceiver.decodedIRData.decodedRawData;

    switch (code) {
      case IR_UP:
        angle = min(angle + STEP, 180);
        break;
      case IR_DOWN:
        angle = max(angle - STEP, 0);
        break;
      case IR_OK:
        angle = 90;
        break;
      case IR_1:
        angle = 0;
        break;
      case IR_3:
        angle = 45;
        break;
      case IR_5:
        angle = 90;
        break;
      case IR_7:
        angle = 135;
        break;
      case IR_9:
        angle = 180;
        break;
    }

    myServo.write(angle);
    Serial.print("角度：");
    Serial.println(angle);

    IrReceiver.resume();
  }
}

範例 5：學習遙控器代碼

/*
 * 遙控器代碼學習工具
 * 按任意遙控器按鈕，顯示可直接複製的程式碼
 */

#include <IRremote.hpp>

const int IR_RECEIVE_PIN = 11;

int buttonCount = 0;

void setup() {
  Serial.begin(9600);
  Serial.println("============================");
  Serial.println("   遙控器代碼學習工具");
  Serial.println("============================");
  Serial.println();
  Serial.println("請依序按下遙控器按鈕...");
  Serial.println("複製下面的 #define 到你的程式中使用");
  Serial.println();

  IrReceiver.begin(IR_RECEIVE_PIN, ENABLE_LED_FEEDBACK);
}

void loop() {
  if (IrReceiver.decode()) {
    // 忽略重複碼
    if (IrReceiver.decodedIRData.decodedRawData != 0 &&
        IrReceiver.decodedIRData.decodedRawData != 0xFFFFFFFF) {

      buttonCount++;

      // 輸出可複製的格式
      Serial.print("#define IR_BUTTON_");
      Serial.print(buttonCount);
      Serial.print("  0x");
      Serial.println(IrReceiver.decodedIRData.decodedRawData, HEX);
    }

    IrReceiver.resume();
    delay(100);  // 避免重複讀取
  }
}

const int IR_RECEIVE_PIN = 11;
const int RED_PIN = 9;

const int BLUE_PIN = 6;

// 遙控器代碼
#define IR_1  0xF30CFF00
#define IR_2  0xE718FF00
#define IR_3  0xA15EFF00
#define IR_4  0xF708FF00
#define IR_5  0xE31CFF00
#define IR_6  0xA55AFF00
#define IR_7  0xBD42FF00
#define IR_8  0xAD52FF00
#define IR_9  0xB54AFF00

bool rainbowMode = false;
int rainbowHue = 0;

void setup() {
  Serial.begin(9600);
  pinMode(RED_PIN, OUTPUT);
  pinMode(GREEN_PIN, OUTPUT);
  pinMode(BLUE_PIN, OUTPUT);

  IrReceiver.begin(IR_RECEIVE_PIN, ENABLE_LED_FEEDBACK);

  Serial.println("RGB LED 遙控器控制");
}

void loop() {
  // 檢查遙控器
  if (IrReceiver.decode()) {
    uint32_t code = IrReceiver.decodedIRData.decodedRawData;
    rainbowMode = false;  // 收到任何按鍵就停止彩虹模式

    switch (code) {
      case IR_1: setColor(255, 0, 0); Serial.println("紅色"); break;
      case IR_2: setColor(0, 255, 0); Serial.println("綠色"); break;
      case IR_3: setColor(0, 0, 255); Serial.println("藍色"); break;
      case IR_4: setColor(255, 255, 0); Serial.println("黃色"); break;
      case IR_5: setColor(0, 255, 255); Serial.println("青色"); break;
      case IR_6: setColor(255, 0, 255); Serial.println("紫色"); break;
      case IR_7: setColor(255, 255, 255); Serial.println("白色"); break;
      case IR_8: setColor(0, 0, 0); Serial.println("關閉"); break;
      case IR_9: rainbowMode = true; Serial.println("彩虹模式"); break;
    }

    IrReceiver.resume();
  }

  // 彩虹模式
  if (rainbowMode) {
    rainbowHue = (rainbowHue + 1) % 360;
    setColorHSV(rainbowHue, 255, 255);
    delay(20);
  }
}

void setColor(int r, int g, int b) {
  analogWrite(RED_PIN, r);
  analogWrite(GREEN_PIN, g);
  analogWrite(BLUE_PIN, b);
}

// HSV 轉 RGB（簡化版）
void setColorHSV(int h, int s, int v) {
  int r, g, b;
  int region = h / 60;
  int remainder = (h % 60) * 255 / 60;

  int p = v * (255 - s) / 255;
  int q = v * (255 - (s * remainder) / 255) / 255;
  int t = v * (255 - (s * (255 - remainder)) / 255) / 255;

  switch (region) {
    case 0: r = v; g = t; b = p; break;
    case 1: r = q; g = v; b = p; break;
    case 2: r = p; g = v; b = t; break;
    case 3: r = p; g = q; b = v; break;
    case 4: r = t; g = p; b = v; break;
    default: r = v; g = p; b = q; break;
  }

  setColor(r, g, b);
}

範例 7：遙控器綜合控制（溫室應用）

/*
 * 智慧溫室遙控控制面板
 * 1=風扇開關
 * 2=霧化器開關
 * 3=LED燈開關
 * 4=窗戶開
 * 5=窗戶關
 * 0=全部關閉
 */

#include <IRremote.hpp>
#include <Servo.h>

const int IR_RECEIVE_PIN = 11;
const int FAN_RELAY = 4;
const int HUMIDIFIER_RELAY = 5;
const int LED_RELAY = 6;
const int WINDOW_SERVO_PIN = 9;

// 遙控器代碼
#define IR_0  0xE916FF00
#define IR_1  0xF30CFF00
#define IR_2  0xE718FF00
#define IR_3  0xA15EFF00
#define IR_4  0xF708FF00
#define IR_5  0xE31CFF00

Servo windowServo;

bool fanOn = false;
bool humidifierOn = false;
bool ledOn = false;
int windowAngle = 0;

void setup() {
  Serial.begin(9600);

  pinMode(FAN_RELAY, OUTPUT);
  pinMode(HUMIDIFIER_RELAY, OUTPUT);
  pinMode(LED_RELAY, OUTPUT);
  windowServo.attach(WINDOW_SERVO_PIN);

  // 初始狀態：全部關閉
  digitalWrite(FAN_RELAY, LOW);
  digitalWrite(HUMIDIFIER_RELAY, LOW);
  digitalWrite(LED_RELAY, LOW);
  windowServo.write(0);

  IrReceiver.begin(IR_RECEIVE_PIN, ENABLE_LED_FEEDBACK);

  Serial.println("=== 智慧溫室遙控面板 ===");
  Serial.println("1=風扇 2=霧化器 3=LED燈");
  Serial.println("4=開窗 5=關窗 0=全關");
  printStatus();
}

void loop() {
  if (IrReceiver.decode()) {
    uint32_t code = IrReceiver.decodedIRData.decodedRawData;

    switch (code) {
      case IR_1:  // 風扇開關
        fanOn = !fanOn;
        digitalWrite(FAN_RELAY, fanOn ? HIGH : LOW);
        Serial.println(fanOn ? "風扇：開" : "風扇：關");
        break;

      case IR_2:  // 霧化器開關
        humidifierOn = !humidifierOn;
        digitalWrite(HUMIDIFIER_RELAY, humidifierOn ? HIGH : LOW);
        Serial.println(humidifierOn ? "霧化器：開" : "霧化器：關");
        break;

      case IR_3:  // LED 燈開關
        ledOn = !ledOn;
        digitalWrite(LED_RELAY, ledOn ? HIGH : LOW);
        Serial.println(ledOn ? "LED燈：開" : "LED燈：關");
        break;

      case IR_4:  // 開窗
        windowAngle = 90;
        windowServo.write(windowAngle);
        Serial.println("窗戶：開啟");
        break;

      case IR_5:  // 關窗
        windowAngle = 0;
        windowServo.write(windowAngle);
        Serial.println("窗戶：關閉");
        break;

      case IR_0:  // 全部關閉
        fanOn = false;
        humidifierOn = false;
        ledOn = false;
        windowAngle = 0;
        digitalWrite(FAN_RELAY, LOW);
        digitalWrite(HUMIDIFIER_RELAY, LOW);
        digitalWrite(LED_RELAY, LOW);
        windowServo.write(0);
        Serial.println("全部關閉");
        break;
    }

    printStatus();
    IrReceiver.resume();
  }
}

void printStatus() {
  Serial.println("-------------------");
  Serial.print("風扇："); Serial.println(fanOn ? "ON" : "OFF");
  Serial.print("霧化器："); Serial.println(humidifierOn ? "ON" : "OFF");
  Serial.print("LED燈："); Serial.println(ledOn ? "ON" : "OFF");
  Serial.print("窗戶："); Serial.println(windowAngle > 0 ? "開" : "關");
  Serial.println("-------------------");
}

八、常見問題排解

問題 1：接收不到訊號

檢查步驟：

□ 1. 接線正確嗎？（OUT、VCC、GND）
□ 2. 遙控器有電嗎？（用手機相機看 IR LED 有沒有亮）
□ 3. 接收器方向對嗎？（圓弧面對著遙控器）
□ 4. 距離會不會太遠？（先近距離測試）
□ 5. 程式中腳位設定正確嗎？
□ 6. 有沒有強光干擾？（太陽光、日光燈）
□ 7. 試著換一個遙控器測試

問題 2：收到的代碼一直是 0 或 FFFFFFFF

可能原因與解決方法：

1. 重複碼問題
   → 長按按鈕會發送重複碼（0xFFFFFFFF）
   → 這是正常的，程式中過濾掉即可

   if (code != 0xFFFFFFFF) {
     // 處理正常代碼
   }

2. 協定不支援
   → 某些遙控器使用特殊協定
   → 嘗試用 decodedRawData 而非 command

3. 訊號不穩定
   → 加濾波電容
   → 減少距離

問題 3：代碼每次都不一樣

可能原因與解決方法：

1. 訊號干擾
   → 遠離日光燈、螢幕等光源
   → 加 100nF 濾波電容

2. 接線不穩
   → 檢查杜邦線是否鬆動
   → 使用較短的線材

3. 按太快
   → 每次按下後等待 0.5 秒再按下一次
   → 程式中加入 delay 防止重複讀取

問題 4：只有某些按鍵可用

可能原因：

1. 代碼定義錯誤
   → 用學習工具重新取得所有按鍵代碼

2. 代碼位數不同
   → 某些按鍵可能是 16 位元，某些是 32 位元
   → 嘗試使用 command 而非 decodedRawData

3. 遙控器問題
   → 某些按鍵可能故障或電池沒電

九、用手機相機看紅外線

檢測遙控器是否正常的小技巧：

1. 打開手機相機（前置或後置都可以）
2. 將遙控器 IR LED 對準鏡頭
3. 按下遙控器按鈕
4. 在手機螢幕上會看到紫色/藍白色閃光

   ┌─────────────┐
   │             │
   │    [●]      │  ← 看到閃光 = 遙控器正常
   │             │
   │   手機相機   │
   └─────────────┘

⚠️ 某些高階手機有 IR 濾鏡，可能看不到
   可以用前置相機或舊手機測試

常用程式模板

#include <IRremote.hpp>

const int IR_PIN = 11;

// 在這裡定義你的遙控器代碼
#define IR_BUTTON_1  0x12345678
#define IR_BUTTON_2  0x87654321

void setup() {
  Serial.begin(9600);
  IrReceiver.begin(IR_PIN, ENABLE_LED_FEEDBACK);
}

void loop() {
  if (IrReceiver.decode()) {
    uint32_t code = IrReceiver.decodedIRData.decodedRawData;

    // 忽略重複碼和無效碼
    if (code != 0 && code != 0xFFFFFFFF) {
      switch (code) {
        case IR_BUTTON_1:
          // 按鈕 1 的動作
          break;
        case IR_BUTTON_2:
          // 按鈕 2 的動作
          break;
      }
    }

    IrReceiver.resume();
  }
}
