關於 Python 常用套件

Python 擁有豐富的套件生態系，幾乎任何應用都能找到現成的套件。本文整理各領域常用的套件，幫助初學者快速認識 Python 的強大之處。

一、套件安裝基礎

使用 pip 安裝套件

# 安裝單一套件
pip install 套件名稱

# 安裝指定版本
pip install 套件名稱==1.2.3

# 從 requirements.txt 安裝
pip install -r requirements.txt

# 查看已安裝套件
pip list

# 解除安裝
pip uninstall 套件名稱

內建套件 vs 第三方套件

類型 說明 範例
內建套件 Python 安裝後即有，不需額外安裝 os, sys, time, json
第三方套件 需用 pip 安裝 requests, numpy, flask

二、資料處理與分析

NumPy - 數值運算基礎

import numpy as np

# 建立陣列
arr = np.array([1, 2, 3, 4, 5])

# 數學運算

print(arr.sum())   # 總和
print(arr * 2)     # 向量運算
項目 說明
用途 高效能數值運算、矩陣操作
安裝 pip install numpy

九、自動化與排程

Schedule - 定時任務

import schedule
import time

def job():
    print("執行任務...")

# 設定排程
schedule.every(10).minutes.do(job)
schedule.every().day.at("10:30").do(job)
schedule.every().monday.do(job)

while True:
    schedule.run_pending()
    time.sleep(1)
項目 說明
用途 定時執行任務
安裝 pip install schedule
適合 定期備份、資料擷取

十四、常見問題

Q1：安裝套件出現權限錯誤？

# 加上 --user
pip install --user 套件名稱

# 或使用虛擬環境
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

Q2：套件版本衝突怎麼辦？

# 使用虛擬環境隔離專案
python -m venv myproject_env

Q3：如何知道套件怎麼用？

  1. 官方文件（最準確）
  2. PyPI 頁面（pypi.org）
  3. GitHub 專案頁面
  4. Stack Overflow

Q4：requirements.txt 怎麼建立？

# 匯出目前環境的套件
pip freeze > requirements.txt

# 安裝 requirements.txt 的套件
pip install -r requirements.txt
