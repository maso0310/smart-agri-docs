語意分割（Semantic Segmentation）教學

什麼是語意分割？

語意分割是將圖片中的「每個像素」都分類到對應類別的技術。

農業應用場景

語意分割在農業上的應用非常廣泛：

  • 作物覆蓋分析：計算田地中作物覆蓋面積
  • 病斑區域識別：精確標出葉片上的病斑範圍
  • 雜草精準噴灑：識別雜草位置進行定點施藥
  • 果實成熟度分析：分割出果實區域計算成熟比例
  • 土壤分析：區分乾濕區域、裸土與植被
  • 植物生長監測：追蹤葉片面積變化

我們使用的工具：YOLOv8-Seg

YOLOv8 不只能做物件偵測，也能做實例分割（Instance Segmentation）！

實例分割 = 語意分割 + 物件偵測
          （每個像素分類）+（區分不同個體）

例如：
- 語意分割：所有蘋果都是「蘋果類」
- 實例分割：蘋果1、蘋果2、蘋果3 分別標記

標註格式（分割版）

分割的標註檔格式與物件偵測不同：

<類別編號> <x1> <y1> <x2> <y2> <x3> <y3> ... <xn> <yn>

每個物件用多邊形座標（歸一化到 0-1）描述其輪廓。

範例（img001.txt）：

0 0.25 0.30 0.35 0.25 0.45 0.30 0.45 0.50 0.35 0.55 0.25 0.50
1 0.60 0.20 0.80 0.20 0.80 0.40 0.60 0.40

這表示：

  • 第一個物件：類別 0，用 6 個點描述的多邊形
  • 第二個物件：類別 1，用 4 個點描述的矩形區域

訓練參數說明

model.train(
    data='data.yaml',      # 資料集設定檔
    epochs=50,             # 訓練輪數
    imgsz=640,             # 圖片大小
    batch=8,               # 批次大小（分割模型較吃記憶體）
    task='segment',        # 指定分割任務
    device='cpu',          # 使用 CPU 或 GPU
)

常見問題

Q1: 物件偵測和語意分割要選哪個？

需求建議選擇
只需知道物體位置物件偵測
需要計算物體面積/形狀語意分割
需要精確的邊界語意分割
運算資源有限物件偵測
需要區分相同類別的不同個體實例分割

Q2: 標註分割資料很麻煩？

確實，分割標註比物件偵測框選更耗時。建議：

  1. 使用半自動標註工具（如 Segment Anything）
  2. 使用現有資料集進行遷移學習
  3. 從小規模資料開始，逐步擴充

Q3: 記憶體不足怎麼辦？

分割模型需要更多記憶體：

# 減少批次大小
model.train(data='data.yaml', batch=4)

# 減少圖片大小
model.train(data='data.yaml', imgsz=320)

進階主題

SAM（Segment Anything Model）

Meta 的通用分割模型，可以分割任何物體：

  • 優點：不需要訓練，一鍵分割
  • 用途：快速標註、通用分割

語意分割 vs 實例分割

語意分割（Semantic Segmentation）：
- 所有同類別物體標記為同一顏色
- 無法區分個別物體

實例分割（Instance Segmentation）：
- 每個物體有獨立的遮罩
- 可以區分同類別的不同個體
- YOLOv8-Seg 做的就是實例分割！
