什麼是 RustDesk

RustDesk 是一個開源免費的遠端桌面軟體，類似 TeamViewer，但：
- 完全免費，無使用限制
- 可以自架伺服器（更安全）
- 支援樹莓派（ARM 架構）
- 跨平台：Windows、Mac、Linux、Android、iOS

使用情境
========

    你的電腦                          樹莓派
   ┌─────────┐        網路          ┌─────────┐
   │ RustDesk│ ◄──────────────────► │ RustDesk│
   │  客戶端 │      遠端連線         │  服務端 │
   └─────────┘                      └─────────┘

   可以看到樹莓派的桌面畫面
   可以用滑鼠鍵盤操作樹莓派

在樹莓派安裝 RustDesk

步驟 1：下載 RustDesk

# 進入下載目錄
cd ~/Downloads

# 下載 RustDesk（ARM64 版本，適用於 Pi 4/5 的 64 位元系統）
wget https://github.com/rustdesk/rustdesk/releases/download/1.2.3/rustdesk-1.2.3-aarch64.deb

# 如果是 32 位元系統，使用這個：
# wget https://github.com/rustdesk/rustdesk/releases/download/1.2.3/rustdesk-1.2.3-armhf.deb

注意：版本號可能會更新，請到 RustDesk GitHub Releases 查看最新版本

步驟 2：安裝 RustDesk

# 安裝下載的 .deb 檔案
sudo apt install ./rustdesk-1.2.3-aarch64.deb

# 如果出現相依性問題，執行：
sudo apt --fix-broken install

步驟 3：啟動 RustDesk

# 從終端機啟動
rustdesk

# 或從桌面選單：Menu → Internet → RustDesk

步驟 4：記下你的 ID 和密碼

RustDesk 啟動後會顯示：

┌─────────────────────────────────┐
│         RustDesk                │
│                                 │
│    你的 ID: 123 456 789        │  ← 記下這個
│                                 │
│    密碼: xxxxxxxx              │  ← 記下這個
│                                 │
└─────────────────────────────────┘

這組 ID 和密碼是別人連到你的樹莓派需要的

步驟 5：設定開機自動啟動

# 設定 RustDesk 服務開機啟動
sudo systemctl enable rustdesk
sudo systemctl start rustdesk

在電腦端安裝 RustDesk

Windows

  1. 到 RustDesk 官網 下載 Windows 版本
  2. 執行安裝程式
  3. 安裝完成後開啟 RustDesk

Mac

  1. 到 RustDesk 官網 下載 Mac 版本
  2. 打開 .dmg 檔案，拖曳到 Applications
  3. 開啟 RustDesk

建立連線

從電腦連到樹莓派

1. 在電腦上開啟 RustDesk

2. 在「控制遠端桌面」欄位輸入樹莓派的 ID
   ┌─────────────────────────────────┐
   │  控制遠端桌面                    │
   │  ┌─────────────────────────┐    │
   │  │ 123 456 789            │    │  ← 輸入樹莓派的 ID
   │  └─────────────────────────┘    │
   │            [連接]               │
   └─────────────────────────────────┘

3. 點擊「連接」

4. 輸入樹莓派的密碼

5. 連線成功！可以看到樹莓派桌面

重要：解決無螢幕無法連線問題

問題描述

當樹莓派沒有接實體螢幕時：
├── RustDesk 連得上，但畫面全黑或解析度很小
├── 顯示「螢幕未連接」或類似訊息
└── 必須接上 HDMI 螢幕才能正常顯示

原因：
樹莓派預設在沒有偵測到螢幕時，不會啟動完整的圖形輸出

解決方案（三個都要做！）

方案 1：修改 cmdline.txt

# 編輯 cmdline.txt
sudo nano /boot/firmware/cmdline.txt

重要：這個檔案只有一行，不要換行！

在該行的最末尾加上（前面加一個空格）：

 vc4.force_hotplug=1

修改前：

console=serial0,115200 console=tty1 root=PARTUUID=xxxxx rootfstype=ext4 ...

修改後：

console=serial0,115200 console=tty1 root=PARTUUID=xxxxx rootfstype=ext4 ... vc4.force_hotplug=1

按 Ctrl+X，然後 Y，然後 Enter 儲存

方案 2：修改 config.txt

# 編輯 config.txt
sudo nano /boot/firmware/config.txt

# 注意：舊版系統可能是 /boot/config.txt
# 如果 /boot/firmware/config.txt 不存在，試試：
# sudo nano /boot/config.txt

在檔案最後面加入以下內容：

# ========================================
# 無螢幕遠端連線設定（Headless Mode）
# ========================================

# 強制啟用 HDMI，即使沒有偵測到螢幕
hdmi_force_hotplug=1

# 設定 HDMI 輸出模式
# hdmi_group=2 表示使用 DMT（電腦螢幕）模式
hdmi_group=2

# hdmi_mode=82 表示 1920x1080 60Hz
# 其他常用選項：
#   hdmi_mode=85 → 1280x720 60Hz
#   hdmi_mode=82 → 1920x1080 60Hz
#   hdmi_mode=16 → 1024x768 60Hz（hdmi_group=1 時）
hdmi_mode=82

# 如果上面還不行，可以再加這些：
# 強制使用 HDMI 音訊（可選）
# hdmi_drive=2

# 增加 HDMI 訊號強度（如果畫面有雜訊）
# config_hdmi_boost=4

按 Ctrl+X，然後 Y，然後 Enter 儲存

方案 3：重新啟動樹莓派

sudo reboot

驗證設定是否生效

# 重開機後，檢查虛擬螢幕是否啟用
# 應該會顯示 1920x1080 或你設定的解析度
tvservice -s

# 或者檢查 Xorg 顯示
DISPLAY=:0 xrandr

常見問題排除

問題 1：連線成功但畫面全黑

可能原因與解決方法：

# 1. 確認 config.txt 設定是否生效
cat /boot/firmware/config.txt | grep hdmi

# 應該看到：
# hdmi_force_hotplug=1
# hdmi_group=2
# hdmi_mode=82

# 2. 確認 cmdline.txt 設定是否生效
cat /boot/firmware/cmdline.txt | grep vc4

# 應該看到 vc4.force_hotplug=1

# 3. 如果還是黑畫面，試著重新啟動顯示管理器
sudo systemctl restart lightdm

問題 2：解析度太小或太大

# 編輯 config.txt 調整 hdmi_mode
sudo nano /boot/firmware/config.txt

# 常用解析度（hdmi_group=2 DMT 模式）：
# hdmi_mode=4  → 640x480 60Hz
# hdmi_mode=9  → 800x600 60Hz
# hdmi_mode=16 → 1024x768 60Hz
# hdmi_mode=35 → 1280x1024 60Hz
# hdmi_mode=51 → 1600x1200 60Hz
# hdmi_mode=82 → 1920x1080 60Hz（推薦）
# hdmi_mode=85 → 1280x720 60Hz

# 修改後重開機
sudo reboot

問題 3：RustDesk 服務沒有自動啟動

# 檢查服務狀態
sudo systemctl status rustdesk

# 如果沒有啟動，手動啟動並設定開機啟動
sudo systemctl enable rustdesk
sudo systemctl start rustdesk

# 或者用另一種方式設定開機啟動
mkdir -p ~/.config/autostart
nano ~/.config/autostart/rustdesk.desktop

在檔案中加入：

[Desktop Entry]
Type=Application
Name=RustDesk
Exec=rustdesk
Hidden=false
NoDisplay=false
X-GNOME-Autostart-enabled=true

問題 4：連線後畫面很卡/延遲高

# 1. 調整 RustDesk 的畫質設定（在連線時選擇「原始」或「平衡」）

# 2. 降低樹莓派的桌面特效
# 使用 Raspberry Pi Configuration 或：
sudo raspi-config
# → Advanced Options → GL Driver → Legacy

# 3. 降低解析度
# 編輯 /boot/firmware/config.txt
# 改用較低的 hdmi_mode，例如 85（1280x720）

問題 5：Pi 5 特別注意事項

# Pi 5 的設定檔位置和舊版不同
# 確認你編輯的是正確的檔案：

# Pi 5 / Bookworm：
/boot/firmware/config.txt
/boot/firmware/cmdline.txt

# Pi 4 / Bullseye 或更舊：
/boot/config.txt
/boot/cmdline.txt

問題 6：找不到 /boot/firmware 目錄

# 如果 /boot/firmware 不存在，可能是舊版系統
# 直接使用 /boot：
sudo nano /boot/config.txt
sudo nano /boot/cmdline.txt

其他替代方案

如果 RustDesk 還是無法使用，可以考慮：

方案 A：使用 VNC

# 樹莓派內建 VNC 支援
sudo raspi-config
# → Interface Options → VNC → Enable

# 然後在電腦安裝 VNC Viewer
# https://www.realvnc.com/en/connect/download/viewer/

方案 B：使用假 HDMI 接頭（HDMI Dummy Plug）

如果軟體設定都不行，可以買一個「HDMI 假負載」
插在樹莓派的 HDMI 孔上，騙過系統以為有螢幕

搜尋：「HDMI Dummy Plug」或「HDMI 假負載」
價格：約 $30-50

方案 C：使用 xrdp（Windows 遠端桌面）

# 安裝 xrdp
sudo apt install xrdp

# 啟動服務
sudo systemctl enable xrdp
sudo systemctl start xrdp

# 然後從 Windows 使用「遠端桌面連線」連到樹莓派的 IP
