基礎電子學與 Arduino

前言

學習 Arduino 之前，了解一些基礎電子學知識會讓你更容易理解電路的運作原理，也能避免燒壞元件。別擔心，這些概念其實很直覺，我們會用生活中的例子來解釋。

一、電壓 (Voltage)

什麼是電壓？

電壓就像「水壓」。

想像你家的水塔：

  • 水塔越高，水壓越大，水流出來的力道越強
  • 電壓也是一樣，電壓越高，推動電流的「力道」越大

單位

  • 伏特 (V, Volt)
  • 常見電壓：USB 5V、乾電池 1.5V、9V 電池、家用電 110V

生活比喻

水塔高度 = 電壓
水塔越高 → 水壓越大 → 水流越急
電壓越高 → 推力越大 → 電流越強

Arduino 相關

  • Arduino Uno 工作電壓：5V
  • Arduino 的 GPIO 腳位輸出：5V (HIGH) 或 0V (LOW)
  • 有些感測器是 3.3V，不能直接接 5V，否則會燒壞！

二、電流 (Current)

什麼是電流？

電流就像「水流量」。

  • 水管裡每秒流過多少水 = 水流量
  • 電線裡每秒流過多少電子 = 電流

單位

  • 安培 (A, Ampere)
  • 常用較小單位：毫安培 (mA) = 0.001A

生活比喻

水流量 = 電流
水流量大 → 能帶動大水車
電流大 → 能驅動大馬達

常見電流值

元件 電流
LED 10-20 mA
Arduino Uno 整體 約 50 mA
小馬達 100-300 mA
步進馬達 28BYJ-48 200-300 mA

Arduino 相關

  • 每個 GPIO 腳位最大電流：40mA（建議不超過 20mA）
  • 整個板子最大電流：200mA
  • 如果需要驅動大電流元件（馬達、繼電器），要用外部電源！

三、電阻 (Resistance)

什麼是電阻？

電阻就像「水管的粗細」。

  • 水管越細，水越難流過去
  • 電阻越大，電流越難通過

單位

  • 歐姆 (Ω, Ohm)
  • 常用較大單位：千歐姆 (kΩ) = 1000Ω

生活比喻

水管粗細 = 電阻
水管越細 → 水流越小
電阻越大 → 電流越小

電阻的用途

1. 限流（保護元件）

LED 不能直接接電源，需要電阻來限制電流：

5V → 電阻 (220Ω) → LED → GND

2. 分壓（降低電壓）

把 5V 變成 3.3V：

5V → R1 (1kΩ) → 輸出點 (3.3V) → R2 (2kΩ) → GND

3. 上拉/下拉電阻

確保輸入腳位有明確的 HIGH 或 LOW 狀態。

四、歐姆定律 ⭐

最重要的公式

V = I × R

電壓 (V) = 電流 (I) × 電阻 (R)

變形公式

I = V / R    （已知電壓和電阻，求電流）
R = V / I    （已知電壓和電流，求電阻）

實際計算範例：LED 限流電阻

情境：用 Arduino 5V 點亮一顆紅色 LED

已知：

  • 電源電壓：5V
  • LED 工作電壓：約 2V
  • LED 建議電流：15mA (0.015A)

計算：

電阻需要承受的電壓 = 5V - 2V = 3V
電阻值 = 3V / 0.015A = 200Ω

→ 選用 220Ω 電阻（常見規格）

水流比喻理解歐姆定律

水壓 (V) = 水流量 (I) × 水管阻力 (R)

- 水壓固定時，水管越細 (R大)，水流越小 (I小)
- 水管固定時，水壓越大 (V大)，水流越大 (I大)

五、電容 (Capacitance)

什麼是電容？

電容就像「蓄水池」或「小水桶」。

  • 可以暫時儲存水，需要時再放出來
  • 電容可以暫時儲存電能，需要時再釋放

單位

  • 法拉 (F, Farad)
  • 常用較小單位：
  • 微法拉 (µF) = 0.000001F
  • 奈法拉 (nF) = 0.000000001F
  • 皮法拉 (pF) = 0.000000000001F

電容的用途

1. 濾波/去耦 (Decoupling)

穩定電源，過濾雜訊：

電源 VCC ──┬── 電容 (0.1µF) ──┬── GND
           │                  │
           └── IC 晶片電源 ───┘

比喻：就像水塔旁邊加一個小水桶，當水壓不穩時，小水桶可以補充或吸收多餘的水。

2. 儲能

暫時儲存電能，在電源中斷時維持短暫供電。

3. 計時電路

配合電阻可以產生延遲效果。

Arduino 相關

  • IC 晶片旁邊常會放 0.1µF (100nF) 的去耦電容
  • 電源輸入端常會放 10µF ~ 100µF 的濾波電容

六、功率 (Power)

什麼是功率？

功率就像「做事的速度」。

  • 同樣搬 100 箱貨物，1 小時搬完比 2 小時搬完「功率」更大
  • 電器消耗能量的速度就是功率

公式

P = V × I

功率 (W) = 電壓 (V) × 電流 (I)

單位

  • 瓦特 (W, Watt)
  • 1W = 1V × 1A

實際計算範例

情境：Arduino Uno 的耗電功率

電壓：5V
電流：50mA = 0.05A
功率 = 5V × 0.05A = 0.25W

為什麼要知道功率？

  1. 選擇電源：電源供應器要能提供足夠的功率
  2. 電阻發熱：電阻會把能量轉換成熱，功率越大越燙
  3. 電池續航：功率越大，電池越快沒電

七、實際應用情境

情境 1：為什麼 LED 要串聯電阻？

問題：LED 直接接 5V 會怎樣？

錯誤接法：5V → LED → GND
結果：LED 瞬間燒壞！

原因：LED 內部電阻很小，直接接電源會產生巨大電流。

正確接法：

5V → 220Ω 電阻 → LED → GND

電阻限制了電流在安全範圍內 (約 15mA)。

情境 2：為什麼馬達要用外部電源？

問題：小馬達直接接 Arduino 腳位會怎樣？

錯誤接法：Arduino D3 → 馬達 → GND
結果：Arduino 可能重啟或燒壞！

原因：

  • 馬達需要 200-500mA 電流
  • Arduino GPIO 最大只能提供 40mA

正確接法：

Arduino D3 → 電晶體/繼電器 → 馬達 → 外部電源

用小電流控制大電流，就像用小開關控制大水閥。

情境 3：為什麼 ESP-01 (3.3V) 不能直接接 Arduino (5V)？

問題：Arduino TX (5V) 直接接 ESP-01 RX 會怎樣？

錯誤接法：Arduino TX (5V) → ESP-01 RX
結果：ESP-01 可能燒壞！

原因：ESP-01 是 3.3V 設備，無法承受 5V 訊號。

解決方案 - 分壓電路：

Arduino TX ── R1 (1kΩ) ──┬── ESP-01 RX
                         │
                    R2 (2kΩ)
                         │
                        GND

輸出電壓 = 5V × 2kΩ / (1kΩ + 2kΩ) = 3.3V ✓

情境 4：按鈕為什麼需要上拉/下拉電阻？

問題：按鈕沒按下時，輸入腳位讀到什麼？

錯誤接法：
按鈕一端接 5V，另一端接 Arduino 輸入腳位
→ 按下時讀到 HIGH，沒按時讀到...？不確定！（浮動狀態）

正確接法 - 下拉電阻：

        5V
        │
      [按鈕]
        │
Arduino ─┴── 10kΩ ── GND

按下 → 讀到 HIGH (5V)
放開 → 讀到 LOW (被電阻拉到 GND)

十、總結與口訣

水流比喻總整理

電壓 = 水壓 (推動力)
電流 = 水流量 (流動的多寡)
電阻 = 水管粗細 (阻礙流動)
電容 = 蓄水池 (暫存能量)
功率 = 做事速度 (消耗能量的快慢)

歐姆定律口訣

    V
   ───
  I × R

蓋住想求的，剩下的就是公式：
- 蓋住 V → V = I × R
- 蓋住 I → I = V / R
- 蓋住 R → R = V / I

安全守則

  1. 先斷電再接線
  2. 確認電壓相容 (5V vs 3.3V)
  3. LED 一定要串電阻
  4. 大電流元件用外部電源
  5. 電容注意正負極 (電解電容)
