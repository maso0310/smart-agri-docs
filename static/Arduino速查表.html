Arduino 速查表

一頁式快速參考，涵蓋最常用的 Arduino 函式與語法。

程式結構

// 初始化，只執行一次
void setup() {
  // 設定腳位、初始化
}

// 主迴圈，重複執行
void loop() {
  // 主要程式邏輯
}

數位 I/O

函式 說明 範例
pinMode(pin, mode) 設定腳位模式 pinMode(13, OUTPUT);
digitalWrite(pin, value) 輸出高/低電位 digitalWrite(13, HIGH);
digitalRead(pin) 讀取數位輸入 int val = digitalRead(2);

模式常數：
- INPUT - 輸入模式
- OUTPUT - 輸出模式
- INPUT_PULLUP - 輸入模式（內建上拉電阻）

電位常數：
- HIGH - 高電位（5V 或 3.3V）
- LOW - 低電位（0V）

類比 I/O

函式 說明 範例
analogRead(pin) 讀取類比值 (0-1023) int val = analogRead(A0);
analogWrite(pin, value) PWM 輸出 (0-255) analogWrite(9, 128);

注意：
- analogRead() 使用 A0-A5 腳位
- analogWrite() 只能用於 PWM 腳位（標有 ~ 符號）
- UNO 的 PWM 腳位：3, 5, 6, 9, 10, 11

時間函式

函式 說明 範例
delay(ms) 暫停（毫秒） delay(1000); // 1秒
delayMicroseconds(us) 暫停（微秒） delayMicroseconds(100);
millis() 開機後經過的毫秒數 unsigned long t = millis();
micros() 開機後經過的微秒數 unsigned long t = micros();

非阻塞延遲範例：

unsigned long previousMillis = 0;
const long interval = 1000;

void loop() {
  unsigned long currentMillis = millis();
  if (currentMillis - previousMillis >= interval) {
    previousMillis = currentMillis;
    // 每秒執行一次
  }
}

序列通訊

函式 說明 範例
Serial.begin(baud) 初始化序列埠 Serial.begin(9600);
Serial.print(data) 印出資料 Serial.print("Hello");
Serial.println(data) 印出資料（換行） Serial.println(123);
Serial.available() 檢查是否有資料 if(Serial.available() > 0)
Serial.read() 讀取一個字元 char c = Serial.read();
Serial.readString() 讀取字串 String s = Serial.readString();

常用鮑率： 9600, 115200

快速範例

LED 閃爍

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}

讀取按鈕

void setup() {
  pinMode(2, INPUT_PULLUP);
  pinMode(13, OUTPUT);
}

void loop() {
  if (digitalRead(2) == LOW) {
    digitalWrite(13, HIGH);
  } else {
    digitalWrite(13, LOW);
  }
}

讀取可變電阻

void setup() {
  Serial.begin(9600);
}

void loop() {
  int value = analogRead(A0);
  Serial.println(value);
  delay(100);
}

PWM LED 漸變

void setup() {
  pinMode(9, OUTPUT);
}

void loop() {
  for (int i = 0; i <= 255; i++) {
    analogWrite(9, i);
    delay(10);
  }
  for (int i = 255; i >= 0; i--) {
    analogWrite(9, i);
    delay(10);
  }
}
