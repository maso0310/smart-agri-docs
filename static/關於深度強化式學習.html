關於深度強化式學習 (Deep Reinforcement Learning)

強化學習基本概念

強化學習 (Reinforcement Learning, RL) 是機器學習的一個分支，其核心思想是讓 智慧體 (Agent) 透過與環境 (Environment) 的互動，學習如何 採取動作 (Action) 以最大化累積獎勵 (Reward)。

深度強化學習 (Deep RL) 則是將深度神經網路與強化學習結合，使用神經網路來近似 價值函數或策略函數，從而能夠處理高維度的狀態空間和動作空間。

核心元素

智慧體 (Agent)

↓ 動作 (Action)      ↑ 狀態 (State) + 獎勵 (Reward)
環境 (Environment)
元素 符號 說明 農業範例
狀態 (State) s, S 環境的當前情況描述 溫度、濕度、土壤水分、光照強度
動作 (Action) a, A 智慧體可執行的行為 澆水、施肥、開燈、通風
獎勵 (Reward) r, R 動作後環境給予的回饋 植物生長速度、果實品質
策略 (Policy) π 狀態到動作的映射 溫度>30°C 時開啟風扇
價值函數 (Value) V(s), Q(s,a) 預期累積獎勵 特定環境配置下的預期產量
折扣因子 γ (gamma) 未來獎勵的重要性 (0~1) 0.99 表示重視長期收益

馬可夫決策過程 (MDP)

強化學習問題通常被建模為馬可夫決策過程 (Markov Decision Process, MDP)， 其核心假設是：未來狀態只取決於當前狀態和動作，與過去的歷史無關（馬可夫性質）。

MDP 五元組

MDP = (S, A, P, R, γ)
  • S：狀態空間 (State Space)
  • A：動作空間 (Action Space)
  • P：狀態轉移機率 P(s'|s,a)
  • R：獎勵函數 R(s,a,s')
  • γ：折扣因子 (0 ≤ γ ≤ 1)

貝爾曼方程 (Bellman Equation)

V(s) = maxa [ R(s,a) + γ Σ P(s'|s,a) V(s') ]
Q(s,a) = R(s,a) + γ Σ P(s'|s,a) maxa' Q(s',a')

主要演算法分類

類別 演算法 特點 適用場景
價值基礎 (Value-based) DQN 使用神經網路估計 Q 值 離散動作空間
Double DQN 減少 Q 值過估計 改善 DQN 穩定性
Dueling DQN 分離狀態價值與優勢 狀態重要性不均
策略基礎 (Policy-based) REINFORCE 直接優化策略 連續動作空間
PPO 近端策略優化，穩定高效 通用，易調參
TRPO 信賴區域策略優化 需要穩定更新
Actor-Critic A2C/A3C 同步/非同步優勢 平行化訓練
SAC 最大熵強化學習 連續控制
TD3 雙延遲深度確定性 連續動作，機器人

DQN (Deep Q-Network)

DQN 是深度強化學習的里程碑演算法，由 DeepMind 於 2013 年提出。它使用深度神經網路來近似 Q 函數，並引入了兩個關鍵技術來穩定訓練：

  • 經驗回放 (Experience Replay)：儲存過去的經驗並隨機採樣訓練
  • 目標網路 (Target Network)：使用較舊的網路計算目標值

DQN 損失函數

L(θ) = E[ (r + γ maxa' Q(s',a'; θ-) - Q(s,a; θ))² ]

PyTorch DQN 實作

import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np
from collections import deque
import random

class DQNetwork(nn.Module):
    """深度 Q 網路"""

    def __init__(self, state_dim, action_dim, hidden_dim=128):
        super(DQNetwork, self).__init__()
        self.network = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, action_dim)
        )

    def forward(self, x):
        return self.network(x)


class ReplayBuffer:
    """經驗回放緩衝區"""

    def __init__(self, capacity=10000):
        self.buffer = deque(maxlen=capacity)

    def push(self, state, action, reward, next_state, done):
        self.buffer.append((state, action, reward, next_state, done))

    def sample(self, batch_size):
        batch = random.sample(self.buffer, batch_size)
        states, actions, rewards, next_states, dones = zip(*batch)
        return (
            np.array(states),
            np.array(actions),
            np.array(rewards, dtype=np.float32),
            np.array(next_states),
            np.array(dones, dtype=np.float32)
        )

    def __len__(self):
        return len(self.buffer)


class DQNAgent:
    """DQN 智慧體"""

    def __init__(self, state_dim, action_dim, lr=1e-3, gamma=0.99,
                 epsilon_start=1.0, epsilon_end=0.01, epsilon_decay=0.995):
        self.state_dim = state_dim
        self.action_dim = action_dim
        self.gamma = gamma
        self.epsilon = epsilon_start
        self.epsilon_end = epsilon_end
        self.epsilon_decay = epsilon_decay

        self.device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

        # 主網路與目標網路
        self.q_network = DQNetwork(state_dim, action_dim).to(self.device)
        self.target_network = DQNetwork(state_dim, action_dim).to(self.device)
        self.target_network.load_state_dict(self.q_network.state_dict())

        self.optimizer = optim.Adam(self.q_network.parameters(), lr=lr)
        self.buffer = ReplayBuffer()

    def select_action(self, state, training=True):
        """ε-greedy 動作選擇"""
        if training and random.random() < self.epsilon:
            return random.randint(0, self.action_dim - 1)

        state_tensor = torch.FloatTensor(state).unsqueeze(0).to(self.device)
        with torch.no_grad():
            q_values = self.q_network(state_tensor)
        return q_values.argmax().item()

    def update(self, batch_size=64):
        """更新網路"""
        if len(self.buffer) < batch_size:
            return 0

        # 採樣經驗
        states, actions, rewards, next_states, dones = self.buffer.sample(batch_size)

        states = torch.FloatTensor(states).to(self.device)
        actions = torch.LongTensor(actions).to(self.device)
        rewards = torch.FloatTensor(rewards).to(self.device)
        next_states = torch.FloatTensor(next_states).to(self.device)
        dones = torch.FloatTensor(dones).to(self.device)

        # 計算當前 Q 值
        current_q = self.q_network(states).gather(1, actions.unsqueeze(1))

        # 計算目標 Q 值
        with torch.no_grad():
            next_q = self.target_network(next_states).max(1)[0]
            target_q = rewards + self.gamma * next_q * (1 - dones)

        # 計算損失並更新
        loss = nn.MSELoss()(current_q.squeeze(), target_q)
        self.optimizer.zero_grad()
        loss.backward()
        self.optimizer.step()

        # 衰減探索率
        self.epsilon = max(self.epsilon_end, self.epsilon * self.epsilon_decay)

        return loss.item()

    def update_target_network(self):
        """更新目標網路"""
        self.target_network.load_state_dict(self.q_network.state_dict())

    def save(self, path):
        torch.save(self.q_network.state_dict(), path)

    def load(self, path):
        self.q_network.load_state_dict(torch.load(path))
        self.target_network.load_state_dict(self.q_network.state_dict())

PPO (Proximal Policy Optimization)

PPO 是目前最流行的深度強化學習演算法之一，由 OpenAI 於 2017 年提出。它的核心思想是 限制每次策略更新的幅度，避免過大的更新導致訓練不穩定。

PPO-Clip 目標函數

LCLIP(θ) = E[ min( rt(θ) At, clip(rt(θ), 1-ε, 1+ε) At ) ]

其中 rt(θ) = π(a|s;θ) / π(a|s;θold) 是新舊策略的機率比， At 是優勢函數估計。

PyTorch PPO 實作

import torch
import torch.nn as nn
import torch.optim as optim
from torch.distributions import Categorical
import numpy as np

class ActorCritic(nn.Module):
    """Actor-Critic 網路"""

    def __init__(self, state_dim, action_dim, hidden_dim=64):
        super(ActorCritic, self).__init__()

        # 共享特徵提取層
        self.shared = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),
            nn.Tanh(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.Tanh()
        )

        # Actor (策略網路)
        self.actor = nn.Linear(hidden_dim, action_dim)

        # Critic (價值網路)
        self.critic = nn.Linear(hidden_dim, 1)

    def forward(self, state):
        features = self.shared(state)
        action_probs = torch.softmax(self.actor(features), dim=-1)
        state_value = self.critic(features)
        return action_probs, state_value

    def get_action(self, state):
        action_probs, _ = self.forward(state)
        dist = Categorical(action_probs)
        action = dist.sample()
        return action, dist.log_prob(action)

    def evaluate(self, states, actions):
        action_probs, state_values = self.forward(states)
        dist = Categorical(action_probs)
        action_log_probs = dist.log_prob(actions)
        entropy = dist.entropy()
        return action_log_probs, state_values.squeeze(), entropy


class PPOAgent:
    """PPO 智慧體"""

    def __init__(self, state_dim, action_dim, lr=3e-4, gamma=0.99,
                 gae_lambda=0.95, clip_epsilon=0.2, epochs=10):
        self.gamma = gamma
        self.gae_lambda = gae_lambda
        self.clip_epsilon = clip_epsilon
        self.epochs = epochs

        self.device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

        self.policy = ActorCritic(state_dim, action_dim).to(self.device)
        self.optimizer = optim.Adam(self.policy.parameters(), lr=lr)

        # 軌跡儲存
        self.states = []
        self.actions = []
        self.rewards = []
        self.log_probs = []
        self.dones = []
        self.values = []

    def select_action(self, state):
        state_tensor = torch.FloatTensor(state).unsqueeze(0).to(self.device)

        with torch.no_grad():
            action, log_prob = self.policy.get_action(state_tensor)
            _, value = self.policy(state_tensor)

        return action.item(), log_prob.item(), value.item()

    def store_transition(self, state, action, reward, log_prob, done, value):
        self.states.append(state)
        self.actions.append(action)
        self.rewards.append(reward)
        self.log_probs.append(log_prob)
        self.dones.append(done)
        self.values.append(value)

    def compute_gae(self, next_value):
        """計算廣義優勢估計 (GAE)"""
        advantages = []
        gae = 0

        values = self.values + [next_value]

        for t in reversed(range(len(self.rewards))):
            delta = self.rewards[t] + self.gamma * values[t+1] * (1 - self.dones[t]) - values[t]
            gae = delta + self.gamma * self.gae_lambda * (1 - self.dones[t]) * gae
            advantages.insert(0, gae)

        returns = [adv + val for adv, val in zip(advantages, self.values)]
        return advantages, returns

    def update(self, next_value):
        """更新策略"""
        # 計算優勢和回報
        advantages, returns = self.compute_gae(next_value)

        # 轉換為張量
        states = torch.FloatTensor(np.array(self.states)).to(self.device)
        actions = torch.LongTensor(self.actions).to(self.device)
        old_log_probs = torch.FloatTensor(self.log_probs).to(self.device)
        advantages = torch.FloatTensor(advantages).to(self.device)
        returns = torch.FloatTensor(returns).to(self.device)

        # 標準化優勢
        advantages = (advantages - advantages.mean()) / (advantages.std() + 1e-8)

        # 多次更新
        for _ in range(self.epochs):
            # 評估當前策略
            new_log_probs, values, entropy = self.policy.evaluate(states, actions)

            # 計算機率比
            ratio = torch.exp(new_log_probs - old_log_probs)

            # PPO-Clip 損失
            surr1 = ratio * advantages
            surr2 = torch.clamp(ratio, 1 - self.clip_epsilon, 1 + self.clip_epsilon) * advantages
            actor_loss = -torch.min(surr1, surr2).mean()

            # 價值損失
            critic_loss = nn.MSELoss()(values, returns)

            # 熵獎勵（鼓勵探索）
            entropy_loss = -entropy.mean()

            # 總損失
            loss = actor_loss + 0.5 * critic_loss + 0.01 * entropy_loss

            self.optimizer.zero_grad()
            loss.backward()
            nn.utils.clip_grad_norm_(self.policy.parameters(), 0.5)
            self.optimizer.step()

        # 清空軌跡
        self.states.clear()
        self.actions.clear()
        self.rewards.clear()
        self.log_probs.clear()
        self.dones.clear()
        self.values.clear()

智慧農業應用範例

智慧溫室環境控制系統

以下範例展示如何使用深度強化學習來控制溫室環境，自動調節溫度、濕度和光照， 以最大化植物生長效益。 

import numpy as np
import torch

class GreenhouseEnvironment:
    """智慧溫室環境模擬器"""

    def __init__(self):
        # 狀態空間: [溫度, 濕度, 土壤水分, 光照, 時間(小時)]
        self.state_dim = 5
        # 動作空間: [無動作, 加熱, 降溫, 加濕, 除濕, 澆水, 開燈, 關燈]
        self.action_dim = 8

        # 最佳生長條件
        self.optimal_temp = 25.0      # 最佳溫度 (°C)
        self.optimal_humidity = 65.0   # 最佳濕度 (%)
        self.optimal_soil = 60.0       # 最佳土壤水分 (%)
        self.optimal_light = 800.0     # 最佳光照 (lux)

        # 環境參數
        self.outdoor_temp = 20.0       # 室外溫度
        self.energy_cost = 0.1         # 能源成本係數

        self.reset()

    def reset(self):
        """重置環境"""
        self.temperature = np.random.uniform(18, 32)
        self.humidity = np.random.uniform(40, 80)
        self.soil_moisture = np.random.uniform(30, 70)
        self.light_level = np.random.uniform(200, 1000)
        self.hour = np.random.randint(0, 24)
        self.step_count = 0

        return self._get_state()

    def _get_state(self):
        """取得當前狀態"""
        return np.array([
            self.temperature / 40.0,        # 正規化
            self.humidity / 100.0,
            self.soil_moisture / 100.0,
            self.light_level / 1500.0,
            self.hour / 24.0
        ], dtype=np.float32)

    def step(self, action):
        """執行動作"""
        energy_used = 0

        # 執行動作
        if action == 0:    # 無動作
            pass
        elif action == 1:  # 加熱
            self.temperature += 2.0
            energy_used = 0.3
        elif action == 2:  # 降溫
            self.temperature -= 2.0
            energy_used = 0.4
        elif action == 3:  # 加濕
            self.humidity += 5.0
            energy_used = 0.1
        elif action == 4:  # 除濕
            self.humidity -= 5.0
            energy_used = 0.2
        elif action == 5:  # 澆水
            self.soil_moisture += 10.0
            energy_used = 0.05
        elif action == 6:  # 開燈
            self.light_level += 300.0
            energy_used = 0.25
        elif action == 7:  # 關燈
            self.light_level -= 300.0

        # 環境自然變化
        self._natural_dynamics()

        # 計算獎勵
        reward = self._calculate_reward(energy_used)

        # 更新時間
        self.step_count += 1
        self.hour = (self.hour + 1) % 24

        # 判斷是否結束（一天）
        done = self.step_count >= 24

        return self._get_state(), reward, done, {}

    def _natural_dynamics(self):
        """環境自然動態變化"""
        # 溫度向室外溫度靠近
        self.temperature += (self.outdoor_temp - self.temperature) * 0.05

        # 濕度自然蒸發
        self.humidity -= 0.5

        # 土壤水分蒸發
        self.soil_moisture -= 0.3

        # 自然光照變化（日夜週期）
        if 6 <= self.hour <= 18:
            natural_light = 500 * np.sin(np.pi * (self.hour - 6) / 12)
        else:
            natural_light = 0
        self.light_level = self.light_level * 0.8 + natural_light * 0.2

        # 限制範圍
        self.temperature = np.clip(self.temperature, 5, 45)
        self.humidity = np.clip(self.humidity, 20, 95)
        self.soil_moisture = np.clip(self.soil_moisture, 10, 100)
        self.light_level = np.clip(self.light_level, 0, 1500)

    def _calculate_reward(self, energy_used):
        """計算獎勵"""
        # 計算與最佳條件的差距
        temp_penalty = -abs(self.temperature - self.optimal_temp) / 10.0
        humidity_penalty = -abs(self.humidity - self.optimal_humidity) / 50.0
        soil_penalty = -abs(self.soil_moisture - self.optimal_soil) / 50.0

        # 光照獎勵（白天需要光，晚上不需要）
        if 6 <= self.hour <= 18:
            light_penalty = -abs(self.light_level - self.optimal_light) / 500.0
        else:
            light_penalty = -self.light_level / 1000.0  # 晚上不需要光

        # 能源成本
        energy_penalty = -energy_used * self.energy_cost

        # 總獎勵
        reward = temp_penalty + humidity_penalty + soil_penalty + light_penalty + energy_penalty

        # 額外獎勵：所有條件都在最佳範圍內
        if (22 <= self.temperature <= 28 and
            55 <= self.humidity <= 75 and
            50 <= self.soil_moisture <= 70):
            reward += 0.5

        return reward


def train_greenhouse_controller():
    """訓練溫室控制器"""
    env = GreenhouseEnvironment()
    agent = DQNAgent(
        state_dim=env.state_dim,
        action_dim=env.action_dim,
        lr=1e-3,
        gamma=0.99
    )

    episodes = 1000
    target_update_freq = 10
    best_reward = float('-inf')

    for episode in range(episodes):
        state = env.reset()
        total_reward = 0
        done = False

        while not done:
            # 選擇動作
            action = agent.select_action(state)

            # 執行動作
            next_state, reward, done, _ = env.step(action)

            # 儲存經驗
            agent.buffer.push(state, action, reward, next_state, done)

            # 更新網路
            loss = agent.update(batch_size=64)

            state = next_state
            total_reward += reward

        # 更新目標網路
        if episode % target_update_freq == 0:
            agent.update_target_network()

        # 記錄最佳模型
        if total_reward > best_reward:
            best_reward = total_reward
            agent.save('best_greenhouse_controller.pth')

        if episode % 100 == 0:
            print(f"Episode {episode}, Reward: {total_reward:.2f}, "
                  f"Epsilon: {agent.epsilon:.3f}, Best: {best_reward:.2f}")

    return agent


# 測試控制器
def test_controller(agent, env, num_episodes=5):
    """測試訓練好的控制器"""
    action_names = ['無動作', '加熱', '降溫', '加濕', '除濕', '澆水', '開燈', '關燈']

    for ep in range(num_episodes):
        state = env.reset()
        total_reward = 0
        done = False

        print(f"\n=== 測試 Episode {ep+1} ===")

        while not done:
            action = agent.select_action(state, training=False)
            next_state, reward, done, _ = env.step(action)

            print(f"Hour {env.hour:2d}: "
                  f"T={env.temperature:.1f}°C, "
                  f"H={env.humidity:.1f}%, "
                  f"Soil={env.soil_moisture:.1f}%, "
                  f"Light={env.light_level:.0f}lux "
                  f"-> {action_names[action]} (R={reward:.2f})")

            state = next_state
            total_reward += reward

        print(f"總獎勵: {total_reward:.2f}")


if __name__ == '__main__':
    # 訓練
    trained_agent = train_greenhouse_controller()

    # 測試
    env = GreenhouseEnvironment()
    test_controller(trained_agent, env)
