關於向量圖及點陣圖

在 GIS、影像處理和農業資訊系統中，了解向量圖（Vector）和點陣圖（Raster）的差異是基礎知識。兩者各有優缺點，適用於不同場景。

一、基本概念

點陣圖（Raster）

由像素（Pixel）組成的影像，每個像素儲存一個數值：

  • 又稱「柵格圖」、「位圖」
  • 類似馬賽克磁磚，由小方格組成
  • 放大會產生鋸齒（像素化）
  • 常見格式：JPEG、PNG、TIFF、GeoTIFF

向量圖（Vector）

由數學公式定義的幾何物件：

  • 使用點、線、多邊形描述形狀
  • 無限縮放不失真
  • 儲存的是座標與屬性
  • 常見格式：SHP、GeoJSON、KML、SVG

二、核心差異比較

特性點陣圖（Raster）向量圖（Vector）
組成元素像素（網格）點、線、面（幾何物件）
縮放特性放大會模糊/鋸齒無限縮放不失真
檔案大小通常較大通常較小
編輯方式修改像素值修改座標/屬性
適合內容連續變化的現象（照片、遙測）離散物件（邊界、道路、點位）
空間分析表面分析、內插幾何運算、網路分析
屬性資料每像素一個值（或多波段）每物件可有多個屬性欄位

資料類型說明範例

植被指數圖NDVI 等遙測產品作物健康圖
溫度/降雨圖氣象資料網格化氣候分布

向量圖應用

資料類型幾何類型範例

採樣點位點土壤採樣位置、感測器
灌溉渠道線水路、管線
道路網線農路、運輸路線

行政區界多邊形鄉鎮區界

四、常見檔案格式

點陣圖格式

格式副檔名特點用途
GeoTIFF.tif/.tiff含地理資訊、多波段遙測、GIS 標準
JPEG.jpg有損壓縮、體積小一般照片
PNG.png無損壓縮、透明支援網頁圖片
JPEG2000.jp2高壓縮比、多解析度大型影像
NetCDF.nc多維陣列、時序資料氣象資料

向量圖格式

格式副檔名特點用途
Shapefile.shp+.dbf+.shx...業界標準、需多檔案GIS 通用
GeoJSON.geojsonJSON 格式、網頁友善Web GIS
KML/KMZ.kml/.kmzGoogle 格式Google Earth
GeoPackage.gpkgSQLite 基礎、單一檔案新一代標準
SVG.svg網頁向量圖圖標、示意圖

五、解析度概念

點陣圖解析度

# 空間解析度
每個像素代表的實際面積
例如：10m 解析度 = 每像素 10m x 10m = 100 m²

# 像素計算
影像涵蓋面積 1 km² = 1,000,000 m²
10m 解析度：1,000,000 / 100 = 10,000 像素
1m 解析度：1,000,000 / 1 = 1,000,000 像素

# 檔案大小估算（單波段 8-bit）
像素數 × 位元深度 / 8 = bytes
1,000,000 × 8 / 8 = 1 MB（未壓縮）

向量圖精度

  • 取決於座標小數位數
  • 頂點數量影響檔案大小
  • 過度簡化會失去細節

六、Python 處理範例

點陣圖處理 (rasterio)

import rasterio
import numpy as np

# 讀取 GeoTIFF
with rasterio.open('ndvi.tif') as src:
    ndvi = src.read(1)  # 讀取第一波段
    profile = src.profile
    transform = src.transform
    crs = src.crs

    print(f"形狀: {ndvi.shape}")
    print(f"解析度: {transform[0]} m")
    print(f"座標系: {crs}")

# 寫入新的 GeoTIFF
with rasterio.open('output.tif', 'w', **profile) as dst:
    dst.write(ndvi, 1)

# 座標轉換：像素 ↔ 地理座標
row, col = 100, 200
x, y = rasterio.transform.xy(transform, row, col)
print(f"像素 ({row}, {col}) → 座標 ({x}, {y})")

向量轉點陣

from rasterio import features
import rasterio

# 向量轉點陣（柵格化）
shapes = [(geom, value) for geom, value in zip(gdf.geometry, gdf['pH'])]

out_shape = (1000, 1000)  # 輸出大小
transform = rasterio.transform.from_bounds(*gdf.total_bounds, *out_shape)

raster = features.rasterize(
    shapes,
    out_shape=out_shape,
    transform=transform,
    fill=0,
    dtype='float32'
)

點陣轉向量

from rasterio import features
import shapely

# 點陣轉向量（向量化）
with rasterio.open('classified.tif') as src:
    image = src.read(1)

    # 取得多邊形
    shapes = features.shapes(image, transform=src.transform)

    polygons = []
    for geom, value in shapes:
        polygons.append({
            'geometry': shapely.geometry.shape(geom),
            'value': value
        })

    gdf = gpd.GeoDataFrame(polygons)

七、選擇指南

情況建議格式原因
儲存衛星影像點陣（GeoTIFF）連續的像素資料
記錄農地邊界向量（Shapefile）精確的邊界線
土壤養分分布點陣（內插結果）連續變化的現象
採樣點位置向量（點）離散的位置資料
灌溉管線向量（線）網路結構
高程地形點陣（DEM）連續的高度值
網頁地圖顯示向量（GeoJSON）或瓦片互動、輕量

八、常見問題

問題原因解決方法
影像放大模糊解析度不足使用更高解析度影像
Shapefile 亂碼編碼問題指定 encoding='utf-8'
檔案過大解析度過高重新取樣、壓縮
座標不對齊座標系不同統一轉換 CRS
