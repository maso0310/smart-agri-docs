關於 Pandas 資料分析

Pandas 是 Python 中最重要的資料分析套件，提供了高效能、易用的資料結構與分析工具。無論是讀取 CSV、清洗資料、還是進行統計分析，Pandas 都是首選工具。

二、核心資料結構

Series - 一維資料

Series 就像是一個有標籤的陣列，每個元素都有一個索引（index）。

# 從清單建立
s = pd.Series([10, 20, 30, 40])
print(s)
# 0    10
# 1    20
# 2    30
# 3    40

# 自訂索引
s = pd.Series([10, 20, 30], index=['a', 'b', 'c'])
print(s['b'])  # 20

# 從字典建立
data = {'蘋果': 100, '香蕉': 50, '橘子': 80}
s = pd.Series(data)

DataFrame - 二維表格

DataFrame 是最常用的資料結構，可以想像成 Excel 試算表或資料庫表格。

# 從字典建立
data = {
    '姓名': ['小明', '小華', '小美'],
    '年齡': [25, 30, 28],
    '城市': ['台北', '台中', '高雄']
}
df = pd.DataFrame(data)
print(df)
#    姓名  年齡  城市
# 0  小明   25  台北
# 1  小華   30  台中
# 2  小美   28  高雄

# 從串列建立
data = [
    ['小明', 25, '台北'],
    ['小華', 30, '台中'],
    ['小美', 28, '高雄']
]
df = pd.DataFrame(data, columns=['姓名', '年齡', '城市'])
資料結構 維度 類比
Series 1D 一欄 Excel 資料
DataFrame 2D 整個 Excel 工作表

六、資料處理與清洗

處理缺失值

df.dropna(subset=['年齡'])     # 只檢查特定欄位
df.dropna(thresh=2)            # 至少 2 個非空值才保留

# 填充缺失值
df.fillna(0)                   # 填入 0
df.fillna('未知')              # 填入字串
df['年齡'].fillna(df['年齡'].mean())  # 填入平均值
df.fillna(method='ffill')      # 向前填充

八、資料合併與連接

串接 concat

# 垂直串接（新增列）
df_all = pd.concat([df1, df2, df3])
df_all = pd.concat([df1, df2], ignore_index=True)

# 水平串接（新增欄）
df_wide = pd.concat([df1, df2], axis=1)

合併 merge

# 內連接（只保留共同鍵）
df_merged = pd.merge(df1, df2, on='id')

# 左連接（保留左表所有資料）
df_merged = pd.merge(df1, df2, on='id', how='left')

# 右連接
df_merged = pd.merge(df1, df2, on='id', how='right')

# 外連接（保留所有資料）
df_merged = pd.merge(df1, df2, on='id', how='outer')

# 不同欄位名稱
df_merged = pd.merge(df1, df2, left_on='user_id', right_on='id')

# 多鍵合併
df_merged = pd.merge(df1, df2, on=['城市', '年份'])
合併方式 說明 SQL 對應
inner 只保留兩邊都有的 INNER JOIN
left 保留左表所有 LEFT JOIN
right 保留右表所有 RIGHT JOIN
outer 保留所有資料 FULL OUTER JOIN

join 方法

# 依索引合併
df1.join(df2, how='left')
df1.join(df2, on='key')

十四、常見問題

Q1：SettingWithCopyWarning 警告怎麼處理？

# 錯誤寫法（可能產生警告）
df[df['年齡'] > 20]['新欄'] = 值

# 正確寫法
df.loc[df['年齡'] > 20, '新欄'] = 值

# 或使用 copy()
df_filtered = df[df['年齡'] > 20].copy()
df_filtered['新欄'] = 值

Q2：如何處理大型資料集？

# 分塊讀取
for chunk in pd.read_csv('large.csv', chunksize=10000):
    process(chunk)

# 指定資料型態節省記憶體
dtypes = {'id': 'int32', 'name': 'category'}
df = pd.read_csv('large.csv', dtype=dtypes)

# 只讀取需要的欄位
df = pd.read_csv('large.csv', usecols=['col1', 'col2'])

Q3：如何加速 Pandas 操作？

  1. 使用向量化操作，避免迴圈
  2. 使用 query() 取代布林索引
  3. 優化資料型態
  4. 考慮使用 modin 或 polars

Q4：inplace=True 是什麼意思？

# 不使用 inplace（原 df 不變，回傳新 df）
df_new = df.drop('欄位', axis=1)

# 使用 inplace（直接修改原 df）
df.drop('欄位', axis=1, inplace=True)

# 建議：盡量避免 inplace，改用方法串接

十五、智慧農業應用範例

感測器資料分析

import pandas as pd

# 讀取感測器資料
df = pd.read_csv('sensor_data.csv')

# 轉換時間
df['timestamp'] = pd.to_datetime(df['timestamp'])
df.set_index('timestamp', inplace=True)

# 計算每日平均
daily_avg = df.resample('D').mean()

# 找出異常溫度
high_temp = df[df['temperature'] > 35]
