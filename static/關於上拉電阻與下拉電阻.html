關於上拉電阻與下拉電阻

前言：為什麼需要上拉/下拉電阻？

當 Arduino 的輸入腳位沒有連接到任何東西時，會發生一個問題。

問題：浮動狀態 (Floating)

什麼是浮動狀態？

Arduino 輸入腳位 ──── ？？？（沒接任何東西）

讀取結果：隨機！有時 HIGH，有時 LOW

輸入腳位就像一根天線，會接收到環境中的電磁雜訊，導致讀取的值不穩定、無法預測。

水流比喻

想像輸入腳位是一個水位感測器：

【浮動狀態】
水池沒有進水管也沒有排水管
水位受天氣、蒸發、下雨影響，忽高忽低
→ 感測器讀數完全不可靠

實際問題

// 錯誤示範：按鈕沒有上拉/下拉電阻
pinMode(2, INPUT);  // 只設定為輸入，沒有上拉

void loop() {
  int state = digitalRead(2);
  // state 的值會亂跳，即使沒有按按鈕
  // 可能連續讀到：HIGH, LOW, HIGH, HIGH, LOW, LOW...
}

解決方案一：上拉電阻 (Pull-up Resistor)

原理

用一個電阻把輸入腳位「拉」向高電位 (VCC)，讓預設狀態為 HIGH。

電路圖

        VCC (5V)
          │
         [R] 10kΩ（上拉電阻）
          │
 Arduino ─┴──────── 按鈕 ──── GND
 輸入腳位

運作方式

按鈕狀態 電流路徑 腳位電壓 讀取值
沒按 VCC → 電阻 → 腳位 約 5V HIGH
按下 腳位直接接 GND 0V LOW

水流比喻

【有上拉電阻】
水池接了一條小水管持續進水（上拉電阻）
保持高水位（HIGH）

按鈕 = 排水閥
沒按 → 水位維持高（HIGH）
按下 → 水快速排掉，水位變低（LOW）

為什麼用 10kΩ？

  • 太小（如 100Ω）：按下按鈕時電流太大，浪費電、可能過熱
  • 太大（如 1MΩ）：拉的力道不夠，容易受雜訊干擾
  • 10kΩ 剛剛好：足夠穩定，電流又很小（約 0.5mA）

解決方案二：Arduino 內建上拉電阻 (INPUT_PULLUP)

好消息！

Arduino 內部已經有上拉電阻（約 20-50kΩ），只要啟用就好，不需要外接電阻！

使用方式

pinMode(2, INPUT_PULLUP);  // 啟用內建上拉電阻

簡化後的電路

 Arduino ──────── 按鈕 ──── GND
 輸入腳位

 （內部自動連接上拉電阻到 5V）

完整程式範例

const int BUTTON_PIN = 2;

void setup() {
  Serial.begin(9600);
  pinMode(BUTTON_PIN, INPUT_PULLUP);  // 啟用內建上拉
}

void loop() {
  int state = digitalRead(BUTTON_PIN);

  // 注意：邏輯是反的！
  // 沒按 = HIGH，按下 = LOW
  if (state == LOW) {
    Serial.println("按鈕被按下");
  }

  delay(100);
}

接線圖

Arduino Uno         按鈕
    D2 ─────────── 一端
   GND ─────────── 另一端

超簡單！只要兩條線！

解決方案三：下拉電阻 (Pull-down Resistor)

原理

用一個電阻把輸入腳位「拉」向低電位 (GND)，讓預設狀態為 LOW。

電路圖

        VCC (5V)
          │
        按鈕
          │
 Arduino ─┴──────── [R] 10kΩ ──── GND
 輸入腳位           （下拉電阻）

運作方式

按鈕狀態 電流路徑 腳位電壓 讀取值
沒按 腳位 → 電阻 → GND 約 0V LOW
按下 VCC 直接接腳位 5V HIGH

水流比喻

【有下拉電阻】
水池底部有一個小排水孔（下拉電阻）
水位維持在低位（LOW）

按鈕 = 大水管進水
沒按 → 水位維持低（LOW）
按下 → 大量進水，水位變高（HIGH）

注意

Arduino 沒有內建下拉電阻，必須自己外接！

三種模式完整比較

INPUT vs INPUT_PULLUP vs 外接電阻

模式 預設狀態 按下狀態 需要外接電阻？ 邏輯
INPUT（浮動） 不確定 不確定 必須 -
INPUT_PULLUP HIGH LOW 不需要 負邏輯
INPUT + 外接上拉 HIGH LOW 需要 負邏輯
INPUT + 外接下拉 LOW HIGH 需要 正邏輯

正邏輯 vs 負邏輯

類型 按鈕沒按 按鈕按下 判斷「按下」的寫法
正邏輯 (Active High) LOW HIGH if (state == HIGH)
負邏輯 (Active Low) HIGH LOW if (state == LOW)

程式碼範例

範例 1：使用 INPUT_PULLUP（推薦）

const int BUTTON_PIN = 2;
const int LED_PIN = 13;

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  // INPUT_PULLUP 是負邏輯：按下 = LOW
  if (digitalRead(BUTTON_PIN) == LOW) {
    digitalWrite(LED_PIN, HIGH);  // 按下時 LED 亮
  } else {
    digitalWrite(LED_PIN, LOW);   // 放開時 LED 滅
  }
}

範例 2：使用外接下拉電阻

const int BUTTON_PIN = 2;
const int LED_PIN = 13;

void setup() {
  pinMode(BUTTON_PIN, INPUT);  // 普通輸入，搭配外接下拉電阻
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  // 外接下拉是正邏輯：按下 = HIGH
  if (digitalRead(BUTTON_PIN) == HIGH) {
    digitalWrite(LED_PIN, HIGH);  // 按下時 LED 亮
  } else {
    digitalWrite(LED_PIN, LOW);   // 放開時 LED 滅
  }
}

範例 3：讓負邏輯更直覺

如果覺得 == LOW 代表「按下」不直覺，可以這樣寫：

const int BUTTON_PIN = 2;

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  Serial.begin(9600);
}

void loop() {
  // 轉換成直覺的布林值
  bool buttonPressed = (digitalRead(BUTTON_PIN) == LOW);

  if (buttonPressed) {
    Serial.println("按鈕被按下了！");
  }

  delay(100);
}

範例 4：封裝成函數

const int BUTTON_PIN = 2;

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  Serial.begin(9600);
}

// 自定義函數：回傳按鈕是否被按下
bool isButtonPressed(int pin) {
  return digitalRead(pin) == LOW;  // INPUT_PULLUP 負邏輯
}

void loop() {
  if (isButtonPressed(BUTTON_PIN)) {
    Serial.println("按下！");
  }
  delay(100);
}

什麼時候用哪種？

推薦使用 INPUT_PULLUP 的情況

情境 原因
接按鈕/開關 省一個電阻，接線簡單
快速測試/原型開發 方便快速
減少零件數量 不需要額外電阻

需要使用外接電阻的情況

情境 建議
需要正邏輯（按下 = HIGH） 外接下拉電阻
需要特定電阻值 外接上拉/下拉電阻
長距離接線（雜訊多） 外接較小的上拉電阻（如 4.7kΩ）
多個按鈕共用電源 可能需要外接電阻

不需要上拉/下拉電阻的情況

情境 原因
接感測器輸出 感測器自己會輸出 HIGH/LOW
接其他 Arduino 的輸出 對方會主動輸出電壓
接有輸出驅動的模組 模組內部已處理

常見問題

Q1: 為什麼我的按鈕讀值會亂跳？

A: 很可能沒有使用上拉/下拉電阻，腳位處於浮動狀態。

解決：使用 INPUT_PULLUP 或外接電阻。

Q2: INPUT_PULLUP 為什麼是負邏輯？

A: 因為內部電阻把腳位拉到 HIGH，按下按鈕才會變成 LOW。這是電路特性決定的。

Q3: 可以同時用 INPUT_PULLUP 和外接下拉電阻嗎？

A: 技術上可以，但沒有意義。兩個電阻會形成分壓，讀值會不穩定。請選擇其中一種。

Q4: 內建上拉電阻的阻值是多少？

A: Arduino Uno 的內建上拉電阻約 20-50kΩ，比建議的 10kΩ 大一些，但在一般情況下夠用。

Q5: 為什麼 Arduino 沒有內建下拉電阻？

A: 這是晶片設計的選擇。大多數 AVR 晶片只提供內建上拉電阻。如果需要下拉，就必須外接。

重點總結

口訣

浮動不穩要拉住
上拉預設在高處 (HIGH)
下拉預設在低處 (LOW)
INPUT_PULLUP 最方便
負邏輯按下是 LOW

快速選擇指南

需要接按鈕？
    │
    ├─ 想要簡單 → INPUT_PULLUP（負邏輯）
    │
    └─ 想要正邏輯 → 外接下拉電阻

安全提醒

  1. 不要讓輸入腳位浮動
  2. 不要同時使用內建上拉和外接下拉
  3. 記得上拉是負邏輯，下拉是正邏輯
