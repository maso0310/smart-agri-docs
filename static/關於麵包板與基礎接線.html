關於麵包板與基礎接線

為什麼需要麵包板？

在學習電子電路時，我們需要一個可以快速搭建、測試、修改電路的平台。麵包板（Breadboard）就是這樣的工具：

  • 免焊接：插拔元件即可，不需要焊接技術
  • 可重複使用：拆掉重來，元件不會損壞
  • 快速原型：幾分鐘就能完成電路測試
  • 視覺化：清楚看到電路連接方式

麵包板是什麼？

麵包板是一塊塑膠板，上面有許多小孔，孔的下方有金屬彈片將特定的孔連接在一起。只要把元件的腳插入孔中，就能透過金屬彈片形成電路連接。

內部連接原理（重要！）

電源軌連接方式

電源軌：整排水平連通

    + 軌（紅色）
    ┌─────────────────────────────────────────┐
    │  ●━━━●━━━●━━━●━━━●━━━●━━━●━━━●━━━●━━━●  │  ← 整排相連
    └─────────────────────────────────────────┘

    - 軌（藍色）
    ┌─────────────────────────────────────────┐
    │  ●━━━●━━━●━━━●━━━●━━━●━━━●━━━●━━━●━━━●  │  ← 整排相連
    └─────────────────────────────────────────┘

    用途：提供電源（VCC）和接地（GND）給整個電路

元件區連接方式

元件區：每直排 5 孔相連（被中央溝槽隔開）

    列號：  1     2     3     4     5
          ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐
      a   │ ● │ │ ● │ │ ● │ │ ● │ │ ● │
      b   │ ┃ │ │ ┃ │ │ ┃ │ │ ┃ │ │ ┃ │
      c   │ ┃ │ │ ┃ │ │ ┃ │ │ ┃ │ │ ┃ │   ← 每直排 a-e 相連
      d   │ ┃ │ │ ┃ │ │ ┃ │ │ ┃ │ │ ┃ │
      e   │ ● │ │ ● │ │ ● │ │ ● │ │ ● │
          └───┘ └───┘ └───┘ └───┘ └───┘
          ═════════════════════════════    ← 中央溝槽（斷開）
          ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐
      f   │ ● │ │ ● │ │ ● │ │ ● │ │ ● │
      g   │ ┃ │ │ ┃ │ │ ┃ │ │ ┃ │ │ ┃ │
      h   │ ┃ │ │ ┃ │ │ ┃ │ │ ┃ │ │ ┃ │   ← 每直排 f-j 相連
      i   │ ┃ │ │ ┃ │ │ ┃ │ │ ┃ │ │ ┃ │
      j   │ ● │ │ ● │ │ ● │ │ ● │ │ ● │
          └───┘ └───┘ └───┘ └───┘ └───┘

    重點：
    - 同一直排的 a,b,c,d,e 互相連通
    - 同一直排的 f,g,h,i,j 互相連通
    - 上半部 (a-e) 和下半部 (f-j) 不連通
    - 不同直排之間不連通

基本接線技巧

技巧一：電源配線

從 Arduino 連接電源到麵包板：

Arduino                     麵包板
┌─────────┐                ┌───────────────────────────┐
│         │                │ + ○━━━━━━━━━━━━━━━━━━━━━○ │
│      5V │───紅線────────→│   ↑                       │
│         │                │   接這裡                  │
│     GND │───黑線────────→│ - ○━━━━━━━━━━━━━━━━━━━━━○ │
│         │                │   ↑                       │
└─────────┘                │   接這裡                  │
                           │                           │
                           │   a ○ ○ ○ ○ ○ ○ ○ ○ ○ ○  │
                           │   b ○ ○ ○ ○ ○ ○ ○ ○ ○ ○  │
                           │   ...                     │
                           └───────────────────────────┘

現在整個 + 軌都是 5V，整個 - 軌都是 GND

技巧二：元件正確放置

正確：跨越不同列（形成電路）

    列 1   列 2   列 3   列 4
    ┌───┐ ┌───┐ ┌───┐ ┌───┐
  a │ ● │ │ ○ │ │ ○ │ │ ○ │     LED 負極
  b │ ┃ │ │   │ │   │ │   │        ↓
  c │ ┃ │ │   │ │   │ │   │     ┌──●──┐
  d │ ┃ │ │   │ │ ● │ │   │     │     │
  e │ ● │ │   │ │ ┃ │ │   │     └──●──┘
    └───┘ └───┘ └─┃─┘ └───┘        ↑
                  ┃            LED 正極
    LED 跨越列 1 和列 3

錯誤：同一列的不同行（短路！）

    列 1
    ┌───┐
  a │ ● │ ← LED 負極      這樣是短路！
  b │ ┃ │                 因為 a,b,c,d,e
  c │ ┃ │                 都是連通的
  d │ ● │ ← LED 正極
  e │   │
    └───┘

技巧三：IC 晶片放置

IC 晶片必須跨越中央溝槽：

    列 1   列 2   列 3   列 4
    ┌───┐ ┌───┐ ┌───┐ ┌───┐
  a │   │ │   │ │   │ │   │

  e │ ┃ │ │ ┃ │ │ ┃ │ │ ┃ │
    └─┃─┘ └─┃─┘ └─┃─┘ └─┃─┘
    ══╬═════╬═════╬═════╬══  ← 中央溝槽
    ┌─┃─┐ ┌─┃─┐ ┌─┃─┐ ┌─┃─┐
  f │ ┃ │ │ ┃ │ │ ┃ │ │ ┃ │
  g │ ● │ │ ● │ │ ● │ │ ● │  ← IC 腳位 8-5
  h │   │ │   │ │   │ │   │
  i │   │ │   │ │   │ │   │

    └───┘ └───┘ └───┘ └───┘

    這樣每個腳位都有獨立的連接點（a-d 或 g-j）

實作範例

範例一：LED 閃爍電路

電路圖：

    Arduino D13 ───→ 220Ω電阻 ───→ LED正極 ───→ LED負極 ───→ GND

麵包板接線：

    Arduino                     麵包板
    ┌─────────┐                ┌───────────────────────────────┐
    │         │                │ + ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ │
    │      5V │─紅─────────────│───↑                           │
    │     GND │─黑─────────────│ - ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ │
    │         │                │   ↑ │                         │
    │     D13 │─橙───────┐     ├─────┼─────────────────────────┤
    │         │          │     │     │    1   2   3   4   5    │
    └─────────┘          │     │   a ○   ○   ○   ○   ○        │
                         │     │   b ○   ○   ○   ○   ○        │
                         └────→│   c ●───電阻───●   ○   ○     │
                               │   d ○       ┃   ●LED+●       │
                               │   e ○       ┃   ○   ┃        │
                               │             ┃       ┃        │
                               │           可跳線    可跳線    │
                               │           連接     連到GND   │
                               └───────────────────────────────┘

零件：
- 220Ω 電阻（紅紅棕金）
- LED（長腳正極、短腳負極）

Arduino 程式：

/*
 * LED 閃爍基礎範例
 */

const int LED_PIN = 13;

void setup() {
    pinMode(LED_PIN, OUTPUT);
}

void loop() {
    digitalWrite(LED_PIN, HIGH);  // LED 亮
    delay(1000);                  // 等待 1 秒
    digitalWrite(LED_PIN, LOW);   // LED 滅
    delay(1000);                  // 等待 1 秒
}

                               └───────────────────────────────┘

Arduino 程式：

/*
 * 按鈕控制 LED
 * 按下按鈕時 LED 亮起
 */

const int BUTTON_PIN = 2;
const int LED_PIN = 13;

void setup() {
    pinMode(BUTTON_PIN, INPUT);  // 外部有下拉電阻
    pinMode(LED_PIN, OUTPUT);
}

void loop() {
    int buttonState = digitalRead(BUTTON_PIN);

    if (buttonState == HIGH) {
        digitalWrite(LED_PIN, HIGH);
    } else {
        digitalWrite(LED_PIN, LOW);
    }
}

範例三：可變電阻控制 LED 亮度

電路圖：

    5V ───→ 可變電阻一端
            可變電阻中間腳 ───→ Arduino A0
    GND ──→ 可變電阻另一端

    Arduino D9 (PWM) ───→ 220Ω ───→ LED ───→ GND

麵包板接線：

                               ┌───────────────────────────────┐
    Arduino                    │ + ○ ● ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ │
    ┌─────────┐                │     ↓                         │
    │      5V │─紅────────────→│   ●───可變電阻上腳            │
    │     GND │─黑────────────→│ - ○ ●─可變電阻下腳 ○ ○ ○ ○ ○ │
    │         │                │     ↑                         │
    │      A0 │─橙────────────→│   ●───可變電阻中腳            │
    │      D9 │─黃───────┐     ├───────────────────────────────┤
    │         │          │     │   1   2   3   4   5   6   7   │
    └─────────┘          │     │ a ○   ○   ○   ○   ○   ○   ○  │
                         │     │ b ○   ○   ○   ○   ○   ○   ○  │
                         └────→│ c ●───電阻───●LED+●   ○   ○  │
                               │ d ○       ┃   ○   ┃   ○   ○  │
                               │ e ○       ┃   ○   ●到GND ○  │
                               └───────────────────────────────┘

可變電阻接法（從底部看）：
     ┌─────────┐
     │    ●    │ ← 中間腳（訊號輸出到 A0）
     │  ●   ●  │ ← 兩側腳（一端接 5V，一端接 GND）
     └─────────┘

Arduino 程式：

/*
 * 可變電阻控制 LED 亮度
 * 旋轉可變電阻改變 LED 亮度
 */

const int POT_PIN = A0;   // 可變電阻
const int LED_PIN = 9;    // PWM 腳位

void setup() {
    pinMode(LED_PIN, OUTPUT);
    Serial.begin(9600);
}

void loop() {
    int potValue = analogRead(POT_PIN);       // 讀取 0-1023
    int brightness = map(potValue, 0, 1023, 0, 255);  // 轉換為 0-255

    analogWrite(LED_PIN, brightness);         // PWM 輸出

    Serial.print("可變電阻: ");
    Serial.print(potValue);
    Serial.print(" -> 亮度: ");
    Serial.println(brightness);

    delay(100);
}

常見錯誤與避免

錯誤一：短路

問題：同一直排插入元件的兩個腳位

    錯誤示範：
    ┌───┐
  a │ ● │ ← LED 負極     這兩個孔是連通的！
  b │ ┃ │                LED 正負極直接短路
  c │ ● │ ← LED 正極     可能燒毀 LED 或 Arduino
  d │   │
  e │   │
    └───┘

    正確做法：
    ┌───┐ ┌───┐
  a │ ● │ │   │          跨越不同列
  b │ ┃ │ │   │          透過電阻限流
  c │ ● │ │ ● │
  d │   │ │ ┃ │
  e │   │ │ ● │
    └───┘ └───┘
    電阻    LED

錯誤二：電源軌未連接

問題：某些麵包板的電源軌中間有斷開

    ┌──────────────────────────────────────┐
    │ + ●━━━━━━━━━━━●  ✂  ●━━━━━━━━━━━● │  ← 中間斷開！
    └──────────────────────────────────────┘
                       ↑
                  某些板子這裡斷開

    解決方法：用跳線將兩邊連接起來

    ┌──────────────────────────────────────┐
    │ + ●━━━━━━━━━━━●──跳線──●━━━━━━━━━━━● │
    └──────────────────────────────────────┘

錯誤三：忘記共地

問題：不同電源供電但沒有共地

    Arduino (5V)              外部電源 (9V)
         │                         │
         │                         │
         ▼                         ▼
    ┌─────────┐              ┌─────────┐
    │ 控制訊號 │              │  馬達   │
    └────┬────┘              └────┬────┘
         │                         │
         ✗ 沒有連接 GND ✗          │
         │                         │
                                   ▼
                              電路不正常

    正確做法：所有電源的 GND 必須連接在一起

    Arduino GND ───────────── 外部電源 GND

錯誤四：元件腳位太粗或太細

問題：元件腳位無法正確插入麵包板

    太粗：強行插入會損壞麵包板彈片
    太細：接觸不良，時好時壞

    解決方法：
    1. 太粗的元件（如大功率電阻）：使用轉接線
    2. 太細的元件：用杜邦線焊接延長
    3. 模組類元件：使用排針或杜邦線連接

元件辨識速查

電阻色環

常用電阻值與色環：

    220Ω  = 紅 紅 棕 金    ████████████
    330Ω  = 橙 橙 棕 金
    1kΩ   = 棕 黑 紅 金
    4.7kΩ = 黃 紫 紅 金
    10kΩ  = 棕 黑 橙 金

色環對照：
    黑=0  棕=1  紅=2  橙=3  黃=4
    綠=5  藍=6  紫=7  灰=8  白=9
    金=±5%  銀=±10%

計算方法：
    第一色環 × 10 + 第二色環 × 10^(第三色環)
    例如：紅紅棕 = 22 × 10^1 = 220Ω

LED 極性

辨識 LED 正負極：

方法一：腳長
    長腳 = 正極 (Anode, +)
    短腳 = 負極 (Cathode, -)

方法二：內部結構
      ┌─────┐
      │ ▲   │  ← 較小的是正極
      │ █   │  ← 較大的是負極
      └──┬──┘
        ─┴─

方法三：LED 外殼缺口
    有缺口的一側 = 負極

電解電容極性

辨識電解電容正負極：

    ┌───────────┐
    │ ▓▓▓▓▓▓▓▓▓ │  ← 有標示 (-) 的是負極
    │ ▓ ━━━━ ▓▓ │
    │ ▓ ━━━━ ▓▓ │
    │ ▓▓▓▓▓▓▓▓▓ │
    └─────┬─────┘
      長腳│短腳
       +    -

    長腳 = 正極
    短腳 = 負極
    外殼標示 (-) 的那側 = 負極

快速參考

麵包板連接規則

電源軌：橫向全部連通
元件區：直向 5 孔一組（a-e 或 f-j）
中央溝槽：上下區域斷開

常用接線組合

Arduino 5V   → 麵包板 + 軌
Arduino GND  → 麵包板 - 軌
Arduino Dx   → 元件訊號腳
元件 VCC     → 麵包板 + 軌
元件 GND     → 麵包板 - 軌

安全檢查清單

□ 電源極性正確（紅正黑負）
□ 元件極性正確（LED、電容）
□ 無短路（同列不插兩個腳）
□ 電阻值正確
□ 所有 GND 已連接
□ 電壓符合元件規格
