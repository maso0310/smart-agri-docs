關於電源供應

前言：為什麼電源很重要？

電源就像是電子專案的「血液」，供應不當會導致：
- 🔥 元件燒毀（電壓過高）
- 😵 系統不穩定（電流不足）
- 🔄 重複重啟（電壓不穩）
- 💀 永久損壞（極性接反）

學會正確的電源供應，是做好專案的第一步！

一、電源基礎知識

電壓（Voltage）- 推力

電壓就像「水壓」：

高水塔                        低水塔
  ║                            ║
  ║                            ║
  ╠════╗                       ╠══╗
  ║    ║                       ║  ║
  ║    ║                       ║  ║
  ║    ▼                       ║  ▼
  ║  強水流                    ║ 弱水流

水塔越高 → 水壓越大 → 水流越強
電壓越高 → 推力越大 → 電流越強（在相同電阻下）

單位：伏特（V, Volt）
常見電壓：1.5V、3.3V、5V、9V、12V、24V

電流（Current）- 流量

電流就像「水流量」：

粗水管                        細水管
═══════════                   ───────
    ████████                     ██
    ████████ → 大流量            ██ → 小流量
    ████████                     ██

電流 = 單位時間內通過的電荷量
用電設備越多/越耗電 → 需要的電流越大

單位：安培（A, Ampere）
常用：毫安培（mA）= 0.001A

常見電流需求：
• LED：20mA
• Arduino UNO：50mA
• 伺服馬達：100-500mA
• WiFi 模組：200-300mA

功率（Power）- 總能量

功率 = 電壓 × 電流
P = V × I

範例：
5V × 2A = 10W（10 瓦特）

這表示：
• 電源能提供的最大能力
• 設備消耗的能量

功率不足的症狀：
• 電壓下降
• 系統重啟
• 發熱異常

三者關係圖

               ┌─────────────────────────────────────┐
               │         歐姆定律 & 功率公式         │
               ├─────────────────────────────────────┤
               │                                     │
               │         V = I × R                   │
               │        (電壓=電流×電阻)             │
               │                                     │
               │         P = V × I                   │
               │        (功率=電壓×電流)             │
               │                                     │
               │         P = I² × R                  │
               │         P = V² / R                  │
               │                                     │
               └─────────────────────────────────────┘

實際應用：
想點亮一顆 LED（2V, 20mA）用 5V 電源
需要多大的電阻？

R = (5V - 2V) / 0.02A = 150Ω

3. 變壓器/電源供應器

常見規格：

┌──────────────────────────────────────────┐
│  輸出電壓  │  常見電流  │  適用場景      │
├──────────────────────────────────────────┤
│    5V     │  1A-10A   │  Arduino、LED   │
│    9V     │  1A-2A    │  Arduino Vin    │
│   12V     │  1A-30A   │  LED燈條、馬達  │
│   24V     │  1A-20A   │  工業設備       │
└──────────────────────────────────────────┘

選購重點：
1. 電壓要符合需求
2. 電流要大於總消耗（留 20% 餘量）
3. 注意接頭規格
4. 選擇有認證的產品（安規）

4. 行動電源

行動電源特性：
┌─────────────────────────────────────────┐
│ • 輸出：通常 5V（有些支援 9V/12V）      │
│ • 容量：5000mAh - 30000mAh              │
│ • 優點：攜帶方便、容量大                │
│ • 缺點：可能有低電流截斷問題            │
└─────────────────────────────────────────┘

⚠️ 低電流截斷問題：
很多行動電源在電流低於 50-100mA 時
會自動關閉輸出（以為沒在充電）

解決方法：
• 選擇「小電流模式」的行動電源
• 並聯一個小負載（如 LED）
• 使用專為 Arduino 設計的行動電源

三、Arduino 的電源輸入

Arduino UNO 電源選項

Arduino UNO 有三種供電方式：

┌────────────────────────────────────────────────────┐
│                  Arduino UNO                        │
│                                                     │
│   ┌─────┐                                          │
│   │ USB │ ← 方式1：USB 供電（5V）                  │
│   └─────┘                                          │
│                                                     │
│   ┌─────┐                                          │
│   │DC座 │ ← 方式2：DC 變壓器（7-12V 推薦）        │
│   └─────┘                                          │
│                                                     │
│   Vin ──── ← 方式3：Vin 腳位（7-12V）              │
│   5V ───── ← 方式4：直接供 5V（繞過穩壓）         │
│   3.3V ─── ← 輸出用，勿輸入！                      │
│   GND ──── ← 接地                                  │
│                                                     │
└────────────────────────────────────────────────────┘

各供電方式比較

方式 輸入電壓 優點 缺點
USB 5V 方便、安全 電流有限（500mA）
DC 座 7-12V 穩定、電流大 需要變壓器
Vin 7-12V 彈性高 需注意電壓範圍
5V 腳位 5V（精確） 效率高 無保護，風險高

為什麼 Vin 要 7-12V？

Arduino 內部有穩壓器（Voltage Regulator）：

輸入電壓              穩壓後輸出
  │                      │
  ▼                      ▼
7-12V ──→ [穩壓器] ──→ 5V ──→ 給晶片使用

穩壓器需要「壓差」才能工作：
• 輸入至少比輸出高 2V
• 所以最低要 5V + 2V = 7V

輸入太高會怎樣？
• 多餘的電壓變成熱
• 12V 輸入：(12-5)×0.05A = 0.35W 變成熱
• 超過 12V 可能過熱損壞

ESP8266 / ESP32 的電源

ESP 系列供電注意：

┌─────────────────────────────────────────┐
│           ESP8266 / ESP32               │
├─────────────────────────────────────────┤
│  工作電壓：3.3V（絕對不可用 5V！）      │
│  工作電流：平均 80mA，峰值 300-500mA    │
│                                         │
│  ⚠️ 重要警告：                          │
│  • GPIO 腳位只能承受 3.3V               │
│  • 5V 直接輸入會燒毀                    │
│  • WiFi 傳輸時電流會突然增大            │
└─────────────────────────────────────────┘

供電建議：
• 使用 3.3V 穩壓模組
• 或使用開發板（內建穩壓）
• 電源至少能提供 500mA

什麼是穩壓器？

線性穩壓 vs 開關穩壓

線性穩壓器（如 7805）：
┌─────────────────────────────────────────┐
│ 優點：                                   │
│ • 便宜                                   │
│ • 電路簡單                               │
│ • 輸出乾淨（雜訊低）                     │
│                                         │
│ 缺點：                                   │
│ • 效率低（多餘能量變成熱）               │
│ • 壓差大時會很燙                         │
│ • 不能升壓                               │
└─────────────────────────────────────────┘

開關穩壓器（DC-DC）：
┌─────────────────────────────────────────┐
│ 優點：                                   │
│ • 效率高（80-95%）                       │
│ • 發熱少                                 │
│ • 可升壓也可降壓                         │
│                                         │
│ 缺點：                                   │
│ • 較貴                                   │
│ • 有開關雜訊                             │
│ • 電路較複雜                             │
└─────────────────────────────────────────┘

選擇建議：
• 壓差小、電流小 → 線性穩壓（便宜簡單）
• 壓差大、電流大 → 開關穩壓（省電不燙）
• 對雜訊敏感 → 線性穩壓

五、電源設計實例

實例 1：LED 燈條供電

需求：WS2812B 燈條 60 顆 LED

計算：
• 每顆最大 60mA（全白）
• 60 顆 × 60mA = 3600mA = 3.6A
• 加上 20% 餘量：3.6A × 1.2 = 4.32A

選擇：
• 5V 5A 電源供應器 ✓

接線：
┌────────────┐      ┌──────────────────────┐
│  5V 5A     │      │    WS2812B 燈條      │
│  電源      │      │                      │
│        + ──┼──────┼── VCC                │
│        - ──┼──────┼── GND                │
└────────────┘      └──────────────────────┘
                           │
                    Arduino D6 ── DIN

⚠️ 注意：Arduino 的 GND 也要連接！

實例 2：Arduino + 伺服馬達

需求：Arduino UNO + 2 顆 SG90 伺服馬達

問題：
• SG90 每顆工作電流約 100-250mA
• 峰值可達 500mA
• Arduino USB 只能提供 500mA
• 不夠用！

解決方案：外接電源
┌─────────────┐
│   5V 2A     │
│   電源      ├──┬──────→ 伺服馬達 1 VCC
│             │  │
│             │  ├──────→ 伺服馬達 2 VCC
│             │  │
│         GND ├──┴──┬───→ 伺服馬達 GND
└─────────────┘     │
                    │
              ┌─────┴─────┐
              │  Arduino  │
              │       GND ├────（共地）
              │        D9 ├────→ 伺服馬達 1 訊號
              │       D10 ├────→ 伺服馬達 2 訊號
              └───────────┘

關鍵：電源 GND 和 Arduino GND 要連接！

實例 3：電池供電的行動裝置

需求：Arduino Nano + GPS + OLED 螢幕（行動使用）

功耗估算：
• Arduino Nano：30mA
• GPS 模組：50mA
• OLED 螢幕：20mA
• 總計：100mA

電池選擇方案：

方案 A：4 顆 AA 電池串聯
┌─┐ ┌─┐ ┌─┐ ┌─┐
│+│─│+│─│+│─│+│──→ 6V (1.5V × 4)
│ │ │ │ │ │ │ │
│-│─│-│─│-│─│-│──→ GND
└─┘ └─┘ └─┘ └─┘
• 總電壓：6V（接 Vin，但略低）
• 容量：約 2000mAh
• 使用時間：2000mAh / 100mA = 20 小時

方案 B：2 顆 18650 鋰電池串聯
┌─────┐ ┌─────┐
│18650│─│18650│──→ 7.4V
└─────┘ └─────┘
• 總電壓：7.4V（接 Vin）
• 容量：約 2500mAh
• 使用時間：25 小時
• 需要充電板和保護板

方案 C：單顆 18650 + 升壓模組
┌─────┐   ┌────────┐
│18650│───│MT3608  │──→ 5V
│3.7V │   │升壓模組│
└─────┘   └────────┘
• 直接輸出 5V 給 5V 腳位
• 效率較高

六、電源安全注意事項

常見錯誤與後果

❌ 錯誤 1：電壓接反
┌─────────────────────────────────────────┐
│  後果：立即燒毀！                        │
│  預防：                                  │
│  • 接線前再三確認                        │
│  • 使用有防反接保護的模組                │
│  • 正極紅色，負極黑色                    │
└─────────────────────────────────────────┘

❌ 錯誤 2：電壓過高
┌─────────────────────────────────────────┐
│  例如：把 9V 電池直接接到 ESP8266        │
│  後果：瞬間燒毀！                        │
│  預防：                                  │
│  • 確認設備額定電壓                      │
│  • 使用穩壓器                            │
└─────────────────────────────────────────┘

❌ 錯誤 3：電流不足
┌─────────────────────────────────────────┐
│  例如：用 Arduino 5V 腳位驅動馬達        │
│  後果：                                  │
│  • 馬達無力或不轉                        │
│  • Arduino 重啟                          │
│  • 可能損壞                              │
│  預防：                                  │
│  • 計算總電流需求                        │
│  • 大電流設備用外接電源                  │
└─────────────────────────────────────────┘

❌ 錯誤 4：沒有共地
┌─────────────────────────────────────────┐
│  例如：Arduino 和外接電源的 GND 沒連     │
│  後果：                                  │
│  • 通訊失敗                              │
│  • 訊號不穩定                            │
│  • 可能損壞                              │
│  預防：                                  │
│  • 所有電源的 GND 都要連在一起           │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│  例如：5V Arduino 直接連 3.3V ESP8266    │
│  後果：3.3V 元件燒毀                     │

保護電路

1. 防反接二極體：
   電源 ──→|──→ 電路
        二極體

   反接時二極體不導通，保護電路

2. 保險絲：
   電源 ──[保險絲]──→ 電路

   電流過大時保險絲燒斷，保護電路

3. 穩壓器保護：
   即使輸入電壓波動，輸出維持穩定

4. 電容濾波：
   吸收電壓波動和雜訊

   電源 ──┬──→ 電路
          │
        [電容]
          │
         GND

七、實用技巧

測量電流消耗

用三用電表測量電流：

     ┌─── A ───┐
     │   表    │
電源 ┴─────────┴──→ 設備
        串聯

步驟：
1. 電表選擇「電流」檔位（A 或 mA）
2. 斷開電路
3. 把電表串聯進去
4. 讀取數值

⚠️ 注意：
• 先用大檔位（如 10A）再換小檔位
• 測電流要串聯，不是並聯！
• 並聯測電流會短路爆炸！

估算電池使用時間

公式：
使用時間（小時）= 電池容量（mAh）/ 消耗電流（mA）

範例：
電池：2000mAh
設備消耗：100mA
使用時間 = 2000 / 100 = 20 小時

實際會比計算值短，因為：
• 電池不能完全放電
• 電壓下降後設備可能無法工作
• 溫度影響電池容量

建議打 7 折：20 × 0.7 = 14 小時

電源雜訊處理

問題：感測器讀值跳動、螢幕閃爍

原因：
• 馬達啟動產生干擾
• 開關電源的雜訊
• 長線材當天線

解決方法：

1. 加濾波電容
   VCC ──┬──→
         │
       [100μF]  電解電容（大波動）
         │
       [0.1μF] 陶瓷電容（高頻雜訊）
         │
        GND

2. 分開供電
   數位電路和馬達用不同電源
   最後共地

3. 加磁環
   電源線穿過磁環
   過濾高頻雜訊

八、常見問題

Q1：Arduino 一直重啟？

可能原因：
1. 電流不足
   → 檢查電源容量，加大電源

2. 馬達/繼電器干擾
   → 馬達外接電源，加濾波電容

3. 電壓不穩
   → 使用穩壓模組

4. 程式問題
   → 檢查是否有無窮迴圈或記憶體問題

Q2：ESP8266 WiFi 連不上？

常見原因：電流不足！

ESP8266 發射 WiFi 時電流可達 300-500mA
很多電源供應不上這瞬間大電流

解決：
1. 使用能提供 1A 以上的電源
2. 在 ESP8266 旁加大電容（100-470μF）
3. 不要用 Arduino 的 3.3V 腳位供電

Q3：伺服馬達抖動？

原因：
1. 電源不穩
2. 訊號線干擾
3. 電流不足

解決：
1. 伺服馬達獨立供電
2. 電源加 100μF 電容
3. 訊號線盡量短
4. 確保共地

Q4：如何選擇電源供應器？

選擇步驟：

1. 確定電壓
   所有設備需要什麼電壓？

2. 計算電流
   加總所有設備的消耗

3. 加上餘量
   總電流 × 1.2（留 20% 餘量）

4. 選擇產品
   電壓符合、電流大於計算值
   有安規認證

範例：
設備需要 5V，總電流 2A
選擇：5V 3A 電源（2A × 1.5 = 3A）

九、總結

電源供應檢查清單：

□ 電壓正確嗎？
  • Arduino UNO：5V 或 7-12V（Vin）
  • ESP8266/ESP32：3.3V
  • 感測器：查規格書

□ 電流足夠嗎？
  • 加總所有設備
  • 留 20% 餘量

□ 極性正確嗎？
  • 紅正黑負
  • 接線前再三確認

□ 有共地嗎？
  • 所有電源 GND 連在一起

□ 需要穩壓嗎？
  • 電池供電通常需要
  • 不同電壓設備需要

□ 需要保護嗎？
  • 重要專案加保護電路
  • 使用保險絲
