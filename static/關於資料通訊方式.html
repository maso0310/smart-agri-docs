關於資料通訊方式

前言：為什麼需要了解這些？

當你把 Arduino 接上各種感測器、螢幕、WiFi 模組時，你可能會看到這些名詞：I2C、SPI、UART、TTL... 這些到底是什麼？它們之間有什麼差別？

這篇文件用最簡單的方式，幫你搞懂所有常見的資料通訊方式！

一、串行傳輸 vs 並行傳輸

什麼是串行傳輸（Serial）？

一次只傳一個位元，資料排隊一個一個傳送。

串行傳輸示意圖：

發送端                                               接收端
┌─────┐                                             ┌─────┐
│     │    →  1  0  1  1  0  1  0  0  →            │     │
│ TX  │═══════════════════════════════════════════│ RX  │
│     │           只有一條資料線                    │     │
└─────┘                                             └─────┘

傳送 "10110100" 這個位元組：
時間 →→→→→→→→→→→→→→→→→→→→→→→→→→→→
T1: 傳送 1
T2: 傳送 0
T3: 傳送 1
T4: 傳送 1
T5: 傳送 0
T6: 傳送 1
T7: 傳送 0
T8: 傳送 0
完成！

生活比喻：排隊過獨木橋，一次只能過一個人 🚶→🌉

什麼是並行傳輸（Parallel）？

一次傳多個位元，多條線同時傳送。

並行傳輸示意圖：

發送端                                               接收端
┌─────┐     1 ─────────────────────────→           ┌─────┐
│     │     0 ─────────────────────────→           │     │
│     │     1 ─────────────────────────→           │     │
│ TX  │     1 ─────────────────────────→  8條線    │ RX  │
│     │     0 ─────────────────────────→           │     │
│     │     1 ─────────────────────────→           │     │
│     │     0 ─────────────────────────→           │     │
│     │     0 ─────────────────────────→           │     │
└─────┘                                             └─────┘

傳送 "10110100" 這個位元組：
時間 →
T1: 同時傳送全部 8 個位元
完成！

生活比喻：八線道高速公路，八台車同時通過 🚗🚗🚗🚗🚗🚗🚗🚗

比較表

特點 串行傳輸 並行傳輸
線材數量 少（1-4條） 多（8條以上）
傳輸距離 可以較遠 只能很近
成本 低 高
抗干擾能力 強 弱
同步問題 無 多線同步困難
現代應用 USB、SATA、網路 已逐漸淘汰

結論：現代裝置幾乎都用串行傳輸！

二、同步 vs 非同步傳輸

非同步傳輸（Asynchronous）

沒有時鐘線，靠「約定好的速度」來同步。

非同步傳輸（如 UART）：

發送端                          接收端
┌─────┐                        ┌─────┐
│     │                        │     │
│  TX ├────── 資料線 ─────────→┤ RX  │
│     │                        │     │
│ GND ├────────────────────────┤ GND │
│     │                        │     │
└─────┘                        └─────┘

雙方約定：「我們都用 9600 baud 的速度」
發送端按這個速度發，接收端按這個速度收

⚠️ 如果速度不一致，資料就會出錯（亂碼）！

生活比喻：
你和朋友約好「每秒喊一個數字」
你喊：一...二...三...
朋友聽：一...二...三...
如果你喊太快或太慢，朋友就會漏聽或聽錯

同步傳輸（Synchronous）

有時鐘線，發送端告訴接收端「現在可以讀了」。

同步傳輸（如 SPI、I2C）：

發送端                          接收端
┌─────┐                        ┌─────┐
│     │                        │     │
│DATA ├────── 資料線 ─────────→┤DATA │
│     │                        │     │
│ CLK ├────── 時鐘線 ─────────→┤ CLK │  ← 這條是關鍵！
│     │                        │     │
│ GND ├────────────────────────┤ GND │
│     │                        │     │
└─────┘                        └─────┘

時鐘線的訊號：
CLK:  ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐
    ──┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └──
       ↑   ↑   ↑   ↑   ↑   ↑   ↑   ↑
      每個上升沿，接收端讀一個位元

生活比喻：
老師說：「我拍一下手，你們就翻一頁」
拍！翻第一頁
拍！翻第二頁
拍！翻第三頁
不管快慢，大家都不會錯

比較表

特點 非同步 同步
時鐘線 不需要 需要
速度 需預先約定 可動態調整
可靠性 速度必須匹配 更可靠
代表 UART SPI、I2C

三、TTL 電位準位

什麼是 TTL？

TTL（Transistor-Transistor Logic） 不是一種通訊協定，而是電壓標準。

TTL 電位準位：

        5V ─┬─────────────────────────── 邏輯 "1" (HIGH)
            │
            │   有效範圍：2.0V ~ 5.0V
            │
      2.0V ─┼───────────────────────────
            │
            │   不確定區域（避免使用）
            │
      0.8V ─┼───────────────────────────
            │
            │   有效範圍：0V ~ 0.8V
            │
        0V ─┴─────────────────────────── 邏輯 "0" (LOW)

簡單說：
• 高於 2.0V → 視為 1
• 低於 0.8V → 視為 0
• 中間的電壓 → 不確定，不要用

常見電壓標準比較

不同裝置的電壓標準：

Arduino UNO：     5V TTL
Arduino Nano：    5V TTL
ESP8266/ESP32：   3.3V
樹莓派 GPIO：     3.3V
手機/平板：       1.8V 或 3.3V

⚠️ 重要警告：
5V 裝置直接接 3.3V 裝置可能會燒壞！

錯誤接法：
Arduino (5V TX) ───────→ ESP8266 (3.3V RX)
                          ↑
                       可能燒毀！

正確接法：
Arduino (5V TX) ──[電平轉換器]──→ ESP8266 (3.3V RX)

電平轉換器

常見的電平轉換方法：

1. 電阻分壓（簡單但不完美）
   5V ──[1KΩ]──┬──→ 3.3V 裝置
               │
             [2KΩ]
               │
              GND

2. 電平轉換模組（推薦）
   ┌─────────────────┐
   │  Level Shifter  │
   │                 │
   │ HV ←→ 5V 側    │
   │ LV ←→ 3.3V 側  │
   │                 │
   └─────────────────┘

四、UART 通訊

什麼是 UART？

UART（Universal Asynchronous Receiver/Transmitter） 是最基本的串行通訊方式。

UART 特點：
┌──────────────────────────────────────┐
│ • 非同步（不需要時鐘線）              │
│ • 全雙工（可同時收發）                │
│ • 點對點（一對一連接）                │
│ • 最少只要 2 條線（TX、RX）           │
│ • 速度由鮑率（Baud Rate）決定         │
└──────────────────────────────────────┘

UART 接線

UART 連接兩個裝置：

裝置 A              裝置 B
┌──────┐            ┌──────┐
│      │            │      │
│   TX ├────×───────┤ RX   │   ← 交叉連接！
│      │      ╲     │      │
│   RX ├───────╲────┤ TX   │   ← 交叉連接！
│      │        ╲   │      │
│  GND ├────────────┤ GND  │   ← 共地
│      │            │      │
└──────┘            └──────┘

記憶口訣：「TX 找 RX，RX 找 TX」
（發送找接收，接收找發送）

Arduino UART 程式範例

void setup() {
  Serial.begin(9600);  // 初始化 UART，鮑率 9600
}

void loop() {
  // 發送資料
  Serial.println("Hello World!");

  // 接收資料
  if (Serial.available() > 0) {
    String data = Serial.readString();
    Serial.print("收到: ");
    Serial.println(data);
  }

  delay(1000);
}

五、I2C 通訊

什麼是 I2C？

I2C（Inter-Integrated Circuit） 又稱 IIC 或 TWI，是一種只用兩條線就能連接多個裝置的通訊方式。

I2C 特點：
┌──────────────────────────────────────┐
│ • 同步通訊（有時鐘線）                │
│ • 只需 2 條線（SDA、SCL）             │
│ • 可連接多個裝置（最多 127 個）       │
│ • 每個裝置有獨立位址                  │
│ • 主從架構（Master-Slave）            │
└──────────────────────────────────────┘

I2C 接線

I2C 匯流排架構（一對多）：

                    SDA（資料線）
        ┌──────────────┼──────────────┐
        │              │              │
        │              │              │
   ┌────┴────┐    ┌────┴────┐    ┌────┴────┐
   │ Arduino │    │  LCD    │    │  RTC    │
   │ (主機)  │    │ 0x27    │    │ 0x68    │
   │ Master  │    │ Slave   │    │ Slave   │
   └────┬────┘    └────┬────┘    └────┬────┘
        │              │              │
        │              │              │
        └──────────────┼──────────────┘
                    SCL（時鐘線）

每個裝置都有一個獨特的「位址」：
• LCD 螢幕：0x27
• RTC 時鐘：0x68
• 溫度感測器：0x48
• ...

主機透過位址呼叫特定的裝置

I2C 常見裝置與位址

裝置 常見位址 用途
LCD 1602 (I2C) 0x27 或 0x3F 文字顯示
OLED SSD1306 0x3C 或 0x3D 圖形顯示
DS3231 RTC 0x68 即時時鐘
BMP280 0x76 或 0x77 氣壓/溫度
MPU6050 0x68 或 0x69 加速度/陀螺儀
EEPROM AT24C32 0x50-0x57 資料儲存

Arduino I2C 腳位

不同 Arduino 的 I2C 腳位：

┌────────────────┬───────┬───────┐
│     板子       │  SDA  │  SCL  │
├────────────────┼───────┼───────┤
│ Arduino UNO    │  A4   │  A5   │
│ Arduino Nano   │  A4   │  A5   │
│ Arduino Mega   │  20   │  21   │
│ ESP8266        │  D2   │  D1   │
│ ESP32          │  21   │  22   │
└────────────────┴───────┴───────┘

I2C 掃描器程式

/*
 * I2C 位址掃描器
 * 用來找出連接的 I2C 裝置位址
 */

#include <Wire.h>

void setup() {
  Wire.begin();
  Serial.begin(9600);
  Serial.println("I2C 掃描器啟動...");
}

void loop() {
  byte count = 0;

  Serial.println("開始掃描...");

  for (byte addr = 1; addr < 127; addr++) {
    Wire.beginTransmission(addr);
    byte error = Wire.endTransmission();

    if (error == 0) {
      Serial.print("發現裝置，位址: 0x");
      if (addr < 16) Serial.print("0");
      Serial.println(addr, HEX);
      count++;
    }
  }

  Serial.print("共發現 ");
  Serial.print(count);
  Serial.println(" 個裝置");
  Serial.println();

  delay(5000);
}

六、SPI 通訊

什麼是 SPI？

SPI（Serial Peripheral Interface） 是一種高速的同步串行通訊。

SPI 特點：
┌──────────────────────────────────────┐
│ • 同步通訊（有時鐘線）                │
│ • 全雙工（可同時收發）                │
│ • 速度快（可達數十 MHz）              │
│ • 需要 4 條線（+ 每個裝置 1 條 CS）   │
│ • 主從架構                            │
└──────────────────────────────────────┘

SPI 四條線說明

SPI 訊號線：

┌──────┬──────────────────────────────────────┐
│ 名稱 │              說明                    │
├──────┼──────────────────────────────────────┤
│ MOSI │ Master Out Slave In                  │
│      │ 主機發送，從機接收                   │
├──────┼──────────────────────────────────────┤
│ MISO │ Master In Slave Out                  │
│      │ 主機接收，從機發送                   │
├──────┼──────────────────────────────────────┤
│ SCK  │ Serial Clock                         │
│      │ 時鐘訊號（由主機產生）               │
├──────┼──────────────────────────────────────┤
│ CS   │ Chip Select（又稱 SS）               │
│      │ 晶片選擇（低電位啟用）               │
└──────┴──────────────────────────────────────┘

SPI 接線

SPI 連接多個裝置：

Arduino (Master)
┌────────────────┐
│            MOSI├───────┬───────┬───────→
│                │       │       │
│            MISO├───────┼───────┼───────←
│                │       │       │
│             SCK├───────┼───────┼───────→
│                │       │       │
│          CS1(10)├──────┐│       │
│          CS2(9)├───────┼──────┐│
│          CS3(8)├───────┼──────┼──────┐
└────────────────┘       │      │      │
                         │      │      │
                    ┌────┴──┐┌──┴───┐┌─┴────┐
                    │ SD卡  ││ OLED ││ RF   │
                    │ 模組  ││ 螢幕 ││ 模組 │
                    └───────┘└──────┘└──────┘

每個裝置有獨立的 CS 線
主機拉低某個 CS，就是跟那個裝置通訊

Arduino SPI 腳位

Arduino UNO SPI 腳位：

┌──────────────────┐
│   Arduino UNO    │
│                  │
│   D13 ─── SCK    │  時鐘
│   D12 ─── MISO   │  主機輸入
│   D11 ─── MOSI   │  主機輸出
│   D10 ─── SS/CS  │  晶片選擇（可用其他腳位）
│                  │
└──────────────────┘

SPI vs I2C 比較

特點 SPI I2C
線數 4 + (N-1) 2
速度 快（數十 MHz） 慢（100K-400K）
裝置數量 受 CS 腳位限制 最多 127 個
全雙工 是 否
複雜度 中等 簡單
適用場景 高速傳輸（SD卡、顯示器） 低速感測器

七、USB 通訊

什麼是 USB？

USB（Universal Serial Bus） 是最常見的電腦週邊連接標準。

USB 特點：
┌──────────────────────────────────────┐
│ • 通用性強（幾乎所有設備都支援）      │
│ • 隨插即用（Plug and Play）          │
│ • 可供電（5V，最高可達 100W）         │
│ • 速度快（USB 3.0 達 5Gbps）          │
│ • 支援熱插拔                          │
└──────────────────────────────────────┘

USB 版本比較

USB 版本演進：

┌─────────┬───────────────┬──────────────┐
│  版本   │     速度      │    別稱      │
├─────────┼───────────────┼──────────────┤
│ USB 1.1 │   12 Mbps     │  Full Speed  │
│ USB 2.0 │  480 Mbps     │  High Speed  │
│ USB 3.0 │    5 Gbps     │ SuperSpeed   │
│ USB 3.1 │   10 Gbps     │ SuperSpeed+  │
│ USB 3.2 │   20 Gbps     │              │
│ USB 4.0 │   40 Gbps     │              │
└─────────┴───────────────┴──────────────┘

Arduino 通常使用 USB 2.0（已經足夠）

USB 接頭類型

常見 USB 接頭：

Type-A（標準大頭）        Type-B（印表機頭）
┌───────────┐             ┌─────────┐

Arduino 與 USB

Arduino 上的 USB 功能：

1. 上傳程式
   電腦 ──[USB]──→ Arduino
   把寫好的程式燒錄進去

2. 序列通訊
   電腦 ←──[USB]──→ Arduino
   用 Serial.print() 溝通

3. 供電
   電腦 ──[USB 5V]──→ Arduino
   不需要額外電源

九、常見問題

Q1：I2C 和 SPI 怎麼選？

選 I2C：
• 腳位有限
• 速度要求不高
• 連接很多低速感測器
• 不想接太多線

選 SPI：
• 需要高速傳輸
• SD 卡、TFT 螢幕
• 對速度有要求
• 腳位充足

Q2：TTL 和 RS232 有什麼不同？

TTL：
• 電壓：0V / 5V（或 3.3V）
• 短距離（<1m）
• Arduino 原生支援

RS232：
• 電壓：-12V / +12V
• 長距離（可達 15m）
• 需要轉換晶片（如 MAX232）
• 舊電腦 COM 埠使用

轉換：
Arduino (TTL) ──[MAX232]──→ 電腦 COM 埠 (RS232)

Q3：為什麼要共地（GND）？

電壓是相對的！

裝置 A 認為的 "5V"：相對於 A 的 GND
裝置 B 認為的 "5V"：相對於 B 的 GND

如果 GND 不連接：
A 的 5V 可能是 B 的 3V 或 7V
→ 通訊錯誤或燒毀

所以：任何通訊都要連接 GND！
