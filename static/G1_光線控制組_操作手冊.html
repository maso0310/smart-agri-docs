第一組：光線控制組 操作手冊

模擬情境

組成溫室所需要的光強度控制系統

在智慧溫室中，光線是植物生長的關鍵因素。本組將學習如何感測環境光線強度，並根據光線情況自動控制補光燈（LED）。

💡 你知道嗎？
植物需要光線進行光合作用，不同植物對光照時間（光週期）和光線強度的需求不同。例如：番茄需要每天 14-18 小時的光照，而萵苣只需要 10-12 小時。智慧補光系統可以在陰天或夜間自動補充光線，確保植物健康生長！

學習目標

  1. 認識 Arduino Uno 的基本架構與腳位
  2. 了解類比訊號 (Analog) 與數位訊號 (Digital) 的差異
  3. 學習 PWM（脈衝寬度調變）控制 LED 亮度
  4. 使用光敏電阻感測環境光線
  5. 使用電位器調整參數
  6. 整合感測與控制，實現自動補光系統
  7. 透過序列埠監視器觀察與除錯

元件說明

光敏電阻（Photoresistor / LDR）

光敏電阻是一種特殊的電阻，其電阻值會隨著光線強度改變：

  • 光線強 → 電阻值低（約 1KΩ ~ 10KΩ）
  • 光線弱 → 電阻值高（約 100KΩ ~ 1MΩ）

常見型號：GL5528、GL5516，外觀為圓形，表面有蛇形線條。

電位器（Potentiometer）

電位器是一個三腳的可變電阻，轉動旋鈕可以改變中間腳位的輸出電壓：

  • 左腳：接 VCC（5V）
  • 中腳：輸出（接類比輸入腳位）
  • 右腳：接 GND

在本專案中，電位器用來設定「光線閾值」，讓使用者可以調整系統的靈敏度。

LED（發光二極體）

LED 有正負極之分：

  • 長腳 = 正極（Anode）→ 接電阻後接 Arduino 腳位
  • 短腳 = 負極（Cathode）→ 接 GND

LED 必須串聯限流電阻（通常 220Ω），否則會燒毀！

實作步驟與程式碼

步驟一：基礎 LED 控制（認識數位輸出）

目標：讓 LED 閃爍，認識 digitalWrite()

  1. 打開 Arduino IDE
  2. 輸入以下程式碼
  3. 上傳並觀察 LED 閃爍
/*
 * 01_LED_Blink.ino
 * 基礎 LED 閃爍程式
 * 功能：讓 LED 每秒閃爍一次
 */

const int LED_PIN = 9;  // LED 連接的腳位

void setup() {
  pinMode(LED_PIN, OUTPUT);  // 設定腳位為輸出模式
  Serial.begin(9600);        // 開啟序列埠通訊
  Serial.println("LED 閃爍程式啟動！");
}

void loop() {
  digitalWrite(LED_PIN, HIGH);  // 點亮 LED
  Serial.println("LED 亮");
  delay(1000);                  // 等待 1 秒

  digitalWrite(LED_PIN, LOW);   // 熄滅 LED
  Serial.println("LED 暗");
  delay(1000);                  // 等待 1 秒
}
🔍 程式解說
• pinMode()：設定腳位為輸入或輸出模式
• digitalWrite()：輸出 HIGH（5V）或 LOW（0V）
• delay()：暫停執行，單位為毫秒（1000ms = 1秒）

步驟二：PWM 控制 LED 亮度（呼吸燈效果）

目標：使用 analogWrite() 控制 LED 亮度

/*
 * 02_LED_PWM.ino
 * PWM 呼吸燈效果
 * 功能：LED 漸亮漸暗，模擬呼吸效果
 */

const int LED_PIN = 9;  // 必須使用 PWM 腳位（3, 5, 6, 9, 10, 11）

void setup() {
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
  Serial.println("PWM 呼吸燈啟動！");
}

void loop() {
  // 漸亮：0 → 255
  for (int brightness = 0; brightness <= 255; brightness += 5) {
    analogWrite(LED_PIN, brightness);
    Serial.print("亮度: ");
    Serial.println(brightness);
    delay(30);
  }

  // 漸暗：255 → 0
  for (int brightness = 255; brightness >= 0; brightness -= 5) {
    analogWrite(LED_PIN, brightness);
    Serial.print("亮度: ");
    Serial.println(brightness);
    delay(30);
  }
}
🔍 PWM 說明
• analogWrite(pin, value)：value 範圍是 0-255
• 0 = 完全關閉（0% duty cycle）
• 127 = 半亮（50% duty cycle）
• 255 = 全亮（100% duty cycle）

步驟三：電位器控制 LED 亮度

目標：讀取電位器值，即時調整 LED 亮度

/*
 * 03_Potentiometer_LED.ino
 * 電位器控制 LED 亮度
 * 功能：轉動電位器即時調整 LED 亮度
 */

const int POT_PIN = A1;   // 電位器接 A1
const int LED_PIN = 9;    // LED 接 D9（PWM）

void setup() {
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
  Serial.println("電位器控制 LED 啟動！");
  Serial.println("轉動電位器來調整 LED 亮度");
}

void loop() {
  // 讀取電位器值（0-1023）
  int potValue = analogRead(POT_PIN);

  // 將 0-1023 轉換為 0-255（使用 map 函數）
  int brightness = map(potValue, 0, 1023, 0, 255);

  // 設定 LED 亮度
  analogWrite(LED_PIN, brightness);

  // 顯示數值
  Serial.print("電位器: ");
  Serial.print(potValue);
  Serial.print(" → LED 亮度: ");
  Serial.println(brightness);

  delay(100);  // 短暫延遲，避免序列埠輸出過快
}
🔍 map() 函數說明
map(value, fromLow, fromHigh, toLow, toHigh)
將數值從一個範圍線性對應到另一個範圍。
例如：map(512, 0, 1023, 0, 255) 會回傳 127

步驟四：光敏電阻感測光線

目標：讀取環境光線強度

/*
 * 04_Light_Sensor.ino
 * 光敏電阻感測光線
 * 功能：讀取並顯示環境光線強度
 */

const int LDR_PIN = A0;  // 光敏電阻接 A0

void setup() {
  Serial.begin(9600);
  Serial.println("光線感測器啟動！");
  Serial.println("請用手遮擋或用手電筒照射光敏電阻");
  Serial.println("=====================================");
}

void loop() {
  // 讀取光敏電阻值
  int lightValue = analogRead(LDR_PIN);

  // 計算光線百分比（大約）
  int lightPercent = map(lightValue, 0, 1023, 0, 100);

  // 判斷光線狀態
  String status;
  if (lightValue < 200) {
    status = "非常暗 🌙";
  } else if (lightValue < 400) {
    status = "偏暗 🌘";
  } else if (lightValue < 600) {
    status = "正常 ⛅";
  } else if (lightValue < 800) {
    status = "明亮 🌤️";
  } else {
    status = "非常亮 ☀️";
  }

  // 顯示結果
  Serial.print("光線值: ");
  Serial.print(lightValue);
  Serial.print(" (");
  Serial.print(lightPercent);
  Serial.print("%) - ");
  Serial.println(status);

  delay(500);
}
🔍 觀察重點
• 用手完全遮住光敏電阻，數值會變低（約 50-200）
• 用手電筒照射，數值會變高（約 800-1000）
• 記錄你的環境光線數值，作為設定閾值的參考

步驟五：自動補光系統（整合實作）

目標：當環境光線不足時，自動點亮 LED

/*
 * 05_Auto_Light.ino
 * 自動補光系統
 * 功能：
 *   - 光線不足時自動點亮 LED
 *   - 用電位器調整光線閾值
 *   - LED 亮度與環境光線成反比
 */

const int LDR_PIN = A0;      // 光敏電阻
const int POT_PIN = A1;      // 電位器（設定閾值）
const int LED_RED = 9;       // 紅色 LED（補光燈）
const int LED_GREEN = 10;    // 綠色 LED（狀態指示）

void setup() {
  pinMode(LED_RED, OUTPUT);
  pinMode(LED_GREEN, OUTPUT);
  Serial.begin(9600);

  Serial.println("=====================================");
  Serial.println("   智慧溫室 - 自動補光系統 v1.0");
  Serial.println("=====================================");
  Serial.println("• 電位器：調整光線閾值");
  Serial.println("• 紅色 LED：補光燈");
  Serial.println("• 綠色 LED：光線充足指示");
  Serial.println("=====================================");
}

void loop() {
  // 讀取感測器
  int lightValue = analogRead(LDR_PIN);
  int thresholdValue = analogRead(POT_PIN);

  // 將閾值轉換為與光線值相同的範圍
  int threshold = map(thresholdValue, 0, 1023, 100, 900);

  // 判斷是否需要補光
  if (lightValue < threshold) {
    // 光線不足 → 開啟補光燈
    // 計算補光亮度（越暗越亮）
    int brightness = map(lightValue, 0, threshold, 255, 50);
    brightness = constrain(brightness, 50, 255);  // 限制範圍

    analogWrite(LED_RED, brightness);
    digitalWrite(LED_GREEN, LOW);

    Serial.print("[補光中] ");
  } else {
    // 光線充足 → 關閉補光燈
    analogWrite(LED_RED, 0);
    digitalWrite(LED_GREEN, HIGH);

    Serial.print("[光線OK] ");
  }

  // 顯示詳細資訊
  Serial.print("光線: ");
  Serial.print(lightValue);
  Serial.print(" | 閾值: ");
  Serial.print(threshold);
  Serial.print(" | 狀態: ");
  Serial.println(lightValue < threshold ? "需要補光 🔴" : "光線充足 🟢");

  delay(200);
}
🔧 調整技巧
1. 先觀察正常環境的光線值（例如 500）
2. 用電位器將閾值設定在稍低的位置（例如 400）
3. 用手遮住光敏電阻，觀察補光燈是否自動亮起
4. 調整電位器找到最適合的閾值

步驟六：進階功能 - 平滑補光（選修）

目標：讓補光燈的亮度變化更平滑，避免閃爍

/*
 * 06_Smooth_Auto_Light.ino
 * 平滑自動補光系統（進階版）
 * 功能：使用移動平均濾波，讓亮度變化更平滑
 */

const int LDR_PIN = A0;
const int POT_PIN = A1;
const int LED_RED = 9;
const int LED_GREEN = 10;

// 移動平均濾波參數
const int NUM_READINGS = 10;  // 取樣數量
int readings[NUM_READINGS];   // 儲存讀數的陣列
int readIndex = 0;            // 當前索引
int total = 0;                // 總和
int smoothedLight = 0;        // 平滑後的光線值

// 目標亮度與當前亮度（用於平滑過渡）
int targetBrightness = 0;
int currentBrightness = 0;

void setup() {
  pinMode(LED_RED, OUTPUT);
  pinMode(LED_GREEN, OUTPUT);
  Serial.begin(9600);

  // 初始化讀數陣列
  for (int i = 0; i < NUM_READINGS; i++) {
    readings[i] = 0;
  }

  Serial.println("平滑自動補光系統啟動！");
}

void loop() {
  // === 移動平均濾波 ===
  total = total - readings[readIndex];           // 減去最舊的讀數
  readings[readIndex] = analogRead(LDR_PIN);     // 讀取新值
  total = total + readings[readIndex];           // 加入新讀數
  readIndex = (readIndex + 1) % NUM_READINGS;    // 移動索引
  smoothedLight = total / NUM_READINGS;          // 計算平均值

  // 讀取閾值
  int threshold = map(analogRead(POT_PIN), 0, 1023, 100, 900);

  // 計算目標亮度
  if (smoothedLight < threshold) {
    targetBrightness = map(smoothedLight, 0, threshold, 255, 0);
    targetBrightness = constrain(targetBrightness, 0, 255);
    digitalWrite(LED_GREEN, LOW);
  } else {
    targetBrightness = 0;
    digitalWrite(LED_GREEN, HIGH);
  }

  // === 平滑過渡到目標亮度 ===
  if (currentBrightness < targetBrightness) {
    currentBrightness += 2;  // 漸亮
    if (currentBrightness > targetBrightness) {
      currentBrightness = targetBrightness;
    }
  } else if (currentBrightness > targetBrightness) {
    currentBrightness -= 2;  // 漸暗
    if (currentBrightness < targetBrightness) {
      currentBrightness = targetBrightness;
    }
  }

  analogWrite(LED_RED, currentBrightness);

  // 每秒顯示一次狀態
  static unsigned long lastPrint = 0;
  if (millis() - lastPrint > 1000) {
    Serial.print("光線(平滑): ");
    Serial.print(smoothedLight);
    Serial.print(" | 閾值: ");
    Serial.print(threshold);
    Serial.print(" | LED亮度: ");
    Serial.println(currentBrightness);
    lastPrint = millis();
  }

  delay(10);  // 短延遲讓過渡更平滑
}

知識補充

類比訊號 vs 數位訊號

類型 範圍 Arduino 函數 應用
數位 HIGH/LOW (0/1) digitalRead/Write 開關、按鈕
類比輸入 0-1023 (10-bit) analogRead 感測器
PWM 輸出 0-255 (8-bit) analogWrite LED亮度、馬達轉速

PWM 原理詳解

PWM（Pulse Width Modulation）脈衝寬度調變是一種用數位訊號模擬類比輸出的技術：


PWM 波形示意圖：

100% Duty Cycle (255)：
████████████████████████  → 全亮

50% Duty Cycle (127)：
████████░░░░░░░░████████  → 半亮

25% Duty Cycle (64)：
████░░░░░░░░░░░░████░░░░  → 1/4 亮度

0% Duty Cycle (0)：
░░░░░░░░░░░░░░░░░░░░░░░░  → 全暗
  • 透過快速開關（約 490Hz）模擬類比輸出
  • 開的時間越長（duty cycle 越高），亮度越亮
  • 因為切換速度很快，人眼看起來就像是連續的亮度變化
  • Arduino PWM 腳位：3, 5, 6, 9, 10, 11（腳位旁有 ~ 符號）

分壓電路原理

光敏電阻無法直接讀取電阻值，需要與固定電阻組成分壓電路來產生可測量的電壓：


分壓電路原理圖：

    5V (Vcc)
      │
      │
    ┌─┴─┐
    │   │  R1 = 光敏電阻
    │ LDR│  （亮時約 1KΩ，暗時約 100KΩ）
    │   │
    └─┬─┘
      │
      ├───────→ Vout (接 Arduino A0)
      │
    ┌─┴─┐
    │   │  R2 = 10KΩ 固定電阻
    │10K│
    │   │
    └─┬─┘
      │
     GND

公式：Vout = Vcc × R2 / (R1 + R2)

範例計算：
• 亮時：R1 = 1KΩ → Vout = 5V × 10K/(1K+10K) = 4.55V → ADC ≈ 930
• 暗時：R1 = 100KΩ → Vout = 5V × 10K/(100K+10K) = 0.45V → ADC ≈ 92

植物與光照的關係

不同植物對光照的需求差異很大：

植物類型 每日光照時間 光照強度 (Lux) 說明
番茄、辣椒 14-18 小時 25,000-50,000 高光需求，需要充足日照
萵苣、菠菜 10-14 小時 15,000-25,000 中等光需求
香草（薄荷、羅勒） 12-16 小時 20,000-40,000 喜光但可耐半陰
草莓 12-14 小時 20,000-35,000 需要良好光照才能結果
豆芽、蘑菇 0-8 小時 1,000-5,000 低光或無光環境
💡 光週期效應
植物會根據日照長度（光週期）決定是否開花：
• 長日照植物：日照超過臨界時數才開花（如菠菜、萵苣）
• 短日照植物：日照少於臨界時數才開花（如菊花、草莓）
• 日中性植物：不受日照長度影響（如番茄、黃瓜）

溫室補光燈的類型

類型 優點 缺點 適用場景
LED 植物燈 省電、壽命長、可調光譜 初期成本較高 室內種植、垂直農場
螢光燈管 (T5/T8) 價格便宜、光線均勻 效率較低、含汞 育苗、葉菜類
高壓鈉燈 (HPS) 穿透力強、適合開花期 耗電、發熱量大 大型溫室、開花結果期
金屬鹵化物燈 (MH) 全光譜、接近自然光 壽命較短、需安定器 營養生長期

光譜與植物生長

植物對不同波長的光有不同反應：

  • 藍光 (400-500nm)：促進葉片生長、抑制徒長、增加葉綠素
  • 紅光 (600-700nm)：促進開花結果、光合作用效率最高
  • 遠紅光 (700-800nm)：影響開花時間、莖的伸長
  • 綠光 (500-600nm)：穿透葉片、到達下層葉片
這就是為什麼很多植物補光燈是紫紅色的 —— 因為它們混合了紅光和藍光，這兩種光對植物最有效！

進階應用：使用 LED 燈條

實際溫室中，單顆 LED 的亮度不足。可以升級使用 LED 燈條：

方案一：單色 LED 燈條（12V）

/*
 * LED 燈條控制（需要 MOSFET 或繼電器）
 *
 * 接線：
 * Arduino D9 → MOSFET Gate
 * 12V 電源 + → LED 燈條 +
 * LED 燈條 - → MOSFET Drain
 * MOSFET Source → GND
 * 12V 電源 - → GND（共地）
 */

const int LED_STRIP_PIN = 9;

void setup() {
  pinMode(LED_STRIP_PIN, OUTPUT);
}

void loop() {
  // PWM 控制燈條亮度
  int brightness = 200;  // 0-255
  analogWrite(LED_STRIP_PIN, brightness);
}

方案二：WS2812B 可定址 LED 燈條（彩色）

/*
 * WS2812B 智慧 LED 燈條控制
 * 需要安裝 FastLED 函式庫
 *
 * 接線：
 * Arduino D6 → LED 燈條 DIN
 * 5V → LED 燈條 VCC
 * GND → LED 燈條 GND
 */

#include <FastLED.h>

#define LED_PIN     6
#define NUM_LEDS    30    // LED 數量
#define BRIGHTNESS  200

CRGB leds[NUM_LEDS];

void setup() {
  FastLED.addLeds<WS2812B, LED_PIN, GRB>(leds, NUM_LEDS);
  FastLED.setBrightness(BRIGHTNESS);
}

void loop() {
  // 模擬植物補光（紅光+藍光）
  for (int i = 0; i < NUM_LEDS; i++) {
    if (i % 3 == 0) {
      leds[i] = CRGB::Red;    // 紅光
    } else {
      leds[i] = CRGB::Blue;   // 藍光
    }
  }
  FastLED.show();
}

常見問題與故障排除

Q1: LED 不亮？

檢查步驟：

  1. 確認 LED 正負極是否正確（長腳為正極）
  2. 檢查 220Ω 電阻是否正確連接
  3. 確認腳位設定正確（程式碼中的腳位與實際接線一致）
  4. 用萬用電表測量 Arduino 腳位是否有輸出電壓
  5. 嘗試更換另一顆 LED 測試（LED 可能已燒毀）

Q2: 光敏電阻讀值不變或一直是 0/1023？

檢查步驟：

  1. 確認分壓電路接線正確（光敏電阻接 5V，固定電阻接 GND）
  2. 確認 10KΩ 電阻確實有接到 GND
  3. 檢查中間節點是否正確連接到 A0
  4. 用手電筒照射測試，數值應該會明顯變化
  5. 如果讀值一直是 1023：可能光敏電阻沒接好
  6. 如果讀值一直是 0：可能 GND 沒接好

Q3: 電位器沒反應？

檢查步驟：

  1. 確認三隻腳都有正確連接（左→5V，中→A1，右→GND）
  2. 中間腳必須接到類比輸入腳位
  3. 開啟序列埠監視器觀察讀值變化
  4. 如果左右腳接反，電位器仍可運作，只是方向相反

Q4: 補光燈會閃爍？

可能原因與解決方法：

  1. 光敏電阻讀值不穩定：使用移動平均濾波（參考步驟六的程式碼）
  2. 閾值設定在臨界點：調整電位器，讓閾值遠離當前光線值
  3. 加入遲滯區間：在程式中加入「開啟閾值」和「關閉閾值」，避免頻繁切換
// 遲滯控制範例
const int THRESHOLD_ON = 300;   // 低於此值開燈
const int THRESHOLD_OFF = 400;  // 高於此值關燈

if (lightValue < THRESHOLD_ON) {
  // 開燈
} else if (lightValue > THRESHOLD_OFF) {
  // 關燈
}
// 在兩個閾值之間時，維持原狀態

Q5: 序列埠監視器顯示亂碼？

解決方法：

  1. 確認序列埠監視器的鮑率設定與程式碼中的 Serial.begin() 一致
  2. 程式碼使用 Serial.begin(9600)，監視器也要選擇 9600
  3. 關閉序列埠監視器後重新上傳程式
