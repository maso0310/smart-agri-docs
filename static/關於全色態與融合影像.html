關於全色態與融合影像

基本概念

在遙感影像中，全色影像 (Panchromatic, PAN) 和多光譜影像 (Multispectral, MS) 是兩種最基本的影像類型。它們各有優缺點，而影像融合 (Pan-sharpening) 技術則是結合 兩者優點，產生同時具有高空間解析度和豐富光譜資訊的影像。

全色影像 (Panchromatic)

全色影像是一種單波段灰階影像，其感測器在較寬的可見光波段範圍內（約 450-900nm） 收集輻射能量。由於整合了多個波段的能量，全色影像通常具有較高的空間解析度。

全色影像特點

特性 說明
波段數 單波段（灰階）
波長範圍 約 450-900nm（涵蓋可見光至近紅外）
空間解析度 通常較高（如 Sentinel-2: 10m, WorldView-3: 0.31m）
光譜資訊 無法區分不同波長（無色彩資訊）
資料量 較小（單波段）
主要用途 地物辨識、幾何製圖、影像配準

多光譜影像 (Multispectral)

多光譜影像包含多個獨立波段，每個波段記錄特定波長範圍的電磁輻射。 這使得多光譜影像能夠捕捉地物的光譜特徵，但通常空間解析度較低。

影像融合方法

1. IHS 轉換法 (Intensity-Hue-Saturation)

IHS 方法是最經典的影像融合技術。它將 RGB 影像轉換到 IHS 色彩空間， 用全色影像替換強度分量，再轉換回 RGB。

處理流程

  1. 將多光譜 RGB 轉換到 IHS 空間
  2. 將全色影像匹配到強度 (I) 分量的直方圖
  3. 用全色影像替換 I 分量
  4. 將新的 IHS 轉換回 RGB
限制：IHS 方法只能處理 3 個波段，且可能產生光譜失真。

2. Brovey 轉換法

Brovey 方法是一種簡單的比值融合方法，透過將多光譜波段與全色影像相乘， 並除以多光譜波段的總和來實現融合。

Fusedi = MSi × PAN / Σ MSj

其中 MSi 是第 i 個多光譜波段，PAN 是全色影像。

3. PCA 轉換法 (Principal Component Analysis)

PCA 方法利用主成分分析，將全色影像替換第一主成分（包含大部分空間資訊）， 然後進行逆轉換。

處理流程

  1. 對多光譜影像進行 PCA 轉換
  2. 用全色影像替換第一主成分 (PC1)
  3. 進行逆 PCA 轉換

4. Gram-Schmidt 轉換法

Gram-Schmidt 方法使用多光譜波段的加權平均來模擬全色波段， 然後進行 Gram-Schmidt 正交化處理。這種方法能較好地保持光譜特性。

5. 小波融合法 (Wavelet)

小波融合使用多解析度分析，將全色影像的高頻細節注入到多光譜影像中， 能夠較好地保持光譜資訊。

Python 影像融合實作

使用 Rasterio 進行 Brovey 融合

import numpy as np
import rasterio
from rasterio.enums import Resampling

def brovey_pansharpening(pan_path, ms_path, output_path):
    """
    Brovey 影像融合

    Args:
        pan_path: 全色影像路徑
        ms_path: 多光譜影像路徑 (RGB)
        output_path: 融合影像輸出路徑
    """
    # 讀取全色影像
    with rasterio.open(pan_path) as pan_src:
        pan = pan_src.read(1).astype(np.float32)
        pan_transform = pan_src.transform
        pan_crs = pan_src.crs
        pan_shape = pan.shape

    # 讀取多光譜影像並重採樣到全色解析度
    with rasterio.open(ms_path) as ms_src:
        # 計算縮放因子
        scale_x = pan_shape[1] / ms_src.width
        scale_y = pan_shape[0] / ms_src.height

        # 重採樣多光譜影像
        ms_resampled = ms_src.read(
            out_shape=(ms_src.count, pan_shape[0], pan_shape[1]),
            resampling=Resampling.bilinear
        ).astype(np.float32)

    # Brovey 融合
    # 計算多光譜波段總和
    ms_sum = np.sum(ms_resampled, axis=0)
    ms_sum[ms_sum == 0] = 1  # 避免除以零

    # 融合各波段
    fused = np.zeros_like(ms_resampled)
    for i in range(ms_resampled.shape[0]):
        fused[i] = ms_resampled[i] * pan / ms_sum

    # 將值限制在有效範圍內
    fused = np.clip(fused, 0, 65535).astype(np.uint16)

    # 儲存融合影像
    profile = {
        'driver': 'GTiff',
        'dtype': 'uint16',
        'width': pan_shape[1],
        'height': pan_shape[0],
        'count': ms_resampled.shape[0],
        'crs': pan_crs,
        'transform': pan_transform,
        'compress': 'lzw'
    }

    with rasterio.open(output_path, 'w', **profile) as dst:
        dst.write(fused)

    print(f"融合影像已儲存: {output_path}")
    return fused


# 使用範例
brovey_pansharpening(
    'landsat_pan_15m.tif',
    'landsat_rgb_30m.tif',
    'landsat_fused_15m.tif'
)

IHS 影像融合實作

import numpy as np
import rasterio
from rasterio.enums import Resampling
from skimage import exposure

def rgb_to_ihs(rgb):
    """RGB 轉 IHS"""
    r, g, b = rgb[0], rgb[1], rgb[2]

    # 計算強度
    intensity = (r + g + b) / 3.0

    # 計算飽和度
    min_rgb = np.minimum(np.minimum(r, g), b)
    saturation = 1 - (3 * min_rgb / (r + g + b + 1e-10))

    # 計算色相
    num = 0.5 * ((r - g) + (r - b))
    den = np.sqrt((r - g)**2 + (r - b) * (g - b)) + 1e-10
    theta = np.arccos(np.clip(num / den, -1, 1))

    hue = np.where(b > g, 2 * np.pi - theta, theta)

    return np.array([intensity, hue, saturation])


def ihs_to_rgb(ihs):
    """IHS 轉 RGB"""
    i, h, s = ihs[0], ihs[1], ihs[2]

    # 根據色相區域計算 RGB
    r = np.zeros_like(i)
    g = np.zeros_like(i)
    b = np.zeros_like(i)

    # 區域 1: 0 <= H < 2π/3
    mask1 = (h >= 0) & (h < 2 * np.pi / 3)
    b[mask1] = i[mask1] * (1 - s[mask1])
    r[mask1] = i[mask1] * (1 + s[mask1] * np.cos(h[mask1]) /
                           np.cos(np.pi / 3 - h[mask1]))
    g[mask1] = 3 * i[mask1] - (r[mask1] + b[mask1])

    # 區域 2: 2π/3 <= H < 4π/3
    mask2 = (h >= 2 * np.pi / 3) & (h < 4 * np.pi / 3)
    h2 = h[mask2] - 2 * np.pi / 3
    r[mask2] = i[mask2] * (1 - s[mask2])
    g[mask2] = i[mask2] * (1 + s[mask2] * np.cos(h2) /
                           np.cos(np.pi / 3 - h2))
    b[mask2] = 3 * i[mask2] - (r[mask2] + g[mask2])

    # 區域 3: 4π/3 <= H < 2π
    mask3 = (h >= 4 * np.pi / 3) & (h < 2 * np.pi)
    h3 = h[mask3] - 4 * np.pi / 3
    g[mask3] = i[mask3] * (1 - s[mask3])
    b[mask3] = i[mask3] * (1 + s[mask3] * np.cos(h3) /
                           np.cos(np.pi / 3 - h3))
    r[mask3] = 3 * i[mask3] - (g[mask3] + b[mask3])

    return np.array([r, g, b])


def ihs_pansharpening(pan_path, ms_path, output_path):
    """
    IHS 影像融合

    Args:
        pan_path: 全色影像路徑
        ms_path: 多光譜影像路徑 (RGB)
        output_path: 融合影像輸出路徑
    """
    # 讀取全色影像
    with rasterio.open(pan_path) as pan_src:
        pan = pan_src.read(1).astype(np.float32)
        pan_transform = pan_src.transform
        pan_crs = pan_src.crs
        pan_shape = pan.shape

    # 讀取並重採樣多光譜影像
    with rasterio.open(ms_path) as ms_src:
        ms_resampled = ms_src.read(
            out_shape=(3, pan_shape[0], pan_shape[1]),
            resampling=Resampling.bilinear
        ).astype(np.float32)

    # 正規化到 0-1
    pan_norm = (pan - pan.min()) / (pan.max() - pan.min() + 1e-10)
    ms_norm = np.zeros_like(ms_resampled)
    for i in range(3):
        ms_norm[i] = (ms_resampled[i] - ms_resampled[i].min()) / \
                     (ms_resampled[i].max() - ms_resampled[i].min() + 1e-10)

    # RGB 轉 IHS
    ihs = rgb_to_ihs(ms_norm)

    # 直方圖匹配：將全色影像匹配到原始強度分量
    pan_matched = exposure.match_histograms(pan_norm, ihs[0])

    # 用全色影像替換強度分量
    ihs[0] = pan_matched

    # IHS 轉回 RGB
    fused_norm = ihs_to_rgb(ihs)

    # 轉換回原始資料範圍
    fused = np.zeros_like(ms_resampled)
    for i in range(3):
        fused[i] = fused_norm[i] * (ms_resampled[i].max() - ms_resampled[i].min()) + \
                   ms_resampled[i].min()

    fused = np.clip(fused, 0, 65535).astype(np.uint16)

    # 儲存
    profile = {
        'driver': 'GTiff',
        'dtype': 'uint16',
        'width': pan_shape[1],
        'height': pan_shape[0],
        'count': 3,
        'crs': pan_crs,
        'transform': pan_transform,
        'compress': 'lzw'
    }

    with rasterio.open(output_path, 'w', **profile) as dst:
        dst.write(fused)

    print(f"IHS 融合影像已儲存: {output_path}")
    return fused

小波融合實作

import numpy as np
import pywt
import rasterio
from rasterio.enums import Resampling

def wavelet_pansharpening(pan_path, ms_path, output_path, wavelet='db4', level=2):
    """
    小波影像融合

    Args:
        pan_path: 全色影像路徑
        ms_path: 多光譜影像路徑
        output_path: 融合影像輸出路徑
        wavelet: 小波基底 (如 'db4', 'haar', 'sym4')
        level: 分解層數
    """
    # 讀取全色影像
    with rasterio.open(pan_path) as pan_src:
        pan = pan_src.read(1).astype(np.float32)
        pan_transform = pan_src.transform
        pan_crs = pan_src.crs
        pan_shape = pan.shape

    # 讀取並重採樣多光譜影像
    with rasterio.open(ms_path) as ms_src:
        num_bands = ms_src.count
        ms_resampled = ms_src.read(
            out_shape=(num_bands, pan_shape[0], pan_shape[1]),
            resampling=Resampling.bilinear
        ).astype(np.float32)

    # 對全色影像進行小波分解
    pan_coeffs = pywt.wavedec2(pan, wavelet, level=level)

    fused = np.zeros_like(ms_resampled)

    # 對每個多光譜波段進行融合
    for band_idx in range(num_bands):
        ms_band = ms_resampled[band_idx]

        # 對多光譜波段進行小波分解
        ms_coeffs = pywt.wavedec2(ms_band, wavelet, level=level)

        # 融合係數：保留多光譜的低頻（光譜資訊）和全色的高頻（空間細節）
        fused_coeffs = [ms_coeffs[0]]  # 保留多光譜的近似係數

        # 融合高頻細節係數
        for j in range(1, len(pan_coeffs)):
            # pan_coeffs[j] 是 (LH, HL, HH) 元組
            fused_detail = []
            for k in range(3):  # LH, HL, HH
                # 使用最大值選擇或加權平均
                # 這裡使用加權融合，保留更多全色影像的細節
                fused_coeff = 0.3 * ms_coeffs[j][k] + 0.7 * pan_coeffs[j][k]
                fused_detail.append(fused_coeff)
            fused_coeffs.append(tuple(fused_detail))

        # 小波重建
        fused[band_idx] = pywt.waverec2(fused_coeffs, wavelet)

        # 確保尺寸正確
        if fused[band_idx].shape != pan_shape:
            fused[band_idx] = fused[band_idx][:pan_shape[0], :pan_shape[1]]

    # 限制值範圍
    fused = np.clip(fused, 0, 65535).astype(np.uint16)

    # 儲存
    profile = {
        'driver': 'GTiff',
        'dtype': 'uint16',
        'width': pan_shape[1],
        'height': pan_shape[0],
        'count': num_bands,
        'crs': pan_crs,
        'transform': pan_transform,
        'compress': 'lzw'
    }

    with rasterio.open(output_path, 'w', **profile) as dst:
        dst.write(fused)

    print(f"小波融合影像已儲存: {output_path}")
    return fused


# 使用範例
wavelet_pansharpening(
    'worldview_pan_0.5m.tif',
    'worldview_ms_2m.tif',
    'worldview_fused_0.5m.tif',
    wavelet='db4',
    level=3
)

融合品質評估

常用評估指標

指標 全名 說明 理想值
CC Correlation Coefficient 與原始影像的相關性 → 1
RMSE Root Mean Square Error 均方根誤差 → 0
SAM Spectral Angle Mapper 光譜角度差異 → 0
ERGAS Erreur Relative Globale 相對全域誤差 → 0
Q4/Q8 Universal Image Quality Index 通用影像品質指標 → 1
SSIM Structural Similarity 結構相似度 → 1

品質評估程式碼

import numpy as np
from skimage.metrics import structural_similarity as ssim

def calculate_fusion_metrics(original_ms, fused_ms):
    """
    計算影像融合品質指標

    Args:
        original_ms: 原始多光譜影像 (bands, height, width)
        fused_ms: 融合後影像（降取樣到原始解析度比較）

    Returns:
        dict: 各項品質指標
    """
    metrics = {}
    num_bands = original_ms.shape[0]

    # 1. 相關係數 (CC)
    cc_values = []
    for i in range(num_bands):
        orig = original_ms[i].flatten()
        fuse = fused_ms[i].flatten()
        cc = np.corrcoef(orig, fuse)[0, 1]
        cc_values.append(cc)
    metrics['CC_mean'] = np.mean(cc_values)
    metrics['CC_per_band'] = cc_values

    # 2. 均方根誤差 (RMSE)
    rmse_values = []
    for i in range(num_bands):
        diff = original_ms[i] - fused_ms[i]
        rmse = np.sqrt(np.mean(diff ** 2))
        rmse_values.append(rmse)
    metrics['RMSE_mean'] = np.mean(rmse_values)
    metrics['RMSE_per_band'] = rmse_values

    # 3. 光譜角度 (SAM)
    sam_values = []
    for h in range(original_ms.shape[1]):
        for w in range(original_ms.shape[2]):
            orig_vec = original_ms[:, h, w]
            fuse_vec = fused_ms[:, h, w]

            # 計算向量夾角
            dot_product = np.dot(orig_vec, fuse_vec)
            norm_orig = np.linalg.norm(orig_vec)
            norm_fuse = np.linalg.norm(fuse_vec)

            if norm_orig > 0 and norm_fuse > 0:
                cos_angle = dot_product / (norm_orig * norm_fuse)
                cos_angle = np.clip(cos_angle, -1, 1)
                angle = np.arccos(cos_angle)
                sam_values.append(np.degrees(angle))

    metrics['SAM_mean'] = np.mean(sam_values)

    # 4. ERGAS (Erreur Relative Globale Adimensionnelle de Synthèse)
    ratio = 4  # 假設解析度比例
    ergas_sum = 0
    for i in range(num_bands):
        rmse = rmse_values[i]
        mean_val = np.mean(original_ms[i])
        if mean_val > 0:
            ergas_sum += (rmse / mean_val) ** 2
    metrics['ERGAS'] = 100 / ratio * np.sqrt(ergas_sum / num_bands)

    # 5. SSIM
    ssim_values = []
    for i in range(num_bands):
        # 確保資料範圍正確
        orig = original_ms[i].astype(np.float64)
        fuse = fused_ms[i].astype(np.float64)
        data_range = max(orig.max(), fuse.max()) - min(orig.min(), fuse.min())
        ssim_val = ssim(orig, fuse, data_range=data_range)
        ssim_values.append(ssim_val)
    metrics['SSIM_mean'] = np.mean(ssim_values)
    metrics['SSIM_per_band'] = ssim_values

    return metrics

農業應用場景

高解析度作物監測：
  • 使用融合影像可以獲得更精細的田區邊界
  • 識別作物行間的雜草
  • 早期發現局部病蟲害區域
  • 精準農業的變量施肥決策
注意事項：
  • 融合可能導致光譜失真，不適用於嚴格的光譜分析
  • 計算 NDVI 等指數時，應評估融合對光譜的影響
  • 對於定量遙感應用，需要進行光譜保真度驗證
